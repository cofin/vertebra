# Flow Spec: Vertebra PyClient SDK (WASM)
## Goal
Implement lightweight Python SDK for PyScript/Pyodide.

## Workflow Requirements
- **GitHub Issues**: Task 0 is to open a focused GitHub issue for this feature.
- **Pull Requests**: All changes MUST be submitted via GitHub Pull Requests.

## Plan
### Phase 1: SDK Core
- [ ] Task 0: Open GitHub issue for "Vertebra Python SDK for WASM (PyScript)".
- [ ] Task 1: Create `src/py/vertebra_client/` package.
- [ ] Task 2: Implement `nanoarrow` based fetch wrappers.

### Phase 2: PyScript Integration
- [ ] Task 3: Add auto-packaging of shared models into a `.whl`.
- [ ] Task 4: Implement browser-side route client generator.
