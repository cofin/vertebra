# Domain Vocabulary Index

Vertebra uses one domain naming model across Python, Rust, and TypeScript: each class, struct, and function names the domain concept directly, without brand prefixes (`Vertebra*`, except for the root `VertebraError` exception hierarchy in `vertebra.typing`), implementation-mechanism suffixes, or compatibility aliases.

- [Python Framework, Routing & Serialization Domain](framework/routing-and-app.md) — `App`, `Controller`, `Router`, `Route`, `ParamSpec`, `HandlerInfo`, `Request`, `Response`, `SyncInertiaMiddleware`, `AsyncInertiaMiddleware`, `InertiaConfig`, `InertiaResponse`, `JSONSerializer`, `MsgPackSerializer`, `module_loader`, and `OptionalDependency`.
- [Framework Subdomains](framework/subdomains.md) — `di` (`Container`, `DependencyGraph`, `Provide`, `Inject`), `security` (`SecurityConfig`, `Guard`), `autowire` (`AutowireLoader`), `procedures` (`ProcedureRouter`, `Procedure`), `htmx`, `ssr`, `openapi`, `asyncapi`, `queues`, `channels`, `stores`, `email`, native `vertebra.agent.{mcp,a2a}`, and first-party `litestar-mcp` (`LitestarMCP`, `MCPConfig`, `LitestarA2A`, `A2AConfig`) integration.
- [Distributed Queues, Cron Leader Election & Transactional Email](framework/distributed-queues-and-email.md) — Pluggable queue backends (`MemoryQueueBackend`, `RedisQueueBackend`, `ValkeyQueueBackend`, `PostgreSQLQueueBackend`, `OracleQueueBackend`, `SpannerQueueBackend`), `CronScheduler` leader election, `WorkerRunner` with priority lanes, and transactional email transports (`MemoryEmailTransport`, `SmtpEmailTransport`, `ResendEmailTransport`, `SendGridEmailTransport`, `MailgunEmailTransport`, `SesEmailTransport` with native Rust SigV4 signing).

- [`vtb` Command-Line Interface](framework/cli.md) — `vtb run`, `vtb dev`, `vtb build`, `vtb js`, `vtb init`, `vtb ai models`, `vtb ai mcp`, `vtb workers run`, `VertebraExtensionGroup`, `VertebraGroup`, `VertebraEnv`, `CLIPlugin`, `ensure_vertebra_integration`, `discover_entry_point_commands`, `Console`, and `run_dev_tui`.

## Agent Protocols & Harness (`agent/`)

- [Agentic Harness, MCP 2026-07-28 & A2A 1.0 Protocols](agent/mcp-and-a2a-protocol-harness.md) — Model Context Protocol (`MCP 2026-07-28`) Streamable HTTP (`POST /mcp`), Stdio, and WebMCP (`ToolSpec`, `ToolRegistry`, `MCPCore`, `build_webmcp_manifest`) transports, Agent-to-Agent (`A2A 1.0`) JCS/RFC 8785 Ed25519/ECDSA signed agent cards with automatic `AgentInterface` and dynamic request URL resolution, durable DAG workflows, SpecTree execution, Rust PyO3 cryptographic fastpaths, and GenAI telemetry.
- [MCP Implementation Limitations](agent/mcp-limitations.md) — Single-version negotiation, unimplemented legacy methods and `GET` SSE, unvalidated `Mcp-Session-Id` and `Mcp-Param-*`, unpopulated resource subscriptions, and the `MCPRegistry` / `MCPService` alias subclasses.
- [Shared-Memory Vector Slabs, Zero-Weight Cloud & SQL Embeddings, and Local Broker](agent/embeddings-and-vectors.md) — POSIX shared-memory `VectorSlab` and `VectorCache`, PEP 3118 `VectorView` and `VectorBatchView`, `Embedder`, `VertexEmbedder`, `GeminiEmbedder`, `PushdownEmbedder`, `BigQueryEmbeddingPushdown`, `SpannerEmbeddingPushdown`, `PostgresEmbeddingPushdown`, `OracleEmbeddingPushdown` (over the `vertebra._oracle` wheel), `GemmaEmbedder`, `FastEmbedder`, `StaticEmbedder`, `RemoteEmbedder`, and `1x` RAM `EmbeddingBroker`.
- [Embeddings Limitations](agent/embeddings-limitations.md) — `VertexEmbedder` posting Generative Language `BatchEmbedContents` to the Vertex AI host and `GeminiEmbedder.embed_multimodal` text descriptors in place of media parts.
