# Task 1.1: Co-locate `ShmStatementCache` inside `ShmLeaseTable` (`stmt_offset` / `stmt_capacity`) and expose unified `NativeLeaseBroker` attachment in `vertebra-py`

## Objective

Allocate and attach `ShmStatementCache` directly inside `ShmLeaseTable`'s single `ShmRegion` using the existing `ShmLeaseHeader.stmt_capacity` and `ShmLeaseHeader.stmt_offset` fields so worker processes inheriting `VERTEBRA_BROKER_SHM_FD` share both connection leases and the 4-way set-associative statement cache over a single file descriptor without creating a second `{shm_name}-stmt` region.

## Context

- `src/rs/vertebra-core/src/broker.rs:60-91`: `ShmLeaseHeader` already defines `pub stmt_capacity: u32` (line 67) and `pub stmt_offset: u64` (line 68), and `ShmStatementCache::from_raw_ptrs` already exists, but `ShmLeaseTable::init_in_region` (`src/rs/vertebra-core/src/broker.rs:149-197`) sets `hdr.stmt_capacity = 0` and `hdr.stmt_offset = 0`.
- `src/py/vertebra/extensions/broker/transport.py:354-380`: `ShmBrokerTransport.__init__` creates a process-local `NativeStatementCache` when `NativeLeaseBroker.from_env()` is used (line 358) or opens a second named SHM segment `f"{self._config.shm_name}-stmt"` (lines 372-376).

## Steps

- [ ] 1. In `src/rs/vertebra-core/src/broker.rs:143-197`, add `ShmLeaseTable::required_size_with_statements(pool_size: u32, max_overflow: u32, stmt_capacity: u32) -> usize`, `ShmLeaseTable::init_in_region_with_statements(region: ShmRegion, pool_size: u32, max_overflow: u32, stmt_capacity: u32) -> Result<Self, BrokerError>`, and `ShmLeaseTable::statement_cache(&self) -> Option<ShmStatementCache>` using `ShmStatementCache::from_raw_ptrs`:
  ```rust
  pub const fn required_size_with_statements(
      pool_size: u32,
      max_overflow: u32,
      stmt_capacity: u32,
  ) -> usize {
      let base = Self::required_size(pool_size, max_overflow);
      if stmt_capacity == 0 {
          base
      } else {
          base + ShmStatementCache::required_size(stmt_capacity)
      }
  }
  ```
- [ ] 2. In `src/rs/vertebra-py/src/broker.rs:115-225`, update `NativeLeaseBroker::new`, `create_named`, `open_named`, `from_fd`, and `from_env` to accept `stmt_capacity: u32 = 512`, and add `pub fn statement_cache(&self) -> Option<NativeStatementCache>` on `NativeLeaseBroker`.
- [ ] 3. In `src/py/vertebra/extensions/broker/transport.py:354-380`, obtain `self._stmt_cache` from `self._native.statement_cache()` first before falling back to a standalone `NativeStatementCache`.
- [ ] 4. Add unit tests in `src/rs/vertebra-core/src/broker.rs` and `src/py/tests/unit/extensions/test_shm_broker.py` verifying that two processes/handles attached via `from_fd` share statement cache entries inserted through the co-located `ShmLeaseTable`.
