# Task 1.2: Wire `ShmLeaseTable::reclaim_worker(pid)` into `vertebra-http` SHM worker lifecycle teardown and respawn hooks

## Objective

Invoke `ShmLeaseTable::reclaim_worker(lifecycle.last_pid)` automatically inside `Supervisor::poll_workers` and `Supervisor::handle_worker_exit` (`src/rs/vertebra-http/src/workers/supervisor.rs`) and pass the co-located statement cache capacity in `RingFactory::with_broker_config` (`src/rs/vertebra-http/src/workers/factory.rs`) so crashed workers immediately release their held database connection leases and wake blocked waiters.

## Context

- `src/rs/vertebra-http/src/workers/factory.rs:91-107`: `WorkerLifecycle::check_alive_and_reclaim(&mut self, broker_table: &ShmLeaseTable)` and `RingFactory::reclaim_worker_leases` (`lines 260-263`) exist, and `WorkerLifecycle::respawn` (`lines 149-188`) spawns replacement workers, but `respawn` does not forward `VERTEBRA_BROKER_SHM_FD` / `VERTEBRA_BROKER_SHM_SIZE` env vars and `Supervisor::poll_workers` (`src/rs/vertebra-http/src/workers/supervisor.rs:40-67`) calls `!lifecycle.check_alive()` without calling `broker_table.reclaim_worker(lifecycle.last_pid)`.

## Steps

- [ ] 1. In `src/rs/vertebra-http/src/workers/factory.rs:208-253`, update `RingFactory::with_broker_config` to initialize `ShmLeaseTable::init_in_region_with_statements(region, pool_size, max_overflow, 512)` and store `broker_shm_fd` and `broker_shm_size` on `WorkerLifecycle` (lines 25-70) so `WorkerLifecycle::respawn` (`lines 149-188`) sets `VERTEBRA_BROKER_SHM_FD`, `VERTEBRA_BROKER_SHM_SIZE`, `VERTEBRA_BROKER_POOL_SIZE`, and `VERTEBRA_BROKER_MAX_OVERFLOW` on respawned child processes.
- [ ] 2. In `src/rs/vertebra-http/src/workers/supervisor.rs:40-119`, pass `&Arc<ShmLeaseTable>` (cloned from `factory_lock.broker_table()`) into `Supervisor::process_worker_exit(lifecycle, shm, &broker_table)` so worker exit immediately calls `let reclaimed = broker_table.reclaim_worker(lifecycle.last_pid);`:
  ```rust
  let broker_table = Arc::clone(factory_lock.broker_table());
  for lifecycle in factory_lock.lifecycles_mut().iter_mut() {
      if lifecycle.state == WorkerHealth::Running && !lifecycle.check_alive() {
          Self::process_worker_exit(lifecycle, shm, &broker_table);
      }
      // ...
  }
  ```
- [ ] 3. Add a unit test `supervisor_reclaims_broker_leases_on_worker_exit` in `src/rs/vertebra-http/src/workers/supervisor.rs` that acquires a lease on `factory.broker_table()` for a child worker's PID, lets the child exit, runs `Supervisor::poll_workers`, and asserts `broker_table.stats().active_leases == 0` and `total_reclaimed == 1`.
