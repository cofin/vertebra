# Task 2.1: Wire `AlchemyPlugin` and `ShmSessionBroker` to auto-attach SHM lease checkout/checkin and `ShmStatementCache` across SQLAlchemy sync/async engines, and verify with upstream SQLSpec and Advanced Alchemy drivers

## Objective

Wire `AlchemyPlugin.install_state` (`src/py/vertebra/extensions/alchemy/plugin.py:387-424`) and `ShmSessionBroker` (`src/py/vertebra/extensions/alchemy/broker.py:143-178`) so when `broker` is configured on `AlchemyPlugin`, registered sync and async SQLAlchemy engines (`engine` or `async_engine.sync_engine`) automatically attach `ShmSessionBroker` checkout/checkin lease hooks and `before_cursor_execute` statement-plan caching in `ShmStatementCache`.

## Context

- `src/py/vertebra/extensions/alchemy/broker.py:143-178`: `ShmSessionBroker.attach_to_engine` listens for `"checkout"` and `"checkin"` on `engine.pool`, but does not unwrap `AsyncEngine.sync_engine` when an async engine is passed, nor does it hook `"before_cursor_execute"` to populate `ShmBrokerTransport.get_or_compile_statement`.
- `src/py/vertebra/extensions/alchemy/plugin.py:402-423`: `AlchemyPlugin.install_state` collects `engines_map` and `broker_transport`, but never attaches `ShmSessionBroker(broker_transport)` to the engines in `engines_map`.

## Steps

- [ ] 1. In `src/py/vertebra/extensions/alchemy/broker.py:143-178`, update `ShmSessionBroker` to accept `bind_key: str = "sqlalchemy"`, unwrap `target_engine = getattr(engine, "sync_engine", engine)` in `attach_to_engine`, and register a `before_cursor_execute` listener that records compiled SQL in `self.transport.get_or_compile_statement`.
- [ ] 2. In `src/py/vertebra/extensions/alchemy/plugin.py:402-423`, when `broker_transport is not None`, instantiate `ShmSessionBroker(broker_transport, bind_key=str(key))` for each configured engine in `engines_map` and call `session_broker.attach_to_engine(engine)`.
- [ ] 3. Add tests in `src/py/tests/unit/extensions/test_alchemy_plugin.py` verifying that executing queries on a SQLAlchemy engine registered with `AlchemyPlugin(config=..., broker=BrokerPlugin())` acquires and releases SHM leases and populates statement cache metrics.

## Verification

- **Strategy**: `behavior_tdd` — New observable behavior (automatic `ShmSessionBroker` attachment on `AlchemyPlugin` engines).
- **Initial Failing Proof**: A test in `src/py/tests/unit/extensions/test_alchemy_plugin.py` checking `state.broker.metrics().total_acquired` after a SQLAlchemy engine checkout fails with `AssertionError: assert 0 == 1`.

## Acceptance Criteria

- [ ] `crit-1`: `ShmSessionBroker.attach_to_engine` supports both synchronous `Engine` and `AsyncEngine` (`engine.sync_engine`) and records statement plans in `ShmStatementCache`.
- [ ] `crit-2`: `AlchemyPlugin(config=..., broker=BrokerPlugin())` automatically attaches `ShmSessionBroker` to every registered engine during `install_state`.
- [ ] `crit-3`: `uv run pytest src/py/tests/unit/extensions/test_alchemy_plugin.py -q` passes with exit code 0.
