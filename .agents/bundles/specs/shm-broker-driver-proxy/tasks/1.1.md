# Task 1.1: Implement `SqlSpecProvider`, transaction-pinned lease execution, and threshold-based `ShmRegion` Arrow IPC result spilling (`_write_arrow_region` / `_arrow_release`) in `src/py/vertebra/extensions/sqlspec/provider.py`

## Objective

Create `SqlSpecProvider` in `src/py/vertebra/extensions/sqlspec/provider.py` to host any upstream `sqlspec` synchronous or asynchronous configuration (`oracledb`, `spanner`, `bigquery`, `duckdb`, `adbc`, `asyncpg`, `psycopg`, `psqlpy`, `aiosqlite`, etc.) and service worker RPC envelopes (`execute`, `execute_many`, `select_to_arrow`, `begin`, `commit`, `rollback`, `_arrow_release`) over shared memory, spilling result sets at or above `arrow_threshold_rows` / `arrow_threshold_bytes` into a zero-copy `ShmRegion` Arrow IPC buffer.

## Context

- `src/py/vertebra/extensions/sqlspec/plugin.py:62-85`: Defines `DatabaseConfigProtocol[ConnectionT, PoolT, DriverT]`.
- Historical `a5918811:src/py/vertebra/extensions/sqlspec/provider.py` implemented `SqlSpecProvider` with `_write_arrow_region` and `_arrow_release` so large analytical results serialize via `pa.ipc.new_stream` into a shared-memory region rather than copying row dictionaries across process boundaries.

## Steps

- [ ] 1. Create `src/py/vertebra/extensions/sqlspec/provider.py` with `ProxyRequestEnvelope` and `ProxyResponseEnvelope` (`msgspec.Struct(..., frozen=True, gc=False, array_like=True)`) and `SqlSpecProvider`:
  ```python
  class ProxyRequestEnvelope(msgspec.Struct, frozen=True, gc=False, array_like=True):
      """Zero-GC RPC request frame sent from ProxySyncDriver / ProxyAsyncDriver to SqlSpecProvider."""

      request_id: int
      bind_key: str
      op: Literal["execute", "execute_many", "select_to_arrow", "begin", "commit", "rollback", "_arrow_release"]
      sql: str = ""
      parameters: Any = ()
      tx_id: str | None = None
      arrow_threshold_rows: int = 1000
      arrow_threshold_bytes: int = 65_536
      shm_arrow_name: str | None = None
  ```
- [ ] 2. Implement transaction-pinned session map `self._pinned_sessions: dict[str, Any]` inside `SqlSpecProvider` so `begin` allocates a `tx_id` pinned to a single upstream `provide_session()` context until `commit` or `rollback` completes.
- [ ] 3. Implement `_write_arrow_region(self, rows_or_table: Any) -> tuple[str, int, int]` using `import_optional("pyarrow")` and `multiprocessing.shared_memory.SharedMemory` (or `ShmRegion`) to write Arrow IPC stream bytes and track active regions until `_arrow_release` is received.
- [ ] 4. Add unit tests in `src/py/tests/unit/extensions/test_sqlspec_proxy.py` verifying small MessagePack tuple responses, threshold-triggered Arrow IPC shared-memory spilling, `_arrow_release` cleanup, and transaction-pinned `begin` -> `execute` -> `commit`/`rollback` isolation.
