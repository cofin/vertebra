# 2.4 Split rings into `ring/` with shared park and publish helpers

## Objective
Split `src/rs/vertebra-core/src/channel.rs` into `src/rs/vertebra-core/src/ring/{mod,spsc,mpmc,slot}.rs`, rename `buffer.rs` to `layout.rs`, fold `sync.rs` and `process.rs` into `platform/{mod,process}.rs`, replace the 10 copy-pasted futex park/wake loops in `SpscRing` with shared `park_until`, `publish_write`, and `publish_read` helpers (`CORE-07`), remove the 11 unused SPSC/MPMC receive/send variants (`CORE-08`), and enforce `slot_borrowed` across all `SpscRing` receive paths (`CORE-09`).

## Context
- `channel.rs` (2,100+ lines after Task 2.2) mixes `SpscRing`, `MpmcRing`, and `SlotView` in one file and repeats the `SeqCst` wait-word / waiter-counter park handshake 10 times (`CORE-07`).
- 11 methods on `SpscRing` and `MpmcRing` (`send_timeout`, `try_recv_with_flags`, `recv_with_flags`, `recv_view`, `recv_view_timeout`, `recv_timeout_with_flags`, `try_recv_batch`, `read_slot_to_vec`, `read_slot_with_flags`, `MpmcRing::try_recv_with_flags`, `pub fn from_region`) have zero external callers (`CORE-08`).
- `SlotView` sets `slot_borrowed`, but copy-receive methods (`try_recv`, `try_recv_with`) do not check `slot_borrowed` (`CORE-09`).
- `WaitWord` is preserved in `src/rs/vertebra-core/src/platform/mod.rs` (moved from `sync.rs`) for `shm-broker-lease-table` cross-worker coordination.
- `characterization` + performance gate applies because this task restructures hot-path ring internals while preserving all external ring semantics and throughput.

## Steps
- [x] 1. Rename `src/rs/vertebra-core/src/buffer.rs` to `src/rs/vertebra-core/src/layout.rs`, fold `src/rs/vertebra-core/src/sync.rs` into `src/rs/vertebra-core/src/platform/mod.rs` (retaining `WaitWord` in `platform/mod.rs` for `shm-broker-lease-table` cross-worker coordination, and move `src/rs/vertebra-core/src/process.rs` to `src/rs/vertebra-core/src/platform/process.rs`), and update module paths in `vertebra-core` and `vertebra-http`.
- [x] 2. Split `src/rs/vertebra-core/src/channel.rs` into:
  - `src/rs/vertebra-core/src/ring/mod.rs`: `ChannelError`, `RingStats`, `ParkSide`, and shared `park_until` helper preserving the exact `SeqCst` wait-word load -> waiter `fetch_add(1, SeqCst)` -> recheck predicate -> `platform::wait_on_address[_timeout]` -> waiter `fetch_sub(1, SeqCst)` protocol.
  - `src/rs/vertebra-core/src/ring/slot.rs`: `SlotView<'a>` checking and clearing `slot_borrowed` on `Drop` (`CORE-09`).
  - `src/rs/vertebra-core/src/ring/spsc.rs`: `SpscRing` with private `from_region`, `publish_write`, `publish_read`, and `ensure_not_borrowed` (`CORE-07`, `CORE-09`), exposing only `create`, `attach`, `try_send`, `try_send_with`, `send`, `send_with`, `try_recv`, `try_recv_view`, `try_recv_with`, `recv`, `recv_timeout`, `recv_timeout_with`, and `recv_hybrid` (`CORE-08`).
  - `src/rs/vertebra-core/src/ring/mpmc.rs`: `MpmcRing` with private `from_region`, exposing `create`, `attach`, `try_send`, `try_send_with`, `send`, `try_recv`, `try_recv_with`, `recv`, `recv_timeout`, and `recv_timeout_with` (`CORE-08`).
- [x] 3. Update imports in `vertebra-core` (`transport/mod.rs`, `transport/ring_pair.rs`, `tests/test_ring.rs`, `tests/test_mpmc.rs`, `benches/*.rs`), `vertebra-http/src/ring_factory.rs`, and `.agents/skills/review-core/references/areas.toml` (`[areas.runtime-ipc.shards]` paths).
- [x] 4. Add unit test `spsc_copy_recv_while_slot_view_borrowed_returns_busy` in `src/rs/vertebra-core/tests/test_ring.rs` verifying that calling `try_recv` or `try_recv_with` while a `SlotView` is alive returns `Err(ChannelError::SlotBorrowed)` instead of double-consuming the frame (`CORE-09`).
- [x] 5. Commit: `refactor(core): split channel.rs into ring/ and unify futex park/publish helpers` (signed), staging the paths in `files`.
