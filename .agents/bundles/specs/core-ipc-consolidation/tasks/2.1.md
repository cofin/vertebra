# 2.1 Ring and frame correctness fixes

## Objective
Eliminate six lock-free ring and wire-frame bugs in `vertebra-core`: MPMC `try_recv` wedging the slot sequence on `BufferTooSmall` (`CORE-01`), `try_send_with` trusting out-of-bounds closure lengths and wedging on panic (`CORE-02`), unchecked `from_raw_parts` in `read_slot_zero_copy` (`OKF-02`), `TieredRingSet::select_ring` comparing against `slot_size` instead of `payload_capacity()` (`OKF-03`), `write_response_slot` truncating `headers_len > u16::MAX` (`CORE-04`/`OKF-04`), and `BatchSnapshot::deserialize_from` accepting out-of-bounds node offsets (`CORE-20`).

## Context
- `src/rs/vertebra-core/src/channel.rs:1563` and `:1596`: `MpmcRing::try_recv` and `try_recv_with_flags` advance `head` via CAS and then call `self.read_slot(index, out)?`; if `out.len() < len`, `?` returns before `self.sequence(index).store(head.wrapping_add(self.mask + 1), Ordering::Release)`, permanently wedging the slot (`CORE-01`).
- `src/rs/vertebra-core/src/channel.rs:1506-1520` (`MpmcRing::try_send_with`) and `:319-338` (`SpscRing::try_send_with`): `let written = f(payload_slice);` neither validates `written <= self.payload_capacity()` nor releases the slot sequence if `f` panics (`CORE-02`).
- `src/rs/vertebra-core/src/channel.rs:1005-1014` and `:1666-1673`: `read_slot_zero_copy` reads `(*header).len as usize` from shared memory and passes it straight to `std::slice::from_raw_parts(payload_ptr, len)` without checking `len <= self.payload_capacity()` (`OKF-02`).
- `src/rs/vertebra-core/src/transport/ring_pair.rs:269-281`: `TieredRingSet::select_ring` checks `total_size <= self.config.<tier>.slot_size` while `SpscRing::try_send_with` (`channel.rs:312-317`) checks `max_len > self.payload_capacity()` (`slot_size - 8`), so frames in `(slot_size - 8)..=slot_size` pick a tier that immediately fails with `PayloadTooLarge` (`OKF-03`).
- `src/rs/vertebra-core/src/transport/ring_pair.rs:191`: `let headers_len = headers_raw.len() as u16;` truncates headers larger than 65,535 bytes (`CORE-04`/`OKF-04`).
- `src/rs/vertebra-core/src/transport/mod.rs:786-819`: `BatchSnapshot::deserialize_from` never checks `node_count.checked_mul(node_size)` or each `TransportNode`'s `(path_offset + path_len)`, `(query_offset + query_len)`, `(headers_offset + headers_len)`, and `(body_offset + body_len)` against `slab_len` (`CORE-20`).
- `regression_tdd` applies because each item is a concrete correctness bug reproduced by a failing unit test.

## Steps
- [x] 1. Add failing reproduction tests in `src/rs/vertebra-core/tests/test_mpmc.rs`, `src/rs/vertebra-core/tests/test_ring.rs`, and `src/rs/vertebra-core/src/transport/mod.rs`:
  - `mpmc_buffer_too_small_does_not_wedge` (`test_mpmc.rs`): send a 32-byte frame into a 2-slot ring, call `try_recv` with an 8-byte buffer (`Err(ChannelError::BufferTooSmall)`), then send and receive 4 more frames to prove the ring wraps without wedging.
  - `mpmc_try_send_with_clamps_oversized_and_survives_panic` (`test_mpmc.rs`) and `spsc_try_send_with_survives_panic` (`test_ring.rs`): wrap `try_send_with` in `std::panic::catch_unwind` where the closure panics, then verify subsequent `try_send`/`try_recv` calls succeed; also verify returning `written > payload_capacity()` returns `Err(ChannelError::PayloadTooLarge)` and releases the slot.
  - `read_slot_zero_copy_rejects_corrupted_shm_len` (`test_ring.rs`): corrupt `SlotHeader.len` in SHM to `u32::MAX` and assert `try_recv_with` returns `Err(ChannelError::CorruptedSlot)`.
  - `tiered_ring_set_selects_next_tier_near_boundary` and `write_response_slot_rejects_oversized_headers` (`ring_pair.rs` inline tests): send a response whose total frame size is `small.slot_size - 4` (asserts it routes to `medium` and succeeds) and a response with a 66,000-byte header block (asserts `Err(RingPairError::InvalidResponse(_))`).
  - `batch_snapshot_rejects_out_of_range_node_offsets` (`transport/mod.rs` inline tests): serialize a `BatchSnapshot` with `body_offset + body_len > slab_len` and assert `BatchSnapshot::deserialize_from` returns `Err(TransportError::DeserializeFailed(_))`.
- [x] 2. Fix `MpmcRing::try_recv` and `try_recv_with_flags` (`src/rs/vertebra-core/src/channel.rs:1550-1612`) so the sequence `head.wrapping_add(self.mask + 1)` is always stored with `Ordering::Release` before propagating `read_slot` errors (`CORE-01`).
- [x] 3. Add a drop guard `SlotSendGuard` in `SpscRing::try_send_with` (`channel.rs:308-344`) and `MpmcRing::try_send_with` (`channel.rs:1489-1533`) that writes `(*header).len = 0` and publishes the sequence if `f` unwinds or returns `written > payload_capacity()`, returning `Err(ChannelError::PayloadTooLarge)` when `written > payload_capacity()` (`CORE-02`).
- [x] 4. Add `ChannelError::CorruptedSlot` (`channel.rs:28-46`) and check `if len > self.payload_capacity() { return Err(ChannelError::CorruptedSlot); }` before `std::slice::from_raw_parts` in `SpscRing::read_slot` (`:946`), `SpscRing::read_slot_zero_copy` (`:1005`), `MpmcRing::read_slot` (`:1647`), and `MpmcRing::read_slot_zero_copy` (`:1666`) (`OKF-02`).
- [x] 5. Fix `TieredRingSet::select_ring` (`src/rs/vertebra-core/src/transport/ring_pair.rs:269-281`) and `TieredRingConfig::select_tier` (`src/rs/vertebra-core/src/tiered_ring.rs:78-90`) to compare `total_size <= ring.payload_capacity()` (`slot_size - SlotHeader::SIZE`), and check `u16::try_from(headers_raw.len()).map_err(|_| RingPairError::InvalidResponse("headers exceed 65535 bytes".into()))?` in `write_response_slot` (`ring_pair.rs:191`) (`OKF-03`, `CORE-04`, `OKF-04`).
- [x] 6. Fix `BatchSnapshot::deserialize_from` (`src/rs/vertebra-core/src/transport/mod.rs:786-819`) to use `checked_mul`/`checked_add` for `nodes_bytes_len` and validate every `TransportNode`'s four `(offset, len)` pairs against the uncompressed slab length before returning `Ok` (`CORE-20`).
- [x] 7. Commit: `fix(core): guard ring slots on error/panic and validate SHM frame bounds` (signed), staging the paths in `files`.
