# 2.8 Shared memory, notifier, and macOS wait cleanup

## Objective
Consolidate the three duplicated `mmap` + error-cleanup blocks in `src/rs/vertebra-core/src/shm.rs` into a single `map_fd_region` helper while deleting unused `ShmRegion::from_fd` and `ShmRegion::size` (`CORE-30`), and make macOS `__ulock_wait` / `__ulock_wake` the default implementation in `src/rs/vertebra-core/src/platform/macos.rs` by removing the `macos-ulock` Cargo feature (`CORE-32`).

## Context
- `src/rs/vertebra-core/src/shm.rs:278-418` duplicates `mmap(ptr::null_mut(), size, PROT_READ | PROT_WRITE, MAP_SHARED, fd, 0)` and failure cleanup across `create_memfd`, `create_shm_open`, and `from_fd`, while `from_fd` (`:109-120`) and `size()` (`:204`, duplicate of `len()`) have zero external callers and `from_raw` (`:212`) is `pub` only for tests (`CORE-30`).
- `src/rs/vertebra-core/src/platform/macos.rs:13-16,72-123` gates `__ulock_wait`/`__ulock_wake` behind `#[cfg(feature = "macos-ulock")]`, causing default macOS builds to park with a 1 ms `nanosleep` spin-sleep even though CI (`.github/workflows/ci.yml:113`) always passes `--features macos-ulock` (`CORE-32`).
- `characterization` applies because `ShmRegion` mapping semantics and `ulock` behavior are preserved while removing dead methods and feature-flag indirection.

## Steps
- [x] 1. In `src/rs/vertebra-core/src/shm.rs`: extract private `unsafe fn map_fd_region(fd: RawFd, size: usize, unlink_name: Option<&CStr>) -> Result<ShmRegion, ShmError>` shared by `create_memfd` and `create_shm_open` (and `attach_fd`), delete `ShmRegion::from_fd` and `ShmRegion::size`, and restrict `ShmRegion::from_raw` to `pub(crate)` (`CORE-30`).
- [x] 2. In `src/rs/vertebra-core/src/platform/macos.rs` and `src/rs/vertebra-core/Cargo.toml`: remove the `macos-ulock` feature from `Cargo.toml`, make the `__ulock_wait` / `__ulock_wake` implementation unconditional on `target_os = "macos"` (with `ENOSYS` activating `platform::enable_fallback()`), and remove `--features macos-ulock` from `.github/workflows/ci.yml:113` (`CORE-32`).
- [x] 3. Commit: `refactor(core): deduplicate ShmRegion mmap and make macOS ulock default` (signed), staging the paths in `files`.
