# 2.2 Skills catalog, `.agents/skills/` progressive disclosure loader, `SkillController`, and `PromptController`

## Objective
Create `src/py/vertebra/agent/mcp/skills.py` and `src/py/vertebra/agent/mcp/controllers.py` to support progressive skill disclosure over MCP (`skill://<name>/SKILL.md`, `skills/list`, `skills/get`, `resources/directory/read`) from `.agents/skills/` and dynamic `SkillSource` backends with SHA-256 file integrity verification, alongside `PromptController` and `SkillController` class-based grouping of tools, prompts, instructions, and guards.

## Context
- `litestar_mcp/mcp/skills.py:18-389` defines `SkillFile`, `Skill`, `SkillCatalog`, and `SkillIntegrityError` where each skill directory contains a `SKILL.md` with YAML frontmatter (`name`, `description`) and optional `references/`, `scripts/`, and `examples/` subdirectories; every file is hashed at catalog load (`sha256:<hex>`) and re-verified on `read_file`.
- `litestar_mcp/mcp/prompt_controller.py:18-76` and `litestar_mcp/mcp/skill_controller.py:14-66` define `PromptController` and `SkillController`, which group `@prompt` and `@tool` methods under shared `prefix`, `instructions`, `guards`, `tags`, and `examples`, and project to an A2A skill descriptor via `to_agent_skill()`.
- Because PyYAML is not a required runtime dependency of Vertebra, `parse_skill_frontmatter` must parse standard `SKILL.md` frontmatter (`name`, `description`, scalar/list keys) with a deterministic stdlib parser (`tomllib`-compatible or line-oriented YAML subset parser) without requiring `import yaml`.
- `behavior_tdd` applies because `skills.py` and `controllers.py` add new MCP skill discovery and controller capabilities.

## Steps
- [ ] 1. Create `src/py/vertebra/agent/mcp/skills.py` defining `SKILL_URI_PREFIX = "skill://"`, `SKILL_FILE_NAME = "SKILL.md"`, `SkillIntegrityError`, `MCPSkillsConfig(msgspec.Struct, frozen=True, gc=False, kw_only=True)` (`paths: tuple[str | Path, ...] = (".agents/skills",)`, `sources: tuple[SkillSource, ...] = ()`, `directory_read: bool = True`, `max_files_per_skill: int = 128`, `max_bytes_per_skill: int = 2_097_152`), `SkillFile(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, `Skill(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, `SkillSource(Protocol)`, `FilesystemSkillSource`, and `SkillCatalog`:
  - `Skill.build(name: str, description: str, *, body: str, files: Mapping[str, bytes | str] | None = None, frontmatter: Mapping[str, Any] | None = None) -> Skill` constructs in-memory skills with computed `sha256:<hex>` digests.
  - `FilesystemSkillSource` scans configured directories (such as `.agents/skills/`), rejects symlinks and path traversal (`..`), parses `SKILL.md` frontmatter, and enforces `max_files_per_skill` and `max_bytes_per_skill`.
  - `SkillCatalog.read_file(uri: str) -> bytes` reads the file via `anyio.to_thread.run_sync`, verifies `compute_sha256_digest(data) == skill_file.digest` (raising `SkillIntegrityError` on mismatch), and emits an `observability.span_skill(skill.name, uri)` telemetry span.
- [ ] 2. Create `src/py/vertebra/agent/mcp/controllers.py` implementing `@prompt`, `@resource`, `PromptController`, and `SkillController`:
  - `PromptController` groups `@prompt` methods under `prefix: str | None = None`, `instructions: str | None = None`, and `guards: Sequence[GuardProtocol] = ()`, prepending `instructions` to the first user message returned by any prompt on the controller.
  - `SkillController(PromptController)` additionally collects `@tool` and `@resource` descriptors defined on the class hierarchy (`get_tools() -> list[Tool]`, `get_resources() -> list[ResourceEntry]`, `get_prompts() -> list[PromptEntry]`), binds them to `self` with the controller's `GuardChain`, and implements `to_agent_skill() -> dict[str, Any]` (`id`, `name`, `description`, `tags`, `examples`).
- [ ] 3. Wire `skills/list`, `skills/get`, `resources/directory/read`, and `skill://` `resources/read` into `src/py/vertebra/agent/mcp/service.py`, and add `MCPRegistry.register_controller(controller: PromptController | SkillController | type[PromptController | SkillController]) -> None`.
- [ ] 4. Export `Skill`, `SkillFile`, `SkillCatalog`, `MCPSkillsConfig`, `FilesystemSkillSource`, `SkillIntegrityError`, `PromptController`, `SkillController`, `prompt`, and `resource` from `src/py/vertebra/agent/mcp/__init__.py`.
- [ ] 5. Commit: `feat(mcp): add .agents/skills progressive disclosure catalog, SkillController, and PromptController` (signed), staging the paths in `files`.
