# 2.1 Full MCP `2026-07-28` registry and handlers (`agent/mcp/{registry,service,routes}.py`)

## Objective
Create `src/py/vertebra/agent/mcp/{registry,service,routes}.py` implementing the complete Model Context Protocol `2026-07-28` specification (`MCP_PROTOCOL_VERSION = "2026-07-28"`): `initialize`, `notifications/initialized`, `ping`, `server/discover`, `tools/list`, `tools/call` (with text, Base64 image/audio/blob, `resource_link`, `structuredContent`, and `isError`), `resources/list`, `resources/read`, `resources/templates/list`, `resources/subscribe`, `resources/unsubscribe`, `prompts/list`, `prompts/get`, `completion/complete`, and `logging/setLevel`, backed by `JsonRpcRouter`, `SchemaDigestCache`, and `AgentObservabilityHarness`.

## Context
- `src/py/vertebra/framework/mcp/__init__.py:52-174` (`McpServer`) only implements 4 methods on outdated `2025-03-26`, converts all tool outputs with `str(out)`, and has no HTTP transport (`MCP-01`, `MCP-02`).
- `litestar_mcp/mcp/routes.py:48-150` and `litestar_mcp/mcp/service.py:82-600` define the `2026-07-28` wire contract: `MCP-Protocol-Version: 2026-07-28`, `Mcp-Method` matching `body.method` (`-32020` `HEADER_MISMATCH` on discrepancy), `Mcp-Name` matching `MCP_NAME_FIELDS[method]` with `=?base64?...?=` decoding, Origin validation (`403` on disallowed cross-origin requests), and `_meta["io.modelcontextprotocol/protocolVersion"]` validation (`-32022` `UNSUPPORTED_PROTOCOL_VERSION`).
- `behavior_tdd` applies because `vertebra.agent.mcp` is a new protocol package with observable wire semantics.

## Steps
- [ ] 1. Create `src/py/vertebra/agent/mcp/registry.py` defining `MCP_PROTOCOL_VERSION = "2026-07-28"`, `MCPConfig(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, `TextContent`, `BlobContent`, `ResourceLinkContent`, `ToolCallOutput(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, `ResourceEntry(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, `ResourceTemplateEntry(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, `PromptArgument(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, `PromptMessage(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, `PromptEntry(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, and `MCPRegistry`:
  - `MCPRegistry` stores registered `Tool`, `ResourceEntry`, `ResourceTemplateEntry` (with RFC 6570 `{param}` URI template matching), `PromptEntry`, and `completion` callbacks, maintains a `_vertebra.SchemaDigestCache` for ETag generation, and notifies registered listeners on mutation.
- [ ] 2. Create `src/py/vertebra/agent/mcp/service.py` implementing `MCPService`:
  - Register handlers on `JsonRpcRouter` for `initialize`, `notifications/initialized`, `ping`, `server/discover`, `tools/list`, `tools/call`, `resources/list`, `resources/read`, `resources/templates/list`, `resources/subscribe`, `resources/unsubscribe`, `prompts/list`, `prompts/get`, `completion/complete`, and `logging/setLevel`.
  - In `tools/call`, run the resolved `GuardChain`, invoke `tool.invoke(arguments, context)` inside `observability.span_tool(tool_name, call_id)`, normalize return values into `content` blocks (`text`, `image`, `audio`, `resource`, `resource_link`) plus `structuredContent` when the return value is a `msgspec.Struct`, dataclass, or `dict`, enforce `config.max_blob_bytes`, and convert `ToolArgumentError` into `-32602` (`INVALID_PARAMS`) with JSON-pointer details.
  - In `resources/subscribe` / `unsubscribe`, register client session subscriptions and push `notifications/resources/updated` frames to `SseStreamBroker` when `notify_resource_updated(uri)` is called.
- [ ] 3. Create `src/py/vertebra/agent/mcp/routes.py` implementing `MCPHttpHandler`:
  - Validate `Origin` against `config.allowed_origins` and same-origin host (`403` on mismatch).
  - Validate `MCP-Protocol-Version`, `Mcp-Method`, and `Mcp-Name` headers (supporting `=?base64?...?=` decoding) against the classified JSON-RPC frame from `_vertebra.classify_jsonrpc_frame`, returning `-32020` (`HEADER_MISMATCH`) or `-32022` (`UNSUPPORTED_PROTOCOL_VERSION`) on mismatch.
  - Serve `If-None-Match` / `ETag` `304 Not Modified` on cacheable GET/POST methods (`server/discover`, `tools/list`, `resources/list`, `resources/templates/list`, `prompts/list`, `skills/list`) using `SchemaDigestCache.combined_etag()`.
  - Support both `application/json` unary responses and `text/event-stream` SSE streaming responses when the client sends `Accept: text/event-stream` and supplies a `progressToken` or active resource subscription.
- [ ] 4. Create `src/py/vertebra/agent/mcp/__init__.py` with lazy exports via `lazy_exports`.
- [ ] 5. Commit: `feat(mcp): implement MCP 2026-07-28 registry, service handlers, and Streamable HTTP route handler` (signed), staging the paths in `files`.
