# 2.5 ORDS/APEX automatic MCP tool/resource synthesis and end-to-end MCP `2026-07-28` conformance tests

## Objective
Update `src/py/vertebra/extensions/apex/__init__.py` and `src/py/vertebra/extensions/apex/gateway.py` (aligned with `extensions-and-data-consolidation:6.6`) so ORDS OpenAPI 3.0 catalogs, Oracle 26ai JSON Relational Duality Views, and Oracle APEX ORDS / PL/SQL packages synthesize executable `vertebra.agent.core.Tool` and `vertebra.agent.mcp.ResourceEntry` objects (instead of `_noop_tool_handler` stubs, `MCP-09`), and author the end-to-end MCP `2026-07-28` conformance test suite in `src/py/tests/unit/agent/test_mcp_conformance.py` and `src/py/tests/unit/agent/test_mcp_enterprise_tools.py` (`MCP-10`).

## Context
- `extensions-and-data-consolidation:6.6` consolidates `apex/` and `apex/` into `src/py/vertebra/extensions/apex/__init__.py` and `src/py/vertebra/extensions/apex/gateway.py`. Tool synthesis descriptors must integrate directly with this consolidated layout rather than creating fragmented submodules.
- Tests for enterprise tool and resource synthesis belong in `src/py/tests/unit/agent/test_mcp_enterprise_tools.py` (complementing `src/py/tests/unit/data/test_apex_gateway.py` and `src/py/tests/unit/data/test_gateway.py`).
- `behavior_tdd` applies because ORDS/APEX tool synthesis is upgraded from inert no-op descriptors to executable, policy-guarded MCP tools and resources.

## Steps
- [ ] 1. In `src/py/vertebra/extensions/apex/__init__.py`, define `OrdsTransportProtocol`, `OrdsMcpSynthesizer`, and `DualityViewMcpHandler`:
  - Merge OpenAPI 3.0 path-item and operation `parameters[]` (`in: "path" | "query" | "header"`) with `requestBody.content["application/json"].schema` into a complete JSON Schema 2020-12 `input_schema` (`{"type": "object", "properties": ..., "required": ...}`).
  - Build executable `Tool` instances for each `OrdsEndpointSpec` that interpolate `{path}` parameters, pass query/header/body payloads to the configured `OrdsTransportProtocol` (with W3C `traceparent` header injection via `inject_w3c_trace_context`), and emit an `observability.span_tool` span.
  - Build executable `Tool` (`duality_<view>_get`, `duality_<view>_put` with `If-Match` ETag concurrency enforcement) and `ResourceEntry` (`ords://duality/<view_name>`) descriptors for each registered `DualityViewSpec`.
- [ ] 2. Update `src/py/vertebra/extensions/apex/__init__.py` to remove `_noop_tool_handler` and `vertebra.framework.mcp` imports, extract full path/query/header/body schemas in `load_ords_openapi`, and delegate `to_mcp_tools(transport=...)` and `to_mcp_resources(transport=...)` to `OrdsMcpSynthesizer`.
- [ ] 3. Update `src/py/vertebra/extensions/apex/gateway.py` to replace `_mcp_server: McpServer` with `MCPRegistry` from `vertebra.agent.mcp`, add `register_plsql_tool(...)` and `register_ords_tool(...)` that build executable `Tool` instances calling `self.execute_plsql_package` and `self.execute_ords_rest` (enforcing `ApexPolicyEvaluator` and `ConfirmationGate`), and export `OrdsMcpSynthesizer` from `src/py/vertebra/extensions/apex/__init__.py`.
- [ ] 4. Create `src/py/tests/unit/agent/test_mcp_conformance.py` and `src/py/tests/unit/agent/test_mcp_enterprise_tools.py` covering:
  - Full MCP `2026-07-28` lifecycle (`initialize`, `ping`, `tools/list`, `tools/call` with structured & binary outputs, `resources/list`, `resources/read`, `resources/templates/list`, `resources/subscribe` + SSE update notification, `prompts/list`, `prompts/get`, `completion/complete`, `logging/setLevel`).
  - Header validation negative cases (`MCP-Protocol-Version` mismatch -> `-32022`, `Mcp-Method` mismatch -> `-32020`, `Mcp-Name` mismatch -> `-32020`, disallowed `Origin` -> `403`, ETag `If-None-Match` -> `304`).
  - `.agents/skills/` catalog loading, `SkillController` tool/prompt invocation with guard inheritance, and `SkillIntegrityError` on disk tamper.
  - `MCPTaskStore` async tool promotion, `input_required` -> `tasks/update` resumption, `tasks/cancel`, owner isolation, and `QueueService(lane="agent")` execution.
  - Executable ORDS OpenAPI endpoint tools, 26ai Duality View ETag tools/resources, and `ApexGateway` policy/confirmation-gated MCP tool execution with `gen_ai.*` telemetry verification.
- [ ] 5. Commit: `feat(apex,mcp): synthesize executable ORDS/26ai/APEX MCP tools and add MCP 2026-07-28 conformance suite` (signed), staging the paths in `files`.
