# Task 1.2: Wire Supervisor Broker SHM Inheritance & Crash Lease Reclamation in vertebra-http

## Objective

Integrate `ShmLeaseTable` into the Rust HTTP/IPC supervisor (`src/rs/vertebra-http/src/config.rs`, `src/rs/vertebra-http/src/workers/{factory,supervisor}.rs`, and `src/rs/vertebra-http/src/main.rs`) so the supervisor allocates and seals the shared-memory broker segment once on startup, passes its file descriptor (`VERTEBRA_BROKER_SHM_FD`) and metadata to every spawned Python worker, and automatically invokes `reclaim_worker(dead_pid)` whenever a worker process exits or crashes.

## Context

- `src/rs/vertebra-http/src/config.rs:76-97` defines `WorkerConfig { count, python_bin, app_path }` and `ServerConfig::from_env()` (`:178-209`).
- `src/rs/vertebra-http/src/workers/factory.rs` defines `WorkerFactory` (`new(worker_count, config)` and `spawn_worker(&self, worker_id, worker_cfg, server_cfg)`) which calls `vertebra_core::platform::process::make_inheritable(&[req_fd, resp_fd])` and spawns `python -m vertebra.supervisor._worker` with `VERTEBRA_REQ_RING_FD` and `VERTEBRA_RESP_RING_FD`.
- `src/rs/vertebra-http/src/workers/supervisor.rs` defines `WorkerLifecycle` (`child`, `pidfd`, `ring_pair`, `state`, `crash_count`, `pid()`, `check_alive(&mut self)`).
- `src/rs/vertebra-http/src/main.rs:230-275` initializes the worker factory, spawns workers in `Topology::Shm`, and monitors worker health.

## Steps

1. Extend `WorkerConfig` in `src/rs/vertebra-http/src/config.rs` with broker capacity settings populated from `ServerConfig::from_env()`:
   - Add `pub broker_pool_size: u32` (default `20`, env `VERTEBRA_BROKER_POOL_SIZE`), `pub broker_max_overflow: u32` (default `10`, env `VERTEBRA_BROKER_MAX_OVERFLOW`), and `pub broker_stmt_capacity: u32` (default `512`, env `VERTEBRA_BROKER_STMT_CAPACITY`).
   - Update `Default for WorkerConfig` and `ServerConfig::from_env()` to parse those environment variables with non-zero validation.
2. Extend `WorkerFactory` in `src/rs/vertebra-http/src/workers/factory.rs`:
   - Add `broker_table: Arc<ShmLeaseTable>` and `broker_shm_fd: RawFd` (on `#[cfg(unix)]`) plus `broker_shm_size: usize` fields to `WorkerFactory`.
   - In `WorkerFactory::new` (and a new `WorkerFactory::with_broker_config(worker_count, ring_config, pool_size, max_overflow)` constructor), allocate a `ShmRegion::create(shm_size)` large enough for `ShmLeaseTable::required_size(pool_size, max_overflow)`, initialize `ShmLeaseTable::init_in_region(region, pool_size, max_overflow)`, and store it in `Arc<ShmLeaseTable>`.
   - In `WorkerFactory::spawn_worker`:
     1. Include `broker_fd` in the slice passed to `vertebra_core::platform::process::make_inheritable(&[req_fd, resp_fd, broker_fd])`.
     2. Pass `.env("VERTEBRA_BROKER_SHM_FD", broker_fd.to_string())`, `.env("VERTEBRA_BROKER_SHM_SIZE", self.broker_shm_size.to_string())`, `.env("VERTEBRA_BROKER_POOL_SIZE", self.broker_table.pool_size().to_string())`, and `.env("VERTEBRA_BROKER_MAX_OVERFLOW", self.broker_table.max_overflow().to_string())` on the spawned `Command`.
   - Add `pub fn broker_table(&self) -> &Arc<ShmLeaseTable>` and `pub fn reclaim_worker_leases(&self, worker_pid: u32) -> u32` on `WorkerFactory`.
3. Update `WorkerLifecycle` in `src/rs/vertebra-http/src/workers/supervisor.rs` and the supervisor monitor in `src/rs/vertebra-http/src/main.rs`:
   - Store `last_pid: u32` on `WorkerLifecycle` when `WorkerLifecycle::new` is constructed (`child.id()`).
   - Add `pub fn check_alive_and_reclaim(&mut self, broker_table: &ShmLeaseTable) -> (bool, u32)` on `WorkerLifecycle` so that when `self.check_alive()` transitions the worker to `WorkerState::Dead`, it immediately invokes `broker_table.reclaim_worker(self.last_pid)` and logs the reclaimed lease count via `tracing::warn!(worker_id = self.worker_id, pid = self.last_pid, reclaimed, "reclaimed broker leases from exited worker")`.
   - Wire `WorkerFactory::with_broker_config` and `check_alive_and_reclaim` into `src/rs/vertebra-http/src/main.rs`.
4. Add unit and integration tests in `src/rs/vertebra-http/tests/it/broker_shm.rs` and `src/rs/vertebra-http/src/config.rs` verifying:
   - `ServerConfig::from_env()` parses `VERTEBRA_BROKER_POOL_SIZE` and `VERTEBRA_BROKER_MAX_OVERFLOW`.
   - `WorkerFactory` initializes `broker_table` with `active_leases == 0`.
   - Simulating a child worker acquiring 3 leases in `factory.broker_table()` and exiting causes `lifecycle.check_alive_and_reclaim(factory.broker_table())` to return `(false, 3)` and restore `active_leases` to `0`.
