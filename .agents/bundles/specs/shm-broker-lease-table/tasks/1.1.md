# Task 1.1: Implement ShmLeaseTable, LeaseSlot, TTL Reaper & Futex Wait Queue in vertebra-core

## Objective

Create `src/rs/vertebra-core/src/broker.rs` and export it from `src/rs/vertebra-core/src/lib.rs` to provide a cross-process, cache-line-isolated shared-memory connection lease broker (`ShmLeaseTable`) backed by `ShmRegion` (`src/rs/vertebra-core/src/shm.rs:41-186`) and `WaitWord` (`crate::platform::WaitWord` in `src/rs/vertebra-core/src/platform/mod.rs`).

## Context

- `src/rs/vertebra-core/src/layout.rs` defines `CacheLine<T>` (`crate::layout::CacheLine`, `#[repr(C, align(64))]` on x86_64/Linux, `#[repr(C, align(128))]` on Apple Silicon) for isolating hot atomic counters across CPU cores.
- `src/rs/vertebra-core/src/platform/mod.rs` defines `WaitWord` (`crate::platform::WaitWord`, `#[repr(C)] pub struct WaitWord { state: AtomicU32 }`) with `wait(&self, expected: u32)`, `wait_timeout(&self, expected: u32, timeout: Duration) -> io::Result<()>`, `wake_one(&self)`, and `wake_all(&self)` backed by Linux `SYS_futex`, macOS `__ulock_wait` / `__ulock_wake`, and Windows `WaitOnAddress`.
- `src/rs/vertebra-core/src/shm.rs:41-186` provides `ShmRegion::create(size)`, `ShmRegion::from_fd(fd, size)`, `ShmRegion::create_named(name, size)`, and `ShmRegion::open_named(name, size)`.
- Each connection slot must occupy a dedicated 64-byte aligned struct (`#[repr(C, align(64))] pub struct LeaseSlot`) so concurrent acquire/release CAS operations across slots never false-share cache lines.

## Steps

1. Create `src/rs/vertebra-core/src/broker.rs` defining the binary layout constants, error enum, slot structures, and `ShmLeaseTable`:
   ```rust
   use std::io;
   use std::sync::atomic::{AtomicU32, AtomicU64, Ordering};
   use std::time::{Duration, Instant, SystemTime, UNIX_EPOCH};

   use crate::layout::CacheLine;
   use crate::shm::ShmRegion;
   use crate::platform::WaitWord;

   pub const BROKER_MAGIC: u64 = u64::from_le_bytes(*b"VTBBRKR1");
   pub const BROKER_ABI_VERSION: u32 = 1;
   pub const MAX_BROKER_SLOTS: u32 = 4096;

   pub const SLOT_STATE_FREE: u32 = 0;
   pub const SLOT_STATE_PRIMARY: u32 = 1;
   pub const SLOT_STATE_OVERFLOW: u32 = 2;

   #[derive(Debug, Clone, Copy, PartialEq, Eq)]
   pub enum BrokerError {
       InvalidCapacity,
       RegionTooSmall { expected: usize, actual: usize },
       InvalidMagic(u64),
       UnsupportedAbi(u32),
       PoolExhausted,
       LeaseNotFound,
       GenerationMismatch,
   }
   ```
2. Define `#[repr(C, align(64))] pub struct ShmLeaseHeader` and `#[repr(C, align(64))] pub struct LeaseSlot` in `src/rs/vertebra-core/src/broker.rs` with compile-time layout assertions (`const _: () = assert!(std::mem::size_of::<LeaseSlot>() == 64);`):
   - `ShmLeaseHeader`:
     - Immutable configuration cache line: `magic: u64`, `abi_version: u32`, `pool_size: u32`, `max_overflow: u32`, `stmt_capacity: u32`, `stmt_offset: u64`, `total_size: u64`.
     - Isolated atomic coordination lines: `active_leases: CacheLine<AtomicU32>`, `waiters: CacheLine<AtomicU32>`, `wake_seq: CacheLine<WaitWord>`, `rr_cursor: CacheLine<AtomicU32>`.
     - Cumulative telemetry counters: `total_acquired: AtomicU64`, `total_released: AtomicU64`, `total_expired: AtomicU64`, `total_timeouts: AtomicU64`, `total_reclaimed: AtomicU64`.
   - `LeaseSlot` (64 bytes):
     - `state_and_pid: AtomicU64` — upper 32 bits store `SLOT_STATE_{FREE,PRIMARY,OVERFLOW}`, lower 32 bits store `worker_pid: u32` (`pack_state_pid(state: u32, pid: u32) -> u64` and `unpack_state_pid(raw: u64) -> (u32, u32)`).
     - `generation: AtomicU64` — monotonically incremented on each acquisition so delayed releases after TTL expiration or crash reclamation fail cleanly with `BrokerError::GenerationMismatch`.
     - `acquired_ns: AtomicU64` — monotonic/epoch nanoseconds when the slot was claimed.
     - `expiry_ns: AtomicU64` — deadline in nanoseconds (`acquired_ns + ttl_ns`) after which `reap_expired` may reclaim the slot.
     - `bind_key_hash: AtomicU64` — 64-bit hash of the database bind key (`default` = `0`).
     - `_pad: [u8; 24]` — explicit padding to 64 bytes.
3. Implement `LeaseGrant` and `LeaseTableStats` value structs in `src/rs/vertebra-core/src/broker.rs`:
   ```rust
   #[derive(Debug, Clone, Copy, PartialEq, Eq)]
   pub struct LeaseGrant {
       pub slot_index: u32,
       pub generation: u64,
       pub worker_pid: u32,
       pub is_overflow: bool,
       pub acquired_ns: u64,
       pub expiry_ns: u64,
       pub bind_key_hash: u64,
   }

   #[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
   pub struct LeaseTableStats {
       pub pool_size: u32,
       pub max_overflow: u32,
       pub active_leases: u32,
       pub primary_in_use: u32,
       pub overflow_in_use: u32,
       pub waiting_threads: u32,
       pub total_acquired: u64,
       pub total_released: u64,
       pub total_expired: u64,
       pub total_timeouts: u64,
       pub total_reclaimed: u64,
   }
   ```
4. Implement `ShmLeaseTable` in `src/rs/vertebra-core/src/broker.rs`:
   - `pub const fn required_size(pool_size: u32, max_overflow: u32) -> usize`: returns `std::mem::size_of::<ShmLeaseHeader>() + ((pool_size + max_overflow) as usize) * std::mem::size_of::<LeaseSlot>()` rounded up to 64-byte alignment.
   - `pub fn init_in_region(region: ShmRegion, pool_size: u32, max_overflow: u32) -> Result<Self, BrokerError>`: validates `pool_size >= 1` and `pool_size + max_overflow <= MAX_BROKER_SLOTS`, checks `region.size() >= Self::required_size(pool_size, max_overflow)`, zeroes the header and slot array, writes `BROKER_MAGIC` and `BROKER_ABI_VERSION`, and returns `ShmLeaseTable`.
   - `pub fn attach_region(region: ShmRegion) -> Result<Self, BrokerError>`: validates `magic == BROKER_MAGIC`, `abi_version == BROKER_ABI_VERSION`, and `region.size() >= Self::required_size(pool_size, max_overflow)`.
   - `pub fn try_acquire(&self, worker_pid: u32, ttl_ns: u64, bind_key_hash: u64) -> Result<LeaseGrant, BrokerError>`:
     1. Calls `self.reap_expired(monotonic_now_ns())` if `active_leases.0.load(Ordering::Acquire) >= self.total_capacity()`.
     2. Atomically increments `active_leases` from `cur` to `cur + 1` via `compare_exchange_weak` while `cur < pool_size + max_overflow`. If `cur >= pool_size + max_overflow`, returns `Err(BrokerError::PoolExhausted)`.
     3. Scans slots starting at `rr_cursor.0.fetch_add(1, Ordering::Relaxed) % total_capacity` to CAS `state_and_pid` from `0` to `pack_state_pid(state, worker_pid)` where `state` is `SLOT_STATE_PRIMARY` when `slot_index < pool_size` and `SLOT_STATE_OVERFLOW` otherwise.
     4. Increments `slot.generation` (`fetch_add(1, Ordering::AcqRel) + 1`), stores `acquired_ns`, `expiry_ns`, and `bind_key_hash`, increments `total_acquired`, and returns `Ok(LeaseGrant { ... })`.
   - `pub fn acquire(&self, worker_pid: u32, ttl_ns: u64, timeout: Duration, bind_key_hash: u64) -> Result<LeaseGrant, BrokerError>`:
     1. Fast path: calls `self.try_acquire(worker_pid, ttl_ns, bind_key_hash)` and returns immediately on `Ok`.
     2. If `timeout.is_zero()`, increments `total_timeouts` and returns `Err(BrokerError::PoolExhausted)`.
     3. Slow path: computes `deadline = Instant::now() + timeout`, increments `waiters.0.fetch_add(1, Ordering::AcqRel)` (using a RAII drop guard to guarantee `waiters.0.fetch_sub(1, Ordering::AcqRel)` on exit), snapshots `seq = wake_seq.0.load()`, retries `try_acquire`, and sleeps via `wake_seq.0.wait_timeout(seq, remaining.min(Duration::from_millis(25)))` until a slot is granted or `Instant::now() >= deadline`.
   - `pub fn release(&self, slot_index: u32, generation: u64) -> Result<(), BrokerError>`:
     1. Validates `slot_index < total_capacity` and checks `slot.generation.load(Ordering::Acquire) == generation`.
     2. Reads `old = slot.state_and_pid.load(Ordering::Acquire)`; if `unpack_state_pid(old).0 == SLOT_STATE_FREE`, returns `Err(BrokerError::LeaseNotFound)`.
     3. Re-verifies `slot.generation.load(Ordering::Acquire) == generation` and CASes `slot.state_and_pid` from `old` to `0`.
     4. Decrements `active_leases.0.fetch_sub(1, Ordering::AcqRel)`, increments `total_released`, and if `waiters.0.load(Ordering::Acquire) > 0`, increments `wake_seq.0.fetch_add(1)` and calls `wake_seq.0.wake_one()`.
   - `pub fn reap_expired(&self, now_ns: u64) -> u32` and `pub fn reclaim_worker(&self, worker_pid: u32) -> u32`:
     1. Iterates all `total_capacity` slots; for `reap_expired`, targets slots where `state != SLOT_STATE_FREE && expiry_ns > 0 && now_ns >= expiry_ns`; for `reclaim_worker`, targets slots where `state != SLOT_STATE_FREE && pid == worker_pid`.
     2. Bumps `slot.generation.fetch_add(1, Ordering::AcqRel)` before CASing `slot.state_and_pid` from `old` to `0` so any concurrent holder's subsequent `release` observes `GenerationMismatch`.
     3. Decrements `active_leases`, increments `total_expired` or `total_reclaimed`, and wakes waiting threads (`wake_seq.0.fetch_add(1)` + `wake_all()`).
5. Export `pub mod broker;` and re-export `BrokerError`, `LeaseGrant`, `LeaseSlot`, `LeaseTableStats`, and `ShmLeaseTable` in `src/rs/vertebra-core/src/lib.rs`.
6. Add inline unit tests in `src/rs/vertebra-core/src/broker.rs` and the Rust integration test at `src/rs/vertebra-core/tests/it/broker.rs` covering uncontended acquire/release, overflow marking, generation mismatch protection, TTL expiry reaping, and `reclaim_worker`.

## Acceptance Criteria

- [x] `LeaseSlot` has `#[repr(C, align(64))]` and a compile-time `assert!(std::mem::size_of::<LeaseSlot>() == 64)`.
- [x] `ShmLeaseTable::try_acquire` enforces `pool_size + max_overflow` with zero heap allocations and marks slots `< pool_size` as primary and slots `>= pool_size` as overflow.
- [x] `ShmLeaseTable::acquire` blocks on `WaitWord::wait_timeout` when full and wakes immediately when `release`, `reap_expired`, or `reclaim_worker` frees a slot.
- [x] Releasing a slot with a stale `generation` returns `Err(BrokerError::GenerationMismatch)` without corrupting `active_leases`.
- [x] Every `unsafe` block in `src/rs/vertebra-core/src/broker.rs` is preceded by a `// SAFETY:` comment explaining pointer alignment, bounds, and atomic access invariants.
