# Task 1.4: Multi-Process Contention, Futex Latency & Worker Crash Reclamation Tests

## Objective

Create comprehensive Rust integration tests in `src/rs/vertebra-core/tests/it/broker.rs` and multi-process Python tests in `src/py/tests/unit/extensions/test_shm_lease_broker.py` that prove strict global `pool_size + max_overflow` enforcement under multi-thread and multi-process contention, sub-millisecond futex wakeup latency on slot release, ABA-safe generation validation after TTL expiration, and immediate slot reclamation after a child worker process is killed with `SIGKILL`.

## Context

- Requirements `BRK-R1` through `BRK-R5` mandate that:
  1. Concurrent workers never exceed `pool_size + max_overflow` simultaneous active leases.
  2. Contended callers wake via `WaitWord` futex notification immediately upon `release()` without 2 ms or 10 ms polling delays.
  3. Expired leases are reaped atomically, and stale holders attempting to release a reaped slot fail with `GenerationMismatch` (`release(...) == False`) without double-decrementing `active_leases` or freeing a newly granted lease on the same slot.
  4. When a child worker holding active leases terminates abruptly via `SIGKILL`, `reclaim_worker(child_pid)` frees only that worker's slots and wakes blocked waiters.

## Steps

1. Create `src/rs/vertebra-core/tests/it/broker.rs` with the following integration tests:
   - `test_shm_lease_table_capacity_and_overflow_under_contention`: spawns 8 OS threads sharing a `ShmLeaseTable` (`pool_size = 4`, `max_overflow = 2`, total capacity `6`), each performing 250 acquire-hold-release iterations while tracking a shared atomic `concurrent_holders` gauge; asserts the observed maximum of `concurrent_holders` never exceeds `6` and `stats().active_leases == 0` at completion.
   - `test_shm_lease_table_futex_wakeup_latency`: exhausts all slots (`pool_size = 2`, `max_overflow = 0`), spawns a waiter thread calling `acquire(pid, ttl_ns, Duration::from_secs(2), 0)`, releases one slot from the main thread after 10 ms, and asserts the waiter wakes and acquires the freed slot in `< 5 ms`.
   - `test_shm_lease_table_ttl_reap_and_aba_generation_guard`: acquires a slot with `ttl_ns = 1_000_000` (1 ms), sleeps 5 ms, acquires a new lease on the exhausted pool (triggering `reap_expired`), and verifies that calling `release(first_grant.slot_index, first_grant.generation)` returns `Err(BrokerError::GenerationMismatch)` while leaving the second holder's lease intact.
   - `test_shm_lease_table_cross_process_named_shm`: creates a named region (`ShmRegion::create_named`) in one `ShmLeaseTable` instance and attaches a second `ShmLeaseTable` via `ShmRegion::open_named`, verifying cross-instance lease visibility and `reclaim_worker`.
2. Create `src/py/tests/unit/extensions/test_shm_lease_broker.py` testing `NativeLeaseBroker` across threads and spawned subprocesses (`multiprocessing.get_context("spawn")`):
   - `test_native_lease_broker_named_cross_process_cap`: creates a named `NativeLeaseBroker.create_named(name, pool_size=3, max_overflow=1)` in the parent process and spawns 4 child Python processes that attach via `NativeLeaseBroker.open_named(name, pool_size=3, max_overflow=1)` and contend for 40 leases each; asserts `stats.total_acquired >= 160` and `stats.active_leases == 0`.
   - `test_native_lease_broker_sigkill_worker_reclamation`: spawns a child process that opens the named broker, acquires 2 leases, writes its PID to a pipe, and pauses (`signal.pause()`); parent verifies `broker.stats().active_leases == 2`, sends `os.kill(child.pid, signal.SIGKILL)`, calls `child.join()`, invokes `reclaimed = broker.reclaim_worker(child.pid)`, and asserts `reclaimed == 2` and `broker.stats().active_leases == 0`.
   - `test_native_lease_broker_from_env_fd_inheritance`: creates an anonymous `NativeLeaseBroker(pool_size=4, max_overflow=2)`, verifies `from_env()` returns `None` when `VERTEBRA_BROKER_SHM_FD` is unset, and tests `from_fd` attachment.
