# Task 1.3: Expose GIL-Detached NativeLeaseBroker PyO3 Bindings & Stubs in vertebra-py

## Objective

Create `src/rs/vertebra-py/src/broker.rs`, register `NativeLeaseBroker`, `NativeLeaseGrant`, and `NativeBrokerStats` in `src/rs/vertebra-py/src/lib.rs`, and add complete type annotations in `src/py/vertebra/_vertebra.pyi` so Python workers on both CPython 3.12 and free-threaded CPython 3.14t can acquire, release, inspect, and reclaim cross-process connection leases without holding the GIL during futex waits.

## Context

- `src/rs/vertebra-py/src/lib.rs:40-82` defines `#[pymodule(gil_used = false)] pub fn pymodule_init(m: &Bound<'_, PyModule>) -> PyResult<()>`, registering PyO3 classes into `vertebra._vertebra`.
- PyO3 `0.28` provides `py.detach(|| ...)` on `Python<'_>` to release the GIL (or detach from the free-threaded interpreter state) across blocking system calls.
- `src/py/vertebra/_vertebra.pyi:1-332` is checked against the compiled extension by `mypy` and `mypy.stubtest`.

## Steps

1. Create `src/rs/vertebra-py/src/broker.rs` defining `#[pyclass(frozen, from_py_object)] pub struct NativeLeaseGrant`, `#[pyclass(frozen, from_py_object)] pub struct NativeBrokerStats`, and `#[pyclass] pub struct NativeLeaseBroker`:
   - `NativeLeaseGrant` read-only `#[pyo3(get)]` properties:
     - `slot_index: u32`
     - `generation: u64`
     - `worker_pid: u32`
     - `is_overflow: bool`
     - `acquired_ns: u64`
     - `expiry_ns: u64`
     - `bind_key_hash: u64`
   - `NativeBrokerStats` read-only `#[pyo3(get)]` properties:
     - `pool_size: u32`
     - `max_overflow: u32`
     - `active_leases: u32`
     - `primary_in_use: u32`
     - `overflow_in_use: u32`
     - `waiting_threads: u32`
     - `total_acquired: u64`
     - `total_released: u64`
     - `total_expired: u64`
     - `total_timeouts: u64`
     - `total_reclaimed: u64`
   - `NativeLeaseBroker` constructors and methods:
     - `#[new] #[pyo3(signature = (pool_size=20, max_overflow=10))] pub fn new(pool_size: u32, max_overflow: u32) -> PyResult<Self>`: creates an anonymous `ShmRegion::create(ShmLeaseTable::required_size(pool_size, max_overflow))` and initializes `ShmLeaseTable`.
     - `#[staticmethod] #[pyo3(signature = (name, pool_size=20, max_overflow=10))] pub fn create_named(name: &str, pool_size: u32, max_overflow: u32) -> PyResult<Self>`: creates a named POSIX SHM segment via `ShmRegion::create_named` and initializes `ShmLeaseTable`.
     - `#[staticmethod] #[pyo3(signature = (name, pool_size=20, max_overflow=10))] pub fn open_named(name: &str, pool_size: u32, max_overflow: u32) -> PyResult<Self>`: opens an existing named SHM segment via `ShmRegion::open_named` and attaches `ShmLeaseTable::attach_region`.
     - `#[staticmethod] pub fn from_fd(fd: i32, size: usize) -> PyResult<Self>`: attaches to an inherited file descriptor via `libc::dup(fd)` and `ShmRegion::from_fd` so closing the Python wrapper never closes the supervisor's inherited descriptor prematurely.
     - `#[staticmethod] pub fn from_env() -> PyResult<Option<Self>>`: reads `VERTEBRA_BROKER_SHM_FD` and `VERTEBRA_BROKER_SHM_SIZE` from `std::env::var`; if present, calls `Self::from_fd(fd, size)` and returns `Ok(Some(broker))`, otherwise returns `Ok(None)`.
     - `#[pyo3(signature = (worker_pid, ttl_ns, timeout_ms=5000, bind_key_hash=0))] pub fn acquire(&self, py: Python<'_>, worker_pid: u32, ttl_ns: u64, timeout_ms: u64, bind_key_hash: u64) -> PyResult<Option<NativeLeaseGrant>>`:
       ```rust
       let table = Arc::clone(&self.table);
       let result = py.detach(move || {
           table.acquire(
               worker_pid,
               ttl_ns,
               Duration::from_millis(timeout_ms),
               bind_key_hash,
           )
       });
       match result {
           Ok(grant) => Ok(Some(NativeLeaseGrant::from(grant))),
           Err(BrokerError::PoolExhausted) => Ok(None),
           Err(err) => Err(broker_err_to_py(err)),
       }
       ```
     - `#[pyo3(signature = (worker_pid, ttl_ns, bind_key_hash=0))] pub fn try_acquire(&self, worker_pid: u32, ttl_ns: u64, bind_key_hash: u64) -> PyResult<Option<NativeLeaseGrant>>`.
     - `pub fn release(&self, slot_index: u32, generation: u64) -> PyResult<bool>`: returns `Ok(true)` on release, `Ok(false)` on `LeaseNotFound` or `GenerationMismatch`.
     - `pub fn reap_expired(&self) -> u32` and `pub fn reclaim_worker(&self, worker_pid: u32) -> u32`.
     - `pub fn stats(&self) -> NativeBrokerStats`.
     - `#[getter] pub fn pool_size(&self) -> u32` and `#[getter] pub fn max_overflow(&self) -> u32`.
2. Register `NativeLeaseBroker`, `NativeLeaseGrant`, and `NativeBrokerStats` in `src/rs/vertebra-py/src/lib.rs` inside `pymodule_init`.
3. Add complete class and method signatures for `NativeLeaseGrant`, `NativeBrokerStats`, and `NativeLeaseBroker` to `src/py/vertebra/_vertebra.pyi`.
