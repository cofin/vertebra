# T5: Polyglot API Reference (`docs/reference/`)

## Context & Goal

Create the `docs/reference/` section covering all public Python modules (`vertebra.*`), PEP 561 native extension stubs (`_vertebra.pyi`, `_bundler.pyi`, `_storage.pyi`), the `@vertebra/client` TypeScript SDK (root index and 14 subpath entry points), and the generated `vtb` Click/`rich-click` CLI reference (`docs/reference/cli.md`), keeping every page within the `<= 120 KB` HTML budget and `<= 14` secondary TOC limit.
