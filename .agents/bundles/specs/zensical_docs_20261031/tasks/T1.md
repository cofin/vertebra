# T1: Dependencies, Ruff Markdown Protection, Pre-Commit & Makefile Targets

## Context & Goal

Establish the dependency and build foundation for Zensical documentation without bloated or unmaintained third-party plugins, and protect PyMdown `--8<--` snippet inclusions from Ruff `0.17+` Markdown formatting corruption.

## Files

- `pyproject.toml`
- `.pre-commit-config.yaml`
- `Makefile`

## Steps

- [x] Add `[dependency-groups] doc` in `pyproject.toml` with `"zensical>=0.0.71"`, `"mkdocstrings-python>=2.0.3"`, `"pymdown-extensions>=10.16"`, `"msgspec>=0.18.6"`, and `"rich-click>=1.8.0"`, and include `{ include-group = "doc" }` in `[dependency-groups] dev`.
- [x] Update `[tool.ruff]` in `pyproject.toml` to include `"docs/examples"` and `"tools"` in `src`, set `exclude = ["*.md"]`, `docstring-code-format = true`, and `docstring-code-line-length = 60` under `[tool.ruff.format]`, and add `[tool.ruff.lint.per-file-ignores]` rules for `"docs/examples/**"` and `"tools/**/*.*"`.
- [x] Update `.pre-commit-config.yaml` to add `types_or: [python, pyi, jupyter]` to the `ruff-format` hook and remove the legacy `sphinx-lint` (`v1.0.2`) repository block.
- [x] Add `docs-clean`, `docs`, `docs-serve`, `docs-check`, and `docs-rust` phony targets and recipes to `Makefile` (with `PYTHONPATH=src/py:.` and `uv run --no-sync` so `make docs` works after `uv sync --no-install-project --group doc` without compiling `maturin` Rust extensions), include `tools/docs` and `docs/examples` in `Makefile` `lint`/`lint-all` Ruff and Mypy targets, and update `clean` to remove `site/` and `.cache/`.
