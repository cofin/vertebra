# T2: First-Party Documentation Tooling, Griffe Templates & Unit Tests

## Context & Goal

Build the first-party Python documentation scripts (`tools/docs/`) and custom Griffe Jinja templates (`tools/docs/templates/python/material/`) adapted for Vertebra's `src/py/vertebra` package layout, PEP 561 `.pyi` stubs, `msgspec.Struct` classes, `vtb` (`vertebra.cli:cli`) CLI, and `@vertebra/client` TypeScript export verification.

## Files

- `tools/docs/__init__.py`
- `tools/docs/scan_public_docstrings.py`
- `tools/docs/generate_cli_docs.py`
- `tools/docs/postbuild.py`
- `tools/docs/verify_docs_artifacts.py`
- `tools/docs/templates/python/material/docstring/attributes.html.jinja`
- `tools/docs/templates/python/material/attribute.html.jinja`
- `tools/docs/templates/python/material/summary/attributes.html.jinja`
- `src/py/tests/unit/tools/test_docs_tooling.py`
- `src/py/tests/unit/tools/test_public_docstrings.py`
- `src/py/tests/unit/tools/test_cli_docs.py`

## Steps

- [x] Write failing unit tests in `src/py/tests/unit/tools/{test_docs_tooling,test_public_docstrings,test_cli_docs}.py` covering docstring leak/overload/TypedDict/Struct scanning, `vtb` CLI Markdown generation, post-build `llms.txt`/`llms-full.txt` generation and `<pre>`/`<textarea>`-safe HTML compaction, and artifact verification (including `@vertebra/client` export sync).
- [x] Implement `tools/docs/scan_public_docstrings.py` targeting `src/py/vertebra` (checking `.py` and `.pyi` files for leaked internal vocabulary, `@overload` docstrings, and undocumented `TypedDict` or `msgspec.Struct` fields) and clean up any violations in `src/py/vertebra/`.
- [x] Implement `tools/docs/generate_cli_docs.py` introspecting `vertebra.cli:cli` (`vtb` top-level commands `run`, `dev`, `init`, `build` and command groups `js`, `mcp`, `workers`), filtering `Sentinel.UNSET` and `--help`, and stripping Rich console markup.
- [x] Implement `tools/docs/postbuild.py` (`generate_llms_files`, `emit_legacy_html_redirects`, `compact_site_html`, `sync_root_brand_assets`, and optional `src/rs/target/doc` -> `site/rustdoc/` copy) and `tools/docs/verify_docs_artifacts.py` (`objects.inv`, `llms.txt`, `llms-full.txt`, borderless `logo.svg`/`favicon.svg`, `BANNED_PHRASES`, `<= 120 KB`/`<= 180 KB` budgets, `<= 14` TOC items, internal `#anchor` links, and `@vertebra/client` export sync).
- [x] Create custom Griffe Jinja templates under `tools/docs/templates/python/material/` (`docstring/attributes.html.jinja`, `attribute.html.jinja`, `summary/attributes.html.jinja`) supporting both `TypedDict` and `msgspec.Struct` 3-column field tables.

uv run pytest src/py/tests/unit/tools -q
