# T6: Runnable Examples (`docs/examples/`) & Example Verification Suite

## Context & Goal

Create self-contained, runnable Python example scripts under `docs/examples/` with `# --8<-- [start:example]` / `# --8<-- [end:example]` snippet markers embedded into `docs/examples/index.md` and usage guides, backed by a comprehensive `src/py/tests/unit/docs/test_examples.py` test suite.

## Files

- `docs/examples/__init__.py`
- `docs/examples/quickstart_app.py`
- `docs/examples/routing_and_dtos.py`
- `docs/examples/background_queues.py`
- `docs/examples/live_state_and_ssr.py`
- `docs/examples/storage_and_db.py`
- `docs/examples/agent_mcp_tools.py`
- `docs/examples/index.md`
- `src/py/tests/unit/docs/test_examples.py`

## Steps

- [ ] Write `src/py/tests/unit/docs/test_examples.py` enforcing non-empty example inventory, `__init__.py` module docstrings and `__all__`, zero inline `#` comments (except `# --8<--`, `# fmt:`, `# noqa:`, `# type:`, `# pyright:`, `# pragma:`), zero `tmp_path` leaks, standalone structure (`main()` + top-level imports), balanced `# --8<-- [start:example]` / `[end:example]` slices (`<= 120` chars), Markdown code block width (`<= 84` chars), snippet path resolution across `README.md` and `docs/**/*.md`, and parametrized execution of every example's `main()`.
- [ ] Implement `docs/examples/__init__.py` and runnable scripts (`quickstart_app.py`, `routing_and_dtos.py`, `background_queues.py`, `live_state_and_ssr.py`, `storage_and_db.py`, `agent_mcp_tools.py`) using in-memory backends (`TestClient`, `MemoryQueueBackend`, `MemoryBackend`, `MemoryStore`) so every example runs deterministically without external services.
- [ ] Author `docs/examples/index.md` embedding each script via `--8<-- "docs/examples/<script>.py:example"`.

## Verification

```bash
uv run pytest src/py/tests/unit/docs/test_examples.py -q
```
