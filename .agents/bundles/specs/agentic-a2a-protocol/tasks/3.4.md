# 3.4 A2A `1.0` end-to-end streaming, push notification, and bridge integration tests (`test_a2a_protocol.py`)

## Objective
Create `src/py/tests/unit/agent/test_a2a_protocol.py` with comprehensive behavioral tests covering A2A `1.0` `msgspec.Struct` serialization and card validation, RFC 7515 JWS Agent Card signing and tamper rejection, `message/send`, `message/stream`, `tasks/get`, `tasks/list`, `tasks/cancel` (including `-32001` foreign/unknown task rejection and `-32002` terminal task rejection), `tasks/resubscribe` with `Last-Event-ID` replay, `tasks/pushNotificationConfig/{set,get,list,delete}` with SSRF rejection, `agent/authenticatedExtendedCard`, and bidirectional `McpToolBridge` <-> `A2aAgentBridge` round-trips with OpenTelemetry `gen_ai.*` span verification.

## Steps
- [ ] 1. Create `src/py/tests/unit/agent/test_a2a_protocol.py` with the following test functions:
  - `test_a2a_1_0_models_camel_case_wire_roundtrip_and_card_validation`: verifies `AgentCard`, `Task`, `Message`, `TextPart`, `FilePart`, `DataPart`, and `Artifact` JSON serialization and tests `AgentCard.validate_for_path` on valid, proxy-prefixed, and invalid interface URLs.
  - `test_agent_card_jws_signing_and_tamper_rejection`: signs an `AgentCard` with `AgentCardSigner.sign`, verifies `AgentCardSigner.verify` returns `True`, mutates a skill description on the signed card, and asserts `verify` returns `False`.
  - `test_a2a_http_handler_agent_card_etag_304_and_rust_discovery`: verifies `GET /.well-known/agent-card.json` returns `200` with `A2A-Version: 1.0` and `ETag`, returns `304 Not Modified` on matching weak (`W/"..."`) and strong `If-None-Match` headers, and populates Rust `WellKnownDiscoveryCache`.
  - `test_a2a_message_send_get_list_and_owner_scoped_cancel`: exercises `message/send`, `tasks/get`, and paginated `tasks/list` for two distinct tenants (`tenant-a:alice` and `tenant-b:bob`), proving `bob` receives `-32001` (`TaskNotFoundError`) when querying or cancelling `alice`'s task, cancelling an unknown task ID returns `-32001`, and cancelling an already-completed task returns `-32002` (`TaskNotCancelableError`).
  - `test_a2a_message_stream_and_tasks_resubscribe_sse_replay`: streams a multi-step task via `message/stream`, disconnects mid-stream, calls `tasks/resubscribe` with `Last-Event-ID`, and asserts all `TaskStatusUpdateEvent` and `TaskArtifactUpdateEvent` frames are received in order until `completed`.
  - `test_a2a_push_notification_crud_delivery_and_ssrf_guard`: exercises `tasks/pushNotificationConfig/{set,get,list,delete}`, verifies signed webhook payload delivery on task completion, and asserts `http://169.254.169.254/latest/meta-data/` is rejected with `-32602`.
  - `test_bidirectional_mcp_and_a2a_bridges_preserve_trace_context`: mounts an `MCPService` with a `SkillController`, projects it to A2A `1.0` via `A2aAgentBridge.from_mcp_service`, wraps the resulting A2A service back into MCP tools via `McpToolBridge.from_a2a_service`, invokes the bridged tool inside a root `TraceContext`, and asserts the end-to-end result and unified `trace_id` across all recorded `SpanData` entries.
