# 3.2 A2A `1.0` JSON-RPC + SSE streaming methods and JWS Agent Card signing (`agent/a2a/{service,routes,signing}.py`)

## Objective
Create `src/py/vertebra/agent/a2a/{signing,service,routes}.py` implementing: (1) RFC 7515 JWS Agent Card signing and verification (`AgentCardSigner`), (2) owner-scoped `A2ATaskStore` and `PushNotificationDispatcher`, (3) `A2AService` handling all 11 A2A `1.0` RPC methods (`message/send`, `message/stream`, `tasks/get`, `tasks/list`, `tasks/cancel`, `tasks/resubscribe`, `tasks/pushNotificationConfig/{set,get,list,delete}`, and `agent/authenticatedExtendedCard`), and (4) `A2AHttpHandler` serving JSON-RPC, SSE streams (`SseStreamBroker`), and `/.well-known/agent-card.json` with SHA-256 / FNV-1a ETag `304 Not Modified` responses.

## Context
- `src/py/vertebra/framework/a2a/__init__.py:81-167` (`A2AServer`) has an unbounded task dict with no owner scoping, reports `"canceled"` on nonexistent task IDs, and lacks streaming, push notifications, extended cards, and JWS signatures (`MCP-04`).
- A2A `1.0` standardizes error codes: `-32001` (`TaskNotFoundError`), `-32002` (`TaskNotCancelableError`), `-32003` (`PushNotificationNotSupportedError`), `-32004` (`UnsupportedOperationError`), `-32005` (`ContentTypeNotSupportedError`), and `-32006` (`AuthenticatedExtendedCardNotConfiguredError`).
- `behavior_tdd` applies because `signing.py`, `service.py`, and `routes.py` introduce new A2A `1.0` protocol handlers and security guarantees.

## Steps
- [x] 1. Create `src/py/vertebra/agent/a2a/signing.py` implementing `AgentCardSigner`:
  - Canonicalize the `AgentCard` payload (excluding `signatures`) with sorted keys via `vertebra.utils.serializers`, sign the JWS Protected Header (`{"alg": "HS256", "typ": "JOSE"}` using stdlib `hmac` + `hashlib.sha256` with constant-time `hmac.compare_digest`), and return a new `AgentCard` with `signatures=(AgentCardSignature(protected=..., signature=...),)`.
  - Provide `AgentCardSigner.verify(card: AgentCard, secret: bytes | str) -> bool` verifying the JWS signature in constant time.
- [x] 2. Create `src/py/vertebra/agent/a2a/service.py` defining A2A error constants (`TASK_NOT_FOUND = -32001`, `TASK_NOT_CANCELABLE = -32002`, `PUSH_NOTIFICATION_NOT_SUPPORTED = -32003`, `UNSUPPORTED_OPERATION = -32004`, `EXTENDED_CARD_NOT_CONFIGURED = -32006`), `A2AConfig(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, `A2ATaskStore` (owner-scoped with bounded capacity, TTL, and `ResponseCacheStore` persistence), `PushNotificationDispatcher` (validating webhook URLs against SSRF and delivering signed status/artifact events), and `A2AService`:
  - Implement `message/send`, `message/stream`, `tasks/get`, `tasks/list` (with cursor pagination), `tasks/cancel` (raising `-32001` when unknown or owned by another caller, and `-32002` when already in `TERMINAL_A2A_STATES`), `tasks/resubscribe` (replaying missed `TaskStatusUpdateEvent` and `TaskArtifactUpdateEvent` frames from `SseReplayBuffer` and streaming live updates until terminal), `tasks/pushNotificationConfig/{set,get,list,delete}`, and `agent/authenticatedExtendedCard` (requiring `AgentContext.identity.is_authenticated`).
  - Wrap every RPC method and task state transition in `observability.span_rpc("a2a", method)` and `observability.span_a2a_task(task_id, state)`.
- [x] 3. Create `src/py/vertebra/agent/a2a/routes.py` implementing `A2AHttpHandler`:
  - Serve `GET /.well-known/agent-card.json` (or `config.agent_card_path`) with `A2A-Version: 1.0`, `Cache-Control`, and RFC 9110 weak/strong `If-None-Match` `304 Not Modified` support, and provide `register_in_discovery_cache(cache)` to populate Rust `WellKnownDiscoveryCache` (`MCP-07`).
  - Serve `POST /a2a` (or `config.path`), switching between `application/json` unary responses and `text/event-stream` SSE responses for `message/stream` and `tasks/resubscribe`.
- [x] 4. Export `A2AConfig`, `A2AHttpHandler`, `A2AService`, `A2ATaskStore`, `AgentCardSigner`, and `PushNotificationDispatcher` from `src/py/vertebra/agent/a2a/__init__.py`.
- [x] 5. Commit: `feat(a2a): implement A2A 1.0 JSON-RPC/SSE service, push notifications, and JWS card signing` (signed), staging the paths in `files`.
