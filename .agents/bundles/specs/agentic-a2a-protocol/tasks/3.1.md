# 3.1 Full A2A `1.0` data models as `msgspec.Struct(frozen=True, gc=False)` (`agent/a2a/models.py`)

## Objective
Create `src/py/vertebra/agent/a2a/models.py` defining the complete Agent-to-Agent (A2A) `1.0` specification data models as `msgspec.Struct(..., frozen=True, gc=False, rename="camel")` value objects without requiring `protobuf` or `a2a-sdk` at runtime, and update `src/py/vertebra/extensions/apex/__init__.py` and `src/py/vertebra/extensions/apex/gateway.py` to emit A2A `1.0` `AgentCard` and `AgentSkill` models (`MCP-04`, `MCP-09`).

## Context
- `src/py/vertebra/framework/a2a/__init__.py:25-79` defines a pre-1.0 `AgentCard` lacking `supportedInterfaces`, `defaultInputModes`, `defaultOutputModes`, `protocolVersion`, and `signatures`, and a mutable `A2ATask` struct (`MCP-04`).
- `litestar_mcp/a2a/plugin.py:122-141` validates that an A2A `1.0` `AgentCard` advertises at least one `AgentInterface` with `protocol_version` matching `1.0` (`^1\.0(\.[0-9]+)?$`), `protocol_binding == "JSONRPC"`, and an absolute `http(s)://` URL whose path suffix matches the mounted A2A route path.
- Using `msgspec.Struct(frozen=True, gc=False, rename="camel", omit_defaults=True)` gives zero-GC-overhead serialization through `vertebra.utils.serializers` while remaining 100% wire-compatible with the official A2A `1.0` JSON schema.
- `behavior_tdd` applies because `models.py` introduces the A2A `1.0` wire schema and validation rules.

## Steps
