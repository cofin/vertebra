## Objective

Delete the duplicate `src/py/vertebra/framework/_types.py` module, merge `_type_bridge.py` + `_dev_middleware.py` into `src/py/vertebra/framework/dev.py`, merge `_ssr/*` + `ssr/__init__.py` into `src/py/vertebra/framework/ssr/__init__.py`, and merge `_inertia.py` + `inertia/__init__.py` into `src/py/vertebra/framework/inertia/__init__.py` with `msgspec.Struct(frozen=True, gc=False)` prop types, safe subprocess spawning (`start_new_session=True`), `blake2b` asset hashing, and public serializer imports.

## Context

- `src/py/vertebra/framework/_types.py:1-49` defines Python `Request` and `Response` classes that duplicate `vertebra._vertebra.Request`/`Response` and are only imported by `_inertia.py` (`FW-17`).
- `src/py/vertebra/framework/_type_bridge.py:1-64` and `src/py/vertebra/framework/_dev_middleware.py:1-198` are tightly coupled: `DevMiddleware.__init__` (`_dev_middleware.py:57-69`) monkey-patches `type_bridge.invalidate`, `_dev_middleware.py:83-96` chains four `elif path ==` branches, `_dev_middleware.py:104,161,182` uses silent `except Exception: pass` (`S110`, `BLE001`), and line 11 imports from private `vertebra.utils.serializers._json` (`FW-28`, `FW-36`, `FW-48`).
- `src/py/vertebra/framework/_ssr/{__init__,_backends,_prerender}.py` and `src/py/vertebra/framework/ssr/__init__.py` define two incompatible `SsrConfig`, `SsrResult`, and `SsrClient` hierarchies plus an unreferenced `SsrFrame` (`ssr/__init__.py:34-48`). `SidecarSsrClient._ensure_sidecar` (`_backends.py:155-163`) spawns `subprocess.Popen(f"{runtime} {self._entry}", shell=True, preexec_fn=os.setsid, ...)` (`S602`, `PLW1509`), `NativeSsrClient.__init__` (`_backends.py:42`) imports `vertebra._bundler` inside `__init__` (`PLC0415`), and `_backends.py:21` + `_prerender.py:10` import from `vertebra.utils.serializers._json` (`FW-15`, `FW-16`, `FW-28`, `FW-37`, `FW-48`).
- `src/py/vertebra/framework/_inertia.py:1-461` and `src/py/vertebra/framework/inertia/__init__.py:1-84` define two separate `InertiaConfig` and `InertiaResponse` surfaces. `_inertia.py` defines 6 plain-class prop types (`DeferredProp`, `MergeProp`, `DeepMergeProp`, `OnceProp`, `ScrollProp`, `OptionalProp`, `:45-128`) plus 6 redundant factory wrappers (`defer`, `merge`, `deep_merge`, `once`, `scroll`, `optional`, `:131-171`), duplicates partial-reload filtering across `_resolve_props_sync` (`:248-281`) and `_resolve_props_async` (`:283-319`), duplicates CSV header splitting (`:261-265,297-301,426-433`), uses `hashlib.md5` (`:423`, `S324`), and imports from `vertebra.utils.serializers._json` (`:18`) (`FW-15`, `FW-21`, `FW-28`, `FW-38`, `FW-48`).

## Steps

1. **Delete `src/py/vertebra/framework/_types.py` (`FW-17`)**:
   - Remove `src/py/vertebra/framework/_types.py` and replace its `Response(status, headers, body)` usages in Inertia with a `msgspec.Struct(frozen=True, gc=False)` `InertiaHttpResponse(status: int, headers: dict[str, str], body: bytes)` or `vertebra._vertebra.Response`.
2. **Consolidate `src/py/vertebra/framework/dev.py` (`FW-28`, `FW-36`, `FW-48`)**:
   - Create `src/py/vertebra/framework/dev.py` merging `_type_bridge.py` and `_dev_middleware.py`, and delete `src/py/vertebra/framework/_type_bridge.py` and `src/py/vertebra/framework/_dev_middleware.py`.
   - Import `decode_json`, `encode_json`, `encode_json_bytes` from `vertebra.utils.serializers` (`FW-28`).
   - Add `on_invalidate: Callable[[TypeAssets], None] | None = None` to `TypeBridge.__init__` so `TypeBridge.invalidate()` invokes `self._on_invalidate(assets)` directly without monkey-patching (`FW-36`).
   - Replace the 4-branch `if/elif` asset chain (`_dev_middleware.py:83-96`) with a class-level `_ASSET_ROUTES: ClassVar[dict[str, tuple[str, str]]]` mapping path to `(asset_attr, content_type)`, and log send/broadcast exceptions with `logger.debug(..., exc_info=True)` instead of `except Exception: pass` (`FW-36`, `FW-48`).
3. **Consolidate `src/py/vertebra/framework/ssr/__init__.py` (`FW-15`, `FW-16`, `FW-28`, `FW-37`, `FW-48`)**:
   - Merge `src/py/vertebra/framework/_ssr/{__init__,_backends,_prerender}.py` and `src/py/vertebra/framework/ssr/__init__.py` into `src/py/vertebra/framework/ssr/__init__.py`, and delete `src/py/vertebra/framework/_ssr/` (`_ssr/__init__.py`, `_ssr/_backends.py`, `_ssr/_prerender.py`).
   - Define a single `SsrConfig(msgspec.Struct, frozen=True, gc=False, kw_only=True)` supporting `mode: Literal["native", "sidecar"] = "native"`, `entry: str = ""`, `bundle_path: str | None = None`, `sidecar_url: str = "http://127.0.0.1:13714/render"`, `sidecar_port: int = 13714`, `pool_size: int = 4`, `timeout_ms: int = 1000`, `timeout: float = 2.0`, `prerender_routes: tuple[str, ...] = ()`, and `fallback_to_csr: bool = True`.
   - Define a single `SsrResult(msgspec.Struct, frozen=True, gc=False)` (`html: str = ""`, `head: list[str] = msgspec.field(default_factory=list)`, `status: int = 200`, `fallback_csr: bool = False`), delete unused `SsrFrame` (`ssr/__init__.py:34-48`), and unify `SsrClient` (`render`, `render_async`, `invalidate`, `stop`, plus `@staticmethod def from_config(config: SsrConfig) -> SsrClient`).
   - Load `vertebra._bundler` at module top level via `import_optional("vertebra._bundler")`; in `SidecarSsrClient._ensure_sidecar`, spawn `subprocess.Popen([runtime, self._entry], env=env, stdout=subprocess.PIPE, stderr=subprocess.PIPE, start_new_session=True)` without `shell=True` or `preexec_fn=os.setsid`; add `render_async` dispatching blocking sidecar HTTP calls via `SyncPool.default().submit_async`; and import `decode_json`, `encode_json`, `encode_json_bytes` from `vertebra.utils.serializers`.
4. **Consolidate `src/py/vertebra/framework/inertia/__init__.py` (`FW-15`, `FW-21`, `FW-28`, `FW-38`, `FW-48`)**:
   - Merge `src/py/vertebra/framework/_inertia.py` into `src/py/vertebra/framework/inertia/__init__.py` and delete `src/py/vertebra/framework/_inertia.py`.
   - Convert `DeferredProp`, `MergeProp`, `DeepMergeProp`, `OnceProp`, `ScrollProp`, and `OptionalProp` to `msgspec.Struct(frozen=True, gc=False)` and delete the 6 redundant wrapper functions (`defer`, `merge`, `deep_merge`, `once`, `scroll`, `optional`, `FW-21`, `FW-38`).
   - Update `InertiaConfig(msgspec.Struct, frozen=True, gc=False)` to accept `ssr: SsrConfig | None = None` instead of duplicating `ssr_mode`, `ssr_url`, `ssr_timeout`, `ssr_pool_size`, and `sidecar_port` (`FW-38`).
   - Deduplicate `_filter_partial_props` and `_parse_csv_header` across sync and async prop resolution, replace `hashlib.md5(content).hexdigest()[:8]` (`_inertia.py:423`) with `hashlib.blake2b(content, digest_size=4).hexdigest()`, and import serializer helpers from `vertebra.utils.serializers` (`FW-28`, `FW-38`, `FW-48`).
5. **Update unit tests in `test_dev_middleware.py`, `test_inertia_middleware.py`, `test_prerender.py`, and `test_ssr.py`**:
   - Update imports in `src/py/tests/unit/framework/{test_dev_middleware,test_inertia_middleware,test_prerender,test_ssr}.py` to target `vertebra.framework.dev`, `vertebra.framework.inertia`, and `vertebra.framework.ssr`, and replace `defer(...)` / `merge(...)` / `optional(...)` calls with `DeferredProp(...)` / `MergeProp(...)` / `OptionalProp(...)`.
