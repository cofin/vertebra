## Objective

Eliminate eager submodule imports in `vertebra.framework` and `vertebra.extensions.litestar`, add cached lazy attribute resolution and `__dir__` support to `vertebra` and `vertebra.typing` via a shared `lazy_exports` helper in `vertebra.utils.module_loader`, remove `mcp` and `a2a` from `vertebra.framework.__all__`, and invert the dependency between `vertebra.framework.{channels,stores}` and `vertebra.extensions.litestar.{channels,store}` so `vertebra.framework` owns `ChannelBus` and `ResponseCacheStore`.

## Context

- `src/py/vertebra/framework/__init__.py:7-28` eagerly imports 14 submodules (`_app`, `_router`, `a2a`, `asyncapi`, `autowire`, `channels`, `di`, `email`, `htmx`, `inertia`, `live`, `mcp`, `openapi`, `procedures`, `queues`, `security`, `ssr`, `stores`) at package import time (`~118 ms` warm import, `FW-14`, `MCP-08`).
- `src/py/vertebra/extensions/litestar/__init__.py:12-45` eagerly imports all 9 Litestar extension submodules (`channels`, `config`, `ecosystem`, `fastpath`, `offload`, `plugin`, `router`, `store`, `testing`) at package import time (`FW-14`).
- `src/py/vertebra/framework/channels/__init__.py:7-8` imports `ChannelsBackend as ChannelBus` from `vertebra.extensions.litestar.channels` (`src/py/vertebra/extensions/litestar/channels.py:22-133`), and `src/py/vertebra/framework/stores/__init__.py:12` imports `MemoryStore as ResponseCacheStore` from `vertebra.extensions.litestar.store` (`src/py/vertebra/extensions/litestar/store.py:19-122`), inverting the architecture so core framework modules depend on the Litestar adapter (`FW-13`).
- `src/py/vertebra/__init__.py:57-80` defines `__getattr__` without `__dir__`, and `src/py/vertebra/typing.py:20-49` defines `__getattr__` without caching into `globals()[name]` or implementing `__dir__` (`FW-49`).

## Steps

1. **Write failing regression tests in `src/py/tests/unit/test_utils_init.py`**:
   - Add `test_framework_lazy_import_does_not_load_submodules()` running a fresh Python subprocess (`sys.executable -c`) that imports `vertebra.framework`, asserts none of `vertebra.framework.inertia`, `vertebra.framework.ssr`, `vertebra.framework.live`, `vertebra.extensions.litestar` are in `sys.modules`, asserts `"mcp"` and `"a2a"` are not in `vertebra.framework.__all__`, and asserts warm `import vertebra.framework` completes in `< 20 ms`.
   - Add `test_lazy_exports_cache_and_dir()` verifying `dir(vertebra)`, `dir(vertebra.typing)`, `dir(vertebra.framework)`, and `dir(vertebra.extensions.litestar)` include all `__all__` symbols, and accessing an attribute on `vertebra.typing` or `vertebra.framework` caches it in the module's `__dict__`.
   - Add `test_framework_channels_and_stores_do_not_import_litestar_extension()` asserting that importing `vertebra.framework.channels` and `vertebra.framework.stores` does not load `vertebra.extensions.litestar` into `sys.modules`.
2. **Add `lazy_exports` to `src/py/vertebra/utils/module_loader.py:22-37`**:
   - Implement `lazy_exports(module_name: str, exports: tuple[str, ...], mapping: dict[str, tuple[str, str]]) -> tuple[Callable[[str], Any], Callable[[], list[str]]]` that resolves `(submodule_path, attr_name)` via `importlib.import_module`, caches the resolved value in `sys.modules[module_name].__dict__[name]`, raises `AttributeError(f"module {module_name!r} has no attribute {name!r}")` on unknown names, and returns a `__dir__` callable returning `sorted(set(exports) | set(sys.modules[module_name].__dict__.keys()))`.
3. **Move `ChannelBus` and `ResponseCacheStore` into `vertebra.framework` (`FW-13`)**:
   - Create `src/py/vertebra/framework/channels.py` containing the `ChannelBus` implementation moved from `src/py/vertebra/extensions/litestar/channels.py:22-133` (renamed from `ChannelsBackend` to `ChannelBus`), and delete `src/py/vertebra/framework/channels/__init__.py`.
   - Update `src/py/vertebra/extensions/litestar/channels.py` to import `ChannelBus` from `vertebra.framework.channels` and retain `swap_litestar_channels_backend(app_config: Any, backend: ChannelBus | None = None) -> ChannelBus` (`__all__ = ("ChannelBus", "swap_litestar_channels_backend")`).
   - Create `src/py/vertebra/framework/stores.py` containing `ResponseCacheStore` (moved and renamed from `MemoryStore` in `src/py/vertebra/extensions/litestar/store.py:19-122`) and `NamespacedStore` (from `src/py/vertebra/framework/stores/__init__.py:19-46`), and delete `src/py/vertebra/framework/stores/__init__.py`.
   - Update `src/py/vertebra/extensions/litestar/store.py` to import `ResponseCacheStore` from `vertebra.framework.stores` and retain `swap_litestar_response_cache_store(app_config: Any, store: ResponseCacheStore | None = None) -> ResponseCacheStore` (`__all__ = ("ResponseCacheStore", "swap_litestar_response_cache_store")`).
4. **Wire `lazy_exports` across `vertebra`, `vertebra.typing`, `vertebra.framework`, and `vertebra.extensions.litestar` (`FW-14`, `FW-49`, `MCP-08`)**:
   - In `src/py/vertebra/__init__.py:57-80`, add `__dir__() -> list[str]` returning `sorted(__all__)` (or delegate to `lazy_exports`).
   - In `src/py/vertebra/typing.py:20-49`, cache resolved optional symbols in `globals()[name]` before returning and add `__dir__() -> list[str]` returning `sorted(__all__)`.
   - In `src/py/vertebra/framework/__init__.py:1-51`, remove all top-level submodule imports, remove `"mcp"` and `"a2a"` from `__all__`, and wire `__getattr__, __dir__ = lazy_exports(__name__, __all__, _EXPORT_MAP)` (supporting submodule attributes `asyncapi`, `autowire`, `channels`, `di`, `email`, `htmx`, `inertia`, `live`, `openapi`, `procedures`, `queues`, `security`, `ssr`, `stores` as well as `App`, `ParamSpec`, `RouteDef`, `Router`).
   - In `src/py/vertebra/extensions/litestar/__init__.py:1-81`, replace top-level submodule imports with `lazy_exports`, exporting `ChannelBus` and `ResponseCacheStore` instead of `ChannelsBackend` and `MemoryStore`.
