## Objective

Flatten single-file framework subpackages (`di`, `security`, `procedures`, `htmx`, `live`, `openapi`, `asyncapi`, `autowire`) into flat modules under `src/py/vertebra/framework/`, bound and coalesce `LiveState._pending_deltas` using native `_vertebra.state_id`/`field_id`, precompute `Provide` parameter signatures and topological resolution order in `di.py`, implement `Guard.requires` + `CsrfMiddleware` + `RateLimiter` enforcement in `security.py`, deduplicate `ProcedureDef` decorators and `HtmxRequest`/`HtmxResponse` helpers, and wire `OpenAPISpecBuilder.from_app(app)` and `AsyncAPISpecBuilder.from_channels(bus)`.

## Context

- `src/py/vertebra/framework/live/__init__.py:72-135` grows `_pending_deltas: list[LiveDeltaFrame]` without bound when `flush_deltas()` is not called (`FW-35`), re-computes FNV-1a hashes on every ` __setattr__` (`:96-99`), stores `state_id` as an instance attribute instead of a class attribute (`:79`), sets unused `__vertebra_action_id__` in `@live_action` (`:59`), and has no shared cross-language frame fixture with `src/ts/vertebra-client/tests/live.test.ts` (`FW-35`).
- `src/py/vertebra/framework/di/__init__.py:42-119` runs `inspect.signature(provider.dependency)` on every `register()` and every `Container.resolve()` (`:46,105`), ignores the topological `self._order` computed in `compile()` (`:60-61`), and copies `dict(self._providers)` on every `.providers` access (`:40`) (`FW-30`).
- `src/py/vertebra/framework/security/__init__.py:65-115` duplicates 4 `requires_role`, `requires_scope`, `requires_capability`, and `requires_tenant` closures and leaves `CsrfConfig` and `RateLimitConfig` (`:30-45`) as inert config structs with no middleware or rate-limit enforcement (`FW-31`).
- `src/py/vertebra/framework/procedures/__init__.py:40-87` duplicates 3 decorator factories (`procedure_query`, `procedure_mutation`, `procedure_subscription`) (`FW-33`).
- `src/py/vertebra/framework/htmx/__init__.py:48-87` copies all headers into a new lowercase dict on every `HtmxRequest.from_headers` call and duplicates tri-state `bool | str | None` header formatting for `push_url` and `replace_url` (`:102-109`, `FW-34`).
- `src/py/vertebra/framework/openapi/__init__.py:35-100` cannot inspect `vertebra.App` routes (`App.enable_docs()` only stores `_openapi_config` without registering `schema_path` or `docs_path` routes), and `src/py/vertebra/framework/asyncapi/__init__.py:5,62` uses `json.dumps` instead of `vertebra.utils.serializers` (`FW-29`).
- `src/py/vertebra/framework/__init__.py` (from `5.1`) and `src/py/vertebra/framework/live/__init__.py` (from `5.3`) are updated here with explicit `depends_on: ["5.1", "5.3", "5.4"]`.

## Steps

1. **Write failing regression tests in `src/py/tests/unit/framework/test_live_state.py` and `src/py/tests/unit/framework/test_framework_subdomains.py`**:
   - In `test_live_state.py`, add `test_live_state_coalesces_and_bounds_pending_deltas()` mutating a `LiveState` field 1,000 times without calling `flush_deltas()` and asserting `len(state.flush_deltas()) == 1` with the latest value (LWW per `field_id`) and bounded pending capacity (`max_pending_deltas=256`).
   - In `test_framework_subdomains.py`, add tests for `Guard.requires(roles=..., scopes=..., capabilities=..., tenants=...)`, `CsrfMiddleware.verify_request(...)`, `RateLimiter.allow(key)`, `OpenAPISpecBuilder.from_app(app)` + `app.enable_docs()` route responses, and `AsyncAPISpecBuilder.from_channels(bus)`.
2. **Flatten and harden `src/py/vertebra/framework/live.py` (`FW-35`)**:
   - Move `src/py/vertebra/framework/live/__init__.py` to `src/py/vertebra/framework/live.py` and delete `src/py/vertebra/framework/live/__init__.py`.
   - Use `_vertebra.state_id` and `_vertebra.field_id` (from `5.4`), compute `cls.state_id: ClassVar[int]` and `cls._field_ids: ClassVar[dict[str, int]]` once in `LiveState.__init_subclass__`, store pending deltas in an insertion-ordered `dict[int, LiveDeltaFrame]` keyed by `field_id` (coalescing repeated writes to the same field in `O(1)` and capping at `_max_pending_deltas: ClassVar[int] = 256`), remove unused `__vertebra_action_id__` in `live_action`, and assert matching hex wire bytes in both `src/py/tests/unit/framework/test_live_state.py` and `src/ts/vertebra-client/tests/live.test.ts`.
3. **Flatten and optimize `di.py`, `security.py`, `procedures.py`, `htmx.py`, `openapi.py`, `asyncapi.py`, and `autowire.py` (`FW-29`, `FW-30`, `FW-31`, `FW-33`, `FW-34`)**:
   - `src/py/vertebra/framework/di.py` (delete `di/__init__.py`): precompute `parameter_names: tuple[str, ...]` on `Provide.__post_init__`, return `MappingProxyType(self._providers)` from `DependencyGraph.providers`, compute true topological dependency order in `DependencyGraph.compile()`, and iterate `self._graph.compile()` in `Container.resolve()` using precomputed `provider.parameter_names`.
   - `src/py/vertebra/framework/security.py` (delete `security/__init__.py`): add `Guard.requires(*, roles=(), scopes=(), capabilities=(), tenants=())` and make `requires_role`, `requires_scope`, `requires_capability`, and `requires_tenant` 1-line delegates to `Guard.requires`; add `CsrfMiddleware` (validating header token against cookie token on unsafe HTTP methods `POST`/`PUT`/`PATCH`/`DELETE`) and `RateLimiter` (token-bucket per client key enforcing `RateLimitConfig.requests_per_window` and `window_seconds`).
   - `src/py/vertebra/framework/procedures.py` (delete `procedures/__init__.py`): add `ProcedureDef.decorator(cls, kind: ProcedureKind, *, name: str | None = None)` and `ProcedureRouter.query`, `.mutation`, `.subscription` methods, binding `procedure_query`, `procedure_mutation`, and `procedure_subscription` via `ProcedureDef.decorator`.
   - `src/py/vertebra/framework/htmx.py` (delete `htmx/__init__.py`): update `HtmxRequest.from_headers` to accept `Mapping[str, str] | Sequence[tuple[bytes, bytes]]` without allocating an intermediate dict when a mapping is passed, and extract `_tristate(value: bool | str) -> str` for `push_url` and `replace_url`.
   - `src/py/vertebra/framework/openapi.py` and `src/py/vertebra/framework/asyncapi.py` (delete `openapi/__init__.py` and `asyncapi/__init__.py`): add `OpenAPISpecBuilder.from_app(cls, app: App, config: OpenAPIConfig | None = None) -> OpenAPISpecBuilder` walking `app.routes` and `ParamSpec`, register `schema_path` and `docs_path` GET routes when `App.enable_docs()` is called, and add `AsyncAPISpecBuilder.from_channels(cls, bus: ChannelBus, ...)` using `encode_json`/`format_json` from `vertebra.utils.serializers` instead of `json.dumps`.
   - Move `src/py/vertebra/framework/autowire/__init__.py` to `src/py/vertebra/framework/autowire.py` and delete `autowire/__init__.py`.
   - Update `src/py/vertebra/framework/__init__.py` lazy export map to reference the flat modules.
