## Objective

Expose `handler_id`, `state_id`, and `field_id` FNV-1a hash functions from `vertebra-py` (`vertebra._vertebra`), rename `framework/_app.py` and `framework/_router.py` to `framework/app.py` and `framework/router.py`, consolidate `RouteDef` path normalization, `App._route` registration, and `PARAM_CONVERTERS`, and delegate `LitestarRouterTable.match` to the native `Router` while removing redundant `LitestarRouteCompiler` and `extract_litestar_route_entries` wrappers.

## Context

- FNV-1a hashing is reimplemented in Python in three places: `_make_handler_id` in `src/py/vertebra/framework/_app.py:42-48`, `_fnv1a_32` in `src/py/vertebra/framework/_router.py:32-39`, and `_fnv1a_32` + `_fnv1a_16` in `src/py/vertebra/framework/live/__init__.py:33-47` (`FW-18`).
- `src/py/vertebra/framework/_app.py:130-154` (`App._route`) and `src/py/vertebra/framework/_router.py:124-137` (`Router._route`) duplicate decorator registration, `normalize_path` (`_router.py:42-50`) and `compile_template` (`_router.py:53-77`) are standalone module functions instead of `@staticmethod`s on `RouteDef`, and `_make_handler_id` is exported from `src/py/vertebra/__init__.py:18,37,49` (`FW-19`).
- `src/py/vertebra/extensions/litestar/router.py:56-61` (`LitestarRouterTable.match`) scans regexes linearly in `O(N)` instead of delegating to the native `matchit` router, duplicates `_PARAM_CONVERTERS` (`:114-125,186-198`) with `_router.py:24-29`, and defines redundant `LitestarRouteCompiler` (`:82-94`) and `extract_litestar_route_entries` (`:160-163`) wrappers (`FW-21`, `FW-41`).

## Steps

1. **Expose `handler_id`, `state_id`, and `field_id` in `vertebra-py` and `_vertebra.pyi` (`FW-18`)**:
   - In `src/rs/vertebra-py/src/transport.rs` and `src/rs/vertebra-py/src/lib.rs:67-81`, add `#[pyfunction] pub fn handler_id(method: &str, path: &str) -> u32`, `#[pyfunction] pub fn state_id(name: &str) -> u32`, and `#[pyfunction] pub fn field_id(name: &str) -> u16` computing deterministic FNV-1a 32-bit (`0x811C9DC5`, prime `0x01000193`, `"{UPPER_METHOD}:{path}"` for `handler_id`, UTF-8 `name` for `state_id`, and `((h >> 16) ^ (h & 0xFFFF)) as u16` for `field_id`).
   - Declare `def handler_id(method: str, path: str) -> int: ...`, `def state_id(name: str) -> int: ...`, and `def field_id(name: str, /) -> int: ...` in `src/py/vertebra/_vertebra.pyi`.
2. **Consolidate `framework/router.py` and `framework/app.py` (`FW-18`, `FW-19`)**:
   - Rename `src/py/vertebra/framework/_router.py` to `src/py/vertebra/framework/router.py`. Export `PARAM_CONVERTERS`, `ParamSpec`, `RouteDef`, and `Router`. Move `normalize_path` and `compile_template` onto `RouteDef` as `@staticmethod`s (`RouteDef.normalize_path`, `RouteDef.compile_template`) and call `_vertebra.handler_id(method, normalized)` instead of Python `_fnv1a_32`.
   - Rename `src/py/vertebra/framework/_app.py` to `src/py/vertebra/framework/app.py`. Delete `_make_handler_id` and remove it from `src/py/vertebra/__init__.py:18,37,49`. Have `App._route(self, method: str, path: str)` delegate to `self.router._route(method, path)` and append the resulting `RouteDef` to `self._routes` while indexing `(route_def.method, route_def.handler_id)` in `self._handler_map`.
   - Update `src/py/vertebra/framework/__init__.py` lazy export map (from `5.1`) to point `App` at `vertebra.framework.app` and `ParamSpec`, `RouteDef`, `Router` at `vertebra.framework.router`.
3. **Unify `src/py/vertebra/extensions/litestar/router.py` (`FW-21`, `FW-41`)**:
   - Import `PARAM_CONVERTERS`, `RouteDef`, and `Router` from `vertebra.framework.router`, deleting the duplicate `_PARAM_CONVERTERS` table (`:114-125`).
   - Delete `LitestarRouteCompiler` (`:82-94`) and `extract_litestar_route_entries` (`:160-163`), keeping `compile_litestar_router_table(app: Any) -> LitestarRouterTable` as the single compilation entry point.
   - In `LitestarRouterTable`, build an internal `Router` instance populated with the compiled routes and delegate `LitestarRouterTable.match(self, method: str, path: str)` to it so matching uses the shared route matcher instead of linear regex scanning.
4. **Update unit tests in `src/py/tests/unit/framework/test_app.py`**:
   - Add cross-language reference assertions verifying `_vertebra.handler_id("GET", "/users/{id}")`, `_vertebra.state_id("Counter")`, and `_vertebra.field_id("count")` match the FNV-1a reference values, verify `_make_handler_id` is no longer exported from `vertebra`, and verify `RouteDef.normalize_path` / `RouteDef.compile_template` and `LitestarRouterTable.match`.
