## Objective

Delete the custom `vertebra.framework.mcp`, `vertebra.framework.a2a`, and `vertebra.extensions.litestar.ecosystem` modules, add the `vertebra[mcp]` optional extra (`litestar>=2.15`, `litestar-mcp[a2a]>=0.15`), wire `LitestarMCP` and `LitestarA2A` directly in `LitestarConfig` and `LitestarPlugin`, delegate `vertebra.cli.mcp` to `litestar_mcp.mcp.bridge.run_bridge`, and refactor `OrdsOpenApiBridge` and `ApexGateway` to produce executable `litestar_mcp.Tool` and `a2a` skill definitions with full path/query/body `input_schema`.

## Context

- `src/py/vertebra/framework/mcp/__init__.py:1-162` (`McpServer`, `McpToolSpec`, `McpResourceSpec`, `McpPromptSpec`, `mcp_tool`, `mcp_resource`, `mcp_prompt`) and `src/py/vertebra/framework/a2a/__init__.py:1-131` (`A2AServer`, `A2ASkillSpec`, `A2ATask`, `AgentCard`, `a2a_skill`) reimplement a subset of `litestar-mcp[a2a]` without MCP session management, SSE streaming, cancellation, or A2A task state transitions (`MCP-01`, `MCP-04`, `MCP-06`). Deleting both modules per Decision D2 also supersedes `FW-32` (`JsonRpcDispatcher` deduplication between `mcp` and `a2a`).
- `src/py/vertebra/cli/mcp.py:1-58` implements a synchronous `urllib.request.urlopen` line reader (`run_mcp_stdio_bridge`) that drops `Mcp-Session-Id` headers and SSE streams (`MCP-02`, `MCP-03`).
- `src/py/vertebra/extensions/litestar/ecosystem.py:1-106` (`LitestarEcosystemBridge`, `attach_litestar_ecosystem_bridges`) writes inert `app.state["vertebra_ecosystem_bridge"]` keys without registering `LitestarMCP` or `LitestarA2A` plugins (`MCP-05`, `FW-50`).
- `src/py/vertebra/extensions/apex/openapi.py:67-99` (`OrdsOpenApiBridge.load_ords_openapi`) ignores OpenAPI `parameters[]` (dropping path/query parameters on `GET`/`DELETE` endpoints, `FW-53`), and `:101-125` (`to_mcp_tools`, `to_a2a_skills`) plus `src/py/vertebra/extensions/apex/gateway.py:9,95-96,133-156` emit no-op `async def _noop_tool(**kwargs: Any) -> dict[str, Any]: return dict(kwargs)` stubs coupled to `McpServer` (`MCP-09`).

## Steps

1. **Add `vertebra[mcp]` optional dependency and delete `framework/mcp`, `framework/a2a`, and `extensions/litestar/ecosystem.py` (`MCP-01`, `MCP-04`, `MCP-05`, `MCP-06`, `FW-32`, `FW-50`)**:
   - In `pyproject.toml:38-49` under `[project.optional-dependencies]`, add `mcp = ["litestar>=2.15", "litestar-mcp[a2a]>=0.15"]` and include `"litestar-mcp[a2a]>=0.15"` in `[dependency-groups].dev`.
   - Delete `src/py/vertebra/framework/mcp/__init__.py`, `src/py/vertebra/framework/a2a/__init__.py`, and `src/py/vertebra/extensions/litestar/ecosystem.py`.
   - Remove `LitestarEcosystemBridge`, `attach_litestar_ecosystem_bridges`, and `ecosystem` from `src/py/vertebra/extensions/litestar/__init__.py`.
2. **Wire `LitestarMCP` and `LitestarA2A` in `LitestarConfig` and `LitestarPlugin` (`MCP-05`, `FW-50`)**:
   - In `src/py/vertebra/extensions/litestar/config.py:15-35`, add `mcp_config: Any | None = None` and `a2a_config: Any | None = None` fields to `LitestarConfig`.
   - In `src/py/vertebra/extensions/litestar/plugin.py:42-93` (`LitestarPlugin.on_app_init`), when `self._config.mcp_config is not None` or `self._config.a2a_config is not None`, resolve `LitestarMCP` / `LitestarA2A` via `import_optional_attr("litestar_mcp", ...)` (raising `MissingDependencyError("litestar-mcp", install_package="vertebra[mcp]", extra="mcp")` if missing) and append the configured plugin instance(s) to `app_config.plugins` if not already present.
3. **Delegate `src/py/vertebra/cli/mcp.py` to `litestar_mcp.mcp.bridge` (`MCP-02`, `MCP-03`)**:
   - Replace the custom `urllib.request` loop in `src/py/vertebra/cli/mcp.py:16-58` with a wrapper that imports `run_bridge` from `litestar_mcp.mcp.bridge` (raising `MissingDependencyError("litestar-mcp", install_package="vertebra[mcp]", extra="mcp")` if absent) and executes `asyncio.run(run_bridge(url, headers=headers, stdin=stdin, stdout=stdout))`.
4. **Fix `OrdsOpenApiBridge` parameter schema extraction and executable tool/skill generation (`FW-53`, `MCP-09`)**:
   - In `src/py/vertebra/extensions/apex/openapi.py:67-99` (`load_ords_openapi`), merge OpenAPI path-item and operation `parameters[]` (`in: "path" | "query" | "header"`) with `requestBody.content["application/json"].schema` into a complete JSON Schema object (`{"type": "object", "properties": ..., "required": ...}`) on `OrdsEndpointSpec.input_schema`.
   - Update `OrdsOpenApiBridge.to_mcp_tools(self, executor: Callable[[OrdsEndpointSpec, dict[str, Any]], Awaitable[Any]] | None = None) -> list[Any]` (`:101-113`) and `to_a2a_skills(self, executor: Callable[[OrdsEndpointSpec, dict[str, Any]], Awaitable[Any]] | None = None) -> list[Any]` (`:115-125`) to construct executable tool/skill definitions whose handler invokes the injected `executor(ep, kwargs)` (or raises `RuntimeError("ORDS transport executor is required to invoke ORDS tools")` when `executor` is `None`) instead of returning `dict(kwargs)`.
   - In `src/py/vertebra/extensions/apex/gateway.py:9,95-96,133-156`, remove the `from vertebra.framework.mcp import McpServer, McpToolSpec` import, replace `mcp_server: McpServer` on `ApexGateway` with `mcp_tools: tuple[Any, ...]` and `a2a_skills: tuple[Any, ...]`, and route tool execution through an injected ORDS/REST transport callable on `ApexGateway.from_ords_openapi`.
5. **Update unit and integration tests (`MCP-10`)**:
   - In `src/py/tests/unit/framework/test_framework_subdomains.py`, remove tests targeting deleted `vertebra.framework.mcp` and `vertebra.framework.a2a`.
   - In `src/py/tests/unit/extensions/test_litestar_plugin.py`, replace `LitestarEcosystemBridge` tests with tests verifying `LitestarConfig(mcp_config=..., a2a_config=...)` plugin registration and `MissingDependencyError` when `litestar_mcp` is unavailable.
   - In `src/py/tests/unit/cli/test_mcp_cli.py`, test `run_mcp_stdio_bridge` delegation to `litestar_mcp.mcp.bridge.run_bridge`.
   - In `src/py/tests/unit/extensions/test_oracle_apex_and_gateway.py`, verify `OrdsOpenApiBridge.load_ords_openapi` captures path and query `parameters[]` in `input_schema` and that `to_mcp_tools(executor=...)` invokes the executor with endpoint metadata and arguments.
