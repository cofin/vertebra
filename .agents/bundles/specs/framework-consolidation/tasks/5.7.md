## Objective

Add `UnsupportedBackendError(VertebraError)` to `src/py/vertebra/_typing.py`, merge `src/py/vertebra/extensions/worker` into `src/py/vertebra/framework/queues.py` with working retry policies, cron matching, `collections.deque` queueing, per-lane concurrency semaphores, and `UnsupportedBackendError` on non-`memory://` URLs, and upgrade `src/py/vertebra/framework/email.py` to support `"memory"` and `"smtp"` backends while raising `UnsupportedBackendError` for unimplemented third-party API providers.

## Context

- `src/py/vertebra/framework/queues/__init__.py:1-130` (`QueueService`) and `src/py/vertebra/extensions/worker/runner.py:1-155` (`WorkerRunner`, `LaneConfig`, `parse_lanes`, `run_oneshot`) are disconnected implementations of background task execution (`FW-07`). `QueueConfig.backend_url` (`queues/__init__.py:60`) accepts arbitrary URLs (such as `redis://...`) while silently storing items in a Python list (`self._pending.pop(0)` in `O(N)` at `:119`), and `TaskRetryPolicy` (`:28-35`) and `CronSchedule` (`:38-45`) are never read by `QueueService.run_next()` (`:116-129`).
- `src/py/vertebra/framework/email/__init__.py:1-79` (`EmailConfig`, `EmailService`) declares `backend: EmailBackendKind = "memory"` where `EmailBackendKind = Literal["memory", "smtp", "resend", "sendgrid", "mailgun", "ses"]` (`:16`), but `EmailService.send()` (`:65-68`) unconditionally appends to `self._outbox` regardless of `config.backend` (`FW-08`).
- Per Decision D1 in the parent PRD, in-memory and stdlib-backed (`smtp`) modes must execute genuinely, while unimplemented external backend strings/URLs must raise `UnsupportedBackendError(VertebraError)` at initialization or call time.

## Steps

1. **Add `UnsupportedBackendError` to `src/py/vertebra/_typing.py` and write behavior TDD tests**:
   - In `src/py/vertebra/_typing.py`, define `class UnsupportedBackendError(VertebraError):` and export it in `__all__` (sorted per `RUF022`) and `src/py/vertebra/__init__.py` if needed.
   - In `src/py/tests/unit/extensions/test_worker_lanes.py` and `src/py/tests/unit/framework/test_framework_subdomains.py`, write tests asserting:
     - `QueueService(QueueConfig(backend_url="redis://localhost:6379/0"))` raises `UnsupportedBackendError`.
     - `QueueService` retries a failing `@task(retry=TaskRetryPolicy(max_retries=2, initial_backoff_seconds=0.0))` up to `max_retries` before raising, enforces per-lane `LaneConfig.max_concurrency` via `asyncio.Semaphore`, and executes matching `CronSchedule` tasks via `run_due_schedules(minute=..., hour=...)`.
     - `EmailService(EmailConfig(backend="memory"))` appends to `outbox`, `EmailService(EmailConfig(backend="smtp", smtp_host="127.0.0.1", smtp_port=...))` delivers an RFC 5322 `EmailMessage` over `smtplib.SMTP` via `SyncPool.default().submit_async`, and `EmailService(EmailConfig(backend="sendgrid"))` (as well as `"resend"`, `"mailgun"`, `"ses"`) raises `UnsupportedBackendError`.
2. **Merge `extensions/worker` into `src/py/vertebra/framework/queues.py` (`FW-07`)**:
   - Create `src/py/vertebra/framework/queues.py` combining `src/py/vertebra/framework/queues/__init__.py` and `src/py/vertebra/extensions/worker/runner.py`, and delete `src/py/vertebra/framework/queues/__init__.py`, `src/py/vertebra/extensions/worker/__init__.py`, and `src/py/vertebra/extensions/worker/runner.py`.
   - In `QueueService.__init__`, validate `self._config.backend_url.startswith("memory://")` and raise `UnsupportedBackendError(f"QueueService backend {self._config.backend_url!r} is not supported; use 'memory://'")` otherwise.
   - Replace `self._pending: list[QueuedJob]` with `collections.deque[QueuedJob]`, integrate `LaneConfig`, `WorkerRunner`, `parse_lanes`, and `run_oneshot`, enforce `TaskRetryPolicy.max_retries` in `run_next()` / `drain()`, and add `run_due_schedules(self, *, minute: int, hour: int, day_of_month: int = 1, month: int = 1, day_of_week: int = 0) -> list[Any]` matching registered `CronSchedule` fields.
3. **Implement `"memory"` and `"smtp"` in `src/py/vertebra/framework/email.py` (`FW-08`)**:
   - Move `src/py/vertebra/framework/email/__init__.py` to `src/py/vertebra/framework/email.py` and delete `src/py/vertebra/framework/email/__init__.py`.
   - Validate `config.backend` in `EmailService.__init__`: allow `"memory"` and `"smtp"`, and raise `UnsupportedBackendError(f"Email backend {self._config.backend!r} is not supported; use 'memory' or 'smtp'")` for `"resend"`, `"sendgrid"`, `"mailgun"`, or `"ses"`.
   - For `backend == "smtp"`, build an `email.message.EmailMessage` from `EmailMessage` (`subject`, `sender`, `to`, `cc`, `bcc`, `text_body`, `html_body`, `headers`) and dispatch delivery through `smtplib.SMTP(self._config.smtp_host, self._config.smtp_port)` inside `SyncPool.default().submit_async(...)`.
   - Update `src/py/vertebra/framework/__init__.py` lazy export map for `queues` and `email`.
