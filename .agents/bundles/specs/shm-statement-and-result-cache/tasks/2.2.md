# Task 2.2: Implement vertebra.extensions.broker Transport & Wire ShmBrokerTransport to NativeLeaseBroker

## Objective

Create `src/py/vertebra/extensions/broker/transport.py` and update `src/py/vertebra/extensions/alchemy/broker.py` and `src/py/vertebra/extensions/alchemy/__init__.py` so `ShmBrokerTransport` and `ShmSessionBroker` delegate cross-process lease acquisition, release, worker crash reclamation, and prepared-statement plan caching to `NativeLeaseBroker` and `NativeStatementCache`, using `SyncPool.default().submit_async` (`src/py/vertebra/utils/sync_tools.py:165-180`) for non-blocking async futex waits.

## Context

- In `src/py/vertebra/extensions/alchemy/broker.py:318-360`, `ShmBrokerTransport` currently allocates an unused `ShmRegion("broker-default", 65536)` (`:351-360`), encodes a `ChannelMessage` with `msgspec.msgpack.Encoder()` only to discard the bytes (`_ = self._encoder.encode(message)` at `:327` and `:338`), and delegates to `InMemoryBrokerTransport`, which busy-polls with `await asyncio.sleep(min(remaining, 0.002))` (`:230`).
- `SyncPool.default().submit_async(fn, *args, **kwargs)` in `src/py/vertebra/utils/sync_tools.py:165-180` executes blocking operations on the shared worker thread pool and awaits the resulting future on the caller's `asyncio` loop.
- Serialization of statement parameter tuples in Python must route through `encode_msgpack` and `decode_msgpack` in `src/py/vertebra/utils/serializers.py:185-215`.

## Steps

1. Create `src/py/vertebra/extensions/broker/transport.py` containing the production broker domain models and transports (with `msgspec.Struct(..., frozen=True, gc=False)`, PEP 585/604/695 typing, Google-style docstrings, and zero inline `#` comments):
   - `BrokerConfig(msgspec.Struct, frozen=True, gc=False)`:
     - `pool_size: int = 20`
     - `max_overflow: int = 10`
     - `lease_ttl_ms: int = 30_000`
     - `acquire_timeout_ms: int = 5_000`
     - `statement_cache_capacity: int = 512`
     - `shm_name: str | None = None`
   - `BrokerMetrics(msgspec.Struct, frozen=True, gc=False)`:
     - `active_leases: int = 0`
     - `primary_in_use: int = 0`
     - `overflow_in_use: int = 0`
     - `waiting_threads: int = 0`
     - `total_acquired: int = 0`
     - `total_released: int = 0`
     - `total_expired: int = 0`
     - `total_timeouts: int = 0`
     - `total_reclaimed: int = 0`
     - `statement_cache_hits: int = 0`
     - `statement_cache_misses: int = 0`
     - `statement_cache_evictions: int = 0`
   - `StatementPlan(msgspec.Struct, frozen=True, gc=False)`:
     - `sql_hash: int`
     - `dialect: str`
     - `compiled_sql: str`
     - `param_names: tuple[str, ...]`
   - `ConnectionLease`: context-manager and async-context-manager class storing `lease_id: str`, `worker_id: int`, `acquired_at_ns: int`, `ttl_ns: int`, `bind_key: str`, `is_overflow: bool`, `slot_index: int`, and `generation: int`.
   - `InMemoryBrokerTransport`: single-process transport for unit tests and embedded single-worker mode.
   - `ShmBrokerTransport`:
     - Attaches to `NativeLeaseBroker.from_env()` when `VERTEBRA_BROKER_SHM_FD` is set; when `config.shm_name` is set, creates or opens a named `NativeLeaseBroker`; otherwise allocates an anonymous `NativeLeaseBroker(config.pool_size, config.max_overflow)` and `NativeStatementCache(config.statement_cache_capacity)`.
     - `acquire(self, worker_id: int | None = None, timeout_ms: int | None = None, bind_key: str = "default") -> ConnectionLease`: calls `self._native.acquire(pid, ttl_ns, effective_timeout_ms, bind_hash)` (which releases the GIL via `py.detach` during futex wait) and returns a `ConnectionLease` populated with `slot_index` and `generation`, or raises `TimeoutError` when `None` is returned.
     - `async def acquire_async(self, worker_id: int | None = None, timeout_ms: int | None = None, bind_key: str = "default") -> ConnectionLease`:
       1. Attempts an immediate non-blocking `grant = self._native.try_acquire(pid, ttl_ns, bind_hash)`.
       2. If `grant is not None`, constructs and returns `ConnectionLease` immediately on the event loop without thread-pool overhead.
       3. If `grant is None`, awaits `SyncPool.default().submit_async(self._native.acquire, pid, ttl_ns, effective_timeout_ms, bind_hash)` and raises `TimeoutError` if the result is `None`.
     - `release(self, lease_id: str) -> bool`: looks up the active `(slot_index, generation)` for `lease_id` (or parses `slot_index:generation` directly from `lease_id`) and invokes `self._native.release(slot_index, generation)`.
     - `reclaim_worker(self, worker_pid: int) -> int`: delegates to `self._native.reclaim_worker(worker_pid)`.
     - `get_or_compile_statement(self, dialect: str, raw_sql: str, compiler: Callable[[str], tuple[str, tuple[str, ...]]]) -> StatementPlan`: queries `self._stmt_cache.lookup(dialect_tag, raw_sql_bytes)`; on hit, decodes `param_names` via `decode_msgpack` and returns `StatementPlan`; on miss, invokes `compiler(raw_sql)`, encodes `param_names` via `encode_msgpack`, inserts into `self._stmt_cache`, and returns `StatementPlan`.
2. Update `src/py/vertebra/extensions/alchemy/broker.py` and `src/py/vertebra/extensions/alchemy/__init__.py` to use `ShmBrokerTransport`, `InMemoryBrokerTransport`, `BrokerConfig`, `BrokerMetrics`, `ConnectionLease`, and `StatementPlan` from `vertebra.extensions.broker.transport`, and add `ShmSessionBroker` wrapping `ShmBrokerTransport` for SQLAlchemy session checkout/checkin lifecycle hooks.
