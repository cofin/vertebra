# Task 2.3: Integrate BrokerPlugin, AlchemyPlugin & SQLSpecPlugin with /debug/zpages/broker & OpenTelemetry

## Objective

Create `src/py/vertebra/extensions/broker/plugin.py` and `src/py/vertebra/extensions/broker/__init__.py`, and wire `BrokerPlugin`, `AlchemyPlugin` (`src/py/vertebra/extensions/alchemy/plugin.py`), and `SQLSpecPlugin` (`src/py/vertebra/extensions/sqlspec/plugin.py`) to publish live cross-process broker and statement-cache telemetry to `/debug/zpages/broker` (`ZPagesRegistry` in `src/py/vertebra/server/platform.py:102-157`) and OpenTelemetry `db.client.connections.*` metrics (`src/py/vertebra/telemetry/otel.py:97-168`).

## Context

- `src/py/vertebra/server/platform.py:102-157` defines `ZPagesRegistry`, which handles `/healthz`, `/statusz`, `/varz`, and `/rpcz` via `handle_zpage(path: str) -> tuple[int, bytes]`.
- `src/py/vertebra/telemetry/otel.py:97-168` defines `SpanData`, `SpanExporter`, `GenAiMetricSample`, and `GenAiRecorder` using `msgspec.Struct(..., frozen=True, gc=False)` and `encode_json_bytes`.
- `src/py/vertebra/extensions/alchemy/plugin.py:154-290` (`AlchemyPlugin`) and `src/py/vertebra/extensions/sqlspec/plugin.py:243-465` (`ProxySyncConfig`, `ProxyAsyncConfig`, `SQLSpecPlugin`) accept an optional `broker` and install it into application state.

## Steps

1. Extend `src/py/vertebra/telemetry/otel.py` with `DbPoolMetricSample(msgspec.Struct, frozen=True, gc=False)` and `DbPoolRecorder`:
   - `DbPoolMetricSample` fields:
     - `pool_name: str`
     - `active_leases: int`
     - `primary_in_use: int`
     - `overflow_in_use: int`
     - `max_capacity: int`
     - `waiting_threads: int`
     - `total_timeouts: int`
     - `total_reclaimed: int`
     - `statement_cache_hits: int`
     - `statement_cache_misses: int`
     - `wait_duration_ms: float = 0.0`
   - `DbPoolRecorder`: records samples and exports OpenTelemetry-compliant metric points for `db.client.connections.usage`, `db.client.connections.max`, `db.client.connections.wait_time`, `db.client.connections.timeouts`, `db.client.statement_cache.hits`, and `db.client.statement_cache.misses`.
2. Extend `ZPagesRegistry` in `src/py/vertebra/server/platform.py`:
   - Add `_broker_providers: dict[str, Callable[[], dict[str, object]]]` and `register_broker(self, name: str, provider: Callable[[], dict[str, object]]) -> None`.
   - Update `handle_zpage(self, path: str) -> tuple[int, bytes]` to serve `/brokerz` and `/debug/zpages/broker` returning `200` and `encode_json_bytes({"status": "ok", "brokers": {name: provider() for name, provider in self._broker_providers.items()}})`.
3. Create `src/py/vertebra/extensions/broker/plugin.py` and `src/py/vertebra/extensions/broker/__init__.py`:
   - Implement `BrokerPlugin` supporting `use_shm: bool = True`, `config: BrokerConfig`, `zpages: ZPagesRegistry | None = None`, and `otel_recorder: DbPoolRecorder | None = None`.
   - When `zpages` is provided (or resolved from app state), register the broker snapshot callback under `/debug/zpages/broker` reporting `pool_size`, `max_overflow`, `active_leases`, `primary_in_use`, `overflow_in_use`, `utilization_ratio`, `waiting_threads`, `total_acquired`, `total_released`, `total_expired`, `total_timeouts`, `total_reclaimed`, `statement_cache_hits`, `statement_cache_misses`, `statement_cache_evictions`, and `statement_cache_hit_ratio`.
   - When `otel_recorder` is configured, emit `DbPoolMetricSample` on lease acquisition/release and `snapshot_metrics()`.
4. Update `src/py/vertebra/extensions/alchemy/plugin.py` and `src/py/vertebra/extensions/sqlspec/plugin.py`:
   - Wire `AlchemyPlugin` and `SQLSpecPlugin` (`ProxySyncConfig` / `ProxyAsyncConfig`) to route SQL normalization through `broker.get_or_compile_statement(...)` when a `ShmBrokerTransport` or `BrokerPlugin` is attached, and expose `zpages` / `otel_recorder` registration during `install_state` / `on_app_init`.
