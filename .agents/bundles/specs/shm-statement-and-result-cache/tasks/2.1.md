# Task 2.1: Implement Seqlock ShmStatementCache & PyO3 NativeStatementCache

## Objective

Extend `src/rs/vertebra-core/src/broker.rs` and `src/rs/vertebra-py/src/broker.rs` with a lock-free, 4-way set-associative shared-memory prepared-statement digest and parameter-plan cache (`ShmStatementCache` and `NativeStatementCache`) using optimistic seqlock reads and clock-second-chance eviction.

## Context

- Database drivers in `vertebra.extensions.alchemy` and `vertebra.extensions.sqlspec` repeatedly compile raw SQL templates into dialect-normalized SQL strings and ordered bind-parameter plans (`ParameterizedSql`).
- Storing normalized SQL plans in shared memory requires zero reader locks so worker processes on CPython 3.12 and free-threaded CPython 3.14t never block each other on cache hits.
- A 4-way set-associative table of 256-byte cache-line-aligned `StatementSlot` entries (`#[repr(C, align(64))]`) guarded by a per-slot seqlock (`seq: AtomicU64`, odd while a writer mutates the slot, even when quiescent) enables wait-free reads (`seq1 == seq2 && (seq1 & 1) == 0`) and atomic single-slot writer updates.

## Steps

1. Define `StatementSlot`, `StatementPlanEntry`, `StatementCacheStats`, and `ShmStatementCache` in `src/rs/vertebra-core/src/broker.rs`:
   - `pub const STMT_SLOT_PAYLOAD_BYTES: usize = 224;`
   - `#[repr(C, align(64))] pub struct StatementSlot` (256 bytes total, verified via `const _: () = assert!(std::mem::size_of::<StatementSlot>() == 256);`):
     - `seq: AtomicU64` — seqlock version counter (`0` = empty, odd = write in progress, non-zero even = valid committed entry).
     - `sql_hash: AtomicU64` — 64-bit FNV-1a hash of `(dialect_tag, raw_sql)`.
     - `dialect_and_clock: AtomicU32` — lower 8 bits store `dialect_tag: u8`, bit 8 stores the clock second-chance reference bit (`CLOCK_REF_BIT = 1 << 8`).
     - `param_count: AtomicU16` — number of bind parameters in the compiled plan.
     - `sql_len: AtomicU16` — byte length of the normalized SQL prefix inside `payload`.
     - `plan_len: AtomicU16` — byte length of the msgpack-encoded parameter plan suffix inside `payload` (`sql_len + plan_len <= STMT_SLOT_PAYLOAD_BYTES`).
     - `_reserved: [u8; 6]`
     - `payload: [AtomicU64; 28]` (224 bytes accessed via atomic 64-bit word loads/stores to prevent data-race UB under the Rust memory model during optimistic seqlock reads).
   - `#[repr(C, align(64))] pub struct ShmStatementHeader` (64 bytes):
     - `capacity: u32` (rounded up to a power-of-two multiple of 4 ways, default `512` slots = 128 sets of 4 ways), `set_mask: u32`, `hits: AtomicU64`, `misses: AtomicU64`, `inserts: AtomicU64`, `evictions: AtomicU64`.
   - Implement `ShmStatementCache`:
     - `pub fn compute_sql_hash(dialect_tag: u8, raw_sql: &[u8]) -> u64`: deterministic 64-bit FNV-1a hash.
     - `pub fn lookup(&self, dialect_tag: u8, raw_sql: &[u8]) -> Option<StatementPlanEntry>`:
       1. Computes `hash = Self::compute_sql_hash(dialect_tag, raw_sql)` and locates the 4-slot set `set_idx = (hash as usize) & (self.set_mask as usize)`.
       2. For each of the 4 ways in the set, loads `seq1 = slot.seq.load(Ordering::Acquire)`. If `seq1 == 0 || (seq1 & 1) != 0`, continues to next way.
       3. Checks `slot.sql_hash.load(Ordering::Relaxed) == hash` and `(slot.dialect_and_clock.load(Ordering::Relaxed) as u8) == dialect_tag`.
       4. Reads `sql_len`, `plan_len`, `param_count`, and copies the needed 64-bit words from `slot.payload` using `Ordering::Relaxed`, followed by `std::sync::atomic::fence(Ordering::Acquire)` and `seq2 = slot.seq.load(Ordering::Relaxed)`.
       5. If `seq1 == seq2`, sets `CLOCK_REF_BIT` via `slot.dialect_and_clock.fetch_or(CLOCK_REF_BIT, Ordering::Relaxed)`, increments `hits`, and returns `Some(StatementPlanEntry { sql_hash: hash, dialect_tag, param_count, compiled_sql, param_plan })`.
       6. If all 4 ways miss, increments `misses` and returns `None`.
     - `pub fn insert(&self, dialect_tag: u8, raw_sql: &[u8], param_count: u16, compiled_sql: &[u8], param_plan: &[u8]) -> bool`:
       1. Returns `false` if `compiled_sql.len() + param_plan.len() > STMT_SLOT_PAYLOAD_BYTES`.
       2. Selects a target way in the 4-slot set: first any slot matching `hash` or with `seq == 0`; otherwise runs a clock sweep across the 4 ways clearing `CLOCK_REF_BIT` until a victim way is chosen.
       3. Claims the slot for writing by CASing `slot.seq` from `even_seq` to `even_seq + 1` (`Ordering::AcqRel`).
       4. Writes `sql_len`, `plan_len`, `param_count`, `dialect_and_clock` (`dialect_tag | CLOCK_REF_BIT`), `payload` words (`Ordering::Relaxed`), and `sql_hash`, then publishes `slot.seq.store(even_seq + 2, Ordering::Release)` and updates `inserts` (and `evictions` if `even_seq > 0`).
2. Re-export `ShmStatementCache`, `StatementCacheStats`, `StatementPlanEntry`, and `StatementSlot` from `src/rs/vertebra-core/src/lib.rs`.
3. Expose `#[pyclass(frozen, from_py_object)] pub struct NativeStatementPlan`, `#[pyclass(frozen, from_py_object)] pub struct NativeStatementCacheStats`, and `#[pyclass] pub struct NativeStatementCache` in `src/rs/vertebra-py/src/broker.rs` (and wire optional attached statement cache access onto `NativeLeaseBroker::statement_cache(&self) -> Option<NativeStatementCache>`), registering them in `src/rs/vertebra-py/src/lib.rs` and `src/py/vertebra/_vertebra.pyi`.
