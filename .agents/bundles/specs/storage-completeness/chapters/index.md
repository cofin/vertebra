# Chapters: Feature-Complete Storage

* [ch01 — Native Rust Storage Engine, GCP Auth Unification, and Fail-Closed Facade](ch01-native-engine-and-auth/spec.md) — [completed] Implements zero-copy chunk streaming, incremental multipart uploads, conditional puts, paginated listing, server-side rename, OCI PAR presigning, unified `vertebra._vertebra` GCP token caches, and fail-closed `SyncObjectStore` / `AsyncObjectStore` construction.
* [ch02 — SQLSpec, Advanced Alchemy, and Django Storage Contracts](ch02-orm-and-sql-storage-contracts/spec.md) — [completed] Implements exact SQLSpec `_sync` / `_async` protocol and native storage extensions, registers the existing Advanced Alchemy `ObjectStoreBackend` via `get_backend` without monkeypatching `storages.get`, and turns `DjangoStorage` into a `@deconstructible` subclass of `django.core.files.storage.Storage`.
* [ch03 — HTTP Range Streaming and Litestar Store/Static Integration](ch03-litestar-and-range-streaming/spec.md) — [planned] Adds RFC 9110 single-range `206 Partial Content` and `416 Range Not Satisfiable` streaming responses, `ObjectStoreLitestarStore`, and an async static-files adapter for Litestar.
* [ch04 — Strict Arrow SHM Allocation, Parquet Streaming, and OKF Sync](ch04-arrow-shm-and-docs/spec.md) — [planned] Enforces fail-loud named `ShmRegion` allocation, removes JSON pseudo-Arrow fallback from `ArrowCursor.from_rows`, wires batch-streaming Arrow/Parquet storage helpers, and synchronizes usage docs and OKF storage knowledge.
