# 4.1 Accurate stubs, dead bridge code, native module names

## Objective

Build all three PyO3 extensions directly under their package-qualified names (`vertebra._vertebra`, `vertebra._bundler`, `vertebra._storage`), delete the `src/py/vertebra/_bundler.py` re-export shim (`PYB-58`, `FE-12`), add `src/py/vertebra/_bundler.pyi` and `src/py/vertebra/_storage.pyi`, synchronize `src/py/vertebra/_vertebra.pyi` with the Rust exports, and wire `python -m mypy.stubtest` into `make lint` and `make lint-all` (`PYB-47`). Remove dead Rust bridge functions and dependencies: `read_file_range_chunks` and `tokio`/`tokio-util`/`futures-util` in `vertebra-py` (`PYB-41`), `_assert_py_string` (`PYB-40`), `submit_buffers`/`Response.from_buffer`/`get_headers`/`get_body` (`PYB-46`), `ring_name` in `init_transport` (`PYB-18`), and `free_threaded_const_exists` / `send_shm_response_with_backpressure` (`PYB-60`).

## Context

- **`PYB-58` & `FE-12` (`src/py/vertebra/_bundler.py:1-15`, `src/rs/vertebra-bundler/Cargo.toml`, `src/rs/vertebra-storage/Cargo.toml`, `pyproject.toml:108-115`):** Maturin installs `_bundler` and `_storage` as top-level modules, requiring `src/py/vertebra/_bundler.py` as a re-export shim and listing `_bundler` and `_storage` under mypy `ignore_missing_imports`.
- **`PYB-47` (`src/py/vertebra/_vertebra.pyi:27,54,84,114,115,273,274,280-284`, `src/rs/vertebra-py/src/lib.rs:44`):** `_vertebra.pyi` declares `AsgiScope.pop`, `WsgiEnviron.pop`, and `RequestBatchIterator.submit_buffers` (none exist in Rust), declares `update(other=None, **kwargs)` while Rust takes one positional argument, mistypes `raw_query -> bytes | None` (always `bytes`) and `wsgi_environ(server_port: int | str)` (Rust takes `u16`), marks `Response.status/body/headers` as mutable attributes, and declares `__version__` which `lib.rs` does not export.
- **`PYB-41` (`src/rs/vertebra-py/src/asgi_bridge.rs:12-41`, `src/rs/vertebra-py/Cargo.toml:13-16`):** `pub async fn read_file_range_chunks` has zero callers and is the only consumer of `tokio`, `tokio-util`, and `futures-util` in `vertebra-py`.
- **`PYB-18`, `PYB-40`, `PYB-46`, `PYB-60`:** `init_transport` accepts `ring_name` and discards it (`let _ = ring_name` at `api.rs:71`), and `server/_native.py:211-224` branches on default values to call `init_transport()` two ways; `rsgi_protocol.rs:378-381` has `#[allow(dead_code)] fn _assert_py_string`; `batch.rs:44-61` `submit_buffers` has zero callers; `response.rs:117-135,206-213` `Response.from_buffer` and `get_headers`/`get_body` duplicate `__new__` and property getters; `lib.rs:85-93` `free_threaded_const_exists` asserts nothing (`let _ = FREE_THREADED`).
- **Strategy justification:** `static_validation` is required because this task synchronizes type stubs, native module packaging, and dead FFI exports, and adds a new `mypy.stubtest` gate to `make lint` and `make lint-all`.

## Verification

- **Strategy:** `static_validation` — validates native extension packaging, Rust dependency tree, and `.pyi` stub parity with `mypy.stubtest` and `make lint-all`.
- **Initial evidence:** `uv run python -m mypy.stubtest vertebra._vertebra` → fails before the change with missing `__version__`, missing `AsgiScope.pop`, missing `WsgiEnviron.pop`, missing `RequestBatchIterator.submit_buffers`, and signature mismatches.
- **Final evidence:** `make dev && uv run python -m mypy.stubtest vertebra._vertebra vertebra._bundler vertebra._storage && cargo tree --manifest-path src/rs/Cargo.toml -p vertebra-py -e normal --depth 1 && make lint-all && uv run pytest src/py/tests/unit/ffi/test_ffi.py -q` → exits 0 with zero stubtest errors and `tokio` absent from `vertebra-py`'s dependency tree.
