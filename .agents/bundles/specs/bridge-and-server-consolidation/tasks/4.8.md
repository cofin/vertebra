# 4.8 ASGI runner debloat

## Objective

Rename `src/rs/vertebra-py/src/asgi_scope.rs` to `src/rs/vertebra-py/src/asgi.rs` and fix `AsgiScope["extensions"]` so `tls` is advertised only on `https`/`wss` schemes, `early_hint` and `debug` are removed, `http.response.trailers` are transmitted via `submit_raw_response` with `FrameFlags::TRAILERS`, and `http.response.zerocopysend` reads directly from the buffer protocol (`PYB-25`). Replace the 90-line custom coroutine driver in `src/py/vertebra/server/_asgi/_runner.py` with `asyncio.eager_task_factory` (`PYB-11`), merge `AsgiAdapter` into `AsgiRunner` (`PYB-27`), delete the dead Python `src/py/vertebra/server/_asgi/_scope.py` fallback (`PYB-26`), and rename `_asgi/_extensions.py` to `_asgi/_wire.py` after moving `LitestarExtension` to `vertebra.extensions.litestar` and deleting the unwired `FastApiExtension` and extension registry (`PYB-23`, `PYB-24`).

## Context

- **`PYB-25` (`src/rs/vertebra-py/src/asgi_scope.rs:99-119`, `src/py/vertebra/server/_asgi/_queues.py:151-167,182-202`, `src/py/vertebra/server/_asgi/_runner.py:155-160`):** `AsgiScope` unconditionally advertises `tls`, `early_hint`, `debug`, `trailers`, `zerocopysend`, and `pathsend` (allocating 9 Python dicts on every `scope["extensions"]` lookup) even on plaintext `http` connections. Meanwhile `_make_dispatch_coro` in `_runner.py:155-160` drops `resp.trailers`, `resp.early_hints`, and `resp.debug_info` on the floor when constructing the native `Response`, and `AsgiSend` copies `zerocopysend` buffers via `bytes(view)`.
- **`PYB-11` (`src/py/vertebra/server/_asgi/_runner.py:30-33,180-270`):** ~90 lines of custom coroutine stepping (`_drive_coro`, `_step_coro`, `_handle_yielded`, `_resume_coro_in_task`, `_BatchProcessor`, `_DIRECT_SEND`) reimplement Python 3.12+'s built-in `asyncio.eager_task_factory`, and `_current_loop` calls `asyncio.get_event_loop_policy()` (deprecated in Python 3.14).
- **`PYB-26` & `PYB-27` (`src/py/vertebra/server/_asgi/_scope.py:31-83`, `src/py/vertebra/server/_asgi/_adapter.py:36-95`, `_runner.py:124-144`):** Python `AsgiScope` and `build_scope` in `_scope.py` are dead fallbacks because native `AsgiScope` is always present, and `AsgiAdapter` and `AsgiRunner` duplicate `run_single`/`handle_path` setup.
- **`PYB-23` & `PYB-24` (`src/py/vertebra/server/_asgi/_extensions.py:12-20,250-371`):** `_asgi/_extensions.py` imports `vertebra.extensions.litestar` at module top level (pulling Litestar integration into `vertebra.server._asgi`), defines a `FastApiExtension` whose `try_handle` always returns `None`, and maintains a global `register_extension`/`get_extensions` list that `AsgiRunner` never consults.
- **Symbol overlap note (depends on 4.7):** Modifies `_loops.py` (installing `asyncio.eager_task_factory` on each loop thread), `worker.py` and `_dispatch.py` (using `AsgiRunner` directly), and `_asgi/_queues.py` (touched in 4.3/4.4).
- **Strategy justification:** `regression_tdd` is required because `AsgiScope["extensions"]` falsely advertises `"tls"` on plaintext `http` requests and `AsgiRunner` silently drops `http.response.trailers` messages.

## Steps

- [x] 1. In `src/py/tests/unit/server/test_asgi_scope_and_extensions.py`, add two failing regression tests:
  - `test_asgi_scope_advertises_tls_only_on_https_scheme`: constructs `AsgiScope` from a plaintext `http` request and asserts `"tls" not in scope["extensions"]`, `"early_hint" not in scope["extensions"]`, and `"debug" not in scope["extensions"]`, while an `https` scope includes `"tls"`.
  - `test_asgi_runner_emits_trailers_frame_when_app_sends_trailers`: runs an ASGI app through `AsgiRunner` that sends `http.response.start` (`trailers=True`), `http.response.body`, and `http.response.trailers` (`[(b"grpc-status", b"0")]`), and asserts the submitted frames include a `FrameFlags::TRAILERS` frame carrying `grpc-status: 0`.
- [x] 2. Rename `src/rs/vertebra-py/src/asgi_scope.rs` to `src/rs/vertebra-py/src/asgi.rs` (`PYB-25`):
  - Update `build_extensions_dict` (`:99-119`) to advertise only the delivered extensions (`http.response.pathsend`, `http.response.zerocopysend`, `http.response.trailers`), adding `"tls"` only when `self.scheme_str() == "https"` or `"wss"`. Cache the two template dicts (plaintext and TLS) in `PyOnceLock` and return a shallow `.copy()` per access instead of allocating 9 dicts.
  - Update `src/rs/vertebra-py/src/lib.rs` and `src/rs/vertebra-py/src/request.rs` (`mod asgi;`).
- [x] 3. In `src/py/vertebra/server/_asgi/_queues.py` and `src/py/vertebra/server/_asgi/_runner.py` (`PYB-25`):
  - Delete `early_hints` and `debug_info` from `AsgiResponse`.
  - When `resp.trailers` is non-empty, submit the response via `submit_raw_response` as streaming frames (`HEADERS_SENT | STREAMING` -> body frame -> `STREAMING | TRAILERS | FINAL` carrying encoded `resp.trailers`).
  - For `http.response.zerocopysend`, pass the buffer object directly into `Response(status=..., body=buffer, ...)` (which extracts via `PyBuffer` / `&[u8]` without an intermediate `bytes(view)` copy in Python).
- [x] 4. In `src/py/vertebra/server/_loops.py` and `src/py/vertebra/server/_asgi/_runner.py` (`PYB-11`, `PYB-26`, `PYB-27`):
  - In `EventLoopPool._start_loop_thread`, call `loop.set_task_factory(asyncio.eager_task_factory)`.
  - Merge `AsgiAdapter` (`src/py/vertebra/server/_asgi/_adapter.py`) into `AsgiRunner` (`src/py/vertebra/server/_asgi/_runner.py`) and delete `_asgi/_adapter.py` and `_asgi/_scope.py`.
  - Delete `_drive_coro`, `_step_coro`, `_handle_yielded`, `_resume_coro_in_task`, `_BatchProcessor`, `_DIRECT_SEND`, and `_current_loop` from `_runner.py`; schedule batch coroutines via `loop.create_task` inside one `call_soon_threadsafe` per loop shard.
- [x] 5. Rename `src/py/vertebra/server/_asgi/_extensions.py` to `src/py/vertebra/server/_asgi/_wire.py` (`PYB-23`, `PYB-24`):
  - Move `LitestarExtension` to `src/py/vertebra/extensions/litestar/__init__.py` (using a precompiled route table instead of rebuilding per request), delete `FastApiExtension` and the unwired `register_extension`/`get_extensions` global registry, remove all Litestar imports and re-exports from `server/_asgi/`, and import `encode_json_bytes` from `vertebra.utils.serializers` (not `_json`).
- [x] 6. Update `src/py/vertebra/server/_asgi/__init__.py`, `src/py/vertebra/server/worker.py`, `src/py/vertebra/server/_dispatch.py`, and the ASGI test files (`test_asgi.py`, `test_asgi_scope_and_extensions.py`, `test_realtime_backpressure.py`).
- [x] 7. Commit: `refactor(asgi): use eager_task_factory, merge AsgiAdapter into AsgiRunner, and fix extension advertising` (signed), staging exactly the paths in `files`.
