# 4.3 Explicit file bodies

## Objective

Eliminate the `x-vertebra-sendfile` and `x-vertebra-sendfile-range` response headers across RSGI, WSGI, and ASGI so file responses never send empty bodies or leak internal filesystem paths to HTTP clients (`PYB-01`). Model file responses explicitly on `Response` (`ResponsePayload::{Bytes, File { path, offset, len }}`), read file ranges inside `py.detach` during response submission / `Response.from_file`, delete the blocking file-read branch from the `Response.body` getter (`PYB-04`), stat WSGI file wrappers once inside `py.detach` (`PYB-32`), and make `stream_file_chunks` in `file_io.rs` allocate each `PyBytes` chunk once via `PyBytes::new_with` (`PYB-42`).

## Context

- **`PYB-01` (`src/rs/vertebra-py/src/rsgi_protocol.rs:156-221`, `src/rs/vertebra-py/src/wsgi_worker.rs:117-120`, `src/py/vertebra/server/_asgi/_queues.py:169-180`, `src/py/vertebra/server/_wsgi/_adapter.py:103-104`):** Four producers attach `x-vertebra-sendfile` and `x-vertebra-sendfile-range` headers to responses, expecting `vertebra-http` to intercept them. `rg -i "x-vertebra|sendfile" src/rs/vertebra-http src/rs/vertebra-core` returns 0 hits. As a result, `RsgiHttpProtocol.response_file` and `response_file_range` set an empty `body: Bytes::new()` in Rust so clients receive 0 body bytes and the server's absolute filesystem path in the `x-vertebra-sendfile` header.
- **`PYB-04` (`src/rs/vertebra-py/src/response.rs:142-168`):** The Python `Response.body` property getter inspects `self.headers` for `x-vertebra-sendfile` and runs blocking `std::fs::File::open`/`seek`/`read_exact` while holding the GIL.
- **`PYB-32` (`src/py/vertebra/server/_wsgi/_adapter.py:80-82`, `_wsgi/_extensions.py:31-42`, `src/rs/vertebra-py/src/wsgi_environ.rs:172-183`, `wsgi_worker.rs:79-83`):** WSGI file wrappers stat the file up to 3 times (including under the GIL in `WsgiFileWrapper::py_new`), read the entire file into memory, and also attach `x-vertebra-sendfile`.
- **`PYB-42` (`src/rs/vertebra-py/src/file_io.rs:44-95`):** `stream_file_chunks` reads chunks into `Vec<Vec<u8>>`, converts each to `PyBytes`, and `_queues.py:176-177` joins them with `b"".join(...)` (3 copies).
- **Symbol overlap note (depends on 4.2):** Modifies `response.rs`, `transport.rs`, `file_io.rs`, and `_vertebra.pyi` on top of Task 4.1 and Task 4.2.
- **Strategy justification:** `regression_tdd` is required because RSGI `response_file` / `response_file_range` currently deliver empty bodies over the transport and all four file paths leak `x-vertebra-sendfile` headers.
