# 4.6 Event loop pool

## Objective

Rename `src/py/vertebra/server/_runtime_tuning.py` to `src/py/vertebra/server/_loops.py` defining `EventLoopPool` and delete the duplicate `AsyncRuntime` class from `src/py/vertebra/server/_native.py` (`PYB-08`), replace the state-mutating `.loop` property with explicit `primary_loop` and `next_loop()` (`PYB-09`), eliminate the extra `_wrap()` coroutine per scheduled task (`PYB-10`), size worker loop shards from `VERTEBRA_LOOP_SHARDS` (defaulting to `1` on GIL builds and `CgroupQuota.detect().effective_workers` on 3.14t) instead of forwarding `VERTEBRA_WORKERS` (`PYB-02`), and unify GIL status and quarantine handling in `src/py/vertebra/server/_gil_audit.py` (`PYB-51`, `PYB-52`).

## Context

- **`PYB-02` (`src/py/vertebra/supervisor/_worker.py:50`, `src/py/vertebra/server/_native.py:229-242`):** `VERTEBRA_WORKERS` specifies the OS worker process count in `vertebra-http`, but `supervisor/_worker.py:50` passes `int(os.environ.get("VERTEBRA_WORKERS", "1"))` as `worker_count` to `run_worker`, which sets `pool_size = worker_count` on `AsgiEventLoopPool`. Under `vtb-shm-asgi-4w`, each of the 4 worker processes spawns 4 event-loop threads (16 loops contending on 4 GILs).
- **`PYB-08` (`src/py/vertebra/server/_native.py:57-167` vs `src/py/vertebra/server/_runtime_tuning.py:47-246`):** `AsyncRuntime` duplicates `spawn`, `spawn_batch`, `schedule`, `schedule_batch`, and `stop` of `AsgiEventLoopPool` for a single loop, and `_asgi/_runner.py:19` imports `AsyncRuntime` from `_native`, creating a circular dependency.
- **`PYB-09` & `PYB-10` (`src/py/vertebra/server/_runtime_tuning.py:90-93,148-209`, `_native.py:125-167,363-367,483`):** `AsgiEventLoopPool.loop` is a `@property` that increments the round-robin index on every attribute access (`return self.next_loop()`), while callers read `runtime.loop` expecting a stable loop reference. `schedule` and `schedule_batch` wrap every coroutine in an extra `async def _wrap()` coroutine plus a task plus a per-item closure.
- **`PYB-51` & `PYB-52` (`src/py/vertebra/server/_gil_audit.py:17-22,55-95`, `_runtime_tuning.py:26-31`, `_native.py:236`):** `is_free_threaded` and `_is_gil_currently_enabled` duplicate `sys._is_gil_enabled()`; `GilAuditReport.audit` accepts two alias parameters (`before_modules` and `before_extensions`) and is called in `run_worker` with no pre-import baseline (flagging every loaded C extension as suspect); `quarantine_unsafe_modules` logs a message claiming to fall back to a single standard asyncio loop without modifying any loop configuration.
- **Symbol overlap note (depends on 4.5):** Touches `server/_native.py`, `server/_asgi/_runner.py`, and `supervisor/_worker.py` only for `EventLoopPool`, `loop_shards`, and `GilAuditReport` wiring; Task 4.7 splits `_native.py` and Task 4.8 refactors `_asgi/_runner.py`.
- **Strategy justification:** `regression_tdd` is required because `VERTEBRA_WORKERS=4` on a GIL build currently spawns 4 event-loop threads inside a single worker process instead of 1, and `quarantine_unsafe_modules` leaves multi-shard loop sizing unchanged.

## Steps

- [x] 1. In `src/py/tests/unit/server/test_runtime_tuning.py`, add three failing regression tests:
  - `test_worker_with_vertebra_workers_env_defaults_to_single_loop_shard_on_gil`: sets `VERTEBRA_WORKERS=4` (with `VERTEBRA_LOOP_SHARDS` unset) on a GIL build and asserts `resolve_loop_shards()` returns `1` (and honors `VERTEBRA_LOOP_SHARDS=2` when explicitly set).
  - `test_event_loop_pool_primary_loop_is_idempotent`: constructs `EventLoopPool(size=4)` and asserts repeated reads of `pool.primary_loop` return shard 0 without advancing the `next_loop()` round-robin counter.
  - `test_gil_audit_quarantine_forces_single_loop_shard`: runs `GilAuditReport.audit(before_extensions=baseline)` when a non-free-threaded extension was loaded and asserts `quarantine_unsafe_modules(pool_config)` forces `loop_shards = 1` and standard `asyncio.DefaultEventLoopPolicy()`.
- [x] 2. In `src/py/vertebra/server/_gil_audit.py` (`PYB-51`, `PYB-52`):
  - Define `@staticmethod def gil_enabled() -> bool` on `GilAuditReport` and derive `def is_free_threaded() -> bool: return not GilAuditReport.gil_enabled()`.
  - Remove the duplicate `before_modules` parameter from `GilAuditReport.audit(cls, *, before_extensions: frozenset[str] | None = None) -> GilAuditReport`.
  - Make `quarantine_unsafe_modules(self, requested_shards: int) -> int` set `asyncio.set_event_loop_policy(asyncio.DefaultEventLoopPolicy())` and return `1` when `self.reenabled_gil` or `self.suspect_extensions` is non-empty.
- [x] 3. Rename `src/py/vertebra/server/_runtime_tuning.py` to `src/py/vertebra/server/_loops.py` (delete `_runtime_tuning.py`) and refactor `AsgiEventLoopPool` into `EventLoopPool` (`PYB-08`, `PYB-09`, `PYB-10`):
  - Delete `AsyncRuntime` from `src/py/vertebra/server/_native.py:57-167` and use `EventLoopPool` everywhere (`size=1` for single-loop mode).
  - Replace the `@property def loop` with `@property def primary_loop(self) -> asyncio.AbstractEventLoop` (returning `self._loops[0]`) and explicit `def next_loop(self) -> asyncio.AbstractEventLoop`.
  - In `schedule(self, coro)` and `schedule_batch(self, coros)`, use `asyncio.run_coroutine_threadsafe(coro, loop)` (or create the task on the target loop with a done-callback bridging the `concurrent.futures.Future` in one `call_soon_threadsafe` per shard batch) without an inner `async def _wrap()` coroutine.
  - Add `resolve_loop_shards(explicit: int | None = None, audit_report: GilAuditReport | None = None) -> int` reading `VERTEBRA_LOOP_SHARDS` (defaulting to `1` when `GilAuditReport.gil_enabled()` is true, or `CgroupQuota.detect().effective_workers` on free-threaded 3.14t) and applying `audit_report.quarantine_unsafe_modules(...)` (`PYB-02`).
- [x] 4. In `src/py/vertebra/supervisor/_worker.py`, snapshot `before_extensions = GilAuditReport.snapshot_loaded_extensions()` *before* calling `import_app(app_path)`, stop reading `VERTEBRA_WORKERS` as `worker_count`, and pass `before_extensions=before_extensions` into `run_worker` (`PYB-02`, `PYB-51`). Update `src/py/vertebra/server/_native.py` and `src/py/vertebra/server/_asgi/_runner.py` to import `EventLoopPool` from `vertebra.server._loops`.
- [x] 5. Commit: `fix(server): unify EventLoopPool in _loops.py and size shards from VERTEBRA_LOOP_SHARDS` (signed), staging exactly the paths in `files`.
