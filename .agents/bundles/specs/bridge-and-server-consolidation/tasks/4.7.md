# 4.7 Worker and dispatch split

## Objective

Split the 849-line `src/py/vertebra/server/_native.py` into `src/py/vertebra/server/worker.py` (`Worker` runtime class and `run_worker`) and `src/py/vertebra/server/_dispatch.py` (`HandlerSpec`, `BatchDispatchPlan`, module-level runner functions, and centralized error handling), and create `src/py/vertebra/server/_protocol.py` for the single `detect_interface` function (`PYB-21`). Precompile `dict[int, HandlerSpec]` once at worker startup (`PYB-13`), replace per-request closures with module-level functions (`PYB-12`), replace all 14 inline 500/404 `Response(...)` constructions with `Response.error(status, request_id)` and wire `error_handler` (`PYB-14`, `PYB-17`), delete the test-only `async_mode=False` branch and dead `_handler_params`/`_handler_meta`/`_resolve_handler_args`/`_call_handler`/`_coerce_response` try-except (`PYB-15`, `PYB-16`, `PYB-48`), instantiate mounts once at startup (`PYB-19`), and eliminate all re-export shims, `global` statements, function-scoped imports, and private-module serializer imports (`PYB-22`, `PYB-62`).

## Context

- **`PYB-12` & `PYB-13` (`src/py/vertebra/server/_native.py:403,501,572-603,624-658,819`):** `_handler_dispatch_spec` is called twice per request (once in `_partition_batch`, again in `_dispatch_batch`), and `_dispatch_batch` allocates a new closure or coroutine function per request inside the loop.
- **`PYB-14` & `PYB-17` (`src/py/vertebra/server/_native.py:184,196,453,464,482,513-529,561,580,595-601,630-636,656,661`):** `run_worker(error_handler=...)` discards `error_handler` (`_ = error_handler`), `_dispatch_batch(handlers=...)` discards `handlers`, and 14 sites construct inconsistent 500/404 `Response` objects inline.
- **`PYB-15`, `PYB-16`, `PYB-48` (`src/py/vertebra/server/_native.py:485-563,798-841`):** The blocking `async_mode=False` branch of `_dispatch_batch` is never used by `run_worker`; `_handler_params` has zero references; `_handler_meta`, `_resolve_handler_args`, and `_call_handler` are called only by `test_runner.py`; and `_coerce_response` wraps `raw.request_id = request_id` in a `try/except AttributeError` that can never trigger because `Response.request_id` has a setter.
- **`PYB-19` & `PYB-21` (`src/py/vertebra/server/_native.py:290-306,688-696`, `src/py/vertebra/server/_rsgi/_adapter.py:40-56`):** `_run_shm_event_loop` checks `type(adapter).__name__ in {"AsgiRunner", ...}` to see if mounts are already instantiated, and `_detect_protocol` in `_native.py` disagrees with `detect_interface` in `_rsgi/_adapter.py`.
- **`PYB-22` & `PYB-62` (`src/py/vertebra/server/_native.py:31,36-43,195,197-198,283,327,361,428,567,673-680`, `supervisor/_worker.py:28`):** `_native.py`, `_loops.py`, and `supervisor/_worker.py` re-export symbols from other modules, `_native.py` uses 5 `global` statements (`_RUNNING`, `_wsgi_executor`) and 16 function-scoped imports, and imports `from vertebra.utils.serializers._json import encode_json_bytes` from the private module instead of `from vertebra.utils.serializers import encode_json_bytes`.
- **Symbol overlap note (depends on 4.6):** Splits `server/_native.py` (after Task 4.6 removed `AsyncRuntime`) into `server/worker.py` and `server/_dispatch.py` and deletes `_native.py`.
- **Strategy justification:** `characterization` is used because worker batch partitioning, sync/async handler invocation, mount routing, and custom `error_handler` invocation preserve their public contract while eliminating per-request closures, double `lru_cache` lookups, and module globals, gated by `test_runner.py` and `bench-micro`.

## Steps

- [x] 1. Create `src/py/vertebra/server/_protocol.py` (`PYB-21`) containing the single `detect_interface(app: Any) -> Literal["asgi", "wsgi", "rsgi"]` function; update `src/py/vertebra/server/_rsgi/_adapter.py` and `src/py/vertebra/server/worker.py` to import `detect_interface` from `vertebra.server._protocol`, and delete `_detect_protocol`.
- [x] 2. Create `src/py/vertebra/server/_dispatch.py` (`PYB-12`, `PYB-13`, `PYB-14`, `PYB-15`, `PYB-16`, `PYB-17`, `PYB-48`, `PYB-62`):
  - Import `encode_json_bytes` from `vertebra.utils.serializers` at module top level.
  - Define `HandlerSpec(msgspec.Struct, frozen=True, gc=False, array_like=True)` with `compile_handler_table(handlers: Mapping[int, Callable[..., Any]]) -> dict[int, HandlerSpec]` precompiled once at worker startup (`PYB-13`).
  - Store `HandlerSpec` directly inside `BatchDispatchPlan.sync_native` and `BatchDispatchPlan.async_native` tuples so `dispatch_batch` performs zero `lru_cache` lookups.
  - Write module-level `_invoke_sync_handler(spec: HandlerSpec, request: Request, error_handler: ErrorHandler | None) -> Response` and `async def _invoke_async_handler(spec: HandlerSpec, request: Request, error_handler: ErrorHandler | None) -> Response` (`PYB-12`), routing uncaught exceptions through `build_error_response(exc, request, error_handler)` which calls `error_handler(request, exc)` when provided and falls back to `Response.error(500, request.request_id)`, and returning `Response.error(404, request.request_id)` for unmatched routes (`PYB-14`, `PYB-17`).
  - Delete the `async_mode=False` branch of `_dispatch_batch`, `_handler_params`, `_handler_meta`, `_resolve_handler_args`, `_call_handler`, and the dead `except AttributeError` branch in `_coerce_response` (`PYB-15`, `PYB-16`, `PYB-48`).
- [x] 3. Create `src/py/vertebra/server/worker.py` and delete `src/py/vertebra/server/_native.py` (`PYB-19`, `PYB-22`, `PYB-62`):
  - Encapsulate worker state (`running: bool`, `loop_pool: EventLoopPool`, `sync_executor: ThreadPoolExecutor`, `handler_specs: dict[int, HandlerSpec]`, `mounts: list[MountEntry]`, `error_handler: ErrorHandler | None`) on a `Worker` class so zero `global` statements exist.
  - Instantiate mount runners (`AsgiRunner`, `WsgiAdapter`, `RsgiAdapter`) once in `Worker.__init__` for both bridge and SHM topologies, eliminating the `type(adapter).__name__` string check (`PYB-19`).
  - Place all imports at module top level (zero `PLC0415` function-scoped imports) and remove all re-export shims from `worker.py`, `_loops.py`, and `supervisor/_worker.py` (`PYB-22`).
- [x] 4. Update `src/py/vertebra/server/__init__.py`, `src/py/vertebra/supervisor/_worker.py`, `src/py/tests/unit/server/test_runner.py`, `src/py/tests/unit/server/test_rsgi_protocol.py`, and `src/py/tests/unit/ffi/test_ffi.py` to import `Worker`, `run_worker`, `HandlerSpec`, `BatchDispatchPlan`, `partition_batch`, and `dispatch_batch` from `vertebra.server.worker` and `vertebra.server._dispatch`, adding `test_custom_error_handler_invoked_on_sync_and_async_failure` in `test_runner.py`.
- [x] 5. Commit: `refactor(server): split _native.py into worker.py and _dispatch.py and wire error_handler` (signed), staging exactly the paths in `files`.
