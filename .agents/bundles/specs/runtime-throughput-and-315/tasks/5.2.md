# Task 5.2: Complete LitestarFastPathBypass.dispatch and Rust middleware offload configuration wiring

## Objective

Complete `LitestarFastPathBypass.dispatch` so guard-free, middleware-free Litestar routes execute directly on Vertebra's compiled `FastPathRoute` pipeline without per-request Litestar ASGI scope/request/middleware construction, serialize `LitestarOffloadPlan` into `VERTEBRA_OFFLOAD_CONFIG` / `vertebra-http` config JSON so Rust executes offloaded CORS, compression, and static asset mounts, and guard `app.compression_config = None` so standalone ASGI test/server runs retain Python compression when `vertebra-server` is not active.

## Context

- `LitestarFastPathBypass.dispatch` (`src/py/vertebra/extensions/litestar/fastpath.py:216-220`) currently returns `None` unconditionally, leaving compiled `FastPathRoute` entries unused at runtime.
- `LitestarPlugin.on_app_init` (`src/py/vertebra/extensions/litestar/plugin.py:130-137`) builds `self._offload_plan` and unconditionally clears `app_config.compression_config = None`, even when Litestar runs under `TestClient` or standalone ASGI without `vertebra-server`, and never exports the serialized `LitestarOffloadPlan` for `vertebra-http` to consume.

## Steps

1. Write failing tests in `src/py/tests/unit/server/test_litestar_direct_fastpath.py`, `test_litestar_rust_offload.py`, and `src/py/tests/unit/extensions/test_litestar_plugin.py` verifying: (a) `LitestarFastPathBypass.dispatch` executes compiled sync and async `FastPathRoute` handlers (extracting typed path/query params and `msgspec` JSON request bodies and serializing responses via `encode_json_bytes`), returning `(status, content_type, body)` directly while returning `None` for non-eligible routes; (b) `LitestarOffloadPlan.to_server_config()` exports JSON matching `vertebra-http`'s `ServerConfig` CORS/compression/static-asset schema; (c) `LitestarPlugin.on_app_init` preserves `app_config.compression_config` unless `VERTEBRA_SERVER_ACTIVE=1` (or `VERTEBRA_RUST_OFFLOAD=1`) confirms `vertebra-http` ingress compression offload is active.
2. Implement `LitestarFastPathBypass.dispatch` (and async `adispatch` / batch integration hook for `AsgiRunner` when a mounted ASGI app exposes `__vertebra_fastpath__`) in `src/py/vertebra/extensions/litestar/fastpath.py` using centralized `decode_json` / `encode_json_bytes` from `vertebra.utils.serializers` and zero inline `#` comments.
3. Add `to_server_config()` serialization on `LitestarOffloadPlan` in `src/py/vertebra/extensions/litestar/offload.py` and wire `LitestarPlugin` (`plugin.py`) + `_launch.py` / `_worker.py` so `vertebra-http` receives offloaded CORS, compression, and static asset rules, only clearing `app_config.compression_config` when running behind `vertebra-http` with Rust compression enabled.
