# Task 5.4: Align Litestar v2/v3 layer resolution, zstd_compress_level offload, and fastpath middleware disqualifiers

## Objective

Align Litestar v2 in-place `resolve_opts()` and `ownership_layers` hook/metadata resolution, support Litestar v3 `CompressionConfig.zstd_compress_level`, and preserve Python compression/CORS disqualifiers when Rust offload is disabled or skipped.

## Context

Litestar re-review on `cf5979e..8768f70` identified three compatibility edge cases when real Litestar v2 (`2.24.0`) or v3 is installed:
- `BaseRouteHandler.resolve_opts()` in Litestar v2 mutates `self.opt` in place and returns `None`, causing `dict(resolve_fn())` in `_get_handler_opt` to raise `TypeError`.
- Litestar v2 resolves `Controller`/`Router` `after_request` via `ownership_layers` (without a `resolve_after_request` method) and layered `type_decoders`/`response_class` via `resolve_type_decoders` / `resolve_response_class`.
- Litestar v3 `CompressionConfig` uses `zstd_compress_level` (matching `gzip_compress_level`), and `fastpath.py` skipped Python compression/CORS disqualifiers whenever `VERTEBRA_SERVER_ACTIVE=1` even if `offload_compression=False`, `offload_cors=False`, or an unsupported compression backend left Python middleware active.

## Steps

1. Add failing regression tests in `src/py/tests/unit/server/test_litestar_rust_offload.py` and `src/py/tests/unit/server/test_litestar_direct_fastpath.py` reproducing v2 `resolve_opts() -> None`, v2 `ownership_layers` `after_request` and layered `type_decoders`/`response_class`, v3 `zstd_compress_level` extraction, non-offloaded compression/CORS disqualifiers under `VERTEBRA_SERVER_ACTIVE=1`, Litestar-compatible `CSRFConfig`/`CompressionConfig` kwargs, `frozen=True, gc=False` `CreateOrderPayload`, and `AsgiProtocol` file/SSE framing.
2. Update `_get_handler_opt` and `_extract_compression_config` in `src/py/vertebra/extensions/litestar/offload.py`.
3. Update `_has_lifecycle_hook`, `_compile_routes_from_table`, `_handler_has_custom_response_metadata`, and `_resolve_request_body` PEP 604 `isinstance` in `src/py/vertebra/extensions/litestar/fastpath.py`.
4. Run `uv run pytest`, `make lint-all`, and `make review-check`.
