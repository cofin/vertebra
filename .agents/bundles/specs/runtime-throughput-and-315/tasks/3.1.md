# Task 3.1: Remove ingress hot-path locks, redundant h2c peek, and MessagePack header transcoding, and wire Rust middleware offloads

## Objective

Eliminate per-request global `Mutex` acquisitions, `Instant::now()` syscalls, per-request `HealthEndpoint` allocations, discarded `h2c` `MSG_PEEK` syscalls, `RequestBatcher` heap drains, and MessagePack request header transcoding in `vertebra-http`, while tuning Hyper's `http1::Builder`, binding `SO_REUSEPORT` TCP sockets via `socket2`, and wiring Rust CORS, compression, and static asset offloads into `response::handle`.

## Context

- `BackpressureController::try_acquire` and `record_success`/`record_timeout` (`src/rs/vertebra-http/src/backpressure.rs:107-177`) acquire a global `std::sync::Mutex<CircuitBreakerInner>` + `Instant::now()` + `VecDeque` prune twice on every HTTP request across all Tokio worker threads, plus a global Tokio `Semaphore` permit per request.
- `response::handle` (`src/rs/vertebra-http/src/response.rs:163`) constructs `HealthEndpoint::new(HealthConfig::default())` (allocating two `String`s) on every request.
- `server.rs:148` calls `h2c::detect_cleartext_protocol(&stream).await` (`MSG_PEEK` syscall) on every accepted TCP connection and discards the result with `let _ = ...`; `serve_connection` also uses default untuned `auto::Builder` instead of direct tuned `http1::Builder` on HTTP/1.1 cleartext listeners, and `TcpListener::bind` lacks `SO_REUSEPORT` (`backlog = 2048`).
- `RequestBatcher` (`src/rs/vertebra-http/src/batcher.rs:95, 198-216`) replaces its `Vec<PendingRequest>` buffer on every flush instead of double-buffering, and encodes headers into `Vec<(&[u8], &[u8])>` + MessagePack only for `shm.rs` / `bridge.rs` to decode MessagePack and re-encode into compact binary format.
- `cors.rs`, `compression.rs`, and `assets.rs` are implemented and tested in isolation in `vertebra-http` (`#[allow(dead_code)]`) without being wired into `ServerConfig` / `ServerState` / `response::handle`.

## Steps

1. Add behavioral tests in `src/rs/vertebra-http/tests/it/ingress_fastpath.rs` and `server.rs` verifying: (a) lock-free sliding-window `BackpressureController` circuit-breaker tripping, cooldown recovery, and concurrency cap enforcement under multi-threaded load; (b) single-pass compact header encoding from `http::HeaderMap` preserving duplicate headers and exact bytes; (c) configured Rust CORS preflight/response headers, `Accept-Encoding` response compression offload, and static asset serving in `response::handle`; (d) `SO_REUSEPORT` dual-listener binding when enabled.
2. Refactor `BackpressureController` (`src/rs/vertebra-http/src/backpressure.rs`) to replace `Mutex<CircuitBreakerInner>` and per-request `Semaphore::try_acquire_owned` with lock-free atomic `in_flight: CacheLine<AtomicUsize>` RAII `PermitGuard`, atomic sliding-window time buckets (`[AtomicU64; 16]` packing epoch-second + count), and `circuit_open_until_ms: AtomicU64` driven by a coarse monotonic millisecond clock.
3. Cache `health_endpoint: HealthEndpoint`, optional `cors_policy: Option<CorsPolicy>`, `compression_config: Option<CompressionConfig>`, and `static_assets: Vec<StaticAssetMount>` on `ServerState` (`src/rs/vertebra-http/src/server.rs` and `config.rs`, parsed from config JSON / env), and wire them into `src/rs/vertebra-http/src/response.rs` (`0` per-request allocations when unconfigured).
4. Update `src/rs/vertebra-http/src/server.rs` to bind TCP sockets with `socket2` (`SO_REUSEADDR`, `#[cfg(unix)] SO_REUSEPORT` when `reuse_port` is enabled, `TCP_NODELAY`, `listen(2048)`), remove the discarded `h2c::detect_cleartext_protocol` `MSG_PEEK` when `h2c` is not enabled, and serve cleartext HTTP/1.1 connections directly via `hyper::server::conn::http1::Builder::new().keep_alive(true).pipeline_flush(false).max_buf_size(65536).timer(TokioTimer::new())` (falling back to `h2c` peek + `auto::Builder` only when `h2c` is enabled).
5. Double-buffer `RequestBatcher` (`pending` + `draining` `Vec<PendingRequest>`) in `src/rs/vertebra-http/src/batcher.rs` so flushes reuse vector capacity with zero heap allocations, and encode `http::HeaderMap` directly into compact binary `Bytes` (`[name_len: u8][name][val_len: u16 LE][val]`) in one pass without MessagePack intermediate buffers.
