# Task 5.3: Harden SHM tier wakeups, admission fences, ingress Vary/compression offloads, cibuildwheel 3.15 matrix, and Litestar fastpath parity

## Objective

Eliminate concurrency and protocol edge cases uncovered during review across `TieredRingSet` active-tier ordering, `BackpressureController` `SeqCst` queue wakeups, `vertebra-http` `Vary` preservation and compressible media-type filtering, `cibuildwheel` `v4.3.4` Python `3.15`/`3.15t` wheel targets, `Worker._process_batch` root ASGI fastpath routing, and `LitestarPlugin` / `LitestarFastPathBypass` real-Litestar lifecycle, body-replay, exception, middleware, file/SSE ASGI protocol, and test-hygiene contracts.

## Context

- `src/py/vertebra/server/worker.py:620` passes `single_root_asgi._app` instead of `single_root_asgi.dispatch_app` to `drive_asgi_batch`, bypassing `__vertebra_fastpath__` on standalone root-mounted ASGI apps.
- `.github/workflows/release.yaml` pins `pypa/cibuildwheel@v2.22.0` without `cp314t-*` / `cp315t-*` in `CIBW_BUILD`.
- `src/rs/vertebra-core/src/transport/ring_pair.rs` calls `mark_tier_active(bit)` after publishing `write_head`, allowing consumers checking `active_tier_mask()` to miss newly written medium/large/xlarge slots until `active_flags` is set.
- `src/rs/vertebra-http/src/backpressure.rs` lacks a `SeqCst` barrier between `in_flight.fetch_sub` and `queue_depth.load`, `cors.rs` / `compression.rs` overwrite `Vary` instead of appending tokens, `CompressionOffloadConfig::compress_if_eligible` compresses incompressible `Content-Type` headers, and `batcher::http_version_tag` diverges from `response::version_tag`.
- `LitestarPlugin.on_app_init` appends to nonexistent `app_config.on_app_init`, breaking real `Litestar(plugins=[LitestarPlugin()])` initialization; `LitestarFastPathBypass` drains `receive()` without body replay on fallback, lets `HTTPException` escape as `500`, ignores `after_exception` / `csrf_config` / `allowed_hosts` / active Python `compression_config` and `cors_config` / Litestar's default `HTTPException` handler / v3 `resolve_*` deprecations / `Empty` `ScopeState.body`, and emits `http.response.pathsend` / SSE frames without `http.response.start`.

## Steps

1. Add focused regression tests into canonical existing test suites (`test_litestar_plugin.py`, `test_litestar_direct_fastpath.py`, `test_litestar_rust_offload.py`, `test_runner.py`, `test_packaging_and_pgo.py`, `shm.rs`, `ingress_fastpath.rs`), and align Litestar unit tests with `import_optional`, centralized `encode_json_bytes`/`decode_json`, and `msgspec.Struct(..., frozen=True, gc=False)`.
2. Fix `TieredRingSet` active-flag ordering and fallback `has_data_acquire()` checks in `src/rs/vertebra-core/src/transport/ring_pair.rs`.
3. Add `SeqCst` wakeup fences in `src/rs/vertebra-http/src/backpressure.rs`, shared `append_vary_token` across `cors.rs` and `compression.rs`, compressible `Content-Type` gating in `CompressionOffloadConfig::compress_if_eligible`, `batcher::http_version_tag` alignment in `batcher.rs`, and `ensure_finalized` invocation in `vertebra-http/src/main.rs`.
4. Fix `Worker._process_batch` (`single_root_asgi.dispatch_app`), `Request.raw_query -> bytes` in `_vertebra.pyi`, `.agents/skills/review-core/references/areas.toml` (`_bundler.pyi`), and `.github/workflows/release.yaml` (`pypa/cibuildwheel@v4.3.4` with `cp312-* cp313-* cp314-* cp314t-* cp315-* cp315t-*`).
5. Implement `LitestarPlugin.ensure_finalized(app)` (removing `app_config.on_app_init.append`) and harden `LitestarFastPathBypass` / `offload.py` (`ScopeState.body` `Empty` sentinel + pre-seeding + `receive()` replay on fallback, `HTTPException` status/detail JSON serialization, `after_exception`/`csrf_config`/`allowed_hosts`/`compression_config`/`cors_config` checks, default Litestar `HTTPException` filter, v2/v3 layer resolution without deprecation warnings, `http.response.start` before `pathsend` and `http.response.body` SSE streaming, `UploadFile` cleanup in `finally`, `response_headers`/`cookies`/`etag`/`background`/`request_max_body_size` guards, `text/plain; charset=utf-8` default for `-> str`, first-occurrence scalar query values, and unsupported compression backend rejection).
6. Rebuild native extensions with `make dev` and run full verification gates (`make rs-test`, `make py-test`, `make ts-test`, `make coverage`, `make lint-all`, `make review-check`).
