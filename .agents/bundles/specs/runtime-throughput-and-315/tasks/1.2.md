# Task 1.2: Fix CLI env preservation, ASGI App mount guard, Python 3.15 build/PGO/JIT detection, and benchmark harness

## Objective

Preserve `VERTEBRA_WORKERS`, `VERTEBRA_TOPOLOGY`, and `VERTEBRA_THREADS` environment variables in `vtb run` when CLI flags are omitted, add `--jit / --no-jit` (`PYTHON_JIT`), prevent double-mounting `App` instances under `--asgi` (`VERTEBRA_NATIVE=0`), extend `PythonBuildInfo` for Python 3.15 tail-call/JIT/free-threaded/frame-pointer detection, enable `panic = "abort"` and `make build-pgo`, and add Python `3.15`/`3.15t` CI/release/benchmark target support.

## Context

- `src/py/vertebra/cli/run.py` hardcodes `workers: int = 1` and `topology: str = "auto"`, and `_launch.py` unconditionally overwrites `os.environ["VERTEBRA_WORKERS"]` and `os.environ["VERTEBRA_TOPOLOGY"]`, clobbering caller environment variables in benchmark targets.
- `src/py/vertebra/supervisor/_worker.py:73-77` runs `isinstance(app, App)` before checking `VERTEBRA_NATIVE`, causing `vtb run app --asgi` (`VERTEBRA_NATIVE=0`) to mount the `App` twice.
- `PythonBuildInfo` in `src/py/vertebra/build/packaging/pgo.py` and `tools/pgo/python_pgo.py` lacks Python 3.14/3.15 fields (`is_tail_call_interp`, `is_jit_available`, `is_jit_enabled`, `is_free_threaded`, `has_frame_pointers`).
- `tools/benchmarks/targets.py` uses an unsupported `--workers` flag on `uvicorn`, passes env vars without CLI flags to `vtb-asgi`, and lacks `granian-rsgi` and embedded multi-worker targets.
- `src/rs/Cargo.toml` `[profile.release]` omits `panic = "abort"`, `Makefile` hardcodes `3.14t` in `bench-ft` and lacks `build-pgo`, and `.github/workflows/{ci.yml,release.yaml}` lack `"3.15"` and `"3.15t"`.

## Steps

1. Write failing unit tests in `src/py/tests/unit/cli/test_cli_commands.py`, `src/py/tests/unit/build/test_packaging_and_pgo.py`, and `src/py/tests/unit/test_bench_infrastructure.py` covering env-var preservation (`VERTEBRA_WORKERS`, `VERTEBRA_TOPOLOGY`, `VERTEBRA_THREADS`), `--jit` (`PYTHON_JIT=1` on GIL builds, skipped/warned on free-threaded builds), `VERTEBRA_NATIVE=0` `App` ASGI routing without double-mount, `PythonBuildInfo` tail-call/JIT/free-threaded/frame-pointer detection, and benchmark target command generation.
2. Update `src/py/vertebra/cli/run.py` and `src/py/vertebra/cli/_launch.py` so `workers: int | None = None`, `topology: str | None = None`, `threads: int | None = None`, and `jit: bool | None = None` fall back to `VERTEBRA_WORKERS`, `VERTEBRA_TOPOLOGY`, `VERTEBRA_THREADS`, and `VERTEBRA_JIT` when unset, setting `PYTHON_JIT="1"` when JIT is requested on non-free-threaded Python.
3. Update `src/py/vertebra/supervisor/_worker.py` so `isinstance(app, App)` native route registration only runs when `native_flag` is truthy (`"1"`, `"true"`, `"yes"`), and `VERTEBRA_NATIVE=0` routes `App` exclusively through `runner.mount("/", app)` as ASGI.
4. Extend `PythonBuildInfo`, `CPYTHON_PGO_FLAGS`, and `check_pgo_availability` in `src/py/vertebra/build/packaging/pgo.py` and `tools/pgo/python_pgo.py` with `is_tail_call_interp: bool = False`, `is_jit_available: bool = False`, `is_jit_enabled: bool = False`, `is_free_threaded: bool = False`, and `has_frame_pointers: bool = False`.
5. Update `tools/benchmarks/targets.py` to pass explicit `--topology` and `--workers` flags to `vtb`, add `vtb-embedded`, `vtb-shm`, and `granian-rsgi` targets, and remove single-process `uvicorn` when `workers > 1` or pass `--workers` cleanly when supported.
6. Add `panic = "abort"` to `[profile.release]` in `src/rs/Cargo.toml`, parameterize `FT_PYTHON` in `Makefile` (`3.15t` with fallback to `3.14t`) and add `build-pgo`, and add `"3.15"` / `"3.15t"` to `.github/workflows/ci.yml` and `.github/workflows/release.yaml`.
