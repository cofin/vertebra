# Task 2.1: Synchronize AGENTS.md quick commands and OKF v0.2 bundle symbol and PGO references

## Objective

Synchronize `AGENTS.md` and the OKF v0.2 product and knowledge chapters with Python `3.12`–`3.15` / `3.14t` / `3.15t` support, `make build-pgo` / `make bench-all` / `make bench-report` / `mypy.stubtest` quick commands, the new two-phase Rust PGO and `vtb build --profdata --server-binary` packaging contracts, and exact source-verified symbol names across `Cargo.toml`, `_dispatch.py`, `response.rs`, and `worker.py`.

## Context

- `AGENTS.md` still says `Python 3.12+/3.14t`, omits `agent` from the `domains/` list, omits `make build-pgo`, `make bench-all`, and `make bench-report` from `Quick Verification Commands`, and describes `make bench-ft` as `3.14t`-only rather than `FT_PYTHON=3.15t` with `3.14t` fallback.
- Four OKF bundle chapters have minor symbol mismatches against live code:
  1. `packaging-and-pgo.md:34` describes `src/rs/Cargo.toml` `[profile.release]` as `lto = "fat"` and `strip = "symbols"` instead of `lto = true`, `codegen-units = 1`, `opt-level = 3`, `panic = "abort"`.
  2. `product-guidelines.md:36` lists `BatchDispatchPlan` field `sync_inline` instead of `sync_native` (`_dispatch.py:283`).
  3. `platform-and-lifecycle.md:67` writes `state.health.try_intercept(path)` instead of `state.health_endpoint.try_intercept(req_path)` (`response.rs:54`).
  4. `hot-path-and-async-dispatch.md:47` and `pyo3-and-python-runtime.md:45` write `single_root_asgi.dispatch_app(batch)` instead of `drive_asgi_batch(single_root_asgi.dispatch_app, batch, ...)` (`worker.py:615-621`).
- `packaging-and-pgo.md`, `cli.md`, `tech-stack.md`, `benchmarks-and-free-threaded.md`, `polyglot-test-matrix.md`, and `workflow.md` must also reflect `run_pgo_pipeline`, `EXTENSION_MANIFESTS`, `resolve_cargo_release_dir`, `vtb build --profdata --server-binary`, and `tools/pgo` inclusion in `ruff` and `mypy`.
