# 2.2 Resend, SendGrid, and Mailgun API transports and webhook HMAC signature verification

## Objective
Implement `ResendEmailTransport`, `SendGridEmailTransport`, and `MailgunEmailTransport` in `src/py/vertebra/framework/email/providers.py` with single and batch REST dispatch, `Idempotency-Key` header propagation, bounded retry with exponential backoff + `Retry-After` parsing on HTTP `429`/`5xx`, and `WebhookVerifier` supporting constant-time HMAC signature verification for Resend (Svix `svix-id`/`svix-timestamp`/`svix-signature`), SendGrid, and Mailgun delivery webhooks.

## Context
- `src/py/vertebra/framework/email/base.py`: `EmailBackendType` declares `"resend"`, `"sendgrid"`, and `"mailgun"`, which need concrete `EmailTransport` implementations.
- All JSON request encoding and response decoding must use `encode_json_bytes` and `decode_json` from `vertebra.utils.serializers` (`src/py/vertebra/utils/serializers/__init__.py:10,8`).
- Each provider has a distinct REST contract and webhook signing scheme:
  1. **Resend**: `POST https://api.resend.com/emails` and `POST https://api.resend.com/emails/batch` with `Authorization: Bearer <api_key>`, `Idempotency-Key: <key>`, JSON payload `{"from", "to", "cc", "bcc", "reply_to", "subject", "text", "html", "headers", "attachments": [{"filename", "content": base64}], "tags": [{"name", "value"}]}`. Webhooks use Svix HMAC-SHA256 over `f"{svix_id}.{svix_timestamp}.{raw_body}"` with a `whsec_<base64>` secret and `v1,<base64_sig>` header tokens.
  2. **SendGrid**: `POST https://api.sendgrid.com/v3/mail/send` with `Authorization: Bearer <api_key>`, JSON payload `{"personalizations": [{"to": [...], "cc": [...], "bcc": [...], "custom_args": metadata}], "from": {"email": ...}, "reply_to": {"email": ...}, "subject": ..., "content": [{"type": "text/plain", "value": ...}, {"type": "text/html", "value": ...}], "attachments": [{"content": base64, "filename": ..., "type": ...}]}` returning `202 Accepted` and `X-Message-Id`. Webhooks verify `X-Twilio-Email-Event-Webhook-Signature` / `X-Twilio-Email-Event-Webhook-Timestamp` via HMAC-SHA256 over `f"{timestamp}{raw_body}"`.
  3. **Mailgun**: `POST https://api.mailgun.net/v3/<domain>/messages` with HTTP Basic auth (`api:<api_key>`), `multipart/form-data` or URL-encoded fields (`from`, `to`, `cc`, `bcc`, `subject`, `text`, `html`, `h:Reply-To`, `h:X-Idempotency-Key`, `o:tag`, `v:<meta>`). Webhooks verify `signature={"timestamp", "token", "signature"}` using HMAC-SHA256 over `f"{timestamp}{token}"` against `webhook_secret`.
- `behavior_tdd` applies because `ResendEmailTransport`, `SendGridEmailTransport`, `MailgunEmailTransport`, and `WebhookVerifier` introduce new provider REST and webhook verification capabilities.

## Steps
- [x] 1. Create `src/py/vertebra/framework/email/providers.py` defining:
  - `HttpResponseData(msgspec.Struct, frozen=True, gc=False, kw_only=True)`: `status_code: int`, `headers: dict[str, str]`, `body: bytes`.
  - `HttpTransportClient(Protocol)` with `async def request(self, method: str, url: str, *, headers: Mapping[str, str], body: bytes, timeout_seconds: float = 10.0) -> HttpResponseData`, plus `UrllibHttpTransportClient` executing `urllib.request.Request` via `asyncio.to_thread` so zero external HTTP client dependencies are required while allowing test injection.
  - `_RetryableRestTransport`: shared base class implementing `_request_with_retry(self, method: str, url: str, *, headers: dict[str, str], body: bytes) -> HttpResponseData`:
    - Retries up to `config.max_retries` on HTTP `429`, `500`, `502`, `503`, `504` or `OSError`/`TimeoutError`.
    - Parses `Retry-After` response header (numeric seconds) when present on `429`/`503`, otherwise computes `config.initial_backoff_seconds * (2 ** attempt)`.
    - Raises `EmailDeliveryError(provider=..., status_code=..., retryable=...)` when non-2xx persists after retries or on immediate `4xx` (`!= 429`).
  - `ResendEmailTransport(_RetryableRestTransport)`:
    - Validates `config.api_key` is non-empty on init (raising `ValueError("ResendEmailTransport requires EmailConfig.api_key")`).
    - Implements `send` (`POST {base_url}/emails`) and native `send_batch` (`POST {base_url}/emails/batch`) with `Idempotency-Key` header and `encode_json_bytes` / `decode_json`.
  - `SendGridEmailTransport(_RetryableRestTransport)`:
    - Validates `config.api_key` is non-empty on init.
    - Implements `send` and `send_batch` (`POST {base_url}/v3/mail/send`), extracting `X-Message-Id` from response headers and mapping `EmailAttachment` to base64 JSON entries.
  - `MailgunEmailTransport(_RetryableRestTransport)`:
    - Validates `config.api_key` and `config.mailgun_domain` on init.
    - Implements `send` and `send_batch` (`POST {base_url}/v3/{mailgun_domain}/messages`) with HTTP Basic `Authorization: Basic <base64("api:" + api_key)>`, multipart boundary encoding when `message.attachments` is non-empty, and `decode_json` receipt extraction (`id`).
  - `WebhookVerifier`:
    - `@staticmethod def verify_resend(payload: bytes | str, headers: Mapping[str, str], secret: str, *, now: int | None = None, tolerance_seconds: int = 300) -> WebhookEvent`
    - `@staticmethod def verify_sendgrid(payload: bytes | str, headers: Mapping[str, str], secret: str, *, now: int | None = None, tolerance_seconds: int = 300) -> list[WebhookEvent]`
    - `@staticmethod def verify_mailgun(body: Mapping[str, Any] | bytes | str, secret: str, *, now: int | None = None, tolerance_seconds: int = 300) -> WebhookEvent`
    - All three check `abs(now_ts - timestamp) <= tolerance_seconds` and use `hmac.compare_digest` before returning typed `WebhookEvent` instances (raising `ValueError` on invalid or expired signatures).
