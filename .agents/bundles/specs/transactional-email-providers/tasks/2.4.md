# 2.4 Unit and contract tests for SMTP, Resend, SendGrid, Mailgun, SES, webhooks, and queued delivery

## Objective
Create `src/py/tests/unit/framework/test_email_providers.py` to test `MemoryEmailTransport`, `SmtpEmailTransport` (STARTTLS/TLS, MIME `multipart/alternative`, attachments, connection pool reuse/reconnect, header injection refusal), `ResendEmailTransport`, `SendGridEmailTransport`, `MailgunEmailTransport`, `SesEmailTransport` (Rust `vertebra._storage.py_sign_aws_sigv4_headers` signature verification), `429`/`5xx` retry backoff, `WebhookVerifier` (Resend/Svix, SendGrid, Mailgun), and `EmailService.enqueue` / `enqueue_batch` over `QueueService`.

## Context
- Tasks `2.1`–`2.3` implement all six `EmailBackendType` transports (`memory`, `smtp`, `resend`, `sendgrid`, `mailgun`, `ses`), `WebhookVerifier`, and `EmailService.enqueue`.
- Strong tests must assert observable wire payloads, headers, cryptographic signatures, error refusal paths, and end-to-end queue integration:
  1. `SmtpEmailTransport`: verifies `multipart/alternative` structure (`text/plain` + `text/html`), base64 `EmailAttachment` parts, `STARTTLS` handshake, connection reuse across multiple `send` calls, automatic reconnect on `smtplib.SMTPServerDisconnected`, and `ValueError` on CR/LF header injection.
  2. `ResendEmailTransport`, `SendGridEmailTransport`, and `MailgunEmailTransport`: verifies exact URL, method, auth header (`Bearer` / `Basic`), `Idempotency-Key` header, JSON/multipart body fields, native batch send (`/emails/batch` on Resend), `Retry-After` backoff recovery on transient `429` followed by `200`/`202`, and `EmailDeliveryError` on terminal `4xx`/`5xx`.
  3. `WebhookVerifier`: verifies valid HMAC signatures for Resend (`whsec_` Svix header format), SendGrid, and Mailgun, and asserts `ValueError` on tampered payloads or timestamps older than `tolerance_seconds`.
  4. `SesEmailTransport`: verifies `vertebra._storage.py_sign_aws_sigv4_headers` produces deterministic `Authorization: AWS4-HMAC-SHA256 Credential=.../ses/aws4_request, SignedHeaders=content-type;host;x-amz-content-sha256;x-amz-date;x-amz-security-token, Signature=...` headers matching the canonical AWS SigV4 vector, and verifies both `Simple` and `Raw` MIME SES v2 payloads.
  5. `EmailService.enqueue` and `enqueue_batch`: verifies messages enqueued into `QueueService` are persisted, retried on transient transport errors according to `TaskRetryPolicy`, and delivered when `await queue_service.drain_once()` (or `MultiLaneWorkerRunner.process_once()`) runs.
- `behavior_tdd` applies because each test validates a concrete behavioral contract of the transactional email subsystem.

## Steps
- [ ] 1. Create `src/py/tests/unit/framework/test_email_providers.py` with the following test functions:
  - `test_memory_transport_idempotency_and_recipient_lookup`: sends messages with and without `idempotency_key`, asserting duplicate `idempotency_key` returns the same `EmailReceipt` without duplicating `outbox`, and `find_by_recipient` filters accurately.
  - `test_smtp_transport_mime_multipart_attachments_pooling_and_header_injection_guard`: exercises `SmtpEmailTransport` with `text_body`, `html_body`, and two `EmailAttachment` items; parses the delivered MIME message to assert `multipart/mixed` -> `multipart/alternative` + attachment payloads; verifies connection pool reuse across 3 sends and transparent reconnect when a pooled connection raises `smtplib.SMTPServerDisconnected`; asserts `ValueError` when a header contains `\r\nBcc: attacker@example.com`.
  - `test_resend_transport_single_batch_and_429_retry_after`: injects a recorded `HttpTransportClient` that returns `429` (`Retry-After: 0`) on call 1 and `200 {"id": "re_123"}` on call 2; verifies `Idempotency-Key` header, `Authorization: Bearer re_test`, JSON payload structure, and `/emails/batch` batch dispatch.
  - `test_sendgrid_and_mailgun_transports_contract_and_error_handling`: verifies `SendGridEmailTransport` (`POST /v3/mail/send`, `202 Accepted`, `X-Message-Id` extraction, base64 attachment mapping) and `MailgunEmailTransport` (`POST /v3/mg.example.com/messages`, Basic auth, multipart attachment encoding), plus `EmailDeliveryError` when `401 Unauthorized` is returned.
  - `test_webhook_verifier_resend_sendgrid_and_mailgun_signatures`: verifies valid signatures and rejects tampered payloads and expired timestamps (`now - timestamp > tolerance_seconds`) for `WebhookVerifier.verify_resend`, `WebhookVerifier.verify_sendgrid`, and `WebhookVerifier.verify_mailgun`.
  - `test_ses_transport_rust_sigv4_headers_simple_and_raw_mime`: calls `SesEmailTransport.send` for a simple text/HTML message and a message with an attachment at fixed timestamp `1_700_000_000` with `aws_session_token="sess-tok"`, asserting the `Authorization`, `x-amz-date`, `x-amz-content-sha256`, and `x-amz-security-token` headers produced by `vertebra._storage.py_sign_aws_sigv4_headers` match the canonical AWS4-HMAC-SHA256 digest and that `Simple` vs `Raw` SES v2 bodies are selected appropriately.
  - `test_email_service_enqueue_and_enqueue_batch_via_queue_service`: wires `EmailService(config, queue_service=qsvc)`, calls `await email_service.enqueue(msg1)` and `await email_service.enqueue_batch([msg2, msg3])`, asserts `len(email_service.outbox) == 0` before worker execution, runs `await qsvc.drain_once()`, and asserts all 3 emails are delivered with receipts.
