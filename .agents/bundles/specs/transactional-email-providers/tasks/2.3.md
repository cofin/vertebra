# 2.3 SesEmailTransport via Rust SigV4 signing and QueueService-backed EmailService.enqueue

## Objective
Add `sign_aws_sigv4_headers` to `src/rs/vertebra-storage/src/signing.rs` and expose `py_sign_aws_sigv4_headers` in `src/rs/vertebra-storage/src/lib.rs` (`vertebra._storage`) using `py.detach`, implement `SesEmailTransport` in `src/py/vertebra/framework/email/ses.py` against the AWS SES v2 `/v2/email/outbound-emails` REST API, and integrate `EmailService.enqueue(...)` and `EmailService.enqueue_batch(...)` with `QueueService` so outbound emails can be durably enqueued and delivered by background workers.

## Context
- `src/rs/vertebra-storage/src/signing.rs:97-186`: `sign_s3_v4_url` implements AWS Signature Version 4 query-string presigning for S3 (`UNSIGNED-PAYLOAD`, service `"s3"`), and `src/rs/vertebra-storage/src/lib.rs:478-504` exposes `py_sign_s3_v4_url` to Python with `py.detach`.
- AWS SES v2 (`POST https://email.{region}.amazonaws.com/v2/email/outbound-emails`) requires header-based AWS Signature Version 4 signing (`Authorization: AWS4-HMAC-SHA256 Credential=.../ses/aws4_request, SignedHeaders=content-type;host;x-amz-content-sha256;x-amz-date[;x-amz-security-token], Signature=...`) with a SHA-256 hex digest of the JSON request body (`x-amz-content-sha256`). Implementing `sign_aws_sigv4_headers` in `signing.rs` and binding `py_sign_aws_sigv4_headers` in `lib.rs` with `py.detach` (Decision D3) keeps all HMAC-SHA256 key derivation and payload hashing in Rust without adding `boto3`/`botocore`.
- Per Decision D4, `EmailService` accepts `queue_service: QueueService | None = None` and registers a built-in `"vertebra.email.send"` task on the `"io"` lane so `await email_service.enqueue(message)` persists the serialized `EmailMessage` into the configured `QueueBackend` (`memory://`, `redis://`, `valkey://`, `postgresql://`, or `oracle://`).
- `behavior_tdd` applies because Rust `sign_aws_sigv4_headers`, `SesEmailTransport`, and `EmailService.enqueue` introduce new AWS SES v2 signing and queued email delivery capabilities.

  pub fn sign_aws_sigv4_headers(
