# 1.5 Make, pre-commit, and lint wiring

## Objective
Wire `make review-check` and `make review-route` into `Makefile`, include `tools/scripts` in Ruff and Mypy targets (`pyproject.toml` and `Makefile`), invoke `review-check` from `make lint` and `make lint-all`, and register a local `review-setup` hook in `.pre-commit-config.yaml`.

## Context
- `Makefile:191-213` (`py-lint`, `lint`, `lint-all`) currently runs Ruff on `src/py/vertebra src/py/tests` and Mypy via `uv run mypy src/py/vertebra`. `pyproject.toml:106` sets `files = ["src/py/vertebra"]` under `[tool.mypy]`.
- Adding `tools/scripts` to Ruff and Mypy ensures `tools/scripts/review_setup.py` is continuously type-checked and linted, and calling `review-check` from `lint` / `lint-all` enforces the review validator in CI (`lint` job runs `make lint-all`).
- `static_validation` applies because this task wires build, lint, and pre-commit configuration gates.

## Steps
- [x] 1. Edit `pyproject.toml:105-110` (`[tool.mypy]`) to set `files = ["src/py/vertebra", "tools/scripts"]`.
- [x] 2. Edit `Makefile`:
  - Add `review-check` and `review-route` to `.PHONY` (`Makefile:1-20`) and the `help` target (`Makefile:35-65`).
  - Define `review-check`: `uv run python -m tools.scripts.review_setup validate`.
  - Define `review-route`: `BASE ?= origin/main` and `uv run python -m tools.scripts.review_setup route --base $(BASE)`.
  - Update `py-lint` (`Makefile:191-196`) and `lint-all` (`Makefile:204-213`) so `ruff check`, `ruff format --check`, and `mypy` include `tools/scripts`, and both `lint` and `lint-all` run `$(MAKE) review-check`.

- [x] 4. Commit: `build(review): wire review-check and review-route into Makefile, lint-all, and pre-commit` (signed), staging `Makefile`, `pyproject.toml`, and `.pre-commit-config.yaml`.
