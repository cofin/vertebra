# 1.6 Benchmark harness and `pre-refactor` baseline

## Objective
Add `make rs-bench`, `make bench-micro` (`tools/benchmarks/micro.py`), `make bench-baseline` (`tools/benchmarks/baseline.py`), and `make bench-check` to `Makefile` (`TOOL-04`, `CORE-40` Makefile part, `HTTP-41` Makefile part), fix `tools/benchmarks/targets.py:95-100` (`OKF-08`) so missing free-threaded 3.14t binaries raise `FileNotFoundError` instead of running `echo`, and record `tools/benchmarks/baselines/pre-refactor.json`.

## Context
- `Makefile:233-272` defines Python benchmark targets (`bench`, `bench-ft`, `bench-compare`, `bench-all`) but has no target for Rust Criterion benchmarks (`TOOL-04`, `CORE-40` Makefile part, `HTTP-41` Makefile part).
- `tools/benchmarks/targets.py:95-100` (`_ft_run`) checks `if not os.path.exists(_FT_SERVER_BIN): return ["echo", f"3.14t server binary not found at {_FT_SERVER_BIN} (run make bench-ft first)"]`, which causes `make bench-all` to succeed with exit 0 while skipping all 3.14t benchmarks (`OKF-08`).
- Chapters 2, 3, 4, 5, and 8 require a committed `tools/benchmarks/baselines/pre-refactor.json` baseline and a `make bench-check BASELINE=pre-refactor` comparator enforcing Global Constraint 9 (fail on `> 3%` throughput regression or `> 5%` p99 latency increase).
- `static_validation` applies because this task adds benchmark CLI tooling, Makefile targets, and the baseline regression comparator.

## Steps
- [x] 1. Edit `tools/benchmarks/targets.py:95-100` (`_ft_run`) to raise `FileNotFoundError(f"3.14t server binary not found at {_FT_SERVER_BIN}; run 'make bench-ft' first")` when `_FT_SERVER_BIN` or `_FT_PYTHON` does not exist (`OKF-08`).
- [x] 2. Create `tools/benchmarks/micro.py` using `msgspec.Struct(frozen=True, gc=False)` models (`MicroBenchSample`, `MicroBenchSuiteResult`) measuring median and p99 latencies across 5 timed rounds (after warmup) for:
  - `request_headers_materialization`: `Request.headers` access on a 16-header native request batch node.
  - `asgi_scope_build_and_copy`: `AsgiScope` construction, key lookup (`method`, `path`, `headers`), and `dict(scope)` copy.
  - `wsgi_environ_items`: `WsgiEnviron` construction and `.items()` materialization.
  - `rsgi_scope_build`: `RsgiScope` construction and attribute reads (`proto`, `method`, `path`, `headers`).
  - `response_construct`: `Response(status=200, headers=..., body=...)` construction and `to_bytes()`.
  - `serializers_msgpack_json`: `encode_json_bytes` / `decode_json` round-trip on a 1 KiB payload.
  - `import_vertebra_ms` and `import_vertebra_framework_ms`: subprocess `python -c "import vertebra"` and `python -c "import vertebra.framework"` warm import times in milliseconds.
- [x] 3. Create `tools/benchmarks/baseline.py` implementing:
  - `BaselineRecord(msgspec.Struct, frozen=True, gc=False)` with `name: str`, `commit: str`, `timestamp: str`, `criterion_ns_per_iter: dict[str, float]`, `micro_ops_per_sec: dict[str, float]`, `micro_p99_ns: dict[str, float]`, `import_ms: dict[str, float]`, and `e2e_rps: dict[str, float]`.
  - `record` subcommand (`python -m tools.benchmarks.baseline record --name <NAME> [--skip-e2e]`) parsing Criterion `target/criterion/<group>/<bench>/new/estimates.json`, `tools.benchmarks.micro` JSON output, and `tools/benchmarks/results/` latest e2e run into `tools/benchmarks/baselines/<NAME>.json`.
  - `check` subcommand (`python -m tools.benchmarks.baseline check --baseline <NAME>`) comparing current Criterion, micro, and e2e measurements against `tools/benchmarks/baselines/<NAME>.json` and exiting 1 if any throughput metric drops by `> 3.0%` or any latency/import metric increases by `> 5.0%`.
- [x] 4. Edit `Makefile:233-272` to add `.PHONY` targets:
  - `rs-bench`: `cd src/rs && cargo bench -p vertebra-core --features compression && cargo bench -p vertebra-http --bench server_throughput`
  - `bench-micro`: `uv run --group bench python -m tools.benchmarks.micro`
  - `bench-baseline`: `NAME ?= pre-refactor` running `rs-bench`, `bench-micro`, and `python -m tools.benchmarks.baseline record --name $(NAME)`
  - `bench-check`: `BASELINE ?= pre-refactor` running `python -m tools.benchmarks.baseline check --baseline $(BASELINE)`
- [x] 5. Extend `src/py/tests/unit/test_benchmarks_cli.py` (or create it if absent) with unit tests covering `_ft_run` raising `FileNotFoundError` when `_FT_SERVER_BIN` is missing (`test_ft_run_missing_binary_raises_file_not_found`), `micro.py` execution (`test_micro_benchmarks_emit_expected_keys`), and `baseline.py` regression detection (`test_baseline_check_fails_on_3pct_throughput_drop_or_5pct_p99_increase`).
- [x] 6. Run `make bench-baseline NAME=pre-refactor` and stage the generated `tools/benchmarks/baselines/pre-refactor.json`.
- [x] 7. Commit: `feat(bench): add rs-bench, bench-micro, and pre-refactor baseline gate` (signed), staging `Makefile`, `tools/benchmarks/targets.py`, `tools/benchmarks/micro.py`, `tools/benchmarks/baseline.py`, `tools/benchmarks/baselines/pre-refactor.json`, and `src/py/tests/unit/test_benchmarks_cli.py`.
