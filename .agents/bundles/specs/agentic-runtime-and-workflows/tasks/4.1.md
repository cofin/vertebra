# 4.1 Extendable `AgentRuntime` with pluggable model providers, tool execution loop, retry/backoff, and `ConfirmationGate`

## Objective
Create `src/py/vertebra/agent/runtime.py` implementing `ModelDelta`, `ModelProvider` protocol, `GoogleGenAIProvider`, `AgentStreamFrame`, `ConfirmationGate` (shared with `src/py/vertebra/extensions/apex/gateway.py`), `RetryPolicy`, `TurnRequest`, `TurnResponse`, and `AgentRuntime` managing multi-turn model generation, parallel tool execution, `AgentGroup` specialist transfers, exponential backoff retries, human-in-the-loop confirmation pauses, `TurnBudget` enforcement, and `AgentObservabilityHarness` telemetry.

## Context
- `litestar_mcp/agent/runtime.py:35-578` defines `TurnRequest`, `TurnResponse`, and `AgentRuntime`, using `@dataclass` and lacking model retry/backoff and human-in-the-loop `ConfirmationGate` integration.
- `src/py/vertebra/extensions/apex/gateway.py` defines a simple `ConfirmationGate` that should be promoted to `vertebra.agent.runtime.ConfirmationGate` (supporting pending confirmation tickets, token generation, approval/rejection with caller identity binding, and async wait/resume) and imported by `apex/__init__.py`.
- Every model step (`observability.span_model`), tool call (`observability.span_tool`), and agent turn (`observability.span_turn`) must emit `SpanData`, update `GenAiRecorder` (`GenAiUsage` + `CostTable`), and write an `AgentAuditEvent` to `LogSink`.
- `behavior_tdd` applies because `runtime.py` introduces the multi-turn agent loop, confirmation gate, and retry behavior.

## Steps
- [ ] 1. Create `src/py/vertebra/agent/runtime.py` defining:
  - `ModelDelta(msgspec.Struct, frozen=True, gc=False, kw_only=True, array_like=True)` (`event_type: Literal["delta", "thought", "tool_call", "usage"]`, `text: str = ""`, `tool_name: str | None = None`, `call_id: str | None = None`, `arguments: dict[str, Any] | None = None`, `usage: GenAiUsage | None = None`, `provider_metadata: dict[str, Any] | None = None`).
  - `ModelProvider(Protocol)` with `stream_chat(messages: Sequence[AgentMessage], tools: Sequence[Tool], system_instruction: str, *, context: AgentContext | None = None) -> AsyncIterator[ModelDelta]` and `GoogleGenAIProvider` (lazily importing `google.genai` via `import_optional` and raising `MissingDependencyError` when absent).
  - `AgentStreamFrame(msgspec.Struct, frozen=True, gc=False, kw_only=True, array_like=True)` (`turn_id: str`, `event_type: Literal["delta", "thought", "tool_call", "tool_result", "agent_transfer", "confirmation_required", "done", "error"]`, `agent_name: str = ""`, `text: str = ""`, `tool_name: str | None = None`, `call_id: str | None = None`, `payload: dict[str, Any] | None = None`, `usage: GenAiUsage | None = None`) with `to_sse_frame(event_id: str) -> SseFrame`.
  - `ConfirmationTicket(msgspec.Struct, frozen=True, gc=False, kw_only=True)` and `ConfirmationGate` supporting `request_confirmation(tool_name: str, call_id: str, arguments: dict[str, Any], *, owner_id: str | None = None, reason: str = "") -> ConfirmationTicket`, `approve(token: str, *, owner_id: str | None = None) -> bool`, `reject(token: str, *, owner_id: str | None = None, reason: str = "") -> bool`, and `is_approved(token: str | None, *, owner_id: str | None = None) -> bool`.
  - `RetryPolicy(msgspec.Struct, frozen=True, gc=False, kw_only=True)` (`max_attempts: int = 3`, `base_delay_seconds: float = 0.25`, `max_delay_seconds: float = 10.0`, `jitter_ratio: float = 0.1`).
  - `TurnRequest(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, `TurnResponse(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, and `AgentRuntime`:
    - Execute multi-turn model + tool loops under `TurnBudget` (`max_steps`, `max_tool_calls`, `max_input_tokens`, `max_output_tokens`, `timeout_seconds`).
    - When a called `Tool` has `requires_confirmation=True` and no approved `confirmation_token` is present in `TurnRequest` or `ConfirmationGate`, emit an `AgentStreamFrame(event_type="confirmation_required", ...)` with the issued `ConfirmationTicket` and pause the turn cleanly without executing the mutating tool.
    - Execute non-blocked tool calls concurrently via `anyio.create_task_group()`, handle `AgentGroup` `transfer_to_agent` transitions, apply `compaction_hook`, persist conversation history in `self.sessions`, and emit `span_turn`, `span_model`, and `span_tool` telemetry.
- [ ] 2. Update `src/py/vertebra/extensions/apex/gateway.py` to import and use `ConfirmationGate` from `vertebra.agent.runtime`.
- [ ] 3. Export `AgentRuntime`, `AgentStreamFrame`, `ConfirmationGate`, `ConfirmationTicket`, `GoogleGenAIProvider`, `ModelDelta`, `ModelProvider`, `RetryPolicy`, `TurnRequest`, and `TurnResponse` from `src/py/vertebra/agent/__init__.py`.
- [ ] 4. Commit: `feat(agent): add AgentRuntime with pluggable ModelProvider, retry policy, and ConfirmationGate` (signed), staging the paths in `files`.

- [ ] Every turn records `gen_ai.agent.turn`, `gen_ai.chat`, and `gen_ai.tool.call` spans and updates `GenAiRecorder` token and cost counters.
