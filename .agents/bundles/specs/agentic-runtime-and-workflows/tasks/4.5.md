# 4.5 TypeScript `@vertebra/client/agent` SDK subpath and Vitest suite

## Objective
Create `src/ts/vertebra-client/src/agent/index.ts` (and export it from `src/ts/vertebra-client/src/index.ts`, `package.json`, and `tsup.config.ts`) providing the typed TypeScript client SDK for Vertebra's agentic harness: `McpClient` (MCP `2026-07-28` Streamable HTTP + Base64 `Mcp-Name` header encoding + session management), `A2aClient` (A2A `1.0` `sendMessage`, `streamMessage`, `getTask`, `cancelTask`, `resubscribeTask`, and `getAgentCard` with ETag caching), `AgentStreamClient` (streaming `/agent/chat` and `/agent/confirmations/{token}` over `SseClient`), and `WorkflowLiveSubscriber` (subscribing to `WorkflowLiveState` HLC binary delta frames over `LiveStateClient`), verified by `src/ts/vertebra-client/tests/agent.test.ts`.

## Context
- `src/ts/vertebra-client/src/index.ts:1-49` exports `HttpClient`, `SseClient` (`src/sse.ts`), `LiveStateClient` (`src/live/index.ts`), and `TraceContext` (`src/telemetry.ts`), which provide the transport, SSE reconnection (`Last-Event-ID`), HLC conflict resolution, and W3C `traceparent` primitives needed by `@vertebra/client/agent`.
- `behavior_tdd` applies because `src/ts/vertebra-client/src/agent/index.ts` introduces a new SDK subpath with observable protocol and state-sync behavior.

## Steps
- [x] 1. Create `src/ts/vertebra-client/src/agent/index.ts` implementing:
  - `MCP_PROTOCOL_VERSION = "2026-07-28"`, `encodeMcpHeaderValue(value: string): string` (encoding non-ASCII values as `=?base64?...?=`), and `McpClient`:
    - Sends `MCP-Protocol-Version: 2026-07-28`, `Mcp-Method`, `Mcp-Name` (resolved per method: `tools/call -> name`, `resources/read -> uri`, `prompts/get -> name`, `tasks/* -> taskId`, `skills/get -> uri`), `Mcp-Session-Id`, and W3C `traceparent` (from `TraceContext`).
    - Provides typed `initialize()`, `listTools(cursor?)`, `callTool<T>(name, args, options?)`, `listResources(cursor?)`, `readResource(uri)`, `listPrompts(cursor?)`, `getPrompt(name, args?)`, `listSkills(cursor?)`, `getSkill(uri)`, `getTask(taskId)`, and `cancelTask(taskId)`.
  - `A2aClient`:
    - Provides `getAgentCard()` (caching `ETag` and sending `If-None-Match` on subsequent calls), `sendMessage(message, configuration?)`, `streamMessage(message, onEvent)` (parsing SSE `TaskStatusUpdateEvent` and `TaskArtifactUpdateEvent` frames), `getTask(taskId)`, `cancelTask(taskId)`, and `resubscribeTask(taskId, lastEventId, onEvent)`.
  - `AgentStreamClient`:
    - Wraps `SseClient` and `HttpClient` for `streamChat(request, onFrame)`, `runTurn(request)`, `approveConfirmation(token)`, `rejectConfirmation(token, reason?)`, and `getSessionHistory(sessionId)`.
  - `WorkflowLiveSubscriber`:
    - Wraps `LiveStateClient` to apply incoming `StateDeltaMessage` updates (`FIELD_SET`, `OBJECT_REPLACE`, `BATCH_PATCH`) for a `WorkflowLiveState` room (`runId`, `workflowName`, `status`, `activeNodes`, `completedNodes`, `nodeOutputs`) and invoke typed state listeners.
- [x] 2. Export all symbols from `src/ts/vertebra-client/src/index.ts`, add `"./agent"` to `exports` in `src/ts/vertebra-client/package.json`, and register `"agent": "src/agent/index.ts"` in the consolidated `tsup.config.ts` (from `frontend-and-tooling-consolidation:7.6`).
- [x] 3. Create `src/ts/vertebra-client/tests/agent.test.ts` testing:
  - `McpClient` header construction (`MCP-Protocol-Version`, `Mcp-Method`, `Mcp-Name` for `tools/call`, `resources/read`, `skills/get`, and non-ASCII Base64 sentinel encoding), `Mcp-Session-Id` persistence, and W3C `traceparent` propagation.
  - `A2aClient` `getAgentCard` `ETag` / `304 Not Modified` caching, `sendMessage`, `streamMessage` SSE event parsing, and `cancelTask`.
  - `AgentStreamClient` `confirmation_required` frame handling and `approveConfirmation(token)` round-trip.
  - `WorkflowLiveSubscriber` reactive state reconstruction across HLC-ordered `StateOpcode.FIELD_SET` and `StateOpcode.BATCH_PATCH` frames.
- [x] 4. Commit: `feat(client): add @vertebra/client/agent SDK for MCP, A2A, AgentRuntime, and WorkflowLiveState` (signed), staging the paths in `files`.
