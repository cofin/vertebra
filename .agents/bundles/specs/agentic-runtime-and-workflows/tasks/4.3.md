# 4.3 Pluggable `AgentSessionStore` (5 backends) and streaming chat controller (`agent/{sessions,controller}.py`)

## Objective
Create `src/py/vertebra/agent/sessions.py` implementing the owner-scoped `AgentSessionStore` protocol and 5 concrete storage backends (`MemorySessionStore`, `CacheSessionStore` over `ResponseCacheStore` / Litestar `Store`, `SQLSpecSessionStore`, `AlchemySessionStore`, and `ObjectStoreSessionStore` over `vertebra._storage`), and create `src/py/vertebra/agent/controller.py` implementing `AgentChatController` for SSE streaming turns, synchronous turns, queued background turns (`202 Accepted` + `Last-Event-ID` SSE replay), human-in-the-loop confirmation approvals, and owner-scoped session history retrieval.

## Context
- `litestar_mcp/agent/sessions.py:28-141` provides `SessionStore`, `MemorySessionStore`, and `LitestarStoreSessionStore`, while `litestar_mcp/agent/controller.py:73-174` and `litestar_mcp/queues/tasks.py:48-224` provide `AgentChatController` and `QueuedTurn`.
- Vertebra ships `MemoryStore` / `ResponseCacheStore` (`src/py/vertebra/framework/stores/__init__.py`), `SQLSpec` extensions (`src/py/vertebra/extensions/sqlspec/`), `Alchemy` extensions (`src/py/vertebra/extensions/alchemy/`), and Rust `ObjectStore` (`src/rs/vertebra-storage`). Supporting all 5 backends behind one `AgentSessionStore` protocol lets deployments choose in-memory LRU, Redis/Valkey cache stores, relational SQL tables, or S3/GCS/OCI/R2 object storage for conversation transcripts and workflow checkpoints.
- `behavior_tdd` applies because `sessions.py` and `controller.py` introduce new persistence adapters and HTTP/SSE endpoints.

## Steps
- [x] 1. Create `src/py/vertebra/agent/sessions.py` defining `ANONYMOUS_OWNER = "anonymous"`, `AgentSessionStore(Protocol)` (`load(owner: str, session_id: str) -> list[AgentMessage] | None`, `save(owner: str, session_id: str, messages: Sequence[AgentMessage]) -> None`, `delete(owner: str, session_id: str) -> None`, `lock(owner: str, session_id: str) -> AbstractAsyncContextManager[None]`), and 5 implementations encoding/decoding `list[AgentMessage]` via `vertebra.utils.serializers`:
  - `MemorySessionStore(max_sessions: int = 1024, ttl_seconds: float = 3600.0)`: process-local monotonic-TTL LRU `OrderedDict` with per-session `anyio.Lock`.
  - `CacheSessionStore(store: Any, *, ttl_seconds: int = 3600, key_prefix: str = "vertebra:agent:session")`: backed by `vertebra.framework.stores.MemoryStore` or any Litestar `Store` (`get`/`set`/`delete`).
  - `SQLSpecSessionStore(driver: Any, *, table_name: str = "vertebra_agent_sessions")`: executes parameterized upsert/select/delete SQL statements against a SQLSpec sync or async driver.
  - `AlchemySessionStore(session_factory: Callable[[], Any], *, table_name: str = "vertebra_agent_sessions")`: persists JSONB/text session rows via an SQLAlchemy async session or connection.
  - `ObjectStoreSessionStore(bucket_store: Any, *, prefix: str = "agent-sessions/")`: writes and reads `<prefix>/<owner>/<session_id>.json` objects via Vertebra's storage client.
- [x] 2. Create `src/py/vertebra/agent/controller.py` defining `ChatRequest(msgspec.Struct, frozen=True, gc=False, kw_only=True, forbid_unknown_fields=True)`, `TurnResult(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, `QueuedTurnTicket(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, `ConfirmationDecisionRequest(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, `SessionHistory(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, `SessionNotFoundError`, and `AgentChatController`:
  - `POST {base_path}/chat`: streams `AgentStreamFrame` events over SSE (`SseStreamBroker`) with keepalive pings and `Last-Event-ID` replay.
  - `POST {base_path}/turns`: runs a synchronous turn via `runtime.run_turn` and returns `TurnResult`.
  - `POST {base_path}/turns/async`: enqueues a background turn on `QueueService` (`TaskLane = "agent"`), returns `202 Accepted` with `QueuedTurnTicket(turn_id=..., session_id=..., stream_url=...)`, and streams frames into `SseReplayBuffer` for `GET {base_path}/turns/{turn_id}/stream` (`Last-Event-ID` replay).
  - `POST {base_path}/confirmations/{token}`: approves or rejects a pending `ConfirmationGate` ticket scoped to `AgentContext.identity.owner_key()`.
  - `GET {base_path}/sessions/{session_id}` and `DELETE {base_path}/sessions/{session_id}`: loads or deletes conversation history scoped strictly to `AgentContext.identity.owner_key()`.
- [x] 3. Export all session stores and controller types from `src/py/vertebra/agent/__init__.py`.
- [x] 4. Commit: `feat(agent): add 5-backend AgentSessionStore and streaming AgentChatController` (signed), staging the paths in `files`.
