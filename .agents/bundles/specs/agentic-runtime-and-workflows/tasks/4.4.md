# 4.4 Unified mounting on both native `vertebra.framework.app.App` and Litestar (`agent/plugin.py`, `extensions/litestar/plugin.py`)

## Objective
Create `src/py/vertebra/agent/plugin.py` (`AgentPluginConfig`, `AgentPlugin`) and wire it into `src/py/vertebra/framework/app.py` (consolidated in `5.1`) and `src/py/vertebra/extensions/litestar/plugin.py` (consolidated in `6.3`) so the full agentic harness (MCP `2026-07-28`, A2A `1.0`, `AgentChatController`, `SkillCatalog`, `QueueService` agent lane, `AgentObservabilityHarness`, and `.well-known/{mcp.json,agent-card.json}` discovery) mounts on both native `vertebra.framework.app.App` and Litestar applications (including automatic discovery of Litestar route handlers marked with `opt={"mcp_tool": ...}` / `mcp_resource` / `mcp_prompt` and `litestar-mcp` `SkillController`/`PromptController` classes), delete legacy `src/py/vertebra/framework/mcp/` and `src/py/vertebra/framework/a2a/` stubs (`MCP-01`, `MCP-04`, `MCP-05`, `MCP-08`), and author `src/py/tests/unit/agent/test_runtime_and_workflows.py`.

## Context
- `extensions-and-data-consolidation:6.3` consolidated Litestar integration into `src/py/vertebra/extensions/litestar/plugin.py` (incorporating `LitestarConfig` and removing `ecosystem.py`). `AgentPlugin` integration must wire directly into `src/py/vertebra/extensions/litestar/plugin.py`.
- `framework-and-server-consolidation:5.1` consolidated the native `App` router and mounting logic into `src/py/vertebra/framework/app.py`.
- `src/py/vertebra/framework/__init__.py:5-22` eagerly imports `a2a` and `mcp` (`MCP-08`), which are replaced by `vertebra.agent` (`MCP-01`, `MCP-04`).
- `integration_acceptance` applies because `AgentPlugin` and `LitestarPlugin` compose MCP, A2A, `AgentRuntime`, `SpecTree`, `DynamicWorkflow`, `AgentSessionStore`, and `AgentObservabilityHarness` across both application hosts with positive and negative refusal checks.

## Steps
- [ ] 1. Create `src/py/vertebra/agent/plugin.py` defining `AgentPluginConfig(msgspec.Struct, frozen=True, gc=False, kw_only=True)` (`mcp: MCPConfig | None = MCPConfig()`, `a2a: A2AConfig | None = None`, `runtime: AgentRuntime | None = None`, `agent_base_path: str = "/agent"`, `observability: AgentObservabilityHarness | None = None`, `queue_service: QueueService | None = None`) and `AgentPlugin`:
  - `AgentPlugin.mount_native(app: App) -> None`: registers `POST /mcp`, `GET /.well-known/mcp.json`, `POST /a2a`, `GET /.well-known/agent-card.json`, and `AgentChatController` routes (`/agent/chat`, `/agent/turns`, `/agent/turns/async`, `/agent/turns/{turn_id}/stream`, `/agent/confirmations/{token}`, `/agent/sessions/{session_id}`) on a native `vertebra.framework.app.App` (from `5.1`), and populates the offload discovery manifest (`/.well-known/mcp.json`, `/.well-known/agent-card.json`, excluded SPA prefixes).
  - `AgentPlugin.on_app_init(app_config: Any) -> Any`: implements Litestar `InitPluginProtocol`, walks `app_config.route_handlers` (including nested `Router` and `Controller` trees) to auto-register handlers carrying `mcp_tool`, `mcp_resource`, or `mcp_prompt` in `opt` as well as `SkillController` / `PromptController` subclasses (matching `litestar-mcp` discovery semantics), mounts the MCP, A2A, and `AgentChatController` Litestar routes, and injects `MCPRegistry`, `MCPService`, `A2AService`, `AgentRuntime`, and `AgentObservabilityHarness` into `app_config.state` and Litestar DI `dependencies`.
- [ ] 2. Update `src/py/vertebra/extensions/litestar/plugin.py` (from `6.3`) and delete legacy framework stubs:
  - Add `agent_config: AgentPluginConfig | None = None` to `LitestarConfig` and wire `AgentPlugin(self._config.agent_config).on_app_init(app_config)` into `LitestarPlugin.on_app_init`.
  - Delete `src/py/vertebra/framework/mcp/__init__.py` and `src/py/vertebra/framework/a2a/__init__.py`.
  - Remove `a2a` and `mcp` from `src/py/vertebra/framework/__init__.py` (`MCP-08`).
- [ ] 3. Create `src/py/tests/unit/agent/test_runtime_and_workflows.py` and update `src/py/tests/unit/extensions/test_litestar_plugin.py` and `src/py/tests/unit/framework/test_framework_subdomains.py` testing:
  - `AgentRuntime` multi-turn tool calling, `AgentGroup` transfer, retry backoff, `TurnBudget` refusal, and `ConfirmationGate` pause/approve/reject.
  - `SpecTree` subtask expansion, checkpoint round-trip, and compilation to `DynamicWorkflow`.
  - `DynamicWorkflow` parallel wave execution, cycle detection refusal, conditional skipping, checkpoint resumption, and `LiveStateRoom` binary `StateDeltaFrame` broadcasts.
  - All 5 `AgentSessionStore` backends (`Memory`, `Cache`, `SQLSpec`, `Alchemy`, `ObjectStore`) and `AgentChatController` endpoints.
  - Dual-host mounting of `AgentPlugin` on native `vertebra.framework.app.App` and on a real `Litestar` application via `LitestarPlugin(LitestarConfig(agent_config=AgentPluginConfig(...)))`, verifying `/mcp`, `/.well-known/mcp.json`, `/a2a`, `/.well-known/agent-card.json`, `/agent/chat`, and automatic discovery of `@get(..., opt={"mcp_tool": "health_status"})` route handlers.
- [ ] 4. Commit: `feat(agent,litestar): mount AgentPlugin on native App and Litestar and remove legacy MCP/A2A stubs` (signed), staging the paths in `files`.
