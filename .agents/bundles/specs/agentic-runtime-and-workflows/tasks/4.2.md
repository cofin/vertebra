# 4.2 `SpecTree` hierarchical task planning and `DynamicWorkflow` DAG engine with `LiveState` delta broadcasting

## Objective
Create `src/py/vertebra/agent/spec.py` and `src/py/vertebra/agent/workflow.py` implementing: (1) `Agent`, `AgentGroup` (with non-mutating `transfer_to_agent` synthesis), and `AgentMessage`, (2) hierarchical `SpecTree` (`SpecNode`, `SpecNodeStatus`, parent-child decomposition, dependency readiness, dynamic subtask expansion, and checkpoint snapshot/restore), and (3) `DynamicWorkflow` and `WorkflowEngine` (topological wave execution, conditional edge predicates, parallel fan-out/fan-in, state checkpointing, and live `StateDeltaFrame` broadcasting via `vertebra.framework.live.LiveState` / `LiveStateRoom`).

## Context
- `litestar_mcp/agent/spec.py:22-159` and `litestar_mcp/agent/workflow.py:16-296` provide `Agent`, `AgentGroup`, `DynamicWorkflow`, and `WorkflowEngine`, using `@dataclass` without hierarchical `SpecTree` task planning, checkpoint serialization, or real-time state delta streaming.
- `src/py/vertebra/framework/live/__init__.py:90-250` provides `HybridLogicalClock`, `StateDeltaFrame`, `LiveState`, and `LiveStateRoom`. Connecting `SpecTree` and `DynamicWorkflow` to `LiveStateRoom` lets browser clients subscribe once and receive compact MessagePack HLC delta frames whenever a workflow node or spec subtask starts, streams output, completes, skips, or fails.
- `behavior_tdd` applies because `spec.py` and `workflow.py` add hierarchical planning, DAG wave execution, checkpointing, and live delta broadcasting.

## Steps
- [x] 1. Create `src/py/vertebra/agent/spec.py` defining:
  - `TRANSFER_TOOL_NAME = "transfer_to_agent"`, `AgentMessage(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, `Agent(msgspec.Struct, frozen=True, gc=False, kw_only=True)` (validating unique tool names across `tools` and `skills` and rejecting manual `transfer_to_agent` registration), and `AgentGroup` (synthesizing a typed `Literal[...]` `transfer_to_agent` tool without mutating member `Agent` instances).
  - `SpecNodeStatus = Literal["pending", "ready", "running", "completed", "failed", "skipped"]`, `SpecNode(msgspec.Struct, frozen=True, gc=False, kw_only=True)` (`id: str`, `title: str`, `description: str = ""`, `parent_id: str | None = None`, `depends_on: tuple[str, ...] = ()`, `assigned_agent: str | None = None`, `status: SpecNodeStatus = "pending"`, `output: Any = None`, `children: tuple[str, ...] = ()`), and `SpecTree`:
    - Support `add_node(...)`, `expand_subtasks(parent_id: str, subtasks: Sequence[SpecNode])` (dynamically decomposing a high-level goal into child subtasks whose completion satisfies the parent node), `ready_nodes() -> list[SpecNode]`, `mark_running(node_id)`, `mark_completed(node_id, output)`, `mark_failed(node_id, error)`, `to_checkpoint_bytes() -> bytes`, `from_checkpoint_bytes(data: bytes) -> SpecTree`, and `to_workflow(agents: Mapping[str, Agent]) -> DynamicWorkflow`.
- [x] 2. Create `src/py/vertebra/agent/workflow.py` defining:
  - `StepResult(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, `WorkflowCheckpoint(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, `WorkflowContext`, `WorkflowNode(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, `WorkflowLiveState(LiveState)` (declaring reactive fields `run_id: str`, `workflow_name: str`, `status: str`, `active_nodes: list[str]`, `completed_nodes: list[str]`, `node_outputs: dict[str, Any]`), `DynamicWorkflow`, and `WorkflowEngine`:
    - Validate DAG acyclicity and dependency existence via Kahn's topological sort (`_validate_dependencies`), raising `ValueError` on unknown dependencies and `RuntimeError` on cycles.
    - Execute ready waves concurrently via `anyio.create_task_group()` and memory object streams, evaluating optional `node.condition(ctx)` predicates (marking false branches `"skipped"`), enforcing per-node `anyio.fail_after(node.timeout_seconds)`, and wrapping each node in `observability.span_workflow_step(workflow.name, ctx.run_id, node.name)`.
    - After each node transition (`running`, `completed`, `skipped`, `failed`), update `WorkflowLiveState`, drain its HLC `StateDeltaFrame` packets, and broadcast them to `self.live_room: LiveStateRoom | None` while saving a resumable `WorkflowCheckpoint`.
    - Support `WorkflowEngine.resume_run(workflow: DynamicWorkflow, checkpoint: WorkflowCheckpoint) -> WorkflowContext` skipping already-completed nodes and re-running only remaining or failed downstream nodes.
