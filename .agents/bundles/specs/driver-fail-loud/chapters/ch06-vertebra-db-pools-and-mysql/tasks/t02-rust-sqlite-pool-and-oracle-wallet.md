# Task t02: Delete `SqlitePool`, `OracleWalletMaterial`, and `rmp-serde`

## Objective & Scope Boundary

Delete `SQLITE_DIALECT_TAG`, `SqlitePool` (including `encode_msgpack_rows` / `decode_msgpack_rows`), and `test_sqlite_single_writer_and_multi_reader_leases` from `sqlite/mod.rs`; delete `OracleWalletMaterial` with `from_directory` and `test_oracle_wallet_from_directory` from `oracle/tns.rs`; drop `rmp-serde` from `vertebra-db/Cargo.toml` and the workspace dependency table; let Cargo rewrite `Cargo.lock`. Rewrite the `sqlite` and `tns` module docs, the SQLite crate-doc bullet, and the `lib.rs` re-export.[^sqlite-rs][^tns-rs][^db-cargo][^ws-cargo][^db-lib]

Production files exceed 3 because the dependency removal spans the crate manifest and the workspace manifest, and `Cargo.lock` changes with them; the `Cargo.lock` entries are generated by `cargo check`, not hand-edited. Every Rust change is a deletion plus one doc line.

`OracleWalletMaterial` is deleted whole, including `from_directory`: the method is its only constructor and the struct has no caller anywhere in the workspace. Kept TNS parsing is `parse_tnsnames_ora` and `resolve_tns_alias`. Python wallet handling lives in `src/py/vertebra/db/adapters/oracle/config.py::OracleWallet`, does not call the Rust struct, and stays.

Out of scope: `parse_tnsnames_ora`, `resolve_tns_alias`, `OracleConnectDescriptor` (kept); `SqliteConfig::initialization_pragmas` (kept); `sha2` (t04).
