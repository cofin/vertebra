# Chapters: Fail-Loud Database Drivers

* [ch01 — Oracle and MSSQL Fail-Loud Drivers](ch01-oracle-mssql-fail-loud/spec.md) — [planned] Oracle and MSSQL drivers resolve their native module on every entry point and raise `MissingDependencyError` naming `vertebra-core[oracle]` / `vertebra-core[mssql]`, with SQLite execution and SQLite-only helpers deleted and `AsyncMSSQLDriver` forwarding `dialer` (2 tasks).
* [ch02 — DuckDB, SQLAlchemy, and Oracle Queue Fail-Loud Paths](ch02-duckdb-sqlalchemy-queue-fail-loud/spec.md) — [planned] A GIL-only `duckdb` dependency group feeds DuckDB tests that skip on free-threaded interpreters, DuckDB requires the `duckdb` package, the SQLAlchemy DB-API raises `InterfaceError` on unparsable URLs, and `OracleQueueBackend` requires an executor (4 tasks).
* [ch03 — PostgreSQL/MySQL memory:// Removal and RESP3 Loopback Test Fixture](ch03-remove-memory-fakes/spec.md) — [planned] PostgreSQL and MySQL drivers reject `memory://` with in-memory rows deleted, and a threaded loopback `resp3_server` fixture replaces every `memory://` Redis and Valkey construction in the driver, store, Advanced Alchemy, Starlette, and framework unit tests (3 tasks).
* [ch04 — Redis and Valkey memory:// Removal](ch04-redis-valkey-memory-removal/spec.md) — [planned] `RedisConfig` drops the `memory` scheme, the remaining cache tests use the fixture or live-only conformance, and Redis and Valkey drivers delete memory execution and raise `ImproperConfigurationError` through every `from_redis` / `from_valkey` store factory (2 tasks).
* [ch05 — MSSQL and Oracle Codec Cleanup](ch05-mssql-oracle-codec-cleanup/spec.md) — [planned] Deletes the `encode_tds_sql_batch` binding, Rust TDS/TNS framing, the MSSQL and Oracle pools and dialect tags, and Python probes for unexported natives (4 tasks).
* [ch06 — vertebra-db Pools and MySQL Removal](ch06-vertebra-db-pools-and-mysql/spec.md) — [planned] Deletes the PostgreSQL, DuckDB, SQLite, and MySQL pools, the `mysql` module, the wallet directory loader, and the `sha2` / `rmp-serde` dependencies, and rewrites crate docs to describe codecs (4 tasks).
* [ch07 — Install Hints, Extras Gate, and Conformance Outcomes](ch07-install-hints-and-conformance/spec.md) — [planned] Corrects `MissingDependencyError` hints and `extra=` literals behind an AST gate, and makes conformance skip missing native modules, failing under Docker mode only for non-pending engines (4 tasks).
* [ch08 — PostgreSQL, Redis, and Spanner Queue Backend Fail-Loud Paths](ch08-queue-backend-fail-loud/spec.md) — [planned] PostgreSQL and Spanner queue backends require an injected executor and Redis/Valkey queue backends a live client, with the in-memory fakes moved into tests (3 tasks).
* [ch09 — Documentation and OKF Sync](ch09-docs-and-okf/spec.md) — [planned] Aligns README, database usage and reference docs, and OKF data, testing, product, and ADR chapters with the fail-loud driver baseline (4 tasks).
* [ch10 — Queue Backend Docs and Knowledge](ch10-queue-docs-and-knowledge/spec.md) — [planned] The queues usage guide, queues reference, and OKF distributed-queues chapter state the executor-or-raise and client-or-raise rules with install packages (1 task).
* [ch11 — Agent Knowledge, Dependency Groups, and Embeddings Docs](ch11-agent-knowledge-and-embeddings-docs/spec.md) — [planned] `AGENTS.md`, workflow, benchmark, tech-stack, and test-matrix knowledge state the GIL-only `duckdb` group and `resp3_server` fixture; dialect knowledge, landing pages, and Oracle embedding docs state `InterfaceError` and the pending Oracle and SQL Server drivers (4 tasks).
