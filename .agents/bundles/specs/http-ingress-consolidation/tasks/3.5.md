# 3.5 Lock-free backpressure

## Objective

Split `src/rs/vertebra-http/src/backpressure.rs` into `src/rs/vertebra-http/src/backpressure/{mod,circuit,streams}.rs`, replacing the global `Mutex<CircuitBreakerInner>` and unbounded `VecDeque<(Instant, bool)>` in `record_success`/`record_failure` with fixed-size lock-free time buckets (`HTTP-11`). Deduplicate the Open-to-HalfOpen transition logic using `#[repr(u8)] CircuitState` (`HTTP-12`), and wire `StreamLease` into `body::FrameReceiver` and SHM streaming responses so active stream counts and watermarks are tracked in production (`HTTP-14`).

## Context

- **`HTTP-11` (`src/rs/vertebra-http/src/backpressure.rs:397-439`):** Every response completion calls `record_success` or `record_failure`, which locks `self.circuit.lock()` and pushes `(Instant::now(), bool)` onto `samples: VecDeque<(Instant, bool)>`. Over a 10-second window at 100k req/s, `samples` grows to 1,000,000 entries and serializes every Tokio worker thread on one mutex.
- **`HTTP-12` (`src/rs/vertebra-http/src/backpressure.rs:222,289-321,409,425,436`):** The Open-to-HalfOpen phase transition is duplicated in two methods, `CircuitState` is shadowed by magic `0`/`1`/`2` `u8` literals, and `CircuitPhase` is `pub` despite being internal.
- **`HTTP-14` (`src/rs/vertebra-http/src/backpressure.rs:181-276`):** `acquire_stream`, `on_stream_chunk_enqueued`, `on_stream_chunk_dequeued`, and `StreamGuard` are only called in `tests/backpressure_streams_tests.rs`.
- **Symbol overlap note (depends on 3.4):** Extends `body::FrameReceiver` (from Task 3.1/3.4) with an optional `StreamLease` that calls `on_stream_chunk_dequeued()` on each yielded data frame and releases the stream slot on `Drop`, and wires `StreamLease` acquisition in `dispatcher/shm.rs` when opening a streaming correlation.
- **Strategy justification:** `regression_tdd` is used because the circuit breaker's sample storage grows without bound under load and stream watermarks are not updated when `FrameReceiver` streams chunks; a test asserting O(1) bounded bucket memory and automatic watermark updates on `FrameReceiver` poll fails before the change.

## Steps

- [x] 1. In `src/rs/vertebra-http/tests/backpressure_streams_tests.rs`, add two failing tests:
  - `circuit_breaker_window_is_bounded_and_lock_free`: records 200,000 outcomes across 8 threads and asserts the circuit breaker tracks the exact window totals in fixed-size buckets (16 buckets) without growing heap allocation or dropping concurrent updates.
  - `frame_receiver_with_stream_lease_updates_watermarks_on_poll_and_drop`: wraps a `mpsc::Receiver` and a `StreamLease` in `FrameReceiver`, enqueues chunks past the high watermark, polls `Body::poll_frame` to drain them, and asserts `is_stream_paused()` transitions `true` -> `false` and `active_streams` returns to `0` when `FrameReceiver` drops.
- [x] 2. Create `src/rs/vertebra-http/src/backpressure/circuit.rs` (`HTTP-11`, `HTTP-12`):
  - Define `#[repr(u8)] #[derive(Debug, Clone, Copy, PartialEq, Eq)] pub enum CircuitState { Closed = 0, Open = 1, HalfOpen = 2 }` with `from_u8(u8) -> Self`.
  - Implement a lock-free sliding window over `const BUCKETS: usize = 16` one-second slots:
    ```rust
    struct Bucket {
        epoch_sec: AtomicU64,
        successes: AtomicU64,
        failures: AtomicU64,
    }
    ```
    `record_success` and `record_failure` compute `now_sec = start_instant.elapsed().as_secs()`, select `bucket = &buckets[(now_sec as usize) & (BUCKETS - 1)]`, CAS-reset the bucket if `bucket.epoch_sec != now_sec`, increment `successes` or `failures` with `Ordering::Relaxed`, and evaluate transitions via a single `advance_phase` helper using `state.compare_exchange`. Keep `CircuitPhase` private.
- [x] 3. Create `src/rs/vertebra-http/src/backpressure/streams.rs` (`HTTP-14`) defining `StreamLease` (renamed from `StreamGuard`) with `on_chunk_enqueued(&self, bytes: usize)` and `on_chunk_dequeued(&self, bytes: usize)`. Update `src/rs/vertebra-http/src/body.rs` so `FrameReceiver` holds `lease: Option<StreamLease>`, calls `lease.on_chunk_dequeued(data.len())` whenever `poll_frame` yields a data frame, and drops `lease` on stream completion/drop. Wire `BackpressureController::acquire_stream` into `ShmDispatcher` (`src/rs/vertebra-http/src/dispatcher/shm.rs`) when a streaming response starts.
- [x] 4. Create `src/rs/vertebra-http/src/backpressure/mod.rs` holding `BackpressureController`, `BackpressureConfig`, `AdmissionPermit`, `RejectionReason`, and `BackpressureMetricsSnapshot`, and delete `src/rs/vertebra-http/src/backpressure.rs`.
- [x] 5. Add the `backpressure/record_contended_8_threads` Criterion benchmark group in `src/rs/vertebra-http/benches/server_throughput.rs` measuring 8 threads concurrently calling `record_success`/`record_failure`.
- [x] 6. Commit: `perf(http): replace circuit breaker mutex deque with lock-free atomic buckets and wire StreamLease` (signed), staging exactly the paths in `files`.

## Verification

- **Strategy:** `regression_tdd` — proves bounded fixed-bucket circuit tracking and live `FrameReceiver` stream watermark release with tests that fail before the change, plus a Criterion benchmark for contended recording.
- **Initial evidence:** `cargo test --manifest-path src/rs/Cargo.toml -p vertebra-http --test backpressure_streams_tests` → fails on `circuit_breaker_window_is_bounded_and_lock_free` and `frame_receiver_with_stream_lease_updates_watermarks_on_poll_and_drop`.
- **Final evidence:** `cargo test --manifest-path src/rs/Cargo.toml -p vertebra-http --features tls,compression --test backpressure_streams_tests` → exits 0 with all backpressure and stream lease tests passing.
- **Performance gate:** `cargo bench --manifest-path src/rs/Cargo.toml -p vertebra-http --bench server_throughput -- backpressure/record_contended_8_threads` → runs cleanly and records throughput in task verification evidence; `direct_dispatch/http11_concurrent_1000` does not regress > 3% vs `pre-refactor`.
