# 3.1 Shared body, correlation, and flag primitives

## Objective

Eliminate silent correlation generation truncation after `2^24` slot reuses by moving `src/rs/vertebra-http/src/correlation.rs` to `src/rs/vertebra-http/src/dispatcher/correlation.rs` and introducing a packed `CorrelationId(u64)` type that preserves all 32 bits of the generation counter alongside a 24-bit slot index and 8-bit shard index (`HTTP-19`, `OKF-01`). Collapse the five duplicate `mpsc::Receiver<Result<Frame<Bytes>, Infallible>>` body wrappers across `vertebra-http` into a single `body::FrameReceiver` implementing `http_body::Body` directly (`HTTP-08`), and replace the duplicate `FLAG_*` constant definitions in `response_reader.rs` and `grpc.rs` with `vertebra_core::protocol::flags::FrameFlags` (`HTTP-07`).

## Context

- **`HTTP-19` / `OKF-01` (`src/rs/vertebra-http/src/correlation.rs:49-89`, `src/rs/vertebra-http/src/dispatcher/shm.rs:156-176,276-277,333-334,386-387`, `src/rs/vertebra-http/src/dispatcher/mod.rs:174-175,203-204`):** `InFlightRequests::insert` (`correlation.rs:64`) returns `((generation as u64) << 32) | (index as u64)`, and `shm.rs:176` shifts that left by 8 (`(internal_id << 8) | (shard_idx as u64)`). That discards bits 24..31 of `generation`. When a slot's generation reaches `0x0100_0000`, `complete` compares the 32-bit stored generation against the truncated 24-bit generation from `(correlation_id >> 8) >> 32` and returns `false` on every subsequent completion for that slot. Because `SHARD_CAPACITY` is 8,192 (13 bits), a 24-bit slot field (`0..16_777_216`) leaves 32 full bits for `generation` and 8 bits for `shard`.
- **`HTTP-08` (`src/rs/vertebra-http/src/response.rs:33-72`, `collector.rs:20-41`, `sse.rs:28-49`, `http3.rs:69-95`, `grpc.rs:319-335`):** Five distinct structs (`ReceiverFrameStream`, `PendingResponseBody`, `SseFrameReceiverStream`, `H3ChannelBody`, `GrpcStreamBody`) wrap `mpsc::Receiver<Result<Frame<Bytes>, Infallible>>` to poll frames.
- **`HTTP-07` (`src/rs/vertebra-http/src/response_reader.rs:29-33`, `src/rs/vertebra-http/src/grpc.rs:22`):** Both files redefine `FLAG_STREAMING`, `FLAG_FINAL`, `FLAG_ERROR`, `FLAG_HEADERS_SENT`, and `FLAG_TRAILERS` instead of importing from `vertebra_core`.
- **Strategy justification:** `regression_tdd` is required because `OKF-01`/`HTTP-19` is a correlation completion defect when the 32-bit generation counter sets any of its top 8 bits.

- [x] 2. Move `src/rs/vertebra-http/src/correlation.rs` to `src/rs/vertebra-http/src/dispatcher/correlation.rs` and add `CorrelationId`:
  ```rust
  #[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
  pub struct CorrelationId(u64);

  impl CorrelationId {
      pub const MAX_SLOT: u32 = 0x00FF_FFFF;

      #[inline]
      pub const fn encode(shard: u8, slot: u32, generation: u32) -> Self {
          debug_assert!(slot <= Self::MAX_SLOT);
          let raw = ((generation as u64) << 32)
              | (((slot & Self::MAX_SLOT) as u64) << 8)
              | (shard as u64);
          Self(raw)
      }

      #[inline]
      pub const fn from_raw(raw: u64) -> Self {
          Self(raw)
      }

      #[inline]
      pub const fn raw(self) -> u64 {
          self.0
      }

      #[inline]
      pub const fn shard(self) -> usize {
          (self.0 & 0xFF) as usize
      }

      #[inline]
      pub const fn slot(self) -> usize {
          ((self.0 >> 8) & (Self::MAX_SLOT as u64)) as usize
      }

      #[inline]
      pub const fn generation(self) -> u32 {
          (self.0 >> 32) as u32
      }
  }
  ```
