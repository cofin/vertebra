# 3.7 Ingress endpoints

## Objective

Move `discovery.rs`, `profile.rs`, `assets.rs`, and `access_log.rs` under `src/rs/vertebra-http/src/ingress/` and wire them into `ingress::Pipeline`: replace the `DashMap` in `WellKnownDiscoveryCache` with fixed document slots and config-driven paths/headers and apply the Decision D3 benchmark rule (`HTTP-42`, `MCP-07`); make `/debug/pprof` return real mimalloc/process stats and `501 Not Implemented` when CPU sampling is not compiled, using `vertebra_core::util::crypto::constant_time_eq` (`HTTP-33`); index static asset metadata at startup and stream large files through `FrameReceiver` (`HTTP-43`); and route access logs into `vertebra_core::logger::AsyncLogCore` with valid JSON string escaping (`HTTP-34`).

## Context

- **`HTTP-42` & `MCP-07` (`src/rs/vertebra-http/src/discovery.rs:10,28-124`):** `WellKnownDiscoveryCache` uses a `DashMap<String, CachedDiscoveryDoc>` for three fixed documents, rebuilds a `HeaderMap` on every `serve` call, hardcodes `"2026-07-28"` (`:84`) and `DEFAULT_SPA_EXCLUDED_PREFIXES` (`:10`), and has zero callers outside `tests/mcp_discovery_bridge_tests.rs`. Under roadmap Decision D3, we wire it into `ingress::Pipeline` with config-driven paths and protocol version, benchmark `GET /.well-known/agent-card.json` against the Python route, and keep it if at least 5% faster (or delete `ingress/discovery.rs` in this same task if not).
- **`HTTP-33` (`src/rs/vertebra-http/src/profile.rs:16-25,51-53,76-99`):** `/debug/pprof/profile` returns fake JSON `{"profile":"cpu","pid":..,"threads":..}` instead of a profile, `is_authorized` is a one-line wrapper, and `constant_time_eq` duplicates `vertebra_core::util::crypto::constant_time_eq` (added in Chapter 2 Task 2.9). Under the roadmap stub policy (Global Constraint 6), `/debug/pprof/heap` returns real allocator/RSS metrics, while `/debug/pprof/profile` returns `501 Not Implemented` with an explicit diagnostic body unless CPU profiling is enabled, never fake profile JSON.
- **`HTTP-43` (`src/rs/vertebra-http/src/assets.rs:153,244,284,312-331`):** `StaticAssets::serve` calls `tokio::fs::read` (loading entire files into memory), runs up to three blocking `Path::is_file()` calls per request for `.br`/`.zst`/`.gz` sidecars, and implements a third `Accept-Encoding` parser (`accepts_encoding` at `:284`).
- **`HTTP-34` (`src/rs/vertebra-http/src/access_log.rs:47-166`):** `AccessLogger` pushes every log line onto an unbounded `Mutex<Vec<String>>` with no consumer, formats JSON strings with Rust `{:?}` (`:115`, which emits invalid JSON `\u{...}` escapes for control/non-ASCII characters), and never uses `format_utc_clf_timestamp` (`:166`).
- **Symbol overlap note (depends on 3.6):** Extends `ingress/pipeline.rs`, `ingress/mod.rs`, `config.rs`, and `lib.rs` created in Task 3.6.
- **Strategy justification:** `integration_acceptance` is used because this task wires four endpoint/filter modules into `ingress::Pipeline` and verifies end-to-end request interception, streaming responses, and negative refusal states (unauthorized profile request `401`, CPU profile stub refusal `501`, invalid JSON injection in access log paths).

## Steps

- [x] 1. Move `src/rs/vertebra-http/src/discovery.rs` to `src/rs/vertebra-http/src/ingress/discovery.rs` (`HTTP-42`, `MCP-07`):
  - Replace `DashMap<String, CachedDiscoveryDoc>` with a fixed-slot struct `WellKnownDocs` holding prebuilt `HeaderMap`s (`etag`, `cache-control`, and configurable `mcp-protocol-version` / `a2a-version` from `ServerConfig`) and configurable `spa_excluded_prefixes: Vec<Box<str>>`.
  - Wire `WellKnownDocs::try_intercept(&self, method, path, headers)` into `ingress::Pipeline::intercept_request`.
  - Execute the **Decision D3 benchmark rule**: benchmark `GET /.well-known/agent-card.json` (and `If-None-Match` `304`) with `oha -n 10000 -c 50` against `vertebra-server` with `WellKnownDocs` enabled vs routed through the Python worker.
    - **Outcome A (Rust cache >= 5% higher req/s or >= 10% lower p99 latency):** Keep `src/rs/vertebra-http/src/ingress/discovery.rs` wired in `Pipeline` and record both numbers in `## Notes & Discoveries`.
    - **Outcome B (Rust cache < 5% faster):** Delete `src/rs/vertebra-http/src/ingress/discovery.rs` and its `Pipeline` hook in this task, move `spa_excluded_prefixes` into `ingress/assets.rs`, delete the discovery cache tests from `tests/mcp_discovery_bridge_tests.rs`, and record both numbers in `## Notes & Discoveries`.
- [x] 2. Move `src/rs/vertebra-http/src/profile.rs` to `src/rs/vertebra-http/src/ingress/profile.rs` (`HTTP-33`):
  - Delete local `constant_time_eq` and `is_authorized` pass-through; call `vertebra_core::util::crypto::constant_time_eq` directly.
  - On `/debug/pprof/heap`, return real process memory/allocator telemetry JSON (`rss_bytes`, `pid`, `uptime_ms`). On `/debug/pprof/profile`, return `501 Not Implemented` (`{"error":"cpu profiling requires the profiling backend"}`) instead of fake CPU profile JSON, and wire `ProfileEndpoint` into `ingress::Pipeline`.
- [x] 3. Move `src/rs/vertebra-http/src/assets.rs` to `src/rs/vertebra-http/src/ingress/assets.rs` (`HTTP-43`):
  - At startup (`StaticAssets::new`), scan the root directory / manifest once to build an immutable `HashMap<Box<str>, AssetEntry>` containing file length, mtime, ETag `HeaderValue`, available precompressed sidecar mask (`.zst`, `.br`, `.gz`), and an in-memory `Bytes` payload for fingerprinted assets `<= 64 KiB`.
  - Delete `accepts_encoding` (`:284`) and reuse `ingress::compression::ResponseCompressor::negotiate_codec`.
  - For files `> 64 KiB` (non-range), stream chunks via `tokio::fs::File` and a bounded `mpsc::Sender` feeding `body::FrameReceiver` instead of calling `tokio::fs::read` on the whole file. Wire `StaticAssets` into `ingress::Pipeline`.
- [x] 4. Move `src/rs/vertebra-http/src/access_log.rs` to `src/rs/vertebra-http/src/ingress/access_log.rs` (`HTTP-34`):
  - Replace `Mutex<Vec<String>>` with an `Arc<vertebra_core::logger::AsyncLogCore>` bounded ring buffer sink (with `drain_lines()` reading from `AsyncLogCore` for tests).
  - Add a RFC 8259 JSON string escaper (`escape_json_str` escaping `"`, `\`, and control bytes `0x00..=0x1F` as `\u00XX`, never Rust `{:?}` `\u{...}`), wire `format_utc_clf_timestamp` to the `%t` format token, and call `AccessLogger::log_exchange` in `ingress::Pipeline::finish_response`.
- [x] 5. Update `src/rs/vertebra-http/tests/assets_and_observability_tests.rs` and `src/rs/vertebra-http/tests/mcp_discovery_bridge_tests.rs` to test the endpoints through `ingress::handle` (including JSON validation via `serde_json::from_str` on paths containing control characters and quotes, `401` on unauthorized `/debug/pprof/heap`, `501` on `/debug/pprof/profile`, and streaming static asset delivery).
- [x] 6. Commit: `refactor(http): wire discovery, profile, streaming assets, and bounded access log in ingress` (signed), staging exactly the paths in `files`.

## Verification

- **Strategy:** `integration_acceptance` — verifies end-to-end ingress handling for discovery, profiling, static assets, and access logging, including negative refusal states (`401`/`501` on profile endpoint, control-char escaping in JSON access logs, `304` conditional caching).
- **Initial evidence:** `cargo test --manifest-path src/rs/Cargo.toml -p vertebra-http --test assets_and_observability_tests --test mcp_discovery_bridge_tests` → green baseline on isolated unit types before pipeline integration.
- **Final evidence:** `cargo test --manifest-path src/rs/Cargo.toml -p vertebra-http --features tls,compression --test assets_and_observability_tests --test mcp_discovery_bridge_tests` → exits 0 with all pipeline-routed endpoint tests passing.
- **Gate proof:** Requesting `/debug/pprof/heap` without a matching bearer token returns `401 Unauthorized`; requesting `/debug/pprof/profile` with a valid token returns `501 Not Implemented` (no fake profile JSON); logging a request URI containing `"\x07\n` produces a JSON line that `serde_json::from_str::<serde_json::Value>` parses without error.

## Acceptance Criteria

- [x] `discovery.rs`, `profile.rs`, `assets.rs`, and `access_log.rs` at the crate root are deleted and replaced by modules under `src/rs/vertebra-http/src/ingress/` (with `discovery.rs` kept or removed per the recorded Decision D3 benchmark result).
- [x] `StaticAssets` indexes file metadata and sidecars at startup, reuses `ResponseCompressor` for encoding negotiation, and streams files `> 64 KiB` via `FrameReceiver`.
- [x] `AccessLogger` holds no unbounded `Mutex<Vec<String>>`, supports the `%t` UTC timestamp token, and emits valid RFC 8259 JSON verified by `serde_json::from_str`.
- [x] `ProfileEndpoint` uses `vertebra_core::util::crypto::constant_time_eq` and returns `501 Not Implemented` for unimplemented CPU profiling rather than placeholder data.
- [x] `make lint` exits 0; no new `# ` comments, nested imports, aliases, or private-module imports.
