# Task 7.5 — Extract `SchemaEmitter`, split `procedures.py`, unify `ZodGenerator`/`ValibotGenerator`, and emit `routes.ts`

## Objective

Add `gc=False` to `TypeNode` (`FE-22`), extract a shared `SchemaEmitter` base class eliminating 6-way `_collect_objects` duplication (`FE-15`), split `src/py/vertebra/build/codegen/procedures.py` into `markers.py`, `_json_schema.py`, and `procedures.py` (`FE-16`), unify the `ZodGenerator` and `ValibotGenerator` entry points (`FE-17`), replace all 5 manual `msgspec.json.format(encode_json_bytes(...))` sites with `format_json` from `vertebra.utils.serializers` (`FE-18`), and emit a typed `routes.ts` table in `BuildOrchestrator._run_codegen` (`FE-19`).

## Context

- `src/py/vertebra/build/codegen/_ir.py:27` defines `class TypeNode(msgspec.Struct, frozen=True):` without `gc=False`, so all 7 IR subclasses carry `PyGC_Head` overhead (`FE-22`).
- `_collect_objects` is duplicated 6 times across `_typescript.py:130`, `zod.py:157`, `valibot.py:157`, `openapi.py:131`, `protobuf.py:140`, and `procedures.py:617`, and `ProcedureClientGenerator` (`procedures.py:424-650`) re-implements TypeScript interface and type-reference rendering already in `TypeScriptGenerator` (`FE-15`).
- `src/py/vertebra/build/codegen/procedures.py` (668 lines) combines Litestar parameter/body markers (lines 1-235), JSON Schema-to-`TypeNode` conversion (lines 236-352), the `@procedure` decorator and `ProcedureRegistry` (lines 353-423), and `ProcedureClientGenerator` (lines 424-668) (`FE-16`).
- `ZodGenerator` (`zod.py:37-125`) and `ValibotGenerator` (`valibot.py:37-125`) each expose three overlapping methods (`generate`, `generate_from_node`, `generate_from_schema`) where `generate` accepts `Iterable[RouteMetadata] | TypeNode | dict[str, Any]` (`FE-17`).
- `_import_map.py:72`, `_orchestrator.py:103,112`, `packaging/standalone.py:101`, and `codegen/_manifest.py:33` call `msgspec.json.format(encode_json_bytes(...), indent=2).decode(...)` instead of `format_json(..., indent=2)`, while `_manifest.py:8` and `_watch.py:14` import from private `vertebra.utils.serializers._json` (`FE-18`).
- `src/py/vertebra/build/_orchestrator.py:211` writes `export const routes = {};` after collecting `routes = RouteCollector().collect(app)` (`FE-19`).

## Steps

1. In `src/py/vertebra/build/codegen/_ir.py:27`:
   - Change `class TypeNode(msgspec.Struct, frozen=True):` to `class TypeNode(msgspec.Struct, frozen=True, gc=False):` (`FE-22`).
2. Create `src/py/vertebra/build/codegen/_emitter.py` (`FE-15`):
   - Define `class SchemaEmitter` with `self._declared: dict[str, ObjectType] = {}`, `reset(self) -> None`, `_collect_route_objects(self, routes: Iterable[RouteMetadata]) -> list[RouteMetadata]`, and `_collect_objects(self, node: TypeNode) -> None` walking `ObjectType`, `ArrayType`, `RecordType`, `UnionType`, and `OptionalType`.
3. Split `src/py/vertebra/build/codegen/procedures.py` (`FE-16`):
   - Move `Parameter`, `Body`, `FromPath`, `FromQuery`, `FromHeader`, `FromCookie`, `FromBody`, `Dependency`, `Provide`, and `SkipValidation` into `src/py/vertebra/build/codegen/markers.py`.
   - Move `ParameterResolution`, `json_schema_to_type_node`, and `resolve_parameter_node` into `src/py/vertebra/build/codegen/_json_schema.py`.
   - Keep `ProcedureParam`, `ProcedureInfo`, `ProcedureRegistry`, `get_procedure_registry`, `procedure`, and `ProcedureClientGenerator` in `src/py/vertebra/build/codegen/procedures.py`, importing `SchemaEmitter` from `_emitter.py` and delegating TypeScript interface and type-reference rendering to `TypeScriptGenerator`.
   - Update `src/py/vertebra/build/codegen/__init__.py` to import marker symbols from `vertebra.build.codegen.markers` and `_json_schema` symbols from `vertebra.build.codegen._json_schema`.
4. Refactor `_typescript.py`, `zod.py`, `valibot.py`, `openapi.py`, and `protobuf.py` to inherit from `SchemaEmitter` (`FE-15`, `FE-17`):
   - Remove the per-class `_collect_objects` copies from all 5 files.
   - In `ZodGenerator` (`zod.py`) and `ValibotGenerator` (`valibot.py`), narrow `generate(self, routes: Iterable[RouteMetadata]) -> str` to accept only `Iterable[RouteMetadata]` and consolidate `generate_from_node` / `generate_from_schema` into a single `emit_schema(self, name: str, schema: TypeNode | dict[str, Any]) -> str` method. Update callers in `src/py/vertebra/build/codegen/plugin.py` and `src/py/tests/unit/extensions/test_codegen_suite.py`.
5. Replace manual `msgspec.json.format` formatting (`FE-18`):
   - In `src/py/vertebra/build/_import_map.py:72`, `src/py/vertebra/build/_orchestrator.py:103,112`, `src/py/vertebra/build/packaging/standalone.py:101`, and `src/py/vertebra/build/codegen/_manifest.py:33`, replace `msgspec.json.format(encode_json_bytes(...), indent=2).decode("utf-8")` with `format_json(..., indent=2)` imported from `vertebra.utils.serializers`.
   - In `src/py/vertebra/build/codegen/_manifest.py:8` and `src/py/vertebra/build/codegen/_watch.py:14`, change `from vertebra.utils.serializers._json import ...` to `from vertebra.utils.serializers import ...`.
6. In `src/py/vertebra/build/_orchestrator.py:210-211` (`FE-19`):
   - Replace `(output_dir / "routes.ts").write_text("export const routes = {};\n")` with a helper `_render_routes_ts(routes: list[RouteMetadata]) -> str` that emits each route's `operation_id: { method: "<METHOD>", path: "<path>" }` inside `export const routes = { ... } as const;`.
