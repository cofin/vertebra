# Task 7.2 — Fix `PySourceWatcher.poll_events` signature mismatch and `BuildOrchestrator` dev watcher lifetime

## Objective

Fix the `PySourceWatcher::poll_events` signature in Rust so it accepts `timeout_ms: Option<u64>` and blocks without the GIL (`FE-14`), retain the native dev watcher/bundler on `BuildOrchestrator` with a background rebuild/HMR loop and explicit `stop()` lifecycle (`FE-13`), and replace mock-only orchestrator/watcher tests with real native-extension tests (`TST-10`).

## Context

- `src/rs/vertebra-bundler/src/hmr.rs:185` defines `pub fn poll_events(&self) -> PyResult<Vec<String>>` with 0 arguments, while `src/py/vertebra/build/codegen/_watch.py:139` calls `watcher.poll_events(timeout_ms)` inside `try: ... except Exception: break`. On the first loop iteration Python raises `TypeError: SourceWatcher.poll_events() takes no arguments (1 given)`, which is caught and silently terminates the watcher thread (`FE-14`).
- `src/py/vertebra/build/_orchestrator.py:151-160` (`_run_native(dev=True)`) creates a local `bundler = bundler_mod.Bundler()`, calls `bundler.start_dev(dev_config)`, and returns `True` without storing `bundler` on `self`. When `_run_native` returns, `bundler` is garbage-collected and its `SourceWatcher` is dropped (`FE-13`).
- `src/py/tests/unit/framework/test_orchestrator.py` mocks `vertebra._bundler` with `MagicMock` in every native test, which is why neither `FE-13` nor `FE-14` was caught (`TST-10`).

## Steps

1. Write failing regression tests first (`regression_tdd`):
   - In `src/py/tests/unit/codegen/test_codegen_watch.py` (new test module), write a test that starts `CodegenWatcher([tmp_path], callback, debounce_ms=50)` using the real `vertebra._bundler.SourceWatcher`, modifies a `.py` file in `tmp_path`, and asserts that `callback` is invoked within `2.0 s` with the modified file path.
   - In `src/py/tests/unit/framework/test_orchestrator.py`, add two real-extension tests (without mocking `vertebra._bundler`):
     - `test_native_build_real_extension_writes_bundle`: creates `src/main.ts` with `export const answer: number = 42;`, runs `BuildOrchestrator(tmp_path, BuildConfig(entry="src/main.ts", outdir="dist")).build()`, and asserts `(tmp_path / "dist" / "main.js").is_file()`.
     - `test_native_dev_retains_watcher_and_rebuilds_on_change`: starts `orch.dev()`, asserts `orch.is_watching` is `True`, modifies `src/main.ts`, waits for the rebuilt `dist/main.js` content to update, and calls `orch.stop()`.
2. In `src/rs/vertebra-bundler/src/hmr.rs`:
   - Update `PySourceWatcher::poll_events` to:
     ```rust
     #[pyo3(signature = (timeout_ms=None))]
     pub fn poll_events(&self, py: Python<'_>, timeout_ms: Option<u64>) -> PyResult<Vec<String>>
     ```
   - Clone the `crossbeam_channel::Receiver<HmrEvent>` under the mutex lock, then inside `py.detach(|| { ... })`:
     - If `timeout_ms` is `Some(ms)` and `ms > 0`, wait for the first event with `rx.recv_timeout(Duration::from_millis(ms))` and then drain any additional queued events via `rx.try_recv()`.
     - If `timeout_ms` is `None` or `Some(0)`, drain immediately via `rx.try_recv()`.
   - Collect paths from `HmrEvent::Update { path, .. }` into `Vec<String>` and return `Ok(paths)`.
   - Add `Bundler::poll_events(&self, py: Python<'_>, timeout_ms: Option<u64>) -> PyResult<Vec<String>>` in `src/rs/vertebra-bundler/src/bundler.rs` using the same receiver drain logic.
   - In `src/py/vertebra/_bundler.pyi` (created in `4.1`), update `SourceWatcher.poll_events(self, timeout_ms: int | None = None) -> list[str]` and `Bundler.poll_events(self, timeout_ms: int | None = None) -> list[str]` so `mypy.stubtest vertebra._bundler` passes.
3. In `src/py/vertebra/build/codegen/_watch.py`:
   - In `_watch_rust` (`_watch.py:124-156`), log unexpected exceptions via `logger.warning("CodegenWatcher poll error", exc_info=True)` instead of silently breaking on the first transient exception, while exiting cleanly when `self._stop_event.is_set()`.
   - Ensure `watcher.stop()` is called in a `finally:` block when `_watch_rust` exits.
4. In `src/py/vertebra/build/_orchestrator.py`:
   - Add `self._native_bundler: Any = None`, `self._dev_watch_thread: threading.Thread | None = None`, and `self._stop_event = threading.Event()` to `BuildOrchestrator.__init__`, plus a `is_watching` property and `stop(self) -> None` method (registered via `atexit.register(self.stop)` when dev watching starts).
   - In `_run_native(self, *, dev: bool)`:
     - Perform an initial bundle build so `outdir/<entry_stem>.js` exists immediately on `dev()` startup.
     - When `dev=True`, retain `self._native_bundler = bundler`, start `bundler.start_dev(dev_config)`, and spawn a daemon thread `self._dev_watch_thread` that loops on `bundler.poll_events(200)` until `self._stop_event.is_set()`, re-running `bundler.build(bundle_config)` on changed files and notifying `HmrNotifier(self._hmr_base_url).notify_reload(reason=changed_path)` when `self._hmr_base_url` is set.
   - In `BuildOrchestrator.stop(self)`: set `self._stop_event`, join `self._dev_watch_thread`, call `self._native_bundler.stop_dev()`, and stop `self._vite_process` if active.
5. In `src/py/vertebra/cli/dev.py`:
   - Retain the `BuildOrchestrator` instance created in `_start_frontend_orchestrator` and ensure `orchestrator.stop()` is called on shutdown alongside `watcher.stop()`.
