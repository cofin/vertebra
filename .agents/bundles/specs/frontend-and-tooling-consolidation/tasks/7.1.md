# Task 7.1 — Clean up `vertebra-bundler` dead state, error mapping, and unused dependencies

## Objective

Remove dead `hmr_rx` receiver state from `Bundler` (`FE-02`), route all `vertebra-bundler` PyO3 error conversions through `From<BundlerError> for PyErr` with a `BundlerError::Poisoned` variant (`FE-08`), replace `tokio::sync::broadcast` and unused `serde`/`serde_json` dependencies in `vertebra-bundler` with `crossbeam-channel` (`FE-09`), and release the GIL inside `Bundler::check_file` (`FE-11`).

## Context

- `src/rs/vertebra-bundler/src/bundler.rs:25,68,93` stores `hmr_rx: Option<broadcast::Receiver<HmrEvent>>` inside `Bundler`, assigns `Some(rx)` in `start_dev`, and resets `None` in `stop_dev`, but no method ever reads from `hmr_rx` (`FE-02`).
- `src/rs/vertebra-bundler/src/errors.rs:29-33` already implements `From<BundlerError> for PyErr`, yet `bundler.rs:35,47-50,65,75,89,103-104,154,175`, `hmr.rs:157,168-181,189,203,212`, and `ssr.rs:299,305` manually map errors via `.map_err(|e| PyRuntimeError::new_err(e.to_string()))`, and `Bundler::new()` returns `PyResult<Self>` despite being infallible (`FE-08`).
- `src/rs/vertebra-bundler/Cargo.toml:36-40` depends on `tokio = { workspace = true }` (`full` features), `serde = { workspace = true }`, and `serde_json = { workspace = true }` only so `hmr.rs:14-48,74` can create a `tokio::sync::broadcast::channel(100)` and derive `Serialize, Deserialize` on `BundleConfig`, `DevConfig`, and `HmrEvent`. `HmrEvent::connected` (`hmr.rs:41-46`) and `HmrEvent::to_json` (`hmr.rs:50-57`) are dead (`#[allow(dead_code)]`), and `PySourceWatcher` (`hmr.rs:140-142`) wraps `Arc<Mutex<Option<SourceWatcher>>>` (`FE-09`).
- `src/rs/vertebra-bundler/src/bundler.rs:108-117` (`Bundler::check_file`) runs `oxc_parser::Parser` while holding the Python GIL, unlike `build` and `transform_file` (`FE-11`).

## Steps

1. In `src/rs/vertebra-bundler/Cargo.toml`:
   - Remove `tokio = { workspace = true }`, `serde = { workspace = true }`, and `serde_json = { workspace = true }` from `[dependencies]`.
   - Add `crossbeam-channel = { workspace = true }` to `[dependencies]`.
2. In `src/rs/vertebra-bundler/src/errors.rs`:
   - Add `#[error("Lock poisoned: {0}")] Poisoned(&'static str)` to `BundlerError`.
3. In `src/rs/vertebra-bundler/src/config.rs`:
   - Remove `use serde::{Deserialize, Serialize};` and remove `Serialize, Deserialize` from `#[derive(...)]` on `BundleConfig` (line 10) and `DevConfig` (line 112).
4. In `src/rs/vertebra-bundler/src/hmr.rs`:
   - Remove `use serde::{Deserialize, Serialize};` and `use tokio::sync::broadcast;`; import `crossbeam_channel::{Receiver, Sender, bounded}`.
   - Remove `Serialize, Deserialize` from `HmrEvent` and delete the dead `HmrEvent::connected` and `HmrEvent::to_json` methods (`hmr.rs:40-57`).
   - Replace `tx: broadcast::Sender<HmrEvent>` in `SourceWatcher` with `tx: Sender<HmrEvent>` and `rx: Receiver<HmrEvent>` created via `bounded(256)` in `SourceWatcher::new`. Update `start`, `notify_type_change`, and `notify_reload` to use `let _ = self.tx.try_send(...)`, and have `SourceWatcher::start(&mut self) -> Result<Receiver<HmrEvent>, BundlerError>` return `Ok(self.rx.clone())`.
   - Simplify `PySourceWatcher` (`hmr.rs:140-216`) to hold a single `Mutex<WatcherState>` (containing `watcher: Option<SourceWatcher>` and `rx: Option<Receiver<HmrEvent>>` alongside `watch_dirs`, `extensions`, `debounce_ms`) instead of `Arc<Mutex<Option<SourceWatcher>>>` + `Arc<Mutex<Option<Receiver<HmrEvent>>>>`, and map lock errors via `.map_err(|_| BundlerError::Poisoned("watcher"))?` and `From<BundlerError> for PyErr`.
5. In `src/rs/vertebra-bundler/src/bundler.rs`:
   - Remove `use tokio::sync::broadcast;`, remove `hmr_rx` from `Bundler` (`bundler.rs:25`), add `rx: Option<crossbeam_channel::Receiver<HmrEvent>>` inside `Bundler` (or expose `poll_events(&self) -> PyResult<Vec<String>>` draining `self.rx`), and derive `Default` on `Bundler`.
   - Change `#[new] pub fn new() -> Self { Self::default() }` (infallible).
   - Replace all `.map_err(|e| PyRuntimeError::new_err(...))` calls in `build`, `start_dev`, `stop_dev`, `notify_type_change`, `notify_reload`, `transform_file`, `init_ssr`, `ssr_render`, `ssr_invalidate`, and `ssr_shutdown` with `?` over `BundlerError` (`BundlerError::Poisoned(...)` for mutex locks).
   - Update `Bundler::check_file` (`bundler.rs:108-117`) to accept `py: Python<'_>` and execute the `Allocator` + `Parser::new` parse inside `py.detach(|| { ... })`.
6. In `src/rs/vertebra-bundler/src/ssr.rs`:
   - Replace `.map_err(|e| PyRuntimeError::new_err(e.to_string()))` in `SsrPool::new` (line 299) and `SsrPool::render` (line 305) with `?`.
7. Update unit tests in `src/rs/vertebra-bundler/src/hmr.rs` and `src/rs/vertebra-bundler/src/bundler.rs` to use `crossbeam_channel::Receiver::recv_timeout` and `Bundler::new()`.
