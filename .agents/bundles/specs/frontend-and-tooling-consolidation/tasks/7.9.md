# Task 7.9 — Harden `Makefile`, `setup-env.sh`, `pyproject.toml` Ruff/Mypy coverage, `.gitignore`, CI `http3` feature gate, `benchmark.yml`, and OKF workflow/test-matrix docs

## Objective

Extend shared-memory test cleanup to `/dev/shm/vtb-*` (`TOOL-01`), add `http3` feature testing and `tools/**` paths-filter coverage to `.github/workflows/ci.yml` (`TOOL-02`), deduplicate mirror detection and clean stale `.npmrc` files in `tools/scripts/setup-env.sh` (`TOOL-03`), expand Ruff rules (`B,BLE,C4,E,F,FURB,I,PERF,PIE,PLW0603,PT,PYI036,RET,RSE,RUF,S110,SIM,SLOT,T20,TID,TRY,UP`) and lint/typecheck `tools/benchmarks` (`TOOL-04`), clean up `.gitignore` and stop ignoring tracked `src/py/vertebra/server/_js/bundle/` (`TOOL-05`), fix `.github/workflows/benchmark.yml` (`TOOL-06`), add missing `__init__.py` files to test packages (`TOOL-07`), and update OKF workflow/test-matrix/tech-stack documentation (`OKF-05`, `OKF-06`).

## Context

- `Makefile:109` (`rs-test`) and `src/py/tests/conftest.py:29` (`_cleanup_shm`) remove `/dev/shm/test-*` and `/dev/shm/*vertebra*`, missing runtime segments named `/vtb-{pid:x}-{seq:x}-{attempt:x}` (`TOOL-01`).
- `.github/workflows/ci.yml:30-44,102-123` never runs `cargo test` with the `http3` feature (leaving `src/rs/vertebra-http/tests/http3_quic_tests.rs` uncompiled in CI) and omits `tools/**` from `dorny/paths-filter` (`TOOL-02`).
- `tools/scripts/setup-env.sh:28-35` removes `uv.toml` and `src/rs/.cargo/config.toml` on non-mirror hosts, but never removes `.npmrc` or `src/ts/vertebra-client/.npmrc` (`TOOL-03`).
- `pyproject.toml:84-99` selects only `["E", "F", "I", "UP", "B", "SIM"]` and `Makefile:97-105` runs Ruff and Mypy only on `src/py/vertebra` and `src/py/tests`, skipping `tools/benchmarks` (`TOOL-04`).
- `.gitignore` contains duplicate entries (`.tmp`, `.mypy-cache`, `build` negations), dead `detect_mcp_tools.py` entries, and line 87 (`src/py/vertebra/server/_js/bundle/`) ignores tracked bundle files (`TOOL-05`).
- `.github/workflows/benchmark.yml:21,50-54,74-81` sets `UV_SYSTEM_PYTHON: "1"` (conflicting with `.venv`), runs `make install` followed by `make build` (building TS and Rust twice), and commits binary `.duckdb` files directly to `main` (`TOOL-06`).
- `src/py/tests/unit/build/`, `src/py/tests/unit/storage/`, and `src/py/tests/unit/telemetry/` lack `__init__.py` (`TOOL-07`).

## Steps

1. In `Makefile` and `src/py/tests/conftest.py` (`TOOL-01`, `TOOL-04`):
   - In `Makefile` (`rs-test`), update the cleanup command to `rm -rf /dev/shm/test-* /dev/shm/*vertebra* /dev/shm/vtb-*`.
   - In `src/py/tests/conftest.py:29`, add `"/dev/shm/vtb-*"` to the `_cleanup_shm` glob list.
   - In `Makefile` (`py-lint`, `py-check`), include `tools/benchmarks` in `ruff check` and `ruff format` paths, and add `cd src/ts/vertebra-client && bunx tsc --noEmit` to `ts-check`.
2. In `tools/scripts/setup-env.sh` (`TOOL-03`):
   - Remove `.npmrc` and `src/ts/vertebra-client/.npmrc` alongside `uv.toml` and `src/rs/.cargo/config.toml` before the `/etc/os-release` mirror check so non-mirror hosts never retain stale generated `.npmrc` files.
3. In `pyproject.toml` (`TOOL-04`):
   - Expand `[tool.ruff.lint] select` to:
     ```toml
     select = [
       "B",
     ```

   - Add minimal per-file-ignores only for legitimate CLI/benchmark output (`"tools/benchmarks/**" = ["T20"]`, `"src/py/tests/**" = ["S110", "TRY003", "BLE001"]`) and fix any newly flagged violations in `src/py/vertebra/`, `src/py/tests/`, and `tools/benchmarks/`.
   - Remove the stale `"_bundler"` entry from `[[tool.mypy.overrides]] module` (replaced by `"vertebra._bundler"` in Chapter 4 Task `4.1`).
4. Add empty `__init__.py` files to `src/py/tests/unit/build/__init__.py`, `src/py/tests/unit/storage/__init__.py`, and `src/py/tests/unit/telemetry/__init__.py` (`TOOL-07`).
5. In `.github/workflows/ci.yml` (`TOOL-02`):
   - Add `tools/benchmarks/**` to the `python` filter and `tools/scripts/**` to the `ci` filter in `changes`.
   - Update `test-rust-features` matrix to test `features: tls,compression,http3` on `ubuntu-latest` and `features: tls,compression,http3,macos-ulock` on `macos-latest`.
6. In `.github/workflows/benchmark.yml` (`TOOL-06`):
   - Remove `UV_SYSTEM_PYTHON: "1"` from `env`.
   - Remove the redundant `make build` step after `make install` because `make bench` and `make bench-all` already depend on `build`.
   - Remove the `Commit History (on main only)` step (`benchmark.yml:74-81`) that pushes `.duckdb` binary commits to `main`, keeping artifact upload (`actions/upload-artifact@v4`) as the sole benchmark storage mechanism.
7. Clean up `.gitignore` (`TOOL-05`):
   - Remove duplicate `.tmp`, `.mypy-cache`, and `!src/py/vertebra/build` entries, remove dead `tools/scripts/detect_mcp_tools.py` and `src/rs/tools/scripts/detect_mcp_tools.py` entries, and remove `src/py/vertebra/server/_js/bundle/` so changes to tracked bundle files are visible to `git status`.
8. Update `.agents/bundles/knowledge/workflow.md`, `.agents/bundles/knowledge/testing/polyglot-test-matrix.md`, and `.agents/bundles/product/tech-stack.md` (`OKF-05`, `OKF-06`) to reflect the fixed `make ts-build` gate, `/dev/shm/vtb-*` cleanup, `http3` CI feature matrix, `vertebra.build.packaging.pgo` module location, and expanded Ruff/TypeScript verification gates.
