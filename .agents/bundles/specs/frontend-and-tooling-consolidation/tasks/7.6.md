# Task 7.6 — Harden `vertebra.build` (`_fallback.py`, lazy `__init__.py`, `_onefile_extract.py`, `pgo.py`) and complete `vertebra.cli` (`init.py`, `_launch.py`, flags)

## Objective

Unify Vite binary discovery and drop `shell=True`/`preexec_fn` in `build/_fallback.py` (`FE-20`), convert `build/__init__.py` to lazy exports with a 5-symbol `__all__` (`FE-21`), deduplicate `OnefileBuilder` trailer extraction via `_onefile_extract.py` (`FE-23`), move `tools/pgo/` into `vertebra/build/packaging/pgo.py` using `msgspec.Struct(frozen=True, gc=False)` and wire it into `StandaloneBuilder` (`FE-24`), implement `vtb init` project scaffolding (`FE-25`), wire dead CLI options/parameters (`FE-26`), and unify server environment assembly across `cli/run.py` and `cli/dev.py` (`FE-27`).

## Context

- `src/py/vertebra/build/_fallback.py:42-65,135-146` duplicates Vite binary lookup between `DevServerProcess.start` and `run_vite_build`, and `DevServerProcess.start` spawns `subprocess.Popen(cmd, shell=True, preexec_fn=os.setsid)` (`FE-20`).
- `src/py/vertebra/build/__init__.py:1-58` eagerly imports 31 symbols across `_config`, `_orchestrator`, `codegen`, and `packaging` (`FE-21`).
- `src/py/vertebra/build/packaging/onefile.py:39-134` duplicates trailer magic/size/SHA-256 verification and decompression inside `_launcher_stub` and `OnefileBuilder.inspect_trailer` / `extract_archive` (`FE-23`).
- `tools/pgo/rust_pgo.py` and `tools/pgo/python_pgo.py` use `@dataclass` instead of `msgspec.Struct(frozen=True, gc=False)` and are never called by `StandaloneBuilder` when `pgo_enabled=True` (`FE-24`).
- `src/py/vertebra/cli/init.py:13-34` prints a message without creating a directory or any files (`FE-25`).
- `cli/build.py:73` (`_ = profile`), `cli/dev.py:48` (`_ = verbose`), `cli/banner/renderer.py:31,35` (`_ = log_level`), and `cli/errors.py:39-42` (`_ = file`) ignore their arguments (`FE-26`).
- `cli/run.py:92-120` and `cli/dev.py:113-135` assemble different subsets of `VERTEBRA_*` environment variables when launching the server (`FE-27`).

## Steps

1. In `src/py/vertebra/build/_fallback.py` (`FE-20`):
   - Extract `def _resolve_vite_argv(*args: str) -> list[str]:` returning `[vite_bin, *args]` when `shutil.which("vite")` is found or `[npx_bin, "vite", *args]` when `shutil.which("npx")` is found (raising `RuntimeError("Neither 'vite' nor 'npx' found on PATH")` otherwise).
   - In `DevServerProcess.start`, pass the argument list directly to `subprocess.Popen(argv, ..., start_new_session=True)` with `shell=False` and no `preexec_fn`.
2. In `src/py/vertebra/build/__init__.py` (`FE-21`):
   - Replace eager imports with `lazy_exports` from `vertebra.utils.module_loading` exposing `__all__ = ("BuildConfig", "BuildOrchestrator", "JsConfig", "codegen", "packaging")`.
   - Update callers in `src/py/vertebra/cli/build.py` and `src/py/tests/unit/build/test_packaging_and_pgo.py` to import `BuildTarget`, `OnefileBuilder`, `StandaloneBuilder`, and PGO helpers from `vertebra.build.packaging`.
3. Create `src/py/vertebra/build/packaging/_onefile_extract.py` and update `onefile.py` (`FE-23`):
   - Move `TRAILER_MAGIC`, `TRAILER_STRUCT`, `inspect_trailer_bytes(payload: bytes) -> tuple[int, int, str]`, and `extract_payload_archive(binary_path: Path, cache_root: Path) -> Path` into `_onefile_extract.py`.
   - Have `OnefileBuilder.inspect_trailer` and `OnefileBuilder.extract_archive` call `_onefile_extract`, and embed `inspect.getsource(_onefile_extract)` inside `OnefileBuilder._launcher_stub()` so the self-extracting stub and `OnefileBuilder` share a single implementation.
4. Move `tools/pgo/{rust_pgo,python_pgo}.py` into `src/py/vertebra/build/packaging/pgo.py` and delete `tools/pgo/` (`FE-24`):
   - Convert `RustPgoConfig`, `PythonBuildInfo`, and `PlatformSupport` from `@dataclass` to `msgspec.Struct(frozen=True, gc=False)`.
   - Re-export `PlatformSupport`, `PythonBuildInfo`, `RustPgoConfig`, `build_cargo_pgo_env`, `detect_python_pgo_lto`, `merge_profdata_command`, `resolve_llvm_profdata`, and `validate_pgo_support` from `vertebra.build.packaging`.
   - In `StandaloneBuilder.build()` (`src/py/vertebra/build/packaging/standalone.py:66-105`), when `self.pgo_enabled` is `True`, call `detect_python_pgo_lto()` and `RustPgoConfig(profile_dir=output_dir / "pgo-profiles").instrument_rustflags()` and record `python_pgo_enabled`, `python_lto_enabled`, and `rustflags` in `build-manifest.json`.
   - Update `src/py/tests/unit/build/test_packaging_and_pgo.py` to import from `vertebra.build.packaging.pgo`.
5. In `src/py/vertebra/cli/init.py` (`FE-25`):
   - Implement `init(name: str, template: str) -> None` so it creates `Path(name)`, writes `pyproject.toml` (with `[project]` and `[tool.vertebra] app = "app:app"`), writes `app.py` (instantiating `App()` with a `@app.get("/health")` route), and when `template == "web"` creates `src/main.ts` and sets `entry = "src/main.ts"` in `[tool.vertebra]`. Refuse to overwrite an existing non-empty directory by raising `CLIError(f"Directory '{name}' already exists and is not empty")`.
6. Fix dead CLI parameters (`FE-26`):
   - In `src/py/vertebra/cli/build.py:73`, pass `profile=profile` into `StandaloneBuilder` (recording `"profile": self.profile` in `build-manifest.json` and selecting `--release` when `profile == "release"`).
   - In `src/py/vertebra/cli/dev.py:48`, pass `tracebacks_show_locals=verbose` to `configure_logging(level=log_level, tracebacks_show_locals=verbose)` (adding `tracebacks_show_locals: bool = False` to `configure_logging` in `src/py/vertebra/cli/_logging.py`).
   - In `src/py/vertebra/cli/banner/renderer.py:31`, remove the unused `log_level: str = "info"` parameter from `render_banner` and update its callers in `cli/run.py:86` and `cli/dev.py:81`.
   - In `src/py/vertebra/cli/errors.py:39-42`, pass `file=file` into ` Console(stderr=True, file=file)` when `file is not None`.
7. Create `src/py/vertebra/cli/_launch.py` (`FE-27`):
   - Define `class ServerLaunchEnv(msgspec.Struct, frozen=True, gc=False):` with fields `app_path: str`, `host: str`, `port: int`, `workers: int`, `log_level: str`, `dev: bool = False` and method `to_environ(self, base: Mapping[str, str] | None = None) -> dict[str, str]` that sets `VERTEBRA_APP`, `LITESTAR_APP`, `PYTHONPATH`, `VERTEBRA_PYTHON_BIN`, `VERTEBRA_HOST`, `VERTEBRA_PORT`, `VERTEBRA_WORKERS`, `VERTEBRA_LOG_LEVEL`, `VERTEBRA_NATIVE`, and (when `self.dev`) `VERTEBRA_DEV = "1"`.
   - Use `ServerLaunchEnv` in both `src/py/vertebra/cli/run.py` and `src/py/vertebra/cli/dev.py`.
