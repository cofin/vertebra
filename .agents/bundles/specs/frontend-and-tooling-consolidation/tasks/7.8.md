# Task 7.8 — Consolidate `@vertebra/client` WebSocket transport, `BoundedKeySet`, `HttpClient`, framework `useQuery` hooks, `ArrowStreamClient`/`WasmClient`, and `LiveStateClient`

## Objective

Delete the duplicate `RealtimeChannel` (`src/client/ws.ts`) in favor of `WebSocketClient` (`FE-32`), extract an $O(1)$ `BoundedKeySet` shared by `WebSocketClient` and `SseClient` (`FE-33`), remove import-time side effects from `HotReloadClient` (`FE-34`), fix `HttpClient` URL/body handling, 204 parsing, and `requestId` (`FE-35`), scope React `QueryCache` per `ClientProvider` with canonical keys and cache-invalidation subscriptions (`FE-36`), add stale-response cancellation to Vue/Svelte/Angular query hooks (`FE-37`), implement `ArrowStreamClient.fetchStream` and `WasmClient` memory limit checks (`FE-38`), and fix `LiveStateClient` `TextEncoder` reuse and `FieldDelete` handling (`FE-39`).

## Context

- `src/ts/vertebra-client/src/client/ws.ts` (`RealtimeChannel`) duplicates `src/ts/vertebra-client/src/websocket.ts` (`WebSocketClient`) without heartbeats, `unsubscribe` frames, `lastEventId` resume, or idempotency deduplication (`FE-32`).
- `src/ts/vertebra-client/src/websocket.ts:230-243` and `src/ts/vertebra-client/src/sse.ts:175-188` duplicate `recordIdempotencyKey` using an array `shift()` ($O(N)$) alongside a `Set` (`FE-33`).
- `src/ts/vertebra-client/src/hmr/index.ts:293-297` executes `new HotReloadClient().connect()` at module top level whenever `window` is defined (`FE-34`).
- `src/ts/vertebra-client/src/client/client.ts:46-90,129-148`:
  - `buildUrl` only runs when `method === "GET"`, so path parameters in `POST /users/{id}` are never interpolated and remain literal `{id}` in the URL, while `JSON.stringify(input)` still includes `id` in the request body;
  - `interpolatedPath.replace(placeholder, String(value))` does not call `encodeURIComponent(String(value))`;
  - `await response.json()` throws `SyntaxError` on `204 No Content` or empty bodies;
  - `Number.parseInt(response.headers.get("X-Request-ID") || "0", 10)` returns `NaN` on UUID/hex correlation IDs (`FE-35`).
- `src/ts/vertebra-client/src/react/cache.ts:19-22,110` and `src/ts/vertebra-client/src/react/index.tsx:33-54`:
  - `QueryCache.stableKey` uses raw `JSON.stringify(input)`, which depends on object key insertion order;
  - `queryCache` is a global singleton shared across all `ClientProvider` instances and SSR requests;
  - `useQuery` never subscribes to `queryCache.onChange`, so `queryCache.invalidate()` does not trigger a re-render (`FE-36`).
- `src/ts/vertebra-client/src/vue/index.ts:36-58`, `src/svelte/index.ts:36-53`, and `src/angular/index.ts:36-56` lack monotonic request counters / `AbortController` guards against out-of-order responses (`FE-37`).
- `src/ts/vertebra-client/src/arrow.ts:14-49` (`ArrowStreamClient`) never fetches or reads a stream, and `src/ts/vertebra-client/src/wasm.ts:37-42` (`WasmClient.instantiateBytes`) never checks `maxMemoryPages` (`FE-38`).
- `src/ts/vertebra-client/src/live/index.ts:22-39,190-222` allocates `new TextEncoder()` on every `fnv1aStateId`/`fnv1aFieldId` call and ignores `StateOpcode.FieldDelete` in `applyServerDelta` (`FE-39`).

## Steps

1. Write failing Vitest unit tests first (`regression_tdd`):
   - In `src/ts/vertebra-client/tests/unit/client.test.ts`:
     - test `POST /users/{id}` interpolates and URL-encodes `{id}` into `/users/42` while omitting `id` from the JSON body;
     - test `204 No Content` returns `undefined` data without throwing `SyntaxError`;
     - test `X-Request-ID: req-abc-123` is preserved as `"req-abc-123"` (string | number) instead of `NaN`.
   - In `src/ts/vertebra-client/tests/realtime.test.ts`:
     - test `BoundedKeySet` evicts the oldest key in $O(1)$ using `Set` insertion order when capacity is exceeded;
     - test `HttpClient.subscribe` delegates to `WebSocketClient` and sends `{ type: "unsubscribe" }` when the last listener unsubscribes.
   - In `src/ts/vertebra-client/tests/arrow.test.ts`, `tests/wasm.test.ts`, and `tests/live.test.ts`:
     - test `ArrowStreamClient.fetchBytes()` sends `Accept: application/vnd.apache.arrow.stream` and validates the IPC header;
     - test `WasmClient.instantiateBytes()` rejects a WASM module whose exported `WebAssembly.Memory` initial byte length exceeds `memoryLimitBytes`;
     - test `LiveStateClient.applyServerDelta` deletes a field on `StateOpcode.FieldDelete`.
2. Create `src/ts/vertebra-client/src/internal/lru_set.ts` (`FE-33`):
   - Implement `export class BoundedKeySet` backed by a single `Set<string>` and `readonly capacity: number` (using `this.set.keys().next().value` to delete the oldest entry in $O(1)$ when `this.set.size >= this.capacity`).
   - Replace `seenIdempotencyOrder` + `seenIdempotencySet` + `recordIdempotencyKey` in both `src/ts/vertebra-client/src/websocket.ts` and `src/ts/vertebra-client/src/sse.ts` with `BoundedKeySet`.
3. Delete `src/ts/vertebra-client/src/client/ws.ts` (`FE-32`):
   - Update `src/ts/vertebra-client/src/client/client.ts` to hold `private ws: WebSocketClient | null = null;` and route `subscribe<T>(channel: string, callback: (data: T) => void): () => void` through `WebSocketClient`.
   - Remove `export { RealtimeChannel } from "./client/ws";` from `src/ts/vertebra-client/src/index.ts`.
4. In `src/ts/vertebra-client/src/hmr/index.ts` (`FE-34`):
   - Remove the top-level `if (typeof window !== "undefined") { ... }` side-effect block from `src/hmr/index.ts:293-297` and export `export function initHotReload(hmrPath?: string): HotReloadClient` that constructs, connects, and assigns `window.__vertebra_hmr`.
5. In `src/ts/vertebra-client/src/client/client.ts` and `src/ts/vertebra-client/src/client/types.ts` (`FE-35`):
   - Change `RouteResponse.requestId` in `types.ts:35` to `requestId: string | number | null;` and parse `X-Request-ID` in `client.ts` by returning the raw header string (or `Number(raw)` if `/^\d+$/.test(raw)`, `null` when absent).
   - Update `buildUrl` (`client.ts:129-148`) to run for all HTTP methods, extracting any `{key}` placeholders from `input` with `encodeURIComponent(String(value))` and returning `{ url, bodyInput }` where `bodyInput` excludes consumed path parameters (for `GET`/`HEAD`, remaining keys become query parameters; for other methods, remaining keys become the JSON body).
   - In `callWithResponse` (`client.ts:83`), return `undefined as TOutput` when `response.status === 204` or `response.headers.get("content-length") === "0"`, and only call `await response.json()` when `response.headers.get("content-type")?.includes("application/json")` (falling back to `await response.text()`).
6. In `src/ts/vertebra-client/src/react/cache.ts` and `src/ts/vertebra-client/src/react/index.tsx` (`FE-36`):
   - Update `QueryCache.stableKey` to recursively sort object keys before serializing so `{ a: 1, b: 2 }` and `{ b: 2, a: 1 }` produce identical cache keys.
   - Create a `QueryCache` instance per `ClientProvider` (exposed via context alongside `HttpClient`), and in `useQuery` subscribe to `cache.onChange` via `useSyncExternalStore` (or a version counter state updated by `cache.onChange`) so `cache.invalidate()` triggers a re-fetch/re-render.
7. In `src/ts/vertebra-client/src/vue/index.ts`, `src/ts/vertebra-client/src/svelte/index.ts`, and `src/ts/vertebra-client/src/angular/index.ts` (`FE-37`):
   - Add a monotonically increasing `requestSeq` counter in each `useQuery` / `createQuery` / `injectQuery` composable so out-of-order completions from superseded requests do not overwrite `data`, `error`, or `loading`.
8. In `src/ts/vertebra-client/src/arrow.ts` and `src/ts/vertebra-client/src/wasm.ts` (`FE-38`):
   - Add `public async fetchBytes(init?: RequestInit): Promise<Uint8Array>` to `ArrowStreamClient` that calls `fetch(this.endpoint, { ...init, headers: { ...this.baseHeaders, ...(init?.headers as Record<string, string> | undefined) } })`, reads `new Uint8Array(await response.arrayBuffer())`, validates `ArrowStreamClient.hasIpcHeader(bytes)`, and returns `bytes`.
   - In `WasmClient.instantiateBytes`, inspect exported `WebAssembly.Memory` instances on `instance.exports` (and any `WebAssembly.Memory` in `this.baseImports`) and throw `new RangeError("WebAssembly memory exceeds configured maxMemoryPages")` if `memory.buffer.byteLength > this.memoryLimitBytes`.
9. In `src/ts/vertebra-client/src/live/index.ts` (`FE-39`):
   - Hoist `const UTF8_ENCODER = new TextEncoder();` to module scope and reuse it in `fnv1aStateId` and `fnv1aFieldId`.
   - Handle `delta.opcode === StateOpcode.FieldDelete` in `LiveStateClient.applyServerDelta` by checking the HLC timestamp, updating `this.fieldTimestamps`, deleting `key` from a shallow clone of `this.state`, and calling `this.notify()`.
