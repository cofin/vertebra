## Objective

Add the `vertebra[wasm]` optional extra (`wasmtime>=27.0`) to `pyproject.toml` and upgrade `WasmPluginHost` in `src/py/vertebra/wasm/__init__.py` to compile and execute real `.wasm` guest modules via `wasmtime` with fuel and memory limits when `wasmtime` is installed, or raise `MissingDependencyError` when `wasmtime` is absent (Decision D3).

## Context

- `src/py/vertebra/wasm/__init__.py:43-91` (`WasmPluginHost`) validates only the 8-byte `\x00asm\x01\x00\x00\x00` header (`:57-59`), stores Python callables passed via `exports: dict[str, Callable[..., Any]]` in `self._host_exports` (`:73-75`), and compares a caller-supplied `fuel_cost: int = 100` integer against `cfg.policy.max_fuel` (`:84-86`) without ever compiling or executing WebAssembly bytecode (`FW-09`).
- Per Decision D3 in the parent PRD, `WasmPluginHost` must use `wasmtime>=27.0` as an optional `vertebra[wasm]` extra to execute real `.wasm` modules with `consume_fuel=True` and memory limits when `exports` is not overridden, and raise `MissingDependencyError("wasmtime", install_package="vertebra[wasm]", extra="wasm")` when `wasmtime` is not installed.

## Steps

1. **Add `wasm = ["wasmtime>=27.0"]` to `pyproject.toml`**:
   - Under `[project.optional-dependencies]` in `pyproject.toml`, add `wasm = ["wasmtime>=27.0"]` and add `"wasmtime>=27.0"` to `[dependency-groups].dev`.
2. **Write behavior TDD tests for `WasmPluginHost`**:
   - In `src/py/tests/unit/extensions/test_grpc_service.py` (or a dedicated Wasm section in that file, which already tests adjacent extension primitives), add tests using a minimal valid WebAssembly binary exporting an `(func (export "add") (param i32 i32) (result i32) local.get 0 local.get 1 i32.add)` module (`bytes.fromhex("0061736d0100000001070160027f7f017f030201000707010361646400000a09010700200020016a0b")`):
     - Verify `host.register_module(WasmModuleConfig(name="math", wasm_source=wasm_bytes))` and `host.call_export("math", "add", 20, 22)` returns `42` via `wasmtime`.
     - Verify a tight loop or low `max_fuel=1` policy traps and raises `WasmExecutionError`.
     - Verify that when `wasmtime` is monkeypatched to `None`, calling `register_module` without `exports` raises `MissingDependencyError`.
3. **Implement `wasmtime` execution in `src/py/vertebra/wasm/__init__.py` (`FW-09`)**:
   - Import `MissingDependencyError` from `vertebra._typing` and `import_optional` from `vertebra.utils.module_loader` at module top level (`_wasmtime = import_optional("wasmtime")`).
   - In `WasmPluginHost.register_module`, after validating the 8-byte `WASM_MAGIC_HEADER`, if `exports` is provided, register the Python host callables in `self._host_exports` as before; if `exports` is `None`, require `_wasmtime is not None` (raising `MissingDependencyError("wasmtime", install_package="vertebra[wasm]", extra="wasm")` if missing), create a `wasmtime.Config` with `cfg.consume_fuel = True`, compile `wasmtime.Module(engine, raw)`, and store the compiled engine/module tuple in `self._compiled_modules[config.name]`.
   - In `WasmPluginHost.call_export`, if `(module_name, export_name)` is in `self._host_exports`, enforce `fuel_cost <= cfg.policy.max_fuel` and invoke the Python callable; otherwise instantiate a `wasmtime.Store(engine)` with `store.set_fuel(cfg.policy.max_fuel)` and `store.set_limits(memory_size=cfg.policy.max_memory_bytes)`, instantiate the compiled `wasmtime.Module`, resolve `instance.exports(store)[export_name]`, invoke it with `(store, *args)`, and catch `wasmtime.Trap` / `wasmtime.WasmtimeError` to raise `WasmExecutionError`.
