## Objective

Merge `src/py/vertebra/extensions/grpc/_decorator.py` into `src/py/vertebra/extensions/grpc/__init__.py`, inject `GrpcContext` into 2-parameter `@grpc_method` handlers during ASGI dispatch, raise `GrpcError(GrpcStatus.INTERNAL)` when `decode_lpm_frames` encounters trailing incomplete header bytes, and preserve struct field declaration order by default in `ProtobufSchemaGenerator`.

## Context

- `src/py/vertebra/extensions/grpc/__init__.py:1-31` is a pure re-export shim over `src/py/vertebra/extensions/grpc/_decorator.py:1-508` (`FW-47`).
- `GrpcContext` (`_decorator.py:68-74`) is defined and exported, but `@grpc_method` (`:158-160`) rejects any handler with `len(params) != 1` and `GrpcServiceRegistry.handle_asgi` (`:220-297`) never instantiates or passes `GrpcContext` to handlers (`FW-47`).
- `decode_lpm_frames` (`_decorator.py:114-127`) loops `while offset + 5 <= total:` and silently ignores `1..4` trailing bytes at the end of a buffer instead of raising `GrpcError(GrpcStatus.INTERNAL, "incomplete gRPC LPM frame header")` (`FW-47`).
- `ProtobufSchemaGenerator._collect_struct_definitions` (`_decorator.py:416-419`) sorts struct fields alphabetically (`sorted(info.fields, key=lambda f: f.name)`), causing wire-breaking proto field renumbering whenever a field is added (`FW-47`).

## Steps

1. **Write failing regression tests in `src/py/tests/unit/extensions/test_grpc_service.py`**:
   - Add `test_decode_lpm_frames_rejects_trailing_partial_header()` asserting `decode_lpm_frames(encode_lpm_frame(b"abc") + b"\x00\x00")` raises `GrpcError` with `GrpcStatus.INTERNAL`.
   - Add `test_grpc_method_injects_grpc_context()` decorating a 2-parameter handler `async def get_user(req: UserReq, ctx: GrpcContext) -> UserResp` and dispatching an ASGI request with `(b"x-tenant", b"acme")` and `(b"grpc-timeout", b"5S")` headers, asserting `ctx.metadata["x-tenant"] == "acme"` and `ctx.timeout_seconds == 5.0`.
   - Add `test_protobuf_schema_generator_preserves_declaration_order()` asserting field numbers `1, 2, ...` match `msgspec.Struct` field declaration order by default.
2. **Merge `_decorator.py` into `src/py/vertebra/extensions/grpc/__init__.py` and delete `_decorator.py` (`FW-47`)**:
   - Move the full implementation from `src/py/vertebra/extensions/grpc/_decorator.py` into `src/py/vertebra/extensions/grpc/__init__.py` (preserving `encode_msgpack` and `decode_msgpack` from `vertebra.utils.serializers` added in Task `5.3`) and delete `src/py/vertebra/extensions/grpc/_decorator.py`.
3. **Fix `decode_lpm_frames`, `GrpcContext` injection, and `ProtobufSchemaGenerator` field ordering (`FW-47`)**:
   - In `decode_lpm_frames`, after the `while offset + 5 <= total:` loop, check `if offset < total: raise GrpcError(GrpcStatus.INTERNAL, "incomplete gRPC LPM header")` and validate `_compressed in (0, 1)`.
   - Add `accepts_context: bool = False` to `GrpcMethodSpec`. In `@grpc_method`, allow `len(params) in (1, 2)` (recording `accepts_context = len(params) == 2`). In `GrpcServiceRegistry.handle_asgi`, build `GrpcContext` from `scope` (`peer` from `scope.get("client")`, `metadata` from request headers, `timeout_seconds` parsed from `grpc-timeout` units `H`/`M`/`S`/`m`/`u`/`n`) and pass `ctx` as the second argument in `_dispatch_spec` when `spec.accepts_context` is `True`.
   - In `ProtobufSchemaGenerator.__init__`, add `*, package: str = "vertebra", sort_fields: bool = False` and preserve `info.fields` declaration order when `self._sort_fields` is `False`.
