## Objective

Delete the redundant `SyncStore`, `AsyncStore`, and `StorageRegistry.register_store` wrappers, merge `ReadableFile` from `storage/arrow.py` into `storage/_store.py`, deduplicate native metadata conversion helpers on `ObjectStore`, raise `NotImplementedError` when `ObjectStore.verify_presigned_url` is called with `provider="gcs"`, and fix `UploadTracker` in `storage/pipeline.py` to use `collections.deque`, log cleanup failures, and register `after_flush` on SQLAlchemy sessions.

## Context

- `src/py/vertebra/storage/_store.py:1260-1365` defines `SyncStore` and `AsyncStore` wrapper classes that forward 10 methods 1:1 to `ObjectStore` (`FW-21`, `FW-51`), and `src/py/vertebra/storage/registry.py:59-61` defines `register_store` as a 1-line alias for `register_alias` (`FW-21`).
- `src/py/vertebra/storage/_store.py:617-958` repeats `PutResult(path=str(native_meta.path), size=int(native_meta.size), etag=..., version=native_meta.version)` and `ObjectMeta(...)` conversion blocks 10 times across sync and async methods (`FW-51`).
- `src/py/vertebra/storage/_store.py:980-995` (`ObjectStore.verify_presigned_url`) checks `if self._signing.provider == "s3": ... return self._verify_hmac(...)`, silently falling through to `_verify_hmac` and returning `False` when `self._signing.provider == "gcs"` (`FW-60`).
- `src/py/vertebra/storage/arrow.py:1-127` (`ReadableFile`) is a standalone 127-line file that wraps `ObjectStore.get_range` without an `ObjectStore.open_readable_file(key)` convenience method (`FW-61`).
- `src/py/vertebra/storage/pipeline.py:35-37,80,89,100,108` uses `list.pop(0)` in `O(N)` on `_staged_uploads` and `_pending_deletes`, suppresses all delete exceptions during commit/rollback with `contextlib.suppress(Exception)` (`:101,109,119,129`, `BLE001`), and attaches `before_flush` (`:141`) instead of `after_flush` on SQLAlchemy sessions (`FW-52`, `FW-48`).

## Steps

1. **Write failing regression tests in `test_multicloud_storage.py` and `test_storage_store.py`**:
   - In `src/py/tests/unit/storage/test_multicloud_storage.py`, add `test_verify_presigned_url_gcs_raises_not_implemented()` asserting `store.verify_presigned_url(url)` raises `NotImplementedError` when `SigningConfig(provider="gcs", ...)` is configured.
   - Add `test_upload_tracker_logs_rollback_errors_and_uses_deque(caplog)` verifying `UploadTracker.after_rollback()` logs a warning when `store.delete(key)` fails, uses `collections.deque` for `_staged_uploads` and `_pending_deletes`, and registers `after_flush` in `attach_sqlalchemy_session`.
   - In `src/py/tests/unit/storage/test_storage_store.py`, add `test_object_store_open_readable_file()` verifying `store.open_readable_file("data.parquet")` returns a seekable `ReadableFile` and asserting `SyncStore`, `AsyncStore`, and `StorageRegistry.register_store` are removed.
2. **Consolidate `src/py/vertebra/storage/_store.py`, `src/py/vertebra/storage/arrow.py`, `src/py/vertebra/storage/registry.py`, and `src/py/vertebra/storage/__init__.py` (`FW-21`, `FW-48`, `FW-51`, `FW-60`, `FW-61`)**:
   - Delete `SyncStore` and `AsyncStore` (`_store.py:1260-1365`) and remove them from `_store.py:__all__` and `storage/__init__.py:__all__`.
   - Delete `StorageRegistry.register_store` (`registry.py:59-61`).
   - Move `ReadableFile` from `src/py/vertebra/storage/arrow.py` into `src/py/vertebra/storage/_store.py`, delete `src/py/vertebra/storage/arrow.py`, add `def open_readable_file(self, path: str, *, size: int | None = None) -> ReadableFile:` on `ObjectStore`, and update `src/py/vertebra/storage/__init__.py` to import `ReadableFile` from `vertebra.storage._store`.
   - Extract `@staticmethod def _native_to_put_result(native_meta: Any, fallback_etag: str) -> PutResult` and `@staticmethod def _native_to_object_meta(native_meta: Any) -> ObjectMeta` on `ObjectStore` and use them across `put`, `put_file`, `put_multipart`, `head`, `list`, `put_async`, `put_file_async`, `head_async`, and `list_async`.
   - In `ObjectStore.verify_presigned_url` (`_store.py:980-995`), add `if self._signing.provider == "gcs": raise NotImplementedError("GCS V4 RSA-SHA256 presigned URL verification is not supported offline")`.
   - In `ObjectStore._sign_gcs_v4_iam` (`_store.py:1214-1221`), validate `if parsed_iam.scheme not in {"http", "https"}: raise ValueError(f"Unsupported IAM endpoint scheme: {parsed_iam.scheme!r}")` (`S310`) and narrow `except Exception:` at `:403` and `:1225` to `(RuntimeError, OSError, ValueError)` and `binascii.Error` (`BLE001`).
3. **Fix `UploadTracker` in `src/py/vertebra/storage/pipeline.py` (`FW-48`, `FW-52`)**:
   - Change `self._staged_uploads` and `self._pending_deletes` to `collections.deque[StagedUpload]` and `collections.deque[tuple[ObjectStore, str]]`, replacing `.pop(0)` at `:80,89,100,108` with `.popleft()`.
   - Replace `with contextlib.suppress(Exception):` in `after_commit`, `after_commit_async`, `after_rollback`, and `after_rollback_async` with `try ... except Exception: logger.warning("Failed to delete object %r during transaction cleanup", key, exc_info=True)`.
   - In `attach_sqlalchemy_session` (`:136-145`), register `listen(session_or_factory, "after_flush", self.before_flush)` so staged uploads are flushed only after SQLAlchemy flushes SQL statements without error.
