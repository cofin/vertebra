## Objective

Enforce token expiration in `ApexSessionBridge.verify_session_cookie` and identifier validation/parameterization in `ApexSessionContext`, delete `ApexLangCompiler` (`extensions/apex/apexlang.py`), add explicit `execute`/`execute_sql`/`dial` methods raising `UnsupportedBackendError` on `OracleDriver`, `DataFusionEngine`, `CloudSqlDialer`, and `AlloyDbDialer`, fix `CloudSqlConfig.refresh_lead_seconds` and `CloudSqlDialer.build_tls_context` client PEM loading, remove duplicate/hardcoded parameters in `db/oracle/{driver,wallet,containers}.py`, and harden `ChangeFeed`, `QueryPipeline`, `RelOverlay`, and `TenantPredicate`.

## Context

- `src/py/vertebra/extensions/apex/session.py:86-127` (`ApexSessionBridge.verify_session_cookie`) decodes `exp=int(claims.get("exp", 0))` at line 122 without comparing it against current epoch time, accepting expired cookies indefinitely (`FW-11`).
- `src/py/vertebra/extensions/apex/gateway.py:31-72` (`ApexSessionContext`) interpolates `self.edition`, `self.responsibility_key`, and `self.security_group_key` directly into SQL strings (`f"ALTER SESSION SET EDITION = {self.edition}"` and `f"SELECT resp.responsibility_id, ... WHERE resp.responsibility_key = '{self.responsibility_key}'..."`) without identifier validation or bind parameters (`FW-11`).
- `src/py/vertebra/extensions/apex/apexlang.py:1-147` (`ApexLangCompiler`, `ApexLangDocument`) is a speculative regex parser for a custom `.apex` DSL (`FW-12`).
- `src/py/vertebra/db/oracle/driver.py:69-139` (`SyncOracleDriver`, `AsyncOracleDriver`) has no `execute` method (`FW-03`), uses `zip(..., strict=False)` at `:50` (`B905`, `FW-48`), and accepts duplicate `type_code` and `dtype` parameters in `encode_vector` (`:89-97`, `FW-56`). `OracleWallet.extract` (`wallet.py:59-75`) accepts duplicate `target_dir` and `cache_root` parameters (`FW-56`), and `OracleContainer` (`containers.py:19`) hardcodes `admin_password: str = "WelcomeOracle26ai!"` (`S105`, `FW-48`, `FW-56`).
- `src/py/vertebra/db/dialer/cloudsql.py:54,82` names its field `refresh_Lead_seconds` with a capital `L` (`FW-54`), raises `NotImplementedError` at `:111-112` when `client_cert_pem` and `client_key_pem` are passed to `build_tls_context` (`FW-04`), and neither `CloudSqlDialer` nor `AlloyDbDialer` exposes `dial()` (`FW-04`).
- `src/py/vertebra/db/datafusion.py:46-84` (`DataFusionEngine`) only implements `explain_plan` via substring matching without `execute_sql` (`FW-10`).
- `src/py/vertebra/db/cdc.py:47,99,107` grows `self._history` without bound and silently substitutes `{}` when a spilled `event_id` is missing from `_spill_store`; `src/py/vertebra/db/pipeline.py:19-129` accepts duplicate `chunk_size`/`max_pairs_per_call` parameters in `build_jsonb_object`, silently overwrites colliding step parameter names in `compile()`, and does not validate SQL identifiers in `RelOverlay`/`CteStep`; and `src/py/vertebra/db/rls.py:23-35` does not validate `table_alias`/`tenant_column`/`parameter_cast` identifiers (`FW-59`).

## Steps

1. **Write failing regression tests in `test_oracle_apex_and_gateway.py` and `test_pg_dataplane_and_datafusion.py`**:
   - In `test_oracle_apex_and_gateway.py`, assert `ApexSessionBridge.verify_session_cookie` returns `None` when `exp <= now_epoch`, assert `ApexSessionContext` rejects SQL-injection payloads in `edition` (`"ORA$BASE; DROP USER apps"`), parameterizes `:responsibility_key` and `:security_group_key` in `initialize_apps_context_sql()`, and assert `ApexLangCompiler` is removed from `vertebra.extensions.apex`.
   - Assert `SyncOracleDriver.execute`, `DataFusionEngine.execute_sql`, `CloudSqlDialer.dial`, and `AlloyDbDialer.dial` raise `UnsupportedBackendError` when no live backend/package is connected, and assert `CloudSqlDialer.build_tls_context(client_cert_pem=..., client_key_pem=...)` loads a temporary `0o600` certificate chain.
   - In `test_pg_dataplane_and_datafusion.py`, assert `ChangeFeed` bounds `_history` to `CdcConfig.max_history_size` and raises `KeyError` on missing spilled `event_id`, `QueryPipeline.compile()` raises `ValueError` on conflicting step parameter keys, and `RelOverlay`, `CteStep`, and `TenantPredicate` reject unsafe SQL identifiers.
2. **Harden `ApexSessionBridge` and `ApexSessionContext` and delete `apexlang.py` (`FW-11`, `FW-12`)**:
   - Delete `src/py/vertebra/extensions/apex/apexlang.py` and remove `ApexLangCompiler` and `ApexLangDocument` from `src/py/vertebra/extensions/apex/__init__.py`.
   - In `src/py/vertebra/extensions/apex/session.py:86-127`, add `*, now_epoch: int | None = None` to `verify_session_cookie` and return `None` when `exp <= (int(time.time()) if now_epoch is None else now_epoch)`.
   - In `src/py/vertebra/extensions/apex/gateway.py:31-72`, validate `self.edition` in `ApexSessionContext.__post_init__` against `^[A-Za-z_][A-Za-z0-9_$#]*$` (raising `ValueError` otherwise), and parameterize `responsibility_key` and `security_group_key` as `:responsibility_key` and `:security_group_key` in `initialize_apps_context_sql()` and its returned bind dict.
3. **Clean up `db/oracle/{driver,wallet,config,containers}.py`, `db/dialer/{cloudsql,alloydb}.py`, and `db/datafusion.py` (`FW-03`, `FW-04`, `FW-10`, `FW-48`, `FW-54`, `FW-56`)**:
   - In `src/py/vertebra/db/oracle/driver.py`, change `strict=False` to `strict=True` in `OracleDataFrame.to_dicts` (`:50`, `B905`), remove `dtype` from `SyncOracleDriver.encode_vector` (`:89-97`), and add `execute(self, sql: str, params: dict[str, Any] | Sequence[Any] | None = None) -> list[tuple[Any, ...]]` on `SyncOracleDriver` (and `async def execute` on `AsyncOracleDriver`) that raises `UnsupportedBackendError` unless an `oracledb` connection/executor is bound.
   - In `src/py/vertebra/db/oracle/wallet.py:59-75`, remove `cache_root` from `OracleWallet.extract` (keeping `target_dir: str | Path | None = None`) and update `OracleConfig.resolve_wallet` (`config.py:113`) to pass `target_dir=cache_root`.
   - In `src/py/vertebra/db/oracle/containers.py:19`, change `admin_password: str = ""` (no hardcoded literal password, `S105`) and require a non-empty `admin_password` when `env_vars()` is called.
   - In `src/py/vertebra/db/dialer/cloudsql.py`, rename `refresh_Lead_seconds` to `refresh_lead_seconds` (`:54,82`), implement `client_cert_pem` + `client_key_pem` loading in `build_tls_context` (`:111-112`) using a `0o700` `tempfile.TemporaryDirectory()` with `0o600` PEM files passed to `ctx.load_cert_chain(...)`, and add `async def dial(self) -> Any` on `CloudSqlDialer` and `AlloyDbDialer` (`alloydb.py`) raising `UnsupportedBackendError`.
   - In `src/py/vertebra/db/datafusion.py`, add `execute_sql(self, sql: str) -> Any` that delegates to `datafusion.SessionContext` if `datafusion` is installed or raises `UnsupportedBackendError`.
4. **Harden `db/cdc.py`, `db/pipeline.py`, and `db/rls.py` (`FW-59`)**:
   - In `src/py/vertebra/db/cdc.py`, add `max_history_size: int = 1024` to `CdcConfig`, store `self._history = collections.deque(maxlen=self._config.max_history_size)`, and in `hydrate_notification` (`:107`), raise `KeyError(f"Spilled CDC payload for event_id={event_id} is missing")` when `spilled` is `True` and `event_id not in self._spill_store`.
   - In `src/py/vertebra/db/pipeline.py`, validate `base_table`, `inserted_cte`, `deleted_ids_cte`, `id_column`, and `CteStep.name` against `^[A-Za-z_][A-Za-z0-9_.]*$` in `__post_init__`; remove `chunk_size` from `build_jsonb_object` (keeping `max_pairs_per_call: int = 50`); and in `QueryPipeline.compile()`, raise `ValueError(f"Conflicting parameter key {k!r} across CTE steps")` if two steps define the same parameter key with different values.
   - In `src/py/vertebra/db/rls.py`, validate `table_alias`, `config.tenant_column`, and `config.parameter_cast` against `^[A-Za-z_][A-Za-z0-9_.]*$` in `TenantPredicate.__post_init__`.
