# Task 1.2: Implement pure-Rust TDS SQL Server (`tiberius`) driver (`src/rs/vertebra-db/src/mssql.rs`) with `rustls`, `@P1` parameter binding, and SHM Arrow IPC bindings in `src/py/vertebra/db/mssql.py`

## Objective

Implement the pure-Rust Tabular Data Stream (TDS 7.3/7.4/8.0) SQL Server driver in `src/rs/vertebra-db/src/mssql.rs` (`tiberius` with `rustls` — zero `msodbcsql18` or `unixODBC` C dependency) supporting Cloud SQL for SQL Server (`:3307`), Azure SQL / SQL Server `TrustServerCertificate` and strict TLS modes, `@P1, @P2` positional parameter normalization, and SHM ring + `ShmRegion` Arrow IPC result streaming in `src/py/vertebra/db/mssql.py`.

## Context

- Python SQL Server drivers (`pyodbc`, `mssql-python`) require installing OS-level `unixODBC` and Microsoft's C++ `msodbcsql18` package.
- `tiberius` (`default-features = false`, `features = ["rustls", "tds73", "chrono"]`) + `tokio-util` (`compat`) speaks TDS directly in pure Rust over any Tokio `AsyncRead + AsyncWrite` stream.

## Steps

- [ ] 1. Create `src/rs/vertebra-db/src/mssql.rs` implementing TDS DSN parsing (`mssql://` / `sqlserver://`), `?` / `:name` to `@P1, @P2` parameter rewriter (`rewrite_tsql_placeholders`), `CloudSqlInstanceUri` `:3307` stream integration, and `NativeMssqlPool` writing TDS rows into SHM ring slots or `ShmRegion` Arrow IPC buffers.
- [ ] 2. Expose `NativeMssqlPool` and `rewrite_tsql_placeholders_native` in `src/rs/vertebra-py/src/db.rs` with `py.detach(...)`.
- [ ] 3. Create `src/py/vertebra/db/mssql.py` defining `MssqlConfig(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, `SyncMssqlDriver`, and `AsyncMssqlDriver` with `execute`, `execute_many`, `execute_tuples`, and `select_to_arrow` over `ShmBrokerTransport`.
- [ ] 4. Add unit tests in `src/py/tests/unit/db/test_mssql_native_driver.py` covering TDS DSN parsing, `@P1` placeholder rewriting (ignoring string literals and `--` / `/* */` comments), Cloud SQL for SQL Server dialer configuration, SHM lease acquisition, and Arrow IPC result streaming.
