# 1.1 Pooled SyncPostgresDriver, AsyncPostgresDriver, and Arrow binary COPY streaming

## Objective
Replace the in-memory stub in `SyncPostgresDriver` and `AsyncPostgresDriver` (`src/py/vertebra/db/postgres.py`) with real connection pool management (`psycopg_pool.ConnectionPool` for sync, `asyncpg.Pool` or `psycopg_pool.AsyncConnectionPool` for async) behind the `vertebra[postgres]` optional extra, add PostgreSQL binary `COPY (...) TO STDOUT (FORMAT BINARY)` Arrow batch streaming (`stream_arrow_batches`), and remove the duplicate `reserved_super_connections` parameter from `PostgresConfig.compute_worker_pool_budget`.

## Context
- `src/py/vertebra/db/postgres.py:65-80` (`PostgresConfig.compute_worker_pool_budget`) accepts both `reserved_super_connections: int = 5` and `reserved_admin_connections: int | None = None` for the same calculation (`FW-55`).
- `src/py/vertebra/db/postgres.py:109-147` (`SyncPostgresDriver`) stores `_in_memory_rows: list[tuple[Any, ...]] = []` and returns `list(self._in_memory_rows)` from `execute_tuples` (`:135-143`) without executing `sql` (`FW-01`).
- `src/py/vertebra/db/postgres.py:149-173` (`AsyncPostgresDriver`) wraps `SyncPostgresDriver` synchronously without an async connection pool (`FW-01`).
- `pyproject.toml:32-42` (`[project.optional-dependencies]`) defines only `framework` and `dev`, lacking `postgres`.
- Strategy `behavior_tdd` applies because this task adds pooled PostgreSQL execution and Arrow `COPY` batch streaming where only a stub existed.

  ```python
  @staticmethod
  def compute_worker_pool_budget(
      max_connections: int,
      worker_count: int = 1,
      *,
      replica_count: int = 1,
      workers_per_replica: int | None = None,
      reserved_admin_connections: int = 5,
  ) -> int:
      """Compute per-worker pool size from a cluster-wide database connection budget."""
      usable = max(0, max_connections - reserved_admin_connections)
      per_replica = workers_per_replica if workers_per_replica is not None else worker_count
      total_shards = max(1, replica_count) * max(1, per_replica)
      return max(1, usable // total_shards)
  ```
