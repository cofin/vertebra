# Chapters: MCP Protocol Completeness

`12` dependency-ordered chapters (`35` vertical-slice tasks) completing Vertebra's MCP server across context propagation, opt-in verified proxy identity, authorization, dual-mode transport, subscriptions, skills, MCP Apps metadata, Litestar delegation, CLI commands, and documentation.

* [ch01 — Agent Context Propagation](ch01-agent-context-propagation/spec.md) — [planned] (`4` tasks) Builds trusted `AgentContext` values from headers, scopes, and environs with proxy identity headers off by default and an opt-in `IdentitySource` seam (mTLS subject from trusted proxy CIDRs, custom callable), validates `MCPConfig` identity settings at construction, binds them for every `MCPCore` dispatch and promoted task, and passes them from every transport adapter.
* [ch02 — Guard and Confirmation Correctness](ch02-guard-and-confirmation-correctness/spec.md) — [planned] (`2` tasks) Runs guards once per tool call with typed JSON-RPC errors and makes confirmation tickets pending-only, owner-exact, single-use, expiring, and bounded.
* [ch03 — Version Negotiation and Sessions](ch03-version-negotiation-and-sessions/spec.md) — [planned] (`4` tasks) Adds the supported-version registry (unknown and legacy-only methods return HTTP `200` with JSON-RPC `-32601`; HTTP `404` is reserved for unknown or expired session ids), legacy `initialize` with `MCPSessionStore` sessions, session validation and `DELETE` termination, and one capability builder.
* [ch04 — GET SSE Streams](ch04-get-sse-streams/spec.md) — [planned] (`4` tasks) Adds the streaming response envelope, legacy `GET` SSE streams, incremental adapter writers, list-change and log notifications, and progress delivery (waits on incremental ASGI streaming).
* [ch05 — Resource Subscriptions](ch05-resource-subscriptions/spec.md) — [planned] (`3` tasks) Implements `resources/subscribe` and `resources/unsubscribe`, update fan-out with cleanup, and stateless `subscriptions/listen`.
* [ch06 — Skills Extension](ch06-skills-extension/spec.md) — [planned] (`4` tasks) Completes skill catalog disclosure, the core skills surface and extension capability, and skill wiring across `AgentPlugin` and every framework mount.
* [ch07 — MCP Apps UI Metadata](ch07-mcp-apps-ui-metadata/spec.md) — [planned] (`4` tasks) Adds SEP-1865 `title`, `icons`, and `_meta` models, decorator and registry propagation, `ui://` link validation in every mount, UI extension capability, and app-only visibility filtering.
* [ch08 — Litestar Delegation Parity](ch08-litestar-delegation-parity/spec.md) — [planned] (`1` task) Requires `litestar-mcp>=0.20.0` and forwards dual-mode transport options from `create_mcp_plugin` (waits on the upstream release).
* [ch09 — Stdio and Serve](ch09-stdio-and-serve/spec.md) — [planned] (`2` tasks) Makes the stdio server incremental and session-aware and makes `vtb ai mcp serve` serve the discovered application's MCP surface.
* [ch10 — Bridge Dual Mode and OIDC](ch10-bridge-dual-mode-and-oidc/spec.md) — [planned] (`2` tasks) Forwards both protocol modes with legacy SSE relay and session termination, and authenticates with refreshed OIDC id_tokens (waits on id_token minting).
* [ch12 — IAP Identity Source](ch12-iap-identity-source/spec.md) — [planned] (`1` task) Verifies the ES256 `x-goog-iap-jwt-assertion` against Google's IAP keys with the configured audience, issuer, and expiry, and never trusts the plain IAP email header (follows `ch01`, precedes `ch11`).
* [ch11 — Docs and OKF](ch11-docs-and-okf/spec.md) — [planned] (`4` tasks) Updates user guides, CLI reference, changelog, OKF chapters, and the MCP limitations chapter.
