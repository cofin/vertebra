# 9.2 Reorganize Python unit tests to mirror src/py/vertebra/ 1:1 and replace inspect.getsource checks

## Objective

Eliminate all PR-wave, multi-domain, and misplaced Python test files under `src/py/tests/unit/` by redistributing their test functions into canonical per-module test files that mirror `src/py/vertebra/<subpackage>/<module>.py` (and `src/py/tests/unit/native/` for `vertebra._vertebra`) (`TST-03`, `TST-05`, `FW-47`, `PYB-61`). Replace the `inspect.getsource(SqlGatewayService.handle)` assertion with a behavioral `monkeypatch.setattr(asyncio, "to_thread", ...)` spy (`TST-02`).

## Context

- **Confirmed evidence (`TST-02`, `TST-03`, `TST-05`, `FW-47`, `PYB-61`):**

- **File overlap note:** Runs after `9.1` (`depends_on: [test-suite-consolidation:9.1]`) and before `9.3` (`depends_on: [test-suite-consolidation:9.2]`).  
  ```python
  @pytest.mark.anyio
  async def test_sql_gateway_dispatches_async_pool_without_to_thread(monkeypatch: pytest.MonkeyPatch) -> None:
      """Verify SqlGatewayService.handle awaits the async pool directly without calling asyncio.to_thread."""
      def forbid_to_thread(*_args: object, **_kwargs: object) -> object:
          raise AssertionError("asyncio.to_thread must not be called by SqlGatewayService.handle")

      monkeypatch.setattr(asyncio, "to_thread", forbid_to_thread)
      gw = SqlGatewayService(dsn="postgresql://localhost/test")
      gw.register_procedure("ping", sql="SELECT 1")
      response = await gw.handle("ping", {}, pool=_FakeAsyncPool(rows=[{"?column?": 1}]))
      assert response.status == 200
  ```
