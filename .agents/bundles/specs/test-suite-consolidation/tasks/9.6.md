# 9.6 Enforce branch-coverage floor in pyproject.toml and Makefile

## Objective

Configure `[tool.coverage.run]` (`source = ["vertebra"]`, `branch = true`) and `[tool.coverage.report]` (`fail_under = <measured post-9.3 floor>`) in `pyproject.toml` and update the `coverage` target in `Makefile` so `make coverage` and `make check` fail whenever combined line/branch coverage drops below the established floor (Roadmap requirement **R11** / `C9-R6`).

## Context

- **Confirmed evidence (`R11` / `C9-R6`):**
  - `pyproject.toml:88-90` configures `[tool.pytest.ini_options]` with `testpaths = ["src/py/tests"]`, and has no `[tool.coverage.run]` or `[tool.coverage.report]` sections.
  - `Makefile:189-194` runs `uv run pytest src/py/tests --cov --quiet` without `--cov=vertebra`, `--cov-branch`, or `--cov-fail-under`, so `make coverage` and `make check` (`Makefile:227`) exit 0 regardless of coverage regressions.
- **File overlap note:** Runs after `9.3` (`depends_on: [test-suite-consolidation:9.3, test-suite-consolidation:9.4, test-suite-consolidation:9.5]`), which also edited `pyproject.toml` (`[tool.ruff.lint]` and `[tool.pytest.ini_options]`).
- **Verification strategy justification:** `static_validation` is used because we are configuring and proving a deterministic repository CI gate (`make coverage` / `make check`).

## Steps

- [x] 1. Run `uv run pytest src/py/tests -m "not integration" --cov=vertebra --cov-branch --cov-report=term` to measure the post-`9.3` combined coverage percentage and compare it against the baseline recorded in Task `9.1` `## Notes & Discoveries`. Compute the integer `fail_under` floor as `math.floor(measured_percent)` (never lower than the `9.1` baseline rounded down to the nearest integer).
- [x] 2. In `pyproject.toml` (after `[tool.pytest.ini_options]` at `line 90`), add:
  ```toml

  source = ["vertebra"]

  omit = [
      "src/py/vertebra/**/__main__.py",
  ]

  [tool.coverage.report]
  fail_under = <FLOOR_FROM_STEP_1>
  show_missing = true
  skip_covered = true

  ```

  	@uv run coverage xml >/dev/null 2>&1
