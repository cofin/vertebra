# 1.1 Core JSON-RPC 2.0 dispatcher, cursor pagination, schema builder, and SSE frame codec

## Objective
Create `vertebra.agent` and `vertebra.agent.core` with four foundational modules shared by MCP, A2A, and `AgentRuntime`: `jsonrpc.py` (JSON-RPC 2.0 single and batch envelope parsing, routing, notification suppression, and `-32603` internal error masking), `cursor.py` (opaque URL-safe Base64 offset cursor encoding, validation, and sequence slicing), `schema.py` (`SchemaBuilder`, `Tool`, `ToolCall`, `ToolResult`, `ToolArgumentError`, and `@tool` descriptor deriving JSON Schema 2020-12 and `msgspec.Struct` validators from Python type hints), and `sse.py` (`SseFrame`, `SseReplayBuffer`, and `SseStreamBroker` with `Last-Event-ID` resumption).

## Context
- `src/py/vertebra/framework/mcp/__init__.py:24-174` and `src/py/vertebra/framework/a2a/__init__.py:105-167` currently duplicate partial `handle_jsonrpc` dictionaries that return error objects on JSON-RPC notifications (violating JSON-RPC 2.0), lack batch support, and require manual `input_schema` dictionaries (`MCP-06`).
- `litestar_mcp/core/jsonrpc.py:14-203`, `litestar_mcp/core/_cursor.py:11-25`, `litestar_mcp/core/schema_builder.py:35-432`, and `litestar_mcp/core/tools.py:34-386` establish the reference behavior: notifications (`id is None`) never emit a response frame; uncaught handler exceptions log the traceback server-side and return `-32603` with `{"error": type(exc).__name__}`; `Tool` acts as a method descriptor (`__get__`) that strips context/request/DI parameters by resolved type and validates arguments via a synthesized `msgspec.Struct`.
- All JSON encoding/decoding must use `vertebra.utils.serializers` (`encode_json_bytes`, `decode_json`), and all wire/value objects must be `msgspec.Struct(frozen=True, gc=False)`.
- `behavior_tdd` applies because `vertebra.agent.core` is a new package introducing observable protocol and schema behavior.

## Steps
- [x] 1. Create `src/py/vertebra/agent/core/jsonrpc.py` defining standard error constants (`PARSE_ERROR = -32700`, `INVALID_REQUEST = -32600`, `METHOD_NOT_FOUND = -32601`, `INVALID_PARAMS = -32602`, `INTERNAL_ERROR = -32603`), `JsonRpcError(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, `JsonRpcRequest(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, `JsonRpcResponse(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, `JsonRpcErrorException`, and `JsonRpcRouter`:
  ```python
  class JsonRpcError(msgspec.Struct, frozen=True, gc=False, kw_only=True):
      """JSON-RPC 2.0 error payload."""

      code: int
      message: str
      data: Any = None

      def to_dict(self) -> dict[str, Any]:
          payload: dict[str, Any] = {"code": self.code, "message": self.message}
          if self.data is not None:
              payload["data"] = self.data
          return payload
  ```
  Include `JsonRpcRouter.dispatch(request: JsonRpcRequest, context: Any) -> dict[str, Any] | None` and `JsonRpcRouter.dispatch_payload(raw_bytes: bytes, context: Any) -> bytes | None` supporting both single JSON objects and non-empty JSON batch arrays (executing batch entries concurrently via `anyio.create_task_group` and returning `None` when every entry in a batch is a notification).
- [x] 2. Create `src/py/vertebra/agent/core/cursor.py` defining `CursorPage[T](msgspec.Struct, frozen=True, gc=False, kw_only=True)` with `items: tuple[T, ...]` and `next_cursor: str | None = None`, plus `encode_cursor(offset: int) -> str`, `decode_cursor(cursor: str) -> int` (raising `JsonRpcErrorException(JsonRpcError(code=INVALID_PARAMS, message="Invalid cursor"))` on negative or malformed Base64), and `paginate_sequence[T](items: Sequence[T], cursor: str | None, page_size: int) -> CursorPage[T]`.
- [x] 3. Create `src/py/vertebra/agent/core/schema.py` implementing `SchemaBuilder` (`type_to_json_schema`, `hoist_definitions`, `build_callable_schema`), `ToolCall(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, `ToolResult(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, `ToolArgumentError`, `Tool`, `execute_tool_calls`, and `@tool`:
  - Support `msgspec.Struct` (via `msgspec.json.schema` with `$defs` hoisting), `dataclasses`, `TypedDict`, `enum.Enum`, `Literal`, `Annotated` (extracting description/constraints from `msgspec.Meta` or Litestar `Parameter`), `Union`/`UnionType`, and `Sequence`/`Mapping`/`set`.
  - Strip parameters annotated with `AgentContext`, `Request`, `ASGIConnection`, `FromDishka`, or DI dependency markers from the public JSON Schema and inject them at invocation time inside `Tool.invoke(arguments: dict[str, Any], context: AgentContext | None = None) -> Any`.
  - Convert validation failures from `msgspec.ValidationError` into `ToolArgumentError` carrying the JSON pointer path and expected type.
- [x] 4. Create `src/py/vertebra/agent/core/sse.py` defining `SseFrame(msgspec.Struct, frozen=True, gc=False, kw_only=True, array_like=True)` (`id: str`, `event: str = "message"`, `data: str = ""`, `retry_ms: int | None = None`), `SseReplayBuffer` (bounded ring of recent `(event_id, SseFrame)` entries per session/stream supporting `replay_since(last_event_id: str)`), and `SseStreamBroker` (managing `anyio.create_memory_object_stream` subscriber channels, keepalive ping frames, and deterministic stream cleanup on client disconnect).
- [x] 5. Create `src/py/vertebra/agent/core/__init__.py` re-exporting all public symbols from `jsonrpc`, `cursor`, `schema`, and `sse`, and create `src/py/vertebra/agent/__init__.py` using `vertebra.utils.module_loader.lazy_exports` so subpackages load lazily on attribute access.
- [x] 6. Commit: `feat(agent): add core JSON-RPC router, cursor pagination, schema builder, and SSE codec` (signed), staging the paths in `files`.
