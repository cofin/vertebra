# 1.4 Rust-accelerated JSON-RPC frame classification and schema digest caching in `vertebra-py`

## Objective
Create `src/rs/vertebra-py/src/agent.rs` and register its functions and classes in `src/rs/vertebra-py/src/lib.rs` and `src/py/vertebra/_vertebra.pyi` to expose agentic Rust fastpath bindings: (1) `classify_jsonrpc_frame(payload: &[u8]) -> PyResult<(u8, Option<String>, Option<String>)>` performing zero-copy JSON-RPC envelope classification (frame kind, method name, identifier), and (2) `SchemaDigestCache` providing `compute_schema_digest` and a thread-safe DashMap/RwLock cache of pre-serialized tool and skill JSON Schema bytes with ETag generation.

## Context
- `bridge-and-server-consolidation:4.10` already creates `src/rs/vertebra-py/src/telemetry.rs` (binding `NativeLogSink`/`AsyncLogCore`, `parse_traceparent`, `format_traceparent`, `sanitize_sql`, `NativeJwtGuard`, and `NativeRateLimiter`) and wires `src/py/vertebra/telemetry/{logger,otel,db_propagation}.py`. `src/rs/vertebra-py/src/agent.rs` does not re-bind `AsyncLogCore` or `parse_w3c_traceparent`/`format_w3c_traceparent` or overwrite `src/py/vertebra/telemetry/{logger,otel}.py`.
- High-throughput MCP and A2A servers repeatedly parse and validate incoming JSON-RPC envelopes (`Mcp-Method`, `Mcp-Name` for `tools/call`, `resources/read`, `prompts/get`, `tasks/*`, `skills/get`) and serve `tools/list` / `skills/list` schemas where schema digest caching avoids re-serializing unchanged schemas across worker threads on Python 3.12+ and free-threaded 3.14t.
- `behavior_tdd` applies because new PyO3 classes and functions are added to `_vertebra` and wired into `vertebra.agent.core`.

## Steps
- [ ] 1. Create `src/rs/vertebra-py/src/agent.rs` implementing:
  - `#[pyfunction] pub fn classify_jsonrpc_frame(py: Python<'_>, payload: &[u8]) -> PyResult<(u8, Option<String>, Option<String>)>` classifying the JSON-RPC frame type (single request, batch request, notification, or response) and extracting `(frame_kind, method, id)` without Python object allocation overhead.
  - `#[pyclass(name = "SchemaDigestCache", frozen)] pub struct SchemaDigestCache` using a thread-safe `DashMap<String, (u64, String, Vec<u8>)>` or `RwLock` cache to store `(fnv64_digest, etag, json_bytes)` per tool/skill key with `put(&self, key: &str, json_bytes: &[u8]) -> (u64, String)`, `get_etag(&self, key: &str) -> Option<String>`, `get_bytes<'py>(&self, py: Python<'py>, key: &str) -> Option<Bound<'py, PyBytes>>`, `combined_etag(&self) -> String`, and `compute_schema_digest(bytes: &[u8]) -> u64`.
- [ ] 2. Register `classify_jsonrpc_frame` and `SchemaDigestCache` in `src/rs/vertebra-py/src/lib.rs` and declare their exact signatures in `src/py/vertebra/_vertebra.pyi`.
- [ ] 3. Wire `_vertebra.classify_jsonrpc_frame` and `_vertebra.SchemaDigestCache` into `src/py/vertebra/agent/core/jsonrpc.py` and `src/py/vertebra/agent/core/schema.py` as fastpaths when the native module is available, falling back cleanly to pure-Python implementations when missing.
- [ ] 4. Commit: `feat(py): add Rust JSON-RPC frame classifier and SchemaDigestCache bindings` (signed), staging the paths in `files`.
