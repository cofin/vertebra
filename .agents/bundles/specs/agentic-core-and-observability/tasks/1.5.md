# 1.5 Unit and property tests for JSON-RPC, schema builder, guard inheritance, and telemetry emission

## Objective
Create `src/py/tests/unit/agent/test_core_and_observability.py` with behavior-level unit and property tests proving JSON-RPC 2.0 single and batch framing, notification silence, `-32603` internal error masking, cursor pagination round-trips and tamper rejection, `SchemaBuilder` and `@tool` generation across `msgspec.Struct`, dataclasses, `TypedDict`, `Literal`, `Annotated`, and nested `$defs`, `AgentContext` identity resolution (mTLS, IAP, JWT, ASGI), `GuardChain` ordering and refusal, Rust `_vertebra` `AsyncLogCore`/`W3cTraceContext`/`classify_jsonrpc_frame`/`SchemaDigestCache` bindings, and automatic OpenTelemetry `gen_ai.*` spans, token/cost histograms, and audit events.

## Context
- All tests for `vertebra.agent.core` and `vertebra.agent.observability` belong in the canonical module test file `src/py/tests/unit/agent/test_core_and_observability.py`.
- Tests must assert observable wire outputs, span attributes, histogram values, and refusal exceptions rather than `hasattr`/`callable` checks.
- `behavior_tdd` applies because this suite validates every behavioral contract of Chapter 1 (`C1-R1` through `C1-R5`).

## Steps
- [x] 1. Create `src/py/tests/unit/agent/__init__.py` and `src/py/tests/unit/agent/test_core_and_observability.py` with the following test functions:
  - `test_jsonrpc_single_batch_and_notification_silence`: verifies single call, mixed batch of calls + notifications, all-notification batch returning `None`, malformed JSON returning `-32700`, invalid envelope returning `-32600`, unknown method returning `-32601`, and uncaught `RuntimeError("secret://db")` returning `-32603` with `data == {"error": "RuntimeError"}` and never leaking `"secret://db"` on the wire.
  - `test_cursor_pagination_roundtrip_and_invalid_cursor`: verifies `paginate_sequence` across multiple pages and asserts negative or corrupted cursors raise `JsonRpcErrorException` with code `-32602`.
  - `test_schema_builder_and_tool_descriptor_validation`: verifies `@tool` on standalone functions and controller methods taking nested `msgspec.Struct`, dataclass, `TypedDict`, `Literal`, `Annotated[int, msgspec.Meta(ge=1)]`, and injected `AgentContext`, asserting `$defs` hoisting, stripped `AgentContext` parameter, bound-method invocation via descriptor `__get__`, and `ToolArgumentError` with JSON pointer path on invalid input.
  - `test_sse_replay_buffer_and_stream_broker_resumption`: publishes 5 frames to `SseStreamBroker`, disconnects after frame 2, reconnects with `last_event_id="2"`, and asserts frames 3, 4, and 5 are replayed in order.
  - `test_agent_context_identity_and_guard_chain_inheritance`: tests `AgentContext.from_request` across mTLS, IAP, JWT, and Litestar `ASGIConnection` scopes, and verifies `GuardChain` runs `[app_guard, skill_guard, tool_guard]` in order and aborts before tool execution when any guard raises `PermissionDeniedError`.
  - `test_observability_harness_emits_genai_spans_metrics_and_audit_logs`: runs a parent `span_turn` containing a child `span_model` (recording `GenAiUsage(input_tokens=1200, output_tokens=400, thought_tokens=200, cached_input_tokens=300)`) and a child `span_tool` (plus one failing tool call), then asserts:
    - `span_exporter.drain_spans()` contains 4 spans sharing the root `trace_id` with hierarchical `parent_span_id` links and `gen_ai.*` attributes;
    - `genai_recorder.samples` records accurate token counts, non-zero `usd_cost`, and `duration_histogram("chat")`;
    - `log_sink.drain()` contains 4 valid UTF-8 JSON `AgentAuditEvent` payloads with matching `trace_id` and `span_id`.
  - `test_rust_agent_ffi_classifier_schema_cache_and_async_logger`: exercises `_vertebra.classify_jsonrpc_frame`, `_vertebra.SchemaDigestCache`, `_vertebra.parse_w3c_traceparent`, `_vertebra.format_w3c_traceparent`, and `_vertebra.AsyncLogCore` (`DropOldest` overflow policy and `shutdown` flush).
