# 1.2 Execution context (`AgentContext`, caller identity, cancellation, progress) and guard inheritance

## Objective
Implement `src/py/vertebra/agent/core/context.py` and `src/py/vertebra/agent/core/guards.py` so every MCP tool, prompt, skill, A2A handler, agent turn, and workflow step receives a unified `AgentContext` (with authenticated `CallerIdentity` extracted from mTLS client certificate CN, Bearer JWT claims, `x-forwarded-client-cert` / `x-goog-authenticated-user-email` IAP headers, native `vertebra._vertebra.Request`, or Litestar `ASGIConnection`), cooperative `CancellationToken`, correlated `ProgressReporter`, and hierarchical `GuardChain` enforcement across application, controller/skill, and handler layers.

## Context
- `litestar_mcp/core/context.py:15-150` defines `ToolContext` with `owner_key() -> str | None` (`"<tenant>:<user_id>"`) extracted from Litestar connections, and `litestar_mcp/mcp/service.py:88-120` defines `MCPRequestContext.report_progress(progress, total, message)`.
- Vertebra's Rust HTTP ingress (`src/rs/vertebra-http/src/tls.rs`) extracts mTLS client certificate Subject CN, XFCC (`x-forwarded-client-cert`), and Google Cloud IAP (`x-goog-authenticated-user-email`, `x-goog-iap-jwt-assertion`) headers into the request header map. `AgentContext` must unify both native Vertebra `Request` / ASGI scope headers and Litestar `ASGIConnection` state (`scope["user"]`, `scope["auth"]`) into a single immutable `CallerIdentity(msgspec.Struct, frozen=True, gc=False)`.
- `behavior_tdd` applies because `AgentContext`, `CancellationToken`, `ProgressReporter`, and `GuardChain` introduce new security and execution-lifecycle behavior.

## Steps
- [x] 1. Create `src/py/vertebra/agent/core/context.py` with `CallerIdentity(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, `CancellationToken`, `ProgressReporter`, `AgentContext`, and contextvar helpers `current_agent_context()` / `bind_agent_context(ctx)`:
  ```python
  class CallerIdentity(msgspec.Struct, frozen=True, gc=False, kw_only=True):
      """Normalized caller identity extracted from mTLS, IAP, JWT, or ASGI connection state."""

      user_id: str | None = None
      email: str | None = None
      tenant_id: str = "default"
      roles: tuple[str, ...] = ()
      scopes: tuple[str, ...] = ()
      auth_scheme: Literal["mtls", "iap", "jwt", "connection", "anonymous"] = "anonymous"
      client_cert_subject: str | None = None

      @property
      def is_authenticated(self) -> bool:
          return self.user_id is not None or self.client_cert_subject is not None

      def owner_key(self) -> str | None:
          principal = self.user_id or self.email or self.client_cert_subject
          if principal is None:
              return None
          return f"{self.tenant_id}:{principal}"
  ```
  - Implement `AgentContext.from_request(request_or_connection: Any, *, session_id: str | None = None, turn_id: str | None = None, progress_token: str | int | None = None, progress_callback: Callable[[dict[str, Any]], Awaitable[None]] | None = None) -> AgentContext` inspecting ASGI `scope` (`user`, `auth`, `state`), Litestar `ASGIConnection`, and HTTP headers (`x-vertebra-mtls-subject`, `x-forwarded-client-cert`, `x-goog-authenticated-user-email`, `x-tenant-id`).
  - Implement `CancellationToken` backed by `anyio.Event` with `cancel(reason: str = "")`, `is_cancelled`, `raise_if_cancelled()`, and `wait_cancelled()`.
  - Implement `ProgressReporter.report(progress: float, total: float | None = None, message: str | None = None) -> None` emitting MCP-compliant `notifications/progress` payloads when a `progress_token` is present and no-oping cleanly when absent.
