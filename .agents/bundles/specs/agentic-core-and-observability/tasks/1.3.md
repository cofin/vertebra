# 1.3 End-to-end agentic telemetry harness (`agent/telemetry.py` + `telemetry/genai.py`)

## Objective
Create `src/py/vertebra/telemetry/genai.py` and `src/py/vertebra/agent/telemetry.py` (with compatibility re-export in `src/py/vertebra/agent/observability.py` and extending `src/py/vertebra/telemetry/otel.py`) so every tool call, resource read, prompt render, skill load, MCP/A2A RPC, model generation, agent turn, `SpecTree` node, and `DynamicWorkflow` step automatically emits OpenTelemetry `gen_ai.*` semantic-convention spans into `SpanExporter`, records token/cost/latency histograms in `GenAiRecorder`, propagates W3C `TraceContext` across HTTP headers and JSON-RPC `params._meta["traceparent"]`, and writes structured JSON audit events to `LogSink`.

## Context
- `src/py/vertebra/agent/telemetry.py` (`AgentTelemetryRecorder`) imports `LogSink`, `TraceContext`, `SpanExporter`, and `GenAiRecorder` directly from `vertebra.telemetry` (which already uses `NativeLogSink` and `parse_traceparent`/`format_traceparent` bound from Rust in `bridge-and-server-consolidation:4.10`).
- `src/py/vertebra/telemetry/otel.py:128-168` defines `GenAiMetricSample` and `GenAiRecorder`, but lacks `thought_tokens`, `cached_input_tokens`, cost calculation (`usd_cost`), histogram bucketing (`gen_ai.client.operation.duration`, `gen_ai.client.token.usage`), and operation-specific semantic attributes (`gen_ai.operation.name`, `gen_ai.system`, `gen_ai.request.model`, `gen_ai.agent.name`, `gen_ai.tool.name`, `gen_ai.tool.call.id`, `mcp.method.name`, `mcp.resource.uri`, `mcp.skill.name`, `a2a.task.id`, `a2a.task.state`, `vertebra.workflow.name`, `vertebra.workflow.node`).
- `AgentTelemetryRecorder` (and `AgentObservabilityHarness`) wraps `JsonRpcRouter.dispatch` and `Tool.invoke` automatically so zero manual span boilerplate is needed in user tool functions.
- `behavior_tdd` applies because this task adds new telemetry data structures, cost accounting, trace propagation, and span lifecycle management.

## Steps
- [x] 1. Create `src/py/vertebra/telemetry/genai.py` defining OpenTelemetry `gen_ai.*` semantic attribute constants, `ModelPricing(msgspec.Struct, frozen=True, gc=False, kw_only=True)` (`input_per_million_usd: float`, `output_per_million_usd: float`, `cached_input_per_million_usd: float = 0.0`, `thinking_per_million_usd: float = 0.0`), `CostTable`, `GenAiUsage(msgspec.Struct, frozen=True, gc=False, kw_only=True, array_like=True)` (`input_tokens: int = 0`, `output_tokens: int = 0`, `thought_tokens: int = 0`, `cached_input_tokens: int = 0`), `HistogramSnapshot(msgspec.Struct, frozen=True, gc=False, kw_only=True)`, and `HistogramBucket`:
  ```python
  class GenAiUsage(msgspec.Struct, frozen=True, gc=False, kw_only=True, array_like=True):
      """Token usage breakdown for a single model generation or aggregated turn."""

      input_tokens: int = 0
      output_tokens: int = 0
      thought_tokens: int = 0
      cached_input_tokens: int = 0

      @property
      def total_tokens(self) -> int:
          return self.input_tokens + self.output_tokens + self.thought_tokens
  ```
  Include `extract_w3c_trace_context(headers: Mapping[str, str] | None, rpc_params: Mapping[str, Any] | None) -> TraceContext` and `inject_w3c_trace_context(ctx: TraceContext, headers: dict[str, str] | None = None, rpc_params: dict[str, Any] | None = None) -> None` so W3C `traceparent` flows across both HTTP headers and stdio/JSON-RPC `params._meta["traceparent"]`.
