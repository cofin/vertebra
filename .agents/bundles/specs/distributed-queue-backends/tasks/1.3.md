# 1.3 Distributed cron scheduler, MultiLaneWorkerRunner, LameDuck drain, and OpenTelemetry messaging spans

## Objective
Implement `CronScheduler` (`src/py/vertebra/framework/queues/scheduler.py`) with 5-field cron expression parsing, `zoneinfo.ZoneInfo` timezone evaluation, and lease-based leader election across distributed workers, and create `MultiLaneWorkerRunner` (`src/py/vertebra/server/lanes.py`) wired into `vtb workers run` (`src/py/vertebra/cli/workers.py`) with `LameDuckController` graceful `SIGTERM` drain and OpenTelemetry `messaging.*` spans/metrics recorded via `SpanExporter`.

## Context
- `src/py/vertebra/framework/queues/__init__.py:37-42`: `CronSchedule(expression: str, timezone: str = "UTC")` is declared on `TaskDef` (`:51`), but nothing parses the 5-field cron expression or elects a single leader across a multi-worker deployment to enqueue scheduled ticks without duplicates.
- `src/py/vertebra/server/lanes.py`: worker lanes are consolidated under `src/py/vertebra/server/lanes.py`; keep all worker lane definitions in `src/py/vertebra/server/lanes.py`.
- `src/py/vertebra/cli/workers.py:16-42`: `execute_worker_cli` creates a `WorkerRunner` and waits on an inert `asyncio.Event().wait()` (`:36`) instead of starting lane pull loops and cron scheduling.
- `behavior_tdd` applies because `CronScheduler` and `MultiLaneWorkerRunner` add new distributed scheduling, lame-duck signal draining, and OpenTelemetry `messaging.*` span emission.

## Steps
- [x] 1. Create `src/py/vertebra/framework/queues/scheduler.py` implementing `CronExpression` and `CronScheduler`:
  - `CronExpression(msgspec.Struct, frozen=True, gc=False, kw_only=True)`:
    - `minutes: frozenset[int]` (`0..59`), `hours: frozenset[int]` (`0..23`), `days_of_month: frozenset[int]` (`1..31`), `months: frozenset[int]` (`1..12`), `days_of_week: frozenset[int]` (`0..6`, where `0` or `7` is Sunday in standard cron; normalize `0` to Sunday and `1..6` to Monday..Saturday).
    - `@classmethod def parse(cls, expression: str) -> CronExpression`: supports `*`, `*/step`, `start-end`, `start-end/step`, and comma-separated lists (`1,15,30`), raising `ValueError` on invalid syntax or out-of-range values.
    - `matches(self, dt: datetime) -> bool`: converts `dt` into the target `ZoneInfo(timezone)` and checks membership across all 5 fields.
  - `CronScheduler`:
    - `__init__(self, queue_service: QueueService, *, node_id: str | None = None, lease_key: str = "cron:leader", lease_ttl_seconds: float = 30.0)`: binds to `queue_service`.
    - `async def tick(self, now: datetime | None = None) -> list[TaskEnvelope]`: computes the current minute slot key (`YYYY-MM-DDTHH:MM`), attempts `backend.acquire_lease` (or `renew_lease` if already leader) with `slot=slot_key`. If lease acquisition succeeds and `lease.last_slot != slot_key` (or `acquire_lease` newly claimed the slot), evaluates every registered `TaskDef` with `cron is not None`, enqueues due tasks with `idempotency_key=f"cron:{task_def.name}:{slot_key}"`, and updates the lease slot so a failover leader in the same minute never double-enqueues.
    - `async def run(self, stop_event: asyncio.Event, *, check_interval_seconds: float = 1.0) -> None`: background loop calling `backend.promote_scheduled()` and `self.tick()` until `stop_event.is_set()`.
- [x] 2. Create `src/py/vertebra/server/lanes.py` defining `LaneConfig`, `LaneMetrics`, `MultiLaneWorkerRunner`, and `WorkerRunner = MultiLaneWorkerRunner`:
  - `LaneConfig(msgspec.Struct, frozen=True, gc=False, kw_only=True)`: `queue_name: str`, `concurrency: int = 10`, `drain_timeout_s: float = 30.0`, `lane_kind: TaskLane = "io"`.
  - `LaneMetrics(msgspec.Struct, frozen=True, gc=False, kw_only=True)`: `queue_name: str`, `in_flight: int`, `processed_total: int`, `failed_total: int`, `dlq_total: int`.
  - `MultiLaneWorkerRunner`:
    - Accepts `lanes: Sequence[LaneConfig]`, `queue_service: QueueService | None = None`, `lame_duck: LameDuckController | None = None`, `span_exporter: SpanExporter | None = None`, `scheduler: CronScheduler | None = None`.
    - Preserves `submit`, `stop`, `parse_lanes`, `resolve_job`, and `run_oneshot` in `src/py/vertebra/server/lanes.py` so existing callers and tests in `src/py/tests/unit/extensions/test_worker_lanes.py` continue to work.
    - Adds `async def run(self, *, install_signal_handlers: bool = False) -> None` and `async def process_once(self) -> int`:
      - Installs `SIGTERM`/`SIGINT` handlers (when `install_signal_handlers=True`) that invoke `self.lame_duck.enter_lame_duck()` (`src/py/vertebra/server/platform.py:89-93`) and trigger `await self.stop()`, stopping new dequeues while waiting up to `max(lane.drain_timeout_s)` for in-flight jobs to finish and settle (`ack`/`nack`).
      - Restores parent W3C `TraceContext.parse(envelope.traceparent)` on task execution and records `SpanData` (`name=f"messaging.process {envelope.task_name}"`, attributes `{"messaging.system": backend_scheme, "messaging.destination.name": envelope.lane, "messaging.message.id": envelope.task_id, "messaging.operation": "process", "messaging.worker.lane": envelope.lane, "messaging.message.attempt": envelope.attempt}`) into `self._span_exporter` (`src/py/vertebra/telemetry/otel.py:117-120`).
