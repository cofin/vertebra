# Task 1.2: Implement Sentinel master resolution and Cluster CRC16 hash-slot routing (`MOVED`/`ASK`) in `SyncRedisDriver` and `AsyncRedisDriver`

## Objective

Implement CRC16-XMODEM hash-slot calculation (`crc16_hash_slot(key)` supporting `{hash_tag}` extraction -> `0..16383`), Cluster slot-to-node routing with `MOVED` and `ASK` (`ASKING`) redirection handling, and Sentinel `SENTINEL get-master-addr-by-name <service>` master discovery in `src/rs/vertebra-db/src/resp.rs` and `src/py/vertebra/db/redis.py`.

## Context

- `src/py/vertebra/db/redis.py:191-205`: `RedisConfig` defines `topology: Literal["standalone", "sentinel", "cluster"] = "standalone"`, `sentinel_service_name: str | None = None`, and `cluster_nodes: tuple[str, ...] = ()`, but `SyncRedisDriver` and `AsyncRedisDriver` currently ignore `topology`, `sentinel_service_name`, and `cluster_nodes`.

## Steps

- [ ] 1. Implement `crc16_xmodem` and `redis_hash_slot(key: &[u8]) -> u16` in `src/rs/vertebra-db/src/resp.rs` (extracting `{tag}` when `{` and a non-empty subsequent `}` exist, modulo `16384`) and expose `redis_hash_slot_native` in `vertebra._vertebra`.
- [ ] 2. In `src/py/vertebra/db/redis.py`, add `SyncRedisDriver.hash_slot(key: str | bytes) -> int` and implement Sentinel master resolution (`SENTINEL get-master-addr-by-name <sentinel_service_name>`) when `self._config.topology == "sentinel"`.
- [ ] 3. Implement Cluster slot table and `MOVED <slot> <host>:<port>` / `ASK <slot> <host>:<port>` (sending `ASKING` before replaying the command) retry handling in `SyncRedisDriver` and `AsyncRedisDriver` when `self._config.topology == "cluster"`.
- [ ] 4. Add unit tests in `src/py/tests/unit/db/test_redis_valkey.py` verifying standard CRC16 vectors (`"123456789"` -> `0x31C3`, `"{user:1000}.following"` == `"{user:1000}.followers"`), Sentinel master discovery, and Cluster `MOVED`/`ASK` redirection against loopback mock servers.

## Verification

- **Strategy**: `behavior_tdd` — New observable CRC16 hash-slot calculation, Sentinel discovery, and Cluster `MOVED`/`ASK` routing.
- **Initial Failing Proof**: `SyncRedisDriver.hash_slot("123456789")` fails with `AttributeError: type object 'SyncRedisDriver' has no attribute 'hash_slot'`.

## Acceptance Criteria

- [x] `crit-1`: `SyncRedisDriver.hash_slot` computes RFC/Redis-compliant CRC16-XMODEM modulo 16384 with `{hash_tag}` support.
- [x] `crit-2`: When `topology == "sentinel"`, `SyncRedisDriver` and `AsyncRedisDriver` query `SENTINEL get-master-addr-by-name` to resolve the primary `(host, port)`.
- [x] `crit-3`: When `topology == "cluster"`, `MOVED` updates the slot map and retries on the target node, and `ASK` sends `ASKING` before retrying on the target node.
