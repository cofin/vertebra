# Task 2.1: Wire `SyncPostgresDriver`/`AsyncPostgresDriver`, `SyncMysqlDriver`/`AsyncMysqlDriver`, and `SyncSqliteDriver`/`AsyncSqliteDriver` in `src/py/vertebra/db/` to `vertebra-db` and the SHM broker transport with `ShmRegion` Arrow IPC streaming

## Objective

Implement native Rust execution and shared-memory broker integration for **PostgreSQL** (`tokio-postgres` + `rustls` + `CloudSqlDialer`/`AlloyDbDialer` + `PGCOPY`/`JSONB`), **MySQL** (`mysql_async` with `rustls-tls` + `CloudSqlDialer`), and **SQLite** (`rusqlite` with WAL, `mmap_size`, `busy_timeout`, and multi-reader pool) in `src/rs/vertebra-db` and wire `SyncPostgresDriver`/`AsyncPostgresDriver`, `SyncMysqlDriver`/`AsyncMysqlDriver`, and `SyncSqliteDriver`/`AsyncSqliteDriver` in `src/py/vertebra/db/{postgres,mysql,sqlite}.py` to acquire SHM leases, consult `ShmStatementCache`, and return zero-copy `ShmRegion` Arrow IPC streams (`select_to_arrow`).

## Context

- `src/py/vertebra/db/postgres.py:125-576`: `SyncPostgresDriver` and `AsyncPostgresDriver` currently parse `PGCOPY` and strip `JSONB` headers in Python and do not accept `broker: BrokerTransport | None = None`.
- `src/py/vertebra/db/mysql.py:73-341` and `src/py/vertebra/db/sqlite.py:61-139`: Do not integrate with `ShmBrokerTransport` or `NativeShmCursor` Arrow IPC regions.

## Steps

- [ ] 1. Create `src/rs/vertebra-db/src/postgres.rs`, `src/rs/vertebra-db/src/mysql.rs`, and `src/rs/vertebra-db/src/sqlite.rs` implementing connection pool management, prepared statement caching gated by `PoolerMode`, and SHM ring + `ShmRegion` Arrow IPC result writing.
- [ ] 2. In `src/py/vertebra/db/postgres.py:125-350`, delegate `strip_jsonb_header` and `parse_pgcopy_binary` to `vertebra._vertebra.strip_pg_jsonb_header_native` and `parse_pgcopy_binary_native`, add `broker: BrokerTransport | None = None` to `SyncPostgresDriver` and `AsyncPostgresDriver`, and implement `select_to_arrow(sql, parameters)` backed by `ShmRegion`.
- [ ] 3. In `src/py/vertebra/db/mysql.py:73-341` and `src/py/vertebra/db/sqlite.py:61-139`, add `broker: BrokerTransport | None = None` and `select_to_arrow(sql, parameters)` streaming results through `NativeShmCursor` / `ShmRegion` Arrow IPC when result rows reach `arrow_threshold_rows`.
- [ ] 4. Add unit tests in `src/py/tests/unit/db/test_native_shm_drivers.py` verifying broker lease acquisition, `ShmStatementCache` hits, native `PGCOPY` / `JSONB` decoding, and zero-copy `ShmRegion` Arrow IPC streaming across Postgres, MySQL, and SQLite drivers.

## Verification

- **Strategy**: `behavior_tdd` — New observable behavior (SHM broker leasing and `ShmRegion` Arrow IPC streaming in `Postgres`, `MySQL`, and `SQLite` drivers).
- **Initial Failing Proof**: `SyncSqliteDriver(SqliteConfig(), broker=ShmBrokerTransport()).select_to_arrow("SELECT 1 AS id")` fails with `TypeError: SyncSqliteDriver.__init__() got an unexpected keyword argument 'broker'`.
