# Task 8.8 — Enforce fail-fast binary preflight in `tools/benchmarks/targets.py` and run the full performance gate

## Objective

Replace the silent `["echo", "3.14t server binary not found..."]` fallback in `tools/benchmarks/targets.py` with a deterministic binary path and an explicit preflight validation check (`Target.validate_preflight()`), convert `Target` from `@dataclass` to `msgspec.Struct(frozen=True, gc=False)`, and verify all Chapter 8 performance gates (`TST-08`).

## Context

- In `tools/benchmarks/targets.py:95-100`, `_ft_run(*args: str) -> list[str]` checks `if not os.path.isfile(binary): return ["echo", f"3.14t server binary not found at {binary}"]`.
- Because `ALL_TARGETS["vtb-ft-native-4w"]` (`targets.py:180-195`) calls `_ft_run()` at module import time, importing `tools.benchmarks.targets` before `make bench-ft` builds `src/rs/target-ft/release/vertebra-server` permanently binds `cmd` to `["echo", ...]`, which exits 0 immediately instead of failing fast when selected (`TST-08`).
- `Target` (`targets.py:20-32`) also uses `@dataclass(frozen=True, slots=True)` instead of `msgspec.Struct(..., frozen=True, gc=False)` (Constraint 4).

## Steps

- [x] 1. **RED**: In `src/py/tests/unit/test_bench_infrastructure.py`, add regression tests:
  - `test_ft_target_cmd_never_falls_back_to_echo()`: asserts `ALL_TARGETS["vtb-ft-native-4w"].cmd[0]` ends with `src/rs/target-ft/release/vertebra-server` and is never `"echo"`.
  - `test_target_validate_preflight_raises_when_binary_missing(tmp_path)`: constructs a `Target` whose `cmd[0]` points to a non-existent path under `tmp_path` and asserts `target.validate_preflight()` raises `FileNotFoundError` mentioning the target name and missing binary path.
  - `test_target_is_msgspec_struct()`: asserts `issubclass(Target, msgspec.Struct)`.
  Run `uv run pytest src/py/tests/unit/test_bench_infrastructure.py -q` and confirm failure.
- [x] 2. **GREEN**: In `tools/benchmarks/targets.py`:
  - Replace `@dataclass(frozen=True, slots=True)` on `Target` (`targets.py:20-32`) with `class Target(msgspec.Struct, frozen=True, gc=False):` using `env: dict[str, str] = msgspec.field(default_factory=dict)`.
  - Add `def validate_preflight(self) -> None:` on `Target` that checks `if not (os.path.isfile(self.cmd[0]) or shutil.which(self.cmd[0])): raise FileNotFoundError(f"Benchmark target '{self.name}' executable not found: {self.cmd[0]}")`.
  - Update `_ft_run(*args: str) -> list[str]` (`targets.py:95-100`) to unconditionally return `[_ft_server_binary(), *args]`.
  - Call `target.validate_preflight()` at the start of target execution in `tools/benchmarks/runner.py`.
- [x] 3. **REFACTOR**: Run the full Rust, Python, and Criterion benchmark verification suite to confirm all Chapter 8 optimizations meet their performance gates.
