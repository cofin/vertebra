# Task 8.2 — Add bounded-spin futex/ulock parking to `MpmcRing` blocking operations

## Objective

Replace unbounded `Backoff::snooze()` busy-spinning in `MpmcRing::send`, `MpmcRing::recv`, `MpmcRing::recv_timeout`, and `MpmcRing::recv_timeout_with` in `src/rs/vertebra-core/src/ring/mpmc.rs` with a bounded spin followed by `SeqCst` futex/ulock parking on `ShmHeader.wait_read` / `wait_write` (`CORE-41`).

## Context

- `MpmcRing::initialize` in `src/rs/vertebra-core/src/ring/mpmc.rs` initializes `wait_read`, `wait_write`, `send_waiters`, and `recv_waiters` in `ShmHeader`, but `MpmcRing::send`, `recv`, `recv_timeout`, and `recv_timeout_with` never use them. Instead, they loop forever calling `Backoff::snooze()`, burning 100% CPU core time whenever a worker waits up to `batch_timeout_ms` (`100 ms`) for an incoming batch (`CORE-41`).
- Benchmark harness uses `src/rs/vertebra-core/benches/ring_bench.rs`.

## Steps

- [x] 1. Write a failing regression test and multi-producer/multi-consumer Criterion benchmark first (`regression_tdd`):
  - In `src/rs/vertebra-core/tests/test_mpmc.rs`, add `mpmc_recv_timeout_parks_and_wakes_on_send`: spawn a consumer calling `ring.recv_timeout(&mut out, Duration::from_millis(500))` on an empty `MpmcRing`, sleep `20 ms`, assert `ring.recv_waiters_count() == 1` (proving the consumer transitioned from spinning to parked on `wait_write`), then call `ring.try_send(b"wake", 0)` and assert the consumer wakes within `10 ms` and `recv_waiters_count() == 0`.
  - In `src/rs/vertebra-core/benches/ring_bench.rs`, add a 2-producer × 2-consumer contended benchmark (`mpmc_2p2c_contended`) alongside `mpmc_single_thread`.
- [x] 2. In `src/rs/vertebra-core/src/ring/mpmc.rs`:
  - Add `wait_read_ptr`, `wait_write_ptr`, `send_waiters`, and `recv_waiters` helper methods on `MpmcRing` plus `#[cfg(test)] pub(crate) fn recv_waiters_count(&self) -> u32`.
  - In `MpmcRing::try_send` and `MpmcRing::try_send_with`, after publishing `self.sequence(index).store(tail + 1, Ordering::Release)`, execute:
    ```rust
    self.wait_write_ptr().fetch_add(1, Ordering::SeqCst);
    if self.recv_waiters().load(Ordering::SeqCst) > 0 {
        let _ = platform::wake_one(self.wait_write_ptr());
    }
    ```
  - In `MpmcRing::try_recv`, `try_recv_with_flags`, and `try_recv_with`, after publishing `self.sequence(index).store(head + self.mask + 1, Ordering::Release)`, execute:
    ```rust
    self.wait_read_ptr().fetch_add(1, Ordering::SeqCst);
    if self.send_waiters().load(Ordering::SeqCst) > 0 {
        let _ = platform::wake_one(self.wait_read_ptr());
    }
    ```
  - In `MpmcRing::send`, `recv`, `recv_timeout`, and `recv_timeout_with`, spin with `Backoff::snooze()` while `!backoff.is_completed()`; once `backoff.is_completed()`, increment `send_waiters` / `recv_waiters` with `Ordering::SeqCst`, re-check `has_capacity()` / `has_data()`, and call `platform::wait_on_address` or `platform::wait_on_address_timeout` on `wait_read_ptr()` / `wait_write_ptr()`, decrementing the waiter count on wake or timeout.
  - In `MpmcRing::reset`, also store `0` to `wait_read_ptr`, `wait_write_ptr`, `send_waiters`, and `recv_waiters`.

## Verification

- **Initial failing reproduction (`regression_tdd`)**:
  - Run `cd src/rs && cargo test -p vertebra-core --test test_mpmc mpmc_recv_timeout_parks_and_wakes_on_send` before the fix and confirm `recv_waiters_count()` remains `0` while spinning.
- **Post-fix verification**:
  - `cd src/rs && cargo test -p vertebra-core --test test_mpmc`
  - `cd src/rs && cargo bench -p vertebra-core --bench ring_bench`
- **Performance gate**: `cd src/rs && cargo bench -p vertebra-core --bench ring_bench` — `mpmc_single_thread` $< 150\text{ ns/iter}$ and `mpmc_2p2c_contended` $> 2{,}000{,}000\text{ msgs/s}$ with 0 lost wakeups.

## Acceptance Criteria

- [x] `MpmcRing::try_send`, `try_send_with`, `try_recv`, `try_recv_with_flags`, and `try_recv_with` participate in the `SeqCst` `wait_write`/`wait_read` sleeper/waker handshake (`CORE-41`).
- [x] `MpmcRing::send`, `recv`, `recv_timeout`, and `recv_timeout_with` park via `platform::wait_on_address` / `wait_on_address_timeout` after `Backoff::is_completed()`.
- [x] `mpmc_recv_timeout_parks_and_wakes_on_send` and `benches/ring_bench.rs` pass and meet the performance gate.
