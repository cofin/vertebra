# Task 8.1 — Cache remote `read_head`/`write_head` cursors in `SpscRing` to eliminate cross-core cache-line bounces

## Objective

Cache the last observed remote `read_head` (for the producer) and `write_head` (for the consumer) inside `SpscRing` in `src/rs/vertebra-core/src/ring/spsc.rs` so `try_send`, `try_send_with`, `try_recv_view`, `try_recv`, and `try_recv_with_flags` only reload the remote `ShmHeader` cache line with `Ordering::Acquire` when the locally cached cursor indicates the ring is full or empty (`CORE-10`).

## Context

- In `src/rs/vertebra-core/src/ring/spsc.rs`, `SpscRing::try_send` and `SpscRing::try_send_with` execute `let head = self.read_head().load(Ordering::Acquire);` on every single message, pulling the consumer's `ShmHeader.read_head` cache line across cores even when the producer knows multiple slots remain free.
- Similarly, `try_recv_view`, `try_recv`, and `try_recv_with_flags` execute `let tail = self.write_head().load(Ordering::Acquire);` on every receive even when `head != cached_write_head`.

## Steps

- [x] 1. Record the baseline Criterion numbers:
  - Run `cd src/rs && cargo bench -p vertebra-core --bench ring_throughput` and `cargo bench -p vertebra-core --bench spsc -- spsc_throughput`.
- [x] 2. In `src/rs/vertebra-core/src/ring/spsc.rs`:
  - Add two local atomic cursor caches to `SpscRing`:
    ```rust
    cached_read_head: core::sync::atomic::AtomicU64,
    cached_write_head: core::sync::atomic::AtomicU64,
    ```
    Initialize both to `0` in `SpscRing::from_region` and reset both to `0` in `SpscRing::reset`.
  - Add helper methods on `SpscRing`:
    - `#[inline] fn has_free_slot(&self, next_tail: u64) -> bool`: compares `next_tail != self.cached_read_head.load(Ordering::Relaxed)`; if equal, loads `let actual = self.read_head().load(Ordering::Acquire);`, stores `actual` into `self.cached_read_head` with `Ordering::Relaxed`, and returns `next_tail != actual`.
    - `#[inline] fn has_unread_slot(&self, head: u64) -> bool`: compares `head != self.cached_write_head.load(Ordering::Relaxed)`; if equal, execute `let actual = self.write_head().load(Ordering::Acquire);`, store `actual` into `self.cached_write_head` with `Ordering::Relaxed`, and return `head != actual` (with an `Ordering::Acquire` fence when using the cached fast path so slot payload reads remain ordered after the prior `Acquire` load of `write_head` that populated `cached_write_head`).
  - Update `try_send`, `try_send_with`, `try_recv_view`, `try_recv`, and `try_recv_with_flags` to use `has_free_slot` and `has_unread_slot`.
- [x] 3. Run all existing `SpscRing` unit and proptest suites in `src/rs/vertebra-core/tests/test_ring.rs`.

## Verification

- **Baseline & post-change characterization**:
  - `cd src/rs && cargo test -p vertebra-core`
  - `cd src/rs && cargo bench -p vertebra-core --bench ring_throughput`
  - `cd src/rs && cargo bench -p vertebra-core --bench spsc -- spsc_throughput`
- **Performance gate**: `cd src/rs && cargo bench -p vertebra-core --bench ring_throughput` — `spsc_throughput/ping_pong/256` $> 10{,}000{,}000\text{ ops/s}$ ($< 100\text{ ns/iter}$) and `spsc_burst/fill_drain/256` improves by $\ge 10\%$ over pre-change baseline with zero regression (`< 3%` variance).

## Acceptance Criteria

- [x] `SpscRing` caches `cached_read_head` and `cached_write_head` locally and resets them in `SpscRing::reset` (`CORE-10`).
- [x] `try_send` and `try_send_with` only load `ShmHeader.read_head` when `next == cached_read_head`.
- [x] `try_recv_view`, `try_recv`, and `try_recv_with_flags` only reload `ShmHeader.write_head` when `head == cached_write_head`.
- [x] All unit tests, multi-threaded tests, and proptests in `vertebra-core` pass, and the `ring_throughput` benchmark meets the performance gate.
