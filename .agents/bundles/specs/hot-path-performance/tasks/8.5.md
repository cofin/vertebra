# Task 8.5 — Add direct `submit_response_raw` / `submit_batch_raw` PyO3 fastpath bypassing `Py<Response>` allocation

## Objective

Eliminate per-request `Py<Response>` object allocation on the Python worker hot path when handlers return `bytes`, `str`, or JSON-serializable values (`dict`/`list`/`msgspec.Struct`), submitting raw `(request_id, status, body, headers_raw)` directly into the in-process `BatchBridge` or SHM response ring via `src/rs/vertebra-py/src/transport.rs` and `src/py/vertebra/server/{_dispatch,worker}.py` (`PYB-07`).

## Context

- In `src/py/vertebra/server/_dispatch.py` (`_coerce_response`) and `_dispatch_batch` in `worker.py`, native handler return values (`bytes`, `str`, or JSON-encoded objects) and 404/500 fallbacks can be submitted directly without wrapping in a `vertebra._vertebra.Response` instance.
- Previously, `submit(resp)` called `submit_response`, which borrowed `Py<Response>`, copied fields into `BridgeResponse` (or the SHM response ring), and dropped the Python object (`PYB-07`).

## Steps

- [x] 1. In `src/rs/vertebra-py/src/transport.rs`:
  - Extract the shared Rust submission logic from `submit_response` into an internal helper `submit_raw_inner(py: Python<'_>, request_id: u64, status: u16, headers_raw: Bytes, body: Bytes) -> PyResult<()>` that handles both `WorkerTransport::Shm` and `WorkerTransport::InProcess`.
  - Refactor `submit_response` to delegate to `submit_raw_inner(py, resp.request_id, resp.status, resp.headers_raw.clone(), resp.body.clone())`.
  - Add `#[pyfunction] #[pyo3(signature = (request_id, status, body, headers_raw=None))] pub fn submit_response_raw(py: Python<'_>, request_id: u64, status: u16, body: &[u8], headers_raw: Option<&[u8]>) -> PyResult<()>` that constructs `Bytes::copy_from_slice(body)` and `headers_raw.map(Bytes::copy_from_slice).unwrap_or_default()` and calls `submit_raw_inner`.
  - Add `#[pyfunction] pub fn submit_batch_raw(py: Python<'_>, items: Vec<(u64, u16, Vec<u8>)>) -> PyResult<()>` that submits a batch of `(request_id, status, body)` tuples in a single GIL detach (`py.detach(...)`).
- [x] 2. In `src/rs/vertebra-py/src/lib.rs` and `src/py/vertebra/_vertebra.pyi`:
  - Register `transport::submit_response_raw` and `transport::submit_batch_raw` on the `_vertebra` module and export them in `src/py/vertebra/_vertebra.pyi`.
- [x] 3. In `src/py/vertebra/server/_dispatch.py` and `src/py/vertebra/server/worker.py`:
  - Add `_submit_coerced(raw: Any, request_id: int, vr_cls: Any, submit: Any, submit_raw: Any) -> None`:
    - When `isinstance(raw, bytes)`, call `submit_raw(request_id, 200, raw)`.
    - When `isinstance(raw, str)`, call `submit_raw(request_id, 200, raw.encode("utf-8"))`.
    - When `isinstance(raw, vr_cls)`, set `raw.request_id = request_id` if `raw.request_id == 0` and call `submit(raw)`.
    - Otherwise, call `submit_raw(request_id, 200, encode_json_bytes(raw), _JSON_CONTENT_TYPE_COMPACT)` where `_JSON_CONTENT_TYPE_COMPACT = b"\x0ccontent-type\x10\x00application/json"`.
  - Replace `submit(vr_cls(status=404, body=b"not found", request_id=request.request_id))` and `submit(vr_cls(status=500, body=b"internal server error", request_id=request.request_id))` in `_dispatch_batch` with `submit_raw(request.request_id, 404, b"not found")` and `submit_raw(request.request_id, 500, b"internal server error")`.
- [x] 4. Add unit tests in `src/py/tests/unit/ffi/test_response.py` verifying `submit_response_raw` and `submit_batch_raw` in both raw-body and custom-header modes.

## Verification

- **Baseline & post-change characterization**:
  - `cd src/rs && cargo test --workspace --features tls,compression`
  - `make dev && uv run pytest src/py/tests/unit/ffi/ src/py/tests/unit/server/ -q`
- **Performance gate**: `cd src/rs && cargo bench -p vertebra-http --bench server_throughput -- bridge_dispatch` — `bridge_dispatch/http11_concurrent_1000` $\ge 105{,}000\text{ req/s}$ ($< 9.5\text{ ms}$ per 1,000 requests) with zero `Py<Response>` allocations on `bytes`/`str`/JSON handler returns.

## Acceptance Criteria

- [x] `_submit_coerced` in `src/py/vertebra/server/_dispatch.py` submits `bytes`, `str`, and JSON responses via `submit_response_raw` without instantiating `vertebra._vertebra.Response`.
- [x] 404 and 500 fallback responses in `worker.py` / `_dispatch.py` use `submit_response_raw` directly.
- [x] All Rust and Python unit tests pass.
