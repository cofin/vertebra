# 2.3 SQLAlchemy 2.1 OracleVtbDialect (oracle+vtb) and AlembicImpl DDL migration hooks

## Objective
Wire `OracleVtbDialect` (`oracle+vtb` and `oracle+vertebra`) and `DBAPIConnection` in `src/py/vertebra/extensions/sqlalchemy/dialects.py` to execute through `SyncOracleDriver` with Oracle 26ai `VECTOR(dim, FLOAT32)` and `OSON` `BinaryJson` type descriptors, `RETURNING ... INTO` bulk insert sentinels, and `<=1000` `SelectInLoadSpec` chunking, and extend `AlembicImpl` (`src/py/vertebra/extensions/sqlalchemy/alembic.py`) with `CreateVectorIndexOp`, `DropVectorIndexOp`, `OracleConfig`/`MysqlConfig` migration URL resolution, and live `execute_ddl` migration hooks.

## Context
- `src/py/vertebra/extensions/sqlalchemy/dialects.py:101-150` (`DBAPIConnection`) does not route `oracle+vtb://` URLs to `SyncOracleDriver` (`FW-44`).
- `src/py/vertebra/extensions/sqlalchemy/alembic.py:104-110` (`AlembicImpl.resolve_migration_url`) only accepts `PostgresConfig | str` and cannot resolve `OracleConfig` (Easy Connect / wallet TNS descriptor) or `MysqlConfig` migration URLs, and `alembic.py` has no vector index DDL operation (`CREATE VECTOR INDEX` on Oracle 26ai vs `USING hnsw` on PostgreSQL).
- Note on shared files: `src/py/vertebra/extensions/sqlalchemy/dialects.py` is modified after Task `2.1` (`depends_on: [db-mysql-and-oracle-drivers:2.1, db-mysql-and-oracle-drivers:2.2]`).
- Strategy `behavior_tdd` applies because this task adds `OracleVtbDialect` DBAPI routing, Oracle `RETURNING INTO` compilation, and Alembic vector index DDL operations.

## Steps
- [ ] 1. In `src/py/tests/unit/extensions/test_sqlalchemy.py:146-199`, add failing behavior tests `test_oracle_vtb_dialect_and_alembic_vector_index_ddl` verifying:
  - `DBAPIConnection("oracle+vtb://system:pw@localhost:1521/FREEPDB1", driver=...)` routes `cursor().execute(...)`, `commit()`, `rollback()`, and `close()` through `SyncOracleDriver` with named bind parameters (`paramstyle="named"`).
  - `OracleVtbDialect.compile_insert_returning_sentinel("orders", ("id", "total"), InsertSentinelSpec.create("orders"))` renders Oracle `INSERT INTO orders (id, total) VALUES (:id, :total) RETURNING id, _insert_sentinel INTO :ret_id, :ret__insert_sentinel`.
  - `CreateVectorIndexOp(index_name="idx_items_vec", table_name="items", column_name="embedding", metric="cosine")` renders `CREATE VECTOR INDEX idx_items_vec ON items (embedding) ORGANIZATION INMEMORY NEIGHBOR GRAPH DISTANCE COSINE` for `oracle+vtb` and `CREATE INDEX idx_items_vec ON items USING hnsw (embedding vector_cosine_ops)` for `postgresql+vtb`, and `reverse()` returns `DropVectorIndexOp`.
  - `AlembicImpl.resolve_migration_url(OracleConfig(host="db.internal", port=1521, service_name="FREEPDB1"))` returns `"oracle+vtb://system:@db.internal:1521/FREEPDB1"`.
- [ ] 2. In `src/py/vertebra/extensions/sqlalchemy/dialects.py:101-245`:
  - Import `OracleConfig` and `SyncOracleDriver` from `vertebra.db.oracle`.
  - In `DBAPIConnection.__init__`, instantiate `SyncOracleDriver(self._config)` when `isinstance(self._config, OracleConfig)` and no explicit `driver` was passed.
  - On `OracleVtbDialect`, add `compile_insert_returning_sentinel(cls, table_name: str, columns: Sequence[str], spec: InsertSentinelSpec, *, pk_column: str = "id") -> str` and `type_descriptor(cls, col_type: Any) -> Any` handling Oracle 26ai `Vector` (`array.array`) and `BinaryJson` (`JSON` / `OSON`).
- [ ] 3. In `src/py/vertebra/extensions/sqlalchemy/alembic.py:104-145`:
  - Extend `AlembicImpl.resolve_migration_url(url: PostgresConfig | OracleConfig | MysqlConfig | str) -> str` to resolve `OracleConfig` and `MysqlConfig` into canonical `+vtb` migration URLs.
  - Add `AlembicImpl.execute_ddl(connection: DBAPIConnection, op: CreateViewOp | DropViewOp | CreateVectorIndexOp | DropVectorIndexOp, *, dialect_name: str = "postgresql") -> None` that compiles `op.to_sql(dialect_name)` and executes it on `connection`.
  - Add `CreateVectorIndexOp(msgspec.Struct, frozen=True, gc=False)` and `DropVectorIndexOp(msgspec.Struct, frozen=True, gc=False)` supporting `oracle+vtb` (`CREATE VECTOR INDEX ... ORGANIZATION INMEMORY NEIGHBOR GRAPH DISTANCE <METRIC>`) and `postgresql+vtb` (`CREATE INDEX ... USING hnsw (<col> <ops>)`).
  - Export `CreateVectorIndexOp` and `DropVectorIndexOp` in `src/py/vertebra/extensions/sqlalchemy/alembic.py` and `src/py/vertebra/extensions/sqlalchemy/__init__.py`.
- [ ] 4. Commit: `feat(sqlalchemy): wire OracleVtbDialect and add Alembic vector index DDL hooks` (signed), staging `src/py/vertebra/extensions/sqlalchemy/__init__.py`, `src/py/vertebra/extensions/sqlalchemy/alembic.py`, `src/py/vertebra/extensions/sqlalchemy/dialects.py`, and `src/py/tests/unit/extensions/test_sqlalchemy.py`.
