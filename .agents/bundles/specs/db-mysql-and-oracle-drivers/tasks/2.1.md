# 2.1 Pooled SyncMysqlDriver, AsyncMysqlDriver, and mysql+vtb SQLAlchemy 2.1 dialect

## Objective
Add the `vertebra[mysql]` optional extra (`pymysql>=1.1`, `asyncmy>=0.2.9`) to `pyproject.toml`, implement pooled synchronous (`pymysql`) and asynchronous (`asyncmy`) connection management in `SyncMysqlDriver` and `AsyncMysqlDriver` (`src/py/vertebra/db/mysql.py`) with Cloud SQL `:3307` dialer socket injection, and wire `MysqlVtbDialect` (`mysql+vtb`) and `DBAPIConnection` in `src/py/vertebra/extensions/sqlalchemy/dialects.py`.

## Context
- `src/py/vertebra/db/mysql.py:45-62` (`SyncMysqlDriver.execute_tuples`) ignores `sql` and `parameters` and returns `[]` (`FW-01`).
- `src/py/vertebra/db/mysql.py:64-80` (`AsyncMysqlDriver.execute_tuples`) calls `self._sync.execute_tuples` synchronously without an `asyncmy` pool (`FW-01`).
- `src/py/vertebra/extensions/sqlalchemy/dialects.py:101-150` (`DBAPIConnection`) does not instantiate `SyncMysqlDriver` when `isinstance(self._config, MysqlConfig)` (`FW-44`).
- Strategy `behavior_tdd` applies because this task adds pooled MySQL query execution, transaction control, and `mysql+vtb` DBAPI routing.

## Steps
- [x] 1. In `src/py/tests/unit/data/test_mysql_driver.py`, add failing behavior tests `test_mysql_sync_and_async_driver_pools_and_dialect` verifying:
  - `MysqlConfig.parse_dsn_params()` extracts `host`, `port`, `user`, `password`, `database`, `charset`, and `autocommit` from `mysql://` and `mysql+vtb://` DSNs.
  - `SyncMysqlDriver` acquires connections from a bounded `collections.deque` `pymysql` pool (or injected connection factory), executes `execute_tuples` and `execute_with_description`, supports `commit()`, `rollback()`, and `close()`, and injects a `CloudSqlDialer` TLS socket when `cloud_sql_instance` is set.
  - `AsyncMysqlDriver` delegates `execute_tuples`, `execute_with_description`, and `close` to an `asyncmy` pool (or injected async pool) and raises `MissingDependencyError("asyncmy", extra="mysql")` when `asyncmy` is absent.
  - `DBAPIConnection("mysql+vtb://root:pw@localhost:3306/app", driver=...)` routes cursor execution, `commit()`, `rollback()`, and `close()` through `SyncMysqlDriver`, and `MysqlVtbDialect` compiles MySQL 9.0 `VECTOR(dim)` and `DISTANCE_COSINE` expressions.
- [x] 2. In `pyproject.toml:32-48` (`[project.optional-dependencies]`), add the `mysql` extra:
  ```toml
  mysql = [
      "pymysql>=1.1",
      "asyncmy>=0.2.9",
  ]
  ```
- [x] 3. In `src/py/vertebra/db/mysql.py:19-80`:
  - Add `parse_dsn_params(self) -> dict[str, Any]` on `MysqlConfig` using `urllib.parse.urlparse` to extract `host`, `port` (default `3306`), `user`, `password`, `database`, `charset`, and `autocommit`.
  - Update `SyncMysqlDriver` with `__slots__ = ("_closed", "_config", "_connect_factory", "_dialer", "_idle_conns")` implementing a bounded `collections.deque(maxlen=self._config.max_size)` connection pool over `pymysql.connect` (raising `MissingDependencyError("pymysql", extra="mysql")` when `pymysql` is not installed and no `connect_factory` is supplied), `execute_with_description`, `execute_tuples`, `commit`, `rollback`, and `close`.
  - Update `AsyncMysqlDriver` with `__slots__ = ("_closed", "_config", "_dialer", "_pool")` lazily creating an `asyncmy.create_pool` pool (raising `MissingDependencyError("asyncmy", extra="mysql")` when `asyncmy` is not installed and no `pool` is supplied) and implementing `async def execute_tuples`, `async def execute_with_description`, and `async def close`.
- [x] 4. In `src/py/vertebra/extensions/sqlalchemy/dialects.py:101-254`:
  - Import `MysqlConfig` and `SyncMysqlDriver` from `vertebra.db.mysql`.
  - In `DBAPIConnection.__init__`, instantiate `SyncMysqlDriver(self._config)` when `isinstance(self._config, MysqlConfig)` and no explicit `driver` was passed.
  - On `MysqlVtbDialect`, set `paramstyle = "format"`, `use_insertmanyvalues = True`, `insert_executemany_returning = False`, `supports_native_jsonb = False`, and add `type_descriptor(cls, col_type: Any) -> Any` supporting MySQL 9.0 `Vector` (`VECTOR(dim)`) and `BinaryJson` (`JSON`).
- [x] 5. Commit: `feat(db): implement pooled SyncMysqlDriver, AsyncMysqlDriver, and MysqlVtbDialect` (signed), staging `pyproject.toml`, `src/py/vertebra/db/mysql.py`, `src/py/vertebra/extensions/sqlalchemy/dialects.py`, and `src/py/tests/unit/data/test_mysql_driver.py`.
