# 2.4 Unit and container-backed acceptance tests for MySQL and Oracle drivers, wallets, and +vtb dialects

## Objective
Update `DatabaseRegistry` (`src/py/vertebra/db/_registry.py`) to attach `CloudSqlDialer` to `SyncMysqlDriver` and `AsyncMysqlDriver` when `MysqlConfig.to_cloud_dialer_config()` is non-null, and create the comprehensive MySQL and Oracle integration and negative-state acceptance suite in `src/py/tests/unit/data/test_mysql_driver.py` and `src/py/tests/unit/data/test_oracle_driver.py`.

## Context
- `src/py/vertebra/db/_registry.py:103-129` (`DatabaseRegistry.get_driver` and `get_sync_driver`) creates `AsyncMysqlDriver` / `SyncMysqlDriver` without passing the `CloudSqlDialer` from `MysqlConfig.to_cloud_dialer_config()`.
- Tasks `2.1`, `2.2`, and `2.3` implement the MySQL and Oracle drivers, `OracleWallet` `sqlnet.ora` + PKCS#12-to-PEM conversion, `DBMS_CLOUD` object store staging, `OracleHybridSearch.execute_rrf`, and the `mysql+vtb` and `oracle+vtb` SQLAlchemy/Alembic dialects. This task verifies their full composition and refusal paths (`integration_acceptance`).

## Steps
- [ ] 1. In `src/py/vertebra/db/_registry.py:103-145`, update `get_driver` and `get_sync_driver` so that when `isinstance(config, MysqlConfig)` and `(csql_cfg := config.to_cloud_dialer_config()) is not None`, `CloudSqlDialer(csql_cfg)` is instantiated and passed as `dialer=...` to `AsyncMysqlDriver` and `SyncMysqlDriver`.
- [ ] 2. Create and run tests in `src/py/tests/unit/data/test_mysql_driver.py` and `src/py/tests/unit/data/test_oracle_driver.py` covering end-to-end composition, PKCS#12 wallet conversion, `DBMS_CLOUD` staging, RRF hybrid search, and refusal states:
  - `test_mysql_registry_cloudsql_dialer_and_vtb_dialect_lifecycle`: registers `mysql+vtb://app:pw@127.0.0.1:3306/prod` with `cloud_sql_instance="proj:us-central1:mysql1"` in `DatabaseRegistry`, verifies `CloudSqlDialer` attachment, executes `SELECT`/`INSERT` through `DBAPIConnection("mysql+vtb://...")`, and verifies `MissingDependencyError` refusal when `pymysql` / `asyncmy` is unavailable and no pool is injected.
  - `test_oracle_pkcs12_wallet_extraction_sqlnet_and_mtls_ssl_context`: generates a real RSA-2048 private key, X.509 certificate, and PKCS#12 (`ewallet.p12`) archive via `cryptography.hazmat.primitives.serialization.pkcs12` inside a `Wallet_ATP.zip` along with `tnsnames.ora` and `sqlnet.ora`, extracts it via `OracleWallet.extract`, verifies `_convert_p12_to_pem` writes `0o600` `ewallet.pem` and `build_ssl_context()` loads the certificate chain, and proves zip-slip refusal (`ValueError: Rejected zip member outside target wallet directory`) when a malicious `../../evil.ora` entry is injected.
  - `test_oracle_dbms_cloud_staging_hybrid_rrf_and_arrow_pycapsule`: writes a Parquet/JSONL dataset into `ObjectStore("memory://")`, stages it via `SyncOracleDriver.stage_to_dbms_cloud`, executes `OracleHybridSearch.execute_rrf` and `AsyncOracleDriver.execute_df`, exports the resulting `OracleDataFrame` through `SQLSpecStore.export_arrow_capsule`, and verifies `CreateVectorIndexOp` and `CreateViewOp` execution through `AlembicImpl.execute_ddl` on `oracle+vtb`.
- [ ] 3. Commit: `test(db): add MySQL and Oracle driver, wallet, DBMS_CLOUD, and +vtb dialect acceptance suite` (signed), staging `src/py/vertebra/db/_registry.py`, `src/py/tests/unit/data/test_mysql_driver.py`, and `src/py/tests/unit/data/test_oracle_driver.py`.
